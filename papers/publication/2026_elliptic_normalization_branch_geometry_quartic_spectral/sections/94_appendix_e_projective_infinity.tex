\section{Supplementary projective-infinity check}\label{app:projective-infinity}

This supplementary appendix records a formal large-$y$ consistency check for the same positive branch selected in Theorem~\ref{thm:canonical-branch-dominance}.  It is not used to prove branch selection; the dominance proof is entirely finite-axis algebra.

\begin{lemma}[Fixed-quartic projective-infinity consistency calculation]\label{lem:projective-infinity-consistency}
Let $T:=y^{1/4}$; this auxiliary large parameter is not the elliptic coordinate $\WeierY$ used on the Weierstrass model.
Then the maximal-modulus homogeneous balance of the spectral polynomial at projective infinity is
\begin{equation}\label{eq:infinity-balance}
\Pi_\infty(\lambda,y)
:=
\lambda^4-2y\lambda^2+y^2
=(\lambda^2-y)^2.
\end{equation}
Hence the positive large-\(y\) branch is generated by a double tangency of the sheets $\lambda\sim \pm y^{1/2}$ at infinity.
On the maximal-modulus branch one has
\begin{equation}\label{eq:lambda-high-y}
\lambda_{\mathrm{dom}}(y)
= y^{1/2} + \frac{1}{2}\,y^{1/4} + \frac{1}{4}
+ \frac{7}{64}\,y^{-1/4} + O(y^{-1/2}),
\end{equation}
and the logarithmic branch satisfies
\begin{equation}\label{eq:f-high-y}
f_{\mathrm{dom}}(y)
= \frac{1}{2}\log y + \frac{1}{2}\,y^{-1/4}
+ \frac{1}{8}\,y^{-1/2} + O(y^{-3/4}).
\end{equation}
For this fixed quartic specialization, the exponent $1/4$ describes only the formal local splitting created by the displayed double tangency at infinity.
This is a calculation on the already selected positive branch, not a new branch-selection principle.
No sectorial continuation or uniform large-parameter dominance statement is inferred from this formal expansion.
\end{lemma}

\begin{proof}
Set $y=T^4$ and seek the positive large-\(y\) branch in the form
\[
\lambda=T^2+\alpha T+\beta+\gamma T^{-1}+O(T^{-2}).
\]
Equivalently, on the projective chart $W\neq0$ at the unique point at infinity, this is the local coordinate expansion with $Z/W=y^{-1}=T^{-4}$ and $\Lambda/W=\lambda/y=T^{-2}+O(T^{-3})$.
Thus the computation uses the same normalized branch at the point over \([0:1:0]\) as Lemma~\ref{lem:projective-normalization}; it is not an additional normalization of the singular plane point.
Substituting into $\Pi(\lambda,T^4)$ gives
\begin{align}
\Pi(\lambda,T^4)
&=
T^6(4\alpha^2-1) \notag\\
&\quad
+T^5(4\alpha^3+8\alpha\beta-3\alpha) \notag\\
&\quad
+T^4(\alpha^4+12\alpha^2\beta-3\alpha^2+8\alpha\gamma+4\beta^2-3\beta)
+O(T^3). \label{eq:infinity-expansion}
\end{align}
The leading coefficient $4\alpha^2-1$ is precisely the first-order splitting of the double balance \eqref{eq:infinity-balance}, so the maximal-modulus branch must satisfy $\alpha=1/2$.
The vanishing of the next two coefficients gives $\beta=1/4$ and $\gamma=7/64$.
This proves \eqref{eq:lambda-high-y}.
Equation \eqref{eq:f-high-y} follows by logarithmic expansion.
\end{proof}

For the fixed specialization, the displayed expansion is only the formal projective-infinity continuation of the branch selected earlier on the finite positive axis.
