\section{Reproducible exact certificates}\label{app:reproducibility-note}

All determinant, resultant, Sturm, and endpoint-amplitude calculations used in the proof are finite exact-algebra checks.  A minimal ancillary verifier is included with the source as
\[
\texttt{certificates/verify\_exact\_certificates.py}.
\]
From the paper root it is run by
\[
\texttt{python certificates/verify\_exact\_certificates.py}.
\]
The script uses SymPy with exact rational and algebraic arithmetic only.  Its assertions reproduce the identities listed in Table~\ref{tab:exact-certificates}; a successful run prints \texttt{all exact certificates verified}.  The paper itself keeps only the identities and sign tables needed by the proofs.
