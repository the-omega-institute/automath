\begin{abstract}
We analyze the recurrence polynomials $Z_m(y)$ for the single denominator spectral polynomial
\[
\Pi(\lambda,y)=\lambda^4-\lambda^3-(2y+1)\lambda^2+\lambda+y(y+1).
\]
All results concern this fixed quartic and endpoint windows fixed before the large-$m$ limit.
The prescribed double-root normalization selects the balanced member $P_{-1,-1,1,0}$ and identifies its projective spectral curve with the elliptic model $Y^2=4\lambda^3-4\lambda+1$.
For this fixed canonical member, the normalization gives the finite branch values, the real projection of the two ovals, and the exact real-root count of $\Pi(\cdot,y)$ for every real $y$.
On the positive axis of this canonical specialization, finite algebraic interval criteria identify a unique maximal-modulus branch and distinguish the endpoint collision at $y=0$ from the other real collisions at $y=1$ and $y=y_{\mathrm{sub}}$.
Combining this branch classification with local Puiseux expansions and two-branch estimates on each fixed compact endpoint scale gives the endpoint law: for each fixed $k$,
\[
y_{m,k}
=
-\frac{\pi^2(2k-1)^2}{2m^2}
-\frac{3\pi^2(2k-1)^2}{4m^3}
+O_k(m^{-4})
\]
for each fixed indexed negative zero counted from $0$ leftwards.
Equivalently, the same asymptotic control is uniform on each compact endpoint window fixed before the large-$m$ limit and containing only the corresponding finite set of indexed zeros.
We also record recurrence consequences, including the degree law for $Z_m$ and a forced double zero at $y=-1$.
\end{abstract}
