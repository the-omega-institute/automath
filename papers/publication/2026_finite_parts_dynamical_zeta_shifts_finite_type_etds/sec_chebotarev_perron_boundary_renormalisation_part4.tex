\subsubsection{Examples and obstruction tests}
\label{subsubsec:perron-boundary-examples}

The following examples and tests illustrate the boundary theorem and the
coordinate readout.  The cyclic lift is a finite boundary instance of
\Cref{thm:perron-boundary-determinant-product}, and the Artin-substitution
test is obtained by comparing two coordinate vectors in
\Cref{cor:renormalized-coordinate-readout}.

\begin{remark}[Canonical cyclic-lift boundary]
  \label{cor:canonical-cyclic-lift-boundary}
  Let \(G=\ZZ/q\ZZ\), let every edge have cocycle label \(1\), and let
  \(\chi_j(1)=\omega_q^j\).  Then
  \(A_{\chi_j}=\omega_q^jA\),
  \[
    \Gamma_{\chi_j}=\{\omega_q^j\},\qquad
    s_{\chi_0}=1,\qquad s_{\chi_j}=0\quad(j\ne0),
  \]
  and every congruence class \(C\subset\ZZ/q\ZZ\) has
  \[
    \delta_C=\frac1q .
  \]
  Consequently the canonical cyclic lift is a genuine Perron-boundary case
  of \Cref{thm:perron-boundary-determinant-product}: its constants are obtained
  from the \(q\) root-of-unity reduced determinant layers
  \[
    \mathcal B_{\chi_j}^{\mathrm{ren}}
    =
    \operatorname*{Abel\,FP}_{t\uparrow1}
      \Log\det(I-t\omega_q^j\lambda^{-1}A)^{-1},
    \qquad 0\le j<q,
  \]
  together with the ordinary \(k\ge2\) interior determinant logarithms in
  \eqref{eq:renormalized-fixed-label-determinant}.
\end{remark}

\begin{proof}
  Since every edge label is \(1\in\ZZ/q\ZZ\), twisting by \(\chi_j\)
  multiplies every edge weight by \(\omega_q^j\), hence
  \(A_{\chi_j}=\omega_q^jA\).  The primitive base matrix \(A\) has the
  single peripheral eigenvalue \(\lambda\), so \(A_{\chi_j}\) has the
  single peripheral eigenvalue \(\lambda\omega_q^j\).  This proves the
  displayed \(\Gamma\)-sets and the values of \(s_{\chi_j}\).  The
  character expansion for a singleton class in the abelian group gives
  \(|C|/|G|=1/q\) and only \(\chi_0\) contributes to the sum defining
  \(\delta_C\); hence \(\delta_C=1/q\).  The determinant-layer statement is
  now exactly the \(k=1\) part of
  \Cref{prop:renormalized-fixed-label-determinant-component}; all \(k\ge2\) terms lie
  inside the Perron disc and are unchanged.
\end{proof}

\begin{remark}[Corollary D, Artin obstruction component]
  \label{thm:renormalized-artin-obstruction}
  Under the Perron-boundary algebraic multiplicity data above, define
  \[
    \mathcal L_\varrho^{\mathrm{ren}}
    :=
    \lim_{t\uparrow1}
      \left(\mathcal L_\varrho(t\lambda^{-1})
      +s_\varrho\log(1-t)\right),
  \]
  using the same reduced finite-part convention as in
  \Cref{prop:renormalized-fixed-label-determinant-component}.  Let
  \(K_C^{\mathrm{Art,ren}}\) be the constants obtained from
  \eqref{eq:renormalized-frobenius-product-constant} after replacing
  every \(F_\varrho^{\mathrm{ren}}\) by
  \(\mathcal L_\varrho^{\mathrm{ren}}\).  Then
  \[
    \log\frac{K_C^{\mathrm{ren}}}{K_C^{\mathrm{Art,ren}}}
    =
    -\frac{|C|}{|G|}
      \sum_{\varrho\in\Irr(G)}
        \chi_\varrho^\ast(C)
        \left(F_\varrho^{\mathrm{ren}}
        -\mathcal L_\varrho^{\mathrm{ren}}\right).
  \]
  Hence the Artin-substituted constants agree with the fixed-label
  constants for every conjugacy class if and only if all non-trivial
  renormalized Peter--Weyl discrepancies vanish:
  \[
    F_\varrho^{\mathrm{ren}}
    =
    \mathcal L_\varrho^{\mathrm{ren}}
    \qquad(\varrho\ne\mathbf1).
  \]
\end{remark}

\begin{proof}
  The logarithmic ratio is obtained by subtracting the two defining
  logarithms.  The scalar \(s_\varrho\gamma\) terms are identical in the two
  constants, so only the displayed discrepancy vector remains.  If all
  non-trivial discrepancies vanish, the two constants are plainly equal for
  all classes.  Conversely, equality for all classes says that the class
  function
  \[
    C\longmapsto
    \sum_{\varrho\in\Irr(G)}
      \chi_\varrho^\ast(C)
      (F_\varrho^{\mathrm{ren}}
      -\mathcal L_\varrho^{\mathrm{ren}})
  \]
  vanishes.  The trivial coordinate is fixed by the common scalar
  normalization, and the irreducible characters are an orthonormal basis of
  class functions.  Therefore every non-trivial Fourier coefficient of this
  class function is zero, which is exactly the stated vanishing of the
  renormalized discrepancies.
\end{proof}
