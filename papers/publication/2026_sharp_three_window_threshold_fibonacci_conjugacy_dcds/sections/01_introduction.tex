\section{Introduction}\label{sec:intro}

Finite-window factor codes can collapse individual words and nevertheless
become invertible when successive windows overlap.  For recodings generated
by Pisot numeration, we ask how much future output is required by an inverse
with memory zero.  Our principal result is an effective aperture-linear bound
for every fixed strictly increasing Pisot linear numeration system, with no
Condition~F or zero-preservation assumption.  A single fixed cubic system
attains the linear growth order.

Fix a greedy numeration language and let $u_m$ be the number of its legal
words of length $m$.  Order those words colexicographically and identify them
with $\{0,\ldots,u_m-1\}$.  Evaluate the same positional rank on the full
digit cube, reduce it modulo $u_m$, return the legal word with that residue,
and overlap the resulting windows along the shift.  We call the resulting
sliding code a \emph{cyclic language-rank recoding}.  The positional rank is
established numeration theory
\cite{BertrandMathis1989,BruyereHansel1997,LecomteRigo2001,
CharlierCisterninoStipulanti2022}; cyclic reduction at a fixed length is the
map-specific operation studied here.

After relabeling each output word by its rank, the local rule is the modular
weighted sliding block code
\[
(x_0,\ldots,x_{m-1})\longmapsto
\sum_{j=0}^{m-1}u_jx_j\pmod {u_m}.
\]
The relabeling is symbolwise bijective.  The rule is not a linear cellular
automaton, because its input alphabet is only the digit subset of
$\mathbb Z/u_m\mathbb Z$, not a module on which the rule is a group
endomorphism.  Likewise, $\ell_{\rm cau}-1$ is exactly the least anticipation
of an inverse sliding block code constrained to have memory zero.  This is a
standard invariant under that convention, not a right-closing delay or a
general closing constant.

\medskip
\noindent\textbf{The fixed-system theorem and sharpness.}
Let $U=(u_j)$ be any strictly increasing Pisot numeration system with
$u_0=1$, canonical greedy digit set, and canonical normal words.  Theorem
\ref{thm:pisot-linear-depth-sharpness}, stated and proved immediately after
this introduction, gives an effectively computable $C_U<\infty$ such that
\[
\Phi_{U,m}\text{ injective}\quad\Longrightarrow\quad
\ell_{\rm cau}(U,m)\le C_Um. \tag{A1}
\]
Every row carry is bounded directly by the recurrence growth constants.  A
finite algebraic separation and the contracting conjugates then collapse
adjacent carries beyond an effective aperture.  The finitely many smaller
apertures are handled by exact acyclic longest-path searches.  Thus the proof
does not use Condition~F, zero preservation, or a bounded-zero automaton, and
it avoids the generic exponential vertex count $(2d_U+1)^{m-1}$.

The same theorem fixes the binary cubic system associated with the leading
root $\theta$ of $x^3-2x^2+x-1$ and proves, for every $m\ge4$,
\[
\Phi_{\theta,m}\text{ is injective},\qquad
\ell_{\rm cau}(\theta,m)=2\lfloor m/2\rfloor-1. \tag{A2}
\]
More precisely, the penultimate obstruction set is exactly
$\{E_m,-E_m\}$ and the next obstruction set is empty.  This is the signed
terminal classification in \textup{(A3)}.  Consequently no theorem valid for
every fixed system in the class of \textup{(A1)} can replace $O_U(m)$ by
$o(m)$.  This is sharpness in growth order; it does not assert that the
computed $C_U$ is numerically optimal or that coefficient one is universal.
To the authors' knowledge, this is the first aperture-linear inverse-depth
bound for cyclic language-rank recodings over fixed Pisot numeration systems.

Theorem~\ref{thm:bounded-zero-linear-transient} then frees the contraction
from the code's canonical difference alphabet.  For an arbitrary fixed
$D\ge1$, it treats the finite overlap graph whose edges are bounded
$U$-representations of zero with coefficients in $[-D,D]$ and a uniformly
bounded terminal quotient coefficient.  Either a first-coordinate-nonzero
state reaches a directed cycle, or every path from such a state has fewer
than $C(U,D)m$ edges.  This is a quantitative finite-state theorem about the
standard zero-representation relation itself.  Its statement uses no
canonical rank, legal-word alphabet, cyclic reduction, digit-difference
realization, image shift, or inverse decoder.  The fixed cubic words from
\textup{(A3)}, read only as coefficient paths, show that the linear order is
sharp already for $D=1$.

The adjective ``standard'' is avoided here because it normally specifies the
initial conditions $u_{-1}=\cdots=u_{-d+1}=0$, $u_0=1$.  We allow
nonstandard initial values.  Some iconic systems with standard initial
conditions begin $1,1,\ldots$ and enter the strictly increasing class only
after the familiar shift to $1,2,\ldots$.  Condition~F would also be a real
restriction: the principal root of $x^3-3x^2+2x-1$ is Pisot without
Condition~F \cite[Theorem~3]{Akiyama2000}.

The construction must be separated from numerical $\beta$-normalization.
Our congruences compare integer language ranks, not values in
$\mathbb Z[\beta]$.  For example, if $\beta^2-3\beta+1=0$, then
$(Q_0,Q_1,Q_2)=(1,3,8)$ and the rank of $(2,2)$ is $8$, so its cyclic image
is $(0,0)$; no equality $2+2\beta=0$ is asserted.  The theorem is about this
cyclic language-rank recoding, not numerical $\beta$-normalization in general,
arbitrary $\beta$-transformations, or all Pisot symbolic dynamics.

\medskip
\noindent\textbf{Priority comparison.}
The closest precedents do not subsume \textup{(A1)} for distinct quantitative
reasons.  Frougny's finite-automaton normalization and addition results and
the Berend--Frougny characterization establish finite-state computability in
Pisot bases, not an aperture-linear optimal inverse window for a prescribed
cyclic rank map \cite{Frougny1992,BerendFrougny1994}.  Regularity of bounded
zero-representation automata is classical, including for Pisot systems
without Condition~F, but regularity alone does not bound the survival time of
one-position overlap chains by $C(U,D)m$
\cite{Frougny1992,CartonSudberyYassawi2026}.  Carton--Sudbery--Yassawi's
equivalence of zero preservation and Condition~F is the closest
methodological precedent: it uses Pisot contraction on shifted bounded zero
representations, but has no cyclic rank map, collision graph, future-only
inverse, or $O(m)$ survival-depth theorem
\cite{CartonSudberyYassawi2026}.  Ashley's linear-bound papers are the most
likely source of a mistaken priority objection: their bounds concern
encoders into constrained systems and are linear in the number of states of
a presenting graph (with the relevant memory and anticipation parameters),
whereas the natural pair/difference presentations here have exponentially
many aperture-$m$ states; a state-count-linear theorem would therefore still
be exponential in $m$ \cite{Ashley1988,Ashley1996}.  The
Frougny--Sakarovitch bounded-delay theorem converts a rational relation already
known to have bounded delay into a synchronized, letter-to-letter form; it
does not deduce $O(m)$ delay from injectivity
\cite{FrougnySakarovitch1991}.  Finally, classical pair and fiber graphs give
reachable-cycle injectivity tests and finite inverse windows, but their
generic difference-state count is $(2d_U+1)^{m-1}-1$, not the new
aperture-linear estimate
\cite{AmorosoPatt1972,Richardson1972,Nasu1977,Head1989,LindMarcus1995,
Nasu1995}.  These precedents supply the automata and collision frameworks;
none gives the quantitative implication \textup{(A1)}.

\medskip
\noindent\textbf{Quadratic and simple-Parry results.}
For every quadratic Pisot base, Theorem
\ref{thm:full-quadratic-pisot-threshold} classifies the least nontrivial
aperture $m_*(\beta)$:
\[
m_*(\beta)=3
\quad\Longleftrightarrow\quad
\operatorname{minpoly}(\beta)\in
\{x^2-ax-a:a\ge1\}\cup\{x^2-ax+1:a\ge3\},
\]
and $m_*(\beta)=2$ otherwise.  At and above threshold, finite-block
injectivity begins at length $m$, the natural overlap presentation is the
right Fischer cover with $(\lfloor\beta\rfloor+1)^{m-1}$ states, and the
image is exactly $m$-step, not $(m-1)$-step.  These are exact conclusions for
the cyclic rank map, using standard Fischer--Krieger theory only as the
presentation framework \cite{Fischer1975,Krieger1984,LindMarcus1995}.

For arbitrary nonintegral simple-Parry bases, without a Pisot hypothesis,
Theorem~\ref{thm:simple-parry-causal-collision} quotients the classical pair
graph by coordinatewise differences and obtains an exact longest-path formula
for $\ell_{\rm cau}$.  The unique predecessor of the zero state upgrades the
injective case to a future-only inverse.  Applied to Bassino's cubic
simple-Parry Pisot family \cite{Bassino2002}, this gives injective apertures
$m_n=n-1$ with exact depth $n-1$, a complementary varying-system
unboundedness calculation.

The paper is organized with the structural result first.  Section
\ref{sec:pisot-linear-depth} proves \textup{(A1)}--\textup{(A3)} and the
arbitrary-alphabet bounded-zero theorem.  Sections
\ref{sec:stabilization}--\ref{sec:metallic-cover} develop the Fibonacci and
metallic prototypes.  Section~\ref{sec:quadratic-pisot-extension} proves the
quadratic classification and exact local structure.  Section
\ref{sec:simple-parry-causal-obstructions} develops the arithmetic difference
quotient and the cubic varying-system theorem.  Supplementary material holds
the entropy, Blackwell, pressure, fiber, discrepancy, and geometric
consequences, none of which enters the parameter-uniform proof.
