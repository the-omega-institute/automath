\section*{Data availability statement}

No external data sets were used. The finite-range table values are exact
enumerations obtained from the definitions stated in the paper.  The metallic
threshold verification script and its saved output are supplied as
\url{artifacts/verify_metallic_threshold.py} and
\url{artifacts/metallic_threshold_verification.txt}.  The full
quadratic-Pisot verifier, regression tests and saved output are
\url{artifacts/verify_quadratic_pisot_threshold.py},
\url{artifacts/test_quadratic_pisot_threshold.py} and
\url{artifacts/quadratic_pisot_threshold_verification.txt}.  The documented
literature/API audit is \url{artifacts/literature_check.md}.
