\begin{abstract}
Large formal-mathematics projects increasingly use AI agents for drafting,
review, theorem search, and manuscript preparation.  Ungated agent output,
however, can create theorem-looking but content-poor edits, stale source
references, duplicated submission routes, and premature paper promotion.  We
present an auditable theory-to-paper pipeline used around a Lean-backed BEDC
source workspace and an automath publication workspace.  The central rule is
that AI output is advisory: load-bearing mathematical and submission claims must
pass deterministic gates before they can be recorded as accepted work.
\end{abstract}

\paragraph{Safety interface.}
The long technical record \path{main.tex} states the publication-safety theorem:
if a theory-to-paper pipeline (1) treats AI-generated text, schedules, and review
packets only as advisory proposals, (2) assigns each load-bearing claim to the
appropriate deterministic gates, (3) accepts a claim only after those gates pass,
and (4) records demotion rather than promotion when evidence is insufficient,
then accepted manuscript claims are traceable to their source or artifact
surfaces and unsupported agent output cannot become publication evidence merely
by being written into the paper.  The imported theorem spine is pinned to
the public newmath repository
\url{https://github.com/the-omega-institute/newmath} at source commit
\path{3fb3d6a0641767388a401883062aa522ea0b397b}, specifically file
\path{papers/bedc/parts/visions/audit_map_methodology/automated_theory_discovery_pipeline_calculus.tex}.

\paragraph{Deterministic gates.}
The pipeline separates source development, intake packets, active paper tracks,
AI review loops, deterministic gates, and human promotion decisions.  The gate
interfaces include source builds and axiom checks, source-map and marker audits,
anti-hollow theorem-content linting, overlap/submitted blocking, publication
state checks, and submission-pack checks.  Passing one gate does not replace a
different gate: for example, compilation does not prove theorem growth, and a
human promotion marker does not resolve route overlap.

\paragraph{Evidence boundary and artifacts.}
This presentation submission uses path-verified source architecture and
historical case evidence.  It does not claim a fresh rebuild of the full newmath
source tree, a fresh publication-daemon run, or a fresh Rule110 dynamic artifact
rerun.  Any later command-run claim must record the source commit, environment,
command, exit code, and log path.  The review interface consists of the public
newmath repository at the pinned commit together with supplemental upload of
\path{review_bundle/} and \path{main.tex}.  The repository is the public source
link for the imported theorem spine; the bundle gives the extracted interface
record and case-evidence manifest used by this presentation-only submission.
