# Supplemental Review Bundle

This bundle is the supplemental reviewer-facing interface for evidence that is
local or historical in the short presentation draft.  The public source
repository for the imported BEDC theorem spine is
`https://github.com/the-omega-institute/newmath` at commit
`3fb3d6a0641767388a401883062aa522ea0b397b`.

## Evidence Level

- The bundle provides a pinned source snapshot and path-verified case-evidence manifest.
- It does not claim a fresh rebuild of the full newmath source tree.
- It does not claim a fresh Rule110 dynamic artifact rerun.

## Contents

- `source_snapshots/automated_theory_discovery_pipeline_calculus_3fb3d6a0641767388a401883062aa522ea0b397b.tex`: copied source-interface snapshot for the imported discovery-gate labels.
- `../source_interface_record.json`: line-range and label interface record used by the manuscript.
- `REVIEW_BUNDLE_MANIFEST.json`: public/supplemental artifact mapping for source snapshot and four case studies.

## Submission Rule

Upload this directory, or an archive generated from it, as supplemental material
with the presentation-only submission.  Cite the public `newmath` repository as
the source link for the imported theorem spine; use this bundle for extracted
line-range records, case-evidence manifests, and submission-local provenance.
If a DOI or institutional archive is assigned before submission, record it in
`REVIEW_BUNDLE_MANIFEST.json`, `references.bib`, and the manuscript bibliography
entry.
