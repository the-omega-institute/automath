\section{Introduction}

Let an irrational rotation by \(\alpha\) be coded with a half-open interval
of length \(\beta\).  At each length \(m\), this gives a finite language of
binary words.  We apply a simple arithmetic normalization to those words:
take the Fibonacci value of the word, replace it by its Zeckendorf
representation, and keep the first \(m\) digits.  The output has no adjacent
ones and therefore belongs to the length-\(m\) language of the golden-mean
shift.

The question in this note is only whether that normalization creates
collisions on the words realized by the rotation.  It has a sharp answer.
Write
\[
\delta(\alpha):=\|\alpha\|=\min\{\alpha,1-\alpha\}.
\]
The fold is injective on every realized block language if and only if
\[
\beta\in(0,\delta(\alpha)]\cup[1-\delta(\alpha),1).
\]
In fact, the all-length assertion is equivalent to injectivity at length
two.  In the complementary range, both \(00\) and \(11\) occur with positive
frequency and have the same folded image.

There are two equally elementary ingredients.  First, two equal-length
circle intervals whose initial points differ by \(\alpha\) overlap in
positive measure exactly when their length exceeds \(\delta(\alpha)\).
This decides whether \(11\) occurs; applying the same observation to the
complementary interval decides whether \(00\) occurs.  Second, the folded
image of a word is determined by its Fibonacci value modulo \(F_{m+2}\).
We state this residue characterization explicitly and early in
Proposition~\ref{prop:fold-residue-characterization}.  It is Proposition
2.6 of the longer manuscript from which this note was extracted.

The sparse case \(\beta\leq\delta(\alpha)\) needs no arithmetic: no realized
word has adjacent ones, so the normalization fixes the language pointwise.
In the dense case \(\beta\geq1-\delta(\alpha)\), the complement of each
realized word has no adjacent ones.  Comparing the Fibonacci values of
these complements and using the residue characterization proves
injectivity.  Nothing stronger is being asserted: the result is a
classification for this particular finite normalization on interval-coded
rotation languages, not a general rigidity theorem for dynamical systems.

Zeckendorf's theorem supplies the unique nonconsecutive Fibonacci expansion
\cite{Zeckendorf1972}; Fibonacci representations and their finite-state
normalization have a broader literature, for example
\cite{Frougny1991FibonacciFiniteAutomata}.  The boundary coding
\(\beta=\alpha\) is Sturmian, in the classical terminology of
\cite{MorseHedlund1940}.  Our observation is that this familiar coding sits
exactly on the collision-free boundary for the Fibonacci fold.

Section~\ref{sec:fold} defines the map and proves the residue
characterization.  Section~\ref{sec:classification} proves the two-letter
criterion, records the Sturmian consequence, and gives one example of the
three window regimes.
