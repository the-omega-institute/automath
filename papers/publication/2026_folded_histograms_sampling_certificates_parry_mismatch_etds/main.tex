\begin{abstract}
Assign the Fibonacci weights \(F_2,\ldots,F_{m+1}\) to a binary word,
write its value in Zeckendorf form, and retain the first \(m\) digits.
This defines a map from binary words to the length-\(m\) golden-mean
language.  We determine exactly when this map is injective on every block
language obtained by coding an irrational rotation with an interval of
length \(\beta\).  If \(\delta=\min\{\alpha,1-\alpha\}\), injectivity at
every length holds precisely when
\(\beta\leq\delta\) or \(\beta\geq1-\delta\); in the remaining range it
already fails at length two.  The proof is the combination of an interval
overlap test and an elementary congruence for Fibonacci values.  As a
boundary case, the fold is injective on every Sturmian block language.
\end{abstract}
