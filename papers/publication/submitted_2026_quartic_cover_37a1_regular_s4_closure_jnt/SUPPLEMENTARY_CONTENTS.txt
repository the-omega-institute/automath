R2 submission package contents for JNT

Included in or used to assemble the R2 submission:
- revised_main_flattened.tex: self-contained manuscript source with an inlined
  thebibliography of 22 entries; no .bib or .bbl file is needed to compile it.
- revised_main_flattened.pdf: 37-page manuscript PDF built from
  revised_main_flattened.tex with latexmk -xelatex.
- response_to_referee_r2.tex and response_to_referee_r2.pdf: R2 response source
  and 4-page response PDF.
- highlights.txt: five highlights bullets.
- revised_REPRODUCIBILITY.md: reproducibility note.
- revised_exp_branch_cubic_arithmetic_audit.py
- revised_exp_branch_cubic_rayclass_modform_audit.py
- revised_exp_genus2_jacobian_audit.py
- revised_exp_prym_q_analysis.py
- revised_generate_Q_traces_table.py
- revised_prym_traces_table.tex: generated trace-table output.
- revised_references.bib: reference copy; it is not required to build the
  submitted flattened manuscript.
- editorial_manager_abstract.txt and editorial_manager_submission_text.txt:
  sources for the Editorial Manager text fields.
- SUPPLEMENTARY_CONTENTS.txt and revised_build_note.txt: package and build notes.

Excluded from the R2 upload:
- response_to_referee.tex and response_to_referee.pdf are the R1 response,
  retained only as a record.
- artifacts/export/ contains the regenerable audit outputs
  branch_cubic_arithmetic_audit.json,
  branch_cubic_rayclass_modform_audit.json, genus2_jacobian_audit.json, and
  prym_q_analysis.json, whose SHA-256 values are recorded in
  revised_REPRODUCIBILITY.md.
- LaTeX build byproducts are not uploaded.

The source tree holds a single copy of the manuscript. Earlier modular and
mirrored copies of the same text, and the R0-family scripts, were removed; they
remain in the repository history.
