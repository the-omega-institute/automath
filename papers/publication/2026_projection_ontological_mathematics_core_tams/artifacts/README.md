# Arithmetic Archive Status

This directory separates exact reproducible checks from the upstream claim
that the displayed polynomials are the all-(m) minimal recurrences of the
collision-moment sequences.

## Included

- `generate_sequence_data.py` computes (S_q(m)), (9\le q\le17), directly
  from the residue-count definition for (0\le m\le26). It verifies every
  displayed recurrence on the available independent data and records exact
  Hankel ranks and determinants.
- `sequence_data_q9_17.json` is the generated exact sequence data and the
  finite-window recurrence/minimality checks.
- `verify_polynomial_certificates.py` verifies the 27 modular factorization
  patterns, exact discriminants, Legendre-symbol table, and rank-four
  squareclass fingerprint for the displayed polynomials.
- `polynomial_certificates_q9_17.json` records the exact modular factors and
  discriminant computations produced by that verifier.
- `verify_secondary_spectrum.py` verifies the rational real-root intervals and
  strict modulus separation for every other real and nonreal root.

The files `oracle_*.md` are read-only referee evidence and are not generated by
the archive scripts.

## Still Missing

1. A derivation proving that each displayed recurrence holds for every
   (m\ge m_0(q)), rather than only on the independently generated window
   through (m=26).
2. A full minimality certificate tied to that all-(m) derivation. The exact
   Hankel determinants exclude lower order for any recurrence agreeing with
   the recorded initial data, but do not prove the displayed recurrence
   continues indefinitely.
3. The original raw recurrence-search and Hankel basis-change exports used to
   produce the manuscript's Smith-normal-form table.
4. A checked-in explicit collision matrix or equivalent rational generating
   function for each (q=9,\ldots,17) from which the recurrence identity can
   be verified symbolically.

The modular factorization, discriminant, squareclass, and root-separation
certificates for the displayed polynomials are reproducible here. The missing
items are exactly the bridge from those polynomials to the actual infinite
sequences (S_q(m)); therefore the manuscript keeps that bridge conditional.

## Reproduction

Use Python 3 with NumPy and SymPy installed. From this directory run:

```powershell
python generate_sequence_data.py
python verify_polynomial_certificates.py
python verify_secondary_spectrum.py
```

Each command exits nonzero on a failed assertion. The first two commands
rewrite only their named JSON outputs and print SHA-256 hashes for comparison.
