\begin{abstract}
Let \(U\) be a strictly increasing, eventually linearly recurrent sequence
of positive place values with a finite canonical digit language. Every
infinite multiple context-free sublanguage contains an injective
synchronized orbit whose values return modulo each integer coprime to the
trailing recurrence coefficient. These returns give prime-support and
scatteredness obstructions, including MCF-immunity of the prime and
bounded-\(\Omega\) representation languages. For the intrinsic minimal
tail recurrence, bounded prime support occurs on an infinite
multiple context-free sublanguage if and only if the canonical language
contains a synchronized ray with values \(cb^t\), where \(c\ge1\) and
\(b\ge2\). In a standard greedy system whose minimal tail polynomial is
the minimal polynomial of a weak Perron number \(\beta\), this is equivalent
to integrality of some positive power of \(\beta\). Finally, a finite
paired-loop cover converts slender context-free representations into
recurrence sequences: Mignotte's common-value theorem then implies that a
set represented by slender context-free languages in two multiplicatively
independent weak-Perron systems is finite. Complete effective presentations
also yield a computable cardinality bound.
\end{abstract}
