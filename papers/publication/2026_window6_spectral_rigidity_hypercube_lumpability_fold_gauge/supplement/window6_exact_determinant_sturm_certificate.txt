# Exact determinant and Sturm certificate for the window-6 fold audit

This supplement is a printed, self-contained acceptance certificate for the
algebraic part of the window-6 computation.  It is intentionally redundant with
Appendix A: the manuscript states the theorem-level use of the data, while this
file records the exact determinant factor, the Sturm endpoint convention, and
the independent arithmetic checks a referee can perform without floating-point
eigenvalue routines.

## Sturm endpoint certificate

Let `S_0=Q_6`, `S_1=Q_6'`, and

```
S_{r+1} = -rem(S_{r-1}, S_r)
```

over `QQ[t]` until a constant is reached.  The sequence has degrees
`20,19,...,0`.  At the four rational endpoints, the signs of the full Sturm
sequence are:

```
4841207858/10000000000   -++++++++++++++++++++   V=1
4841207859/10000000000   +++++++++++++++++++++   V=0
-6030939755/10000000000  +-+-+-+-+-+-+-+-+-+-+   V=20
-6030939754/10000000000  --+-+-+-+-+-+-+-+-+-+   V=19
```

The canonical Sturm stream

```
2420603929/5000000000:-++++++++++++++++++++;4841207859/10000000000:+++++++++++++++++++++;-1206187951/2000000000:+-+-+-+-+-+-+-+-+-+-+;-3015469877/5000000000:--+-+-+-+-+-+-+-+-+-+
```

has SHA--256 digest

```
3f456cb31806cf82559e07691386f8a42b2a0555d409e74f2a03063238592ec0
```

By Sturm's theorem, `Q_6` has one real root in each interval

```
(4841207858/10000000000, 4841207859/10000000000)
(-6030939755/10000000000, -6030939754/10000000000)
```

Both intervals are disjoint from the hypercube grid

```
{1, 2/3, 1/3, 0, -1/3, -2/3, -1}.
```

Therefore the rational matrix `P_6` has off-grid eigenvalues and cannot be an
equitable quotient kernel of the simple random walk on `Q_6`.

## Residual certificate

The two vertices `000000` and `010101` satisfy

```
Fold_6^bin(000000) = Fold_6^bin(010101) = 000000.
```

Their one-step target-fiber counts into `000100` are

```
c_000000(000100) = 0
c_010101(000100) = 1
```

Thus no matrix `P` satisfies `T_6 M = M P`.  For the audited pushforward
residual `R_6 = T_6 M - M P_6`, at least one of the corresponding two entries
has absolute value at least `1/12`.
