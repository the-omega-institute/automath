\begin{theorem}[Reusable exact certificate interface for hypercube folds]\label{thm:reusable-exact-certificate-interface-hypercube-folds}
Let \(F:\Omega_m\twoheadrightarrow X\) be any finite hypercube fold with block-indicator matrix \(M\).  Suppose an audited certificate supplies the following finite integer data:
\begin{enumerate}[label=\textup{(\alph*)}]
\item the ordered fiber table of \(F\);
\item the neighbor-count lists \(\mathcal C_{x,y}(F)=\bigl(c_\omega(y)\bigr)_{\omega\in F^{-1}(x)}\), where
\[
c_\omega(y)=\#\{1\le i\le m:F(\omega+e_i)=y\};
\]
\item the cleared characteristic polynomial of the averaged pushforward kernel
\[
P_F=D_F^{-1}M^\top T_mM
\]
and a rational Sturm transcript for any asserted real isolating intervals.
\end{enumerate}
Then the certificate has the following referee-checkable consequences.
\begin{enumerate}[label=\textup{(\roman*)}]
\item The fold is strongly lumpable on the visible state space if and only if every integer list \(\mathcal C_{x,y}(F)\) is constant.  In that case the quotient kernel is uniquely \(P_F\), and \(\Spec(P_F)\subseteq\{1-2k/m:0\le k\le m\}\).
\item If some \(\mathcal C_{x,y}(F)\) has diameter \(\delta>0\), then a two-row subcertificate in that single source fiber proves
\[
\inf_{P\in\RR^{X\times X}}\|T_mM-MP\|_\infty\ge \frac{\delta}{2m}.
\]
In particular no visible kernel can satisfy the exact intertwining equation.
\item If the Sturm transcript certifies a real zero of the cleared characteristic polynomial in a rational interval disjoint from \(\{1-2k/m:0\le k\le m\}\), then the exact averaged kernel \(P_F\) is not the transition kernel of any equitable quotient of \(Q_m\) on the same visible blocks.
\end{enumerate}
Consequently the data in \textup{(a)}--\textup{(c)} form a reusable exact certificate interface: the only fold-specific work is finite integer enumeration and exact Sturm verification, while the mathematical conclusions follow uniformly from the hypercube lumpability and spectral-rigidity theorems.  The interface is intrinsic to the block system: replacing the ordered set \(X\) by a relabeled ordered set conjugates the displayed matrices and permutes the lists \(\mathcal C_{x,y}(F)\), without changing constancy, residual diameters, Chebyshev radii, or the existence of an off-grid spectral witness.
\end{theorem}

\begin{proof}
The fiber table determines \(M\), and the displayed lists are exactly the entries of \(T_mM\) after multiplying by \(m\): for \(\omega\in F^{-1}(x)\), the \((\omega,y)\)-entry of \(T_mM\) is \(c_\omega(y)/m\).  Hence \(T_mM=MP\) can hold for some matrix \(P\) precisely when, for each pair \((x,y)\), this entry is independent of the choice of \(\omega\in F^{-1}(x)\).  This is exactly constancy of every \(\mathcal C_{x,y}(F)\).  When the lists are constant, Lemma \ref{lem:equitable-strong-lumpability-audited-pushforward} identifies the unique quotient with \(P_F\), and Theorem \ref{thm:window6-strong-lumpability-spectral-rigidity} gives the hypercube spectral inclusion.  This proves \textup{(i)}.

If a list has diameter \(\delta\), choose two entries in that list attaining its minimum and maximum.  Theorem \ref{thm:foldbin-complete-residual-budget-skeleton} applied to the finite fold \(F\) gives the exact Chebyshev radius; restricting it to the two entries attaining the diameter \(\delta\) gives the lower bound \(\delta/(2m)\) for every visible compression matrix and rules out exact intertwining.  This proves \textup{(ii)}.

For \textup{(iii)}, clearing denominators in \(\det(tI-P_F)\) does not change the real zeros.  Sturm's theorem counts zeros in a rational interval from the signs of the exact Sturm sequence at the two endpoints.  If such an interval avoids the hypercube grid but contains a zero of the cleared characteristic polynomial, then \(P_F\) has an off-grid eigenvalue.  The contrapositive statement in Theorem \ref{thm:window6-strong-lumpability-spectral-rigidity} therefore excludes \(P_F\) from the class of equitable quotient kernels on the same visible blocks.

Finally, let \(\sigma:X\to X'\) be a relabeling and let \(S\) be its permutation matrix.  The relabeled block matrix is \(MS\), the averaged pushforward is \(S^{-1}P_FS\), and the count list indexed by \((\sigma x,\sigma y)\) is the same multiset as the old list indexed by \((x,y)\).  Thus all diameter and interval assertions are merely reindexed.  Conjugation preserves characteristic polynomials, so Sturm witnesses and off-grid eigenvalues are unchanged.  The final sentence is only the assembly of these proved implications. \qedhere
\end{proof}


\begin{lemma}[Fibonacci-tail prefix recursion]\label{lem:foldbin-fibonacci-tail-prefix-recursion}
Fix \(m\ge1\), and let \(K_m\) be the integer from Definition \ref{def:audited-binary-fold-certificate}.  For \(m<r\le K_m+1\) and \(b\in\{0,1\}\), let \(\mathcal T_r^{(b)}\) be the finite sets defined by
\[
\mathcal T_{K_m+1}^{(0)}=\mathcal T_{K_m+1}^{(1)}=\{0\},
\]
and, for \(m<r\le K_m\), by
\[
\mathcal T_r^{(1)}=\mathcal T_{r+1}^{(0)},
\qquad
\mathcal T_r^{(0)}=
\mathcal T_{r+1}^{(0)}\cup\bigl(F_{r+1}+\mathcal T_{r+1}^{(1)}\bigr).
\]
Then \(\mathcal T_r^{(b)}\) is exactly the set of values
\[
\sum_{s=r}^{K_m} u_sF_{s+1}
\]
where \((u_r,\ldots,u_{K_m})\in\{0,1\}^{K_m-r+1}\) and the concatenated word \((b,u_r,\ldots,u_{K_m})\) has no adjacent ones.  Consequently, for every \(x=(x_1,\ldots,x_m)\in X_m\), with
\[
V_m(x)=\sum_{r=1}^{m}x_rF_{r+1},
\]
one has
\[
(\Fold_m^{\mathrm{bin}})^{-1}(x)
=\{\omega\in\Omega_m:N(\omega)-V_m(x)\in\mathcal T_{m+1}^{(x_m)}\},
\]
and
\[
d_m^{\mathrm{bin}}(x)
=\#\bigl(\mathcal T_{m+1}^{(x_m)}\cap[-V_m(x),2^m-1-V_m(x)]\bigr).
\]
For \(\omega\in\Omega_m\) and \(y\in X_m\), the target-fiber neighbor count is
\[
c_\omega(y)=\sum_{i=1}^{m}\mathbf 1_{\mathcal T_{m+1}^{(y_m)}}
\bigl(N(\omega\oplus e_i)-V_m(y)\bigr),
\]
where \(\omega\oplus e_i\) denotes bit-flip in coordinate \(i\).
\end{lemma}

\begin{proof}
We prove the tail description by backward induction on \(r\).  At the terminal index \(r=K_m+1\) there are no remaining Zeckendorf positions, so the only tail value is the empty sum \(0\), independently of the previous digit \(b\).  This is the displayed terminal condition.

Assume the assertion is known at \(r+1\).  If the previous digit is \(1\), the no-adjacent-ones constraint forces \(u_r=0\); the admissible tail values are therefore exactly the values of a tail beginning at \(r+1\) with previous digit \(0\), namely \(\mathcal T_{r+1}^{(0)}\).  This gives \(\mathcal T_r^{(1)}=\mathcal T_{r+1}^{(0)}\).  If the previous digit is \(0\), either \(u_r=0\), giving the values \(\mathcal T_{r+1}^{(0)}\), or \(u_r=1\), contributing \(F_{r+1}\) and then forcing the next tail to begin with previous digit \(1\), giving \(F_{r+1}+\mathcal T_{r+1}^{(1)}\).  This is precisely the displayed recursion for \(\mathcal T_r^{(0)}\).  The induction proves that the recursion enumerates exactly, and only, legal Fibonacci tails.

Now let \(N\in[0,2^m-1]\), and let \(z_1(N),\ldots,z_{K_m}(N)\) be its greedy Zeckendorf digits.  Definition \ref{def:audited-binary-fold-certificate} and the choice of \(K_m\) ensure that these positions contain the whole expansion: the largest weight needed for any \(N\le2^m-1\) is at most \(F_{K_m+1}\), while \(F_{K_m+2}>2^m-1\) excludes a nonzero digit beyond \(K_m\).  The prefix condition \((z_1(N),\ldots,z_m(N))=x\) is therefore equivalent to
\[
N=V_m(x)+\sum_{s=m+1}^{K_m}z_s(N)F_{s+1}
\]
with the tail legal after the previous digit \(x_m\).  By the induction just proved, this is equivalent to \(N-V_m(x)\in\mathcal T_{m+1}^{(x_m)}\).  Translating the dyadic interval \(0\le N\le2^m-1\), identified with \(\Omega_m\) by \(\omega\mapsto N(\omega)\), gives the fiber formula and the cardinality formula.  Finally, \(c_\omega(y)\) counts the coordinates whose flipped dyadic integer has greedy prefix \(y\); applying the same membership criterion to each flipped word gives the stated sum of indicators. \qedhere
\end{proof}

\begin{theorem}[Exact finite-certificate structure and Fibonacci recursion for the bin-fold family]\label{thm:foldbin-algorithmic-certificate-schema}
For every \(m\ge1\), the rule defining \(\Fold_m^{\mathrm{bin}}\) determines an intrinsic finite certificate
\[
\mathfrak C_m=\bigl(\mathcal F_m,\{\mathcal C_{x,y}\}_{x,y\in X_m},\Delta_m,
\mathcal S_m, C_m(t),\mathcal I_m\bigr)
\]
with the following properties.
\begin{enumerate}[label=\textup{(\roman*)}]
\item \(\mathcal F_m\) is the complete fiber table, \(\mathcal C_{x,y}\) is the target-fiber neighbor-count list, \(\Delta_m\) is the residual diameter tensor, and \(\mathcal S_m\) is the set of extremal two-row skeletons \((x,y;\omega_-,\omega_+)\) with
\[
\omega_-,\omega_+\in(\Fold_m^{\mathrm{bin}})^{-1}(x),
\qquad
c_{\omega_+}(y)-c_{\omega_-}(y)=\Delta_m(x,y)>0.
\]
\item The certificate decides visible strong lumpability and classifies all real \(\epsilon\)-intertwiners by the interval product of Theorems \ref{thm:foldbin-bad-skeleton-classification} and \ref{thm:foldbin-complete-residual-budget-skeleton}.  In particular, \(\mathcal S_m\ne\varnothing\) if and only if the visible fold is not strongly lumpable, and the skeletons with largest value of \(\Delta_m(x,y)\) force the sharp residual lower bound \(\Delta_m/(2m)\).
\item The capacity curve \(C_m(t)=\sum_{x\in X_m}\min\{|(\Fold_m^{\mathrm{bin}})^{-1}(x)|,t\}\) recovers the threshold counts used by the fold-gauge homology theorem.  The residual, fiber, skeleton, and capacity entries of \(\mathfrak C_m\) exist uniformly for all \(m\).  By contrast, the spectral component \(\mathcal I_m\) is a finite-window audit field: when an exact characteristic-polynomial/Sturm transcript is supplied, it certifies the corresponding off-grid spectral assertion for that specified window; the family theorem by itself asserts the algorithmic construction of such a finite transcript, not a precomputed off-grid eigenvalue for every \(m\).
\item The whole certificate is invariant under relabeling of \(X_m\): relabeling only conjugates matrices and reindexes \(\mathcal F_m\), \(\mathcal C_{x,y}\), \(\Delta_m\), \(\mathcal S_m\), and \(C_m\).  Hence the structure theorem is an algebraic-combinatorial certificate for this family, not a numerical observation tied to a preferred ordering of states and not a classification of unrelated folds.
\item The fibers themselves have the following closed recursive description.  Let \(K_m\) be as in Definition \ref{def:audited-binary-fold-certificate}.  For \(x=(x_1,\ldots,x_m)\in X_m\), define
\[
V_m(x):=\sum_{r=1}^{m}x_rF_{r+1},
\]
and define finite tail-value sets \(\mathcal T_r^{(b)}\) for \(m<r\le K_m+1\) and \(b\in\{0,1\}\) by the terminal condition
\[
\mathcal T_{K_m+1}^{(0)}=\mathcal T_{K_m+1}^{(1)}=\{0\},
\]
and, for \(m<r\le K_m\), by the recursion
\[
\mathcal T_r^{(1)}=\mathcal T_{r+1}^{(0)},
\qquad
\mathcal T_r^{(0)}=
\mathcal T_{r+1}^{(0)}\cup\bigl(F_{r+1}+\mathcal T_{r+1}^{(1)}\bigr).
\]
Then
\[
(\Fold_m^{\mathrm{bin}})^{-1}(x)
=\{\omega\in\Omega_m:N(\omega)-V_m(x)\in\mathcal T_{m+1}^{(x_m)}\},
\]
so
\[
d_m^{\mathrm{bin}}(x)
=\#\bigl(\mathcal T_{m+1}^{(x_m)}\cap[-V_m(x),2^m-1-V_m(x)]\bigr).
\]
Consequently every count list and every residual entry is obtained without search over target labels from the finite tail-recursion formula
\[
c_\omega(y)=\sum_{i=1}^{m}\mathbf 1_{\mathcal T_{m+1}^{(y_m)}}
\bigl(N(\omega\oplus e_i)-V_m(y)\bigr),
\]
where \(\omega\oplus e_i\) denotes bit-flip in coordinate \(i\).  Thus the family certificate is an explicit Fibonacci-tail tensor formula, with finite enumeration used only to evaluate these closed expressions in a specified window.
\end{enumerate}
For \(m=6\), the tables and Sturm data printed in Theorem \ref{thm:single-exact-fold6-certificate} are exactly the specialization \(\mathfrak C_6\), and the main theorem uses \(\mathfrak C_6\) through this finite-certificate structure theorem together with the residual-certificate interface of Proposition \ref{thm:foldbin-family-certificate-algorithm}.  Thus the uniform conclusion is the Fibonacci-tail construction and residual/fiber recursion for all windows, while the off-grid spectral nonlumpability conclusion is invoked only in finite windows carrying an accepted Sturm transcript, in this paper the audited window \(6\) transcript of Proposition \ref{prop:journal-facing-computation-proof-protocol}.
\end{theorem}

\begin{proof}
For fixed \(m\), enumerate the finite set \(\Omega_m=\{0,1\}^m\).  Definition \ref{def:audited-binary-fold-certificate} gives \(\Fold_m^{\mathrm{bin}}(\omega)\) by a finite greedy Zeckendorf-prefix computation, so collecting equal values constructs \(X_m\) and the fiber table \(\mathcal F_m\).  For each \(\omega\in\Omega_m\), each coordinate flip \(\omega+e_i\), and each target \(y\in X_m\), counting the occurrences of \(\Fold_m^{\mathrm{bin}}(\omega+e_i)=y\) constructs the integer lists \(\mathcal C_{x,y}\).  Taking maxima and minima in those finite lists constructs \(\Delta_m(x,y)\), and retaining all pairs attaining a positive difference constructs \(\mathcal S_m\).  The capacity curve is obtained by summing the displayed finite expression over the computed fiber sizes.  These constructions use only the recursive tail sets in \textup{(v)} and therefore are uniform in \(m\).  Since \(P_m^{\mathrm{bin}}\) has rational entries obtained from the same finite edge counts, clearing denominators in \(\det(tI-P_m^{\mathrm{bin}})\) gives an integer polynomial; Sturm sequences over \(\QQ[t]\) are finite Euclidean-algorithm computations, so a transcript \(\mathcal I_m\) is finite whenever a particular window is audited.  Such a transcript is a certificate input for that window: without its endpoint signs the theorem supplies the exact polynomial and the algorithmic Sturm procedure, but it does not assert an off-grid root.

The decision and classification statements are exactly Theorem \ref{thm:foldbin-bad-skeleton-classification}, refined by Theorem \ref{thm:foldbin-complete-residual-budget-skeleton}, applied to the constructed lists.  These theorems also prove that positive-diameter two-row skeletons are precisely the local obstructions and that the maximum-diameter ones force the sharp radius \(\Delta_m/(2m)\).  The capacity assertion follows from the jump identity in Theorem \ref{thm:window6-foldbin-gauge-low-degree-homology}.  Under a relabeling \(\sigma:X_m\to X'_m\), the block-indicator matrix is multiplied on the right by the associated permutation matrix, target-count lists are renamed from \((x,y)\) to \((\sigma x,\sigma y)\), and all maxima, minima, skeleton equalities, fiber sizes, and characteristic polynomials are preserved.  Thus the certificate is intrinsic up to relabeling.

The Fibonacci-tail formulas in \textup{(v)} are Lemma \ref{lem:foldbin-fibonacci-tail-prefix-recursion}.  Substituting the audited \(m=6\) fiber table, edge-count matrix, residual tensor, capacity data, and Sturm transcript gives exactly the data package summarized in Theorem \ref{thm:single-exact-fold6-certificate}.  Proposition \ref{thm:foldbin-family-certificate-algorithm} records the same substitution as a reusable decision interface: the residual obstruction and stochastic budget refinement read from the uniform finite package, while the off-grid spectral test reads from the finite-window Sturm field when that field is present.  In the theorem chain leading to Theorem \ref{thm:main-fold6-nonlumpability}, that present field is precisely the audited \(m=6\) transcript accepted by Proposition \ref{prop:journal-facing-computation-proof-protocol}.  Thus the main theorem is an application of the certificate formalism plus a supplied finite-window spectral audit, not an unproved uniform spectral assertion. \qedhere
\end{proof}


\begin{proposition}[Fold\texorpdfstring{$_m^{\mathrm{bin}}$}{m bin} residual-certificate interface]\label{thm:foldbin-family-certificate-algorithm}
For every \(m\ge1\), the binary Zeckendorf-prefix fold \(\Fold_m^{\mathrm{bin}}:\Omega_m\twoheadrightarrow X_m\) admits a finite integer certificate package deciding visible strong lumpability, classifying all approximate visible intertwiners, and testing the audited pushforward for off-grid spectrum.  The package is obtained by the Fibonacci-tail recursion of Lemma \ref{lem:foldbin-fibonacci-tail-prefix-recursion}; its residual and interval-polytope conclusions are exactly the specialization of Theorem \ref{thm:foldbin-complete-residual-budget-skeleton} to \(F=\Fold_m^{\mathrm{bin}}\).  Explicitly, if
\[
c_\omega(y)=\#\{1\le i\le m:\Fold_m^{\mathrm{bin}}(\omega+e_i)=y\},
\]
then all neighbor-count lists, the edge counts
\[
N_{xy}=\#\{(\omega,i):\Fold_m^{\mathrm{bin}}(\omega)=x,
\ \Fold_m^{\mathrm{bin}}(\omega+e_i)=y\},
\]
the pushforward entries \(P_m^{\mathrm{bin}}(x,y)=N_{xy}/(m d_x)\), the residual diameter tensor, the sharp real Chebyshev radius \(\Delta_m/(2m)\), and the row-stochastic feasible polytope are finite integer or rational functions of the tail-membership indicators in Lemma \ref{lem:foldbin-fibonacci-tail-prefix-recursion}. If a list is nonconstant, two entries in that list give the two-row residual skeleton of Theorem \ref{thm:foldbin-complete-residual-budget-skeleton}, so exact visible lumpability fails and every visible Markov kernel has residual at least the corresponding skeleton budget. In window \(6\), the printed fiber table, edge-count matrix, exact residual distribution, supporting stochastic endpoint-sum table, and Sturm certificate are precisely this audited specialization.
\end{proposition}

\begin{proof}

\end{proof}

\begin{theorem}[Bad-example skeleton classification for the bin-fold family]\label{thm:foldbin-bad-skeleton-classification}
For every \(m\ge1\) and every \(\epsilon\ge0\), let \(\mathcal B_m(\epsilon)\) be the set of quadruples
\[
(x,y;\omega_-,\omega_+)
\]
such that \(x,y\in X_m\), \(\omega_-,\omega_+\in(\Fold_m^{\mathrm{bin}})^{-1}(x)\), and
\[
\bigl|c_{\omega_+}(y)-c_{\omega_-}(y)\bigr|>2m\epsilon,
\]
where the counts \(c_\omega(y)\) are the Fibonacci-tail counts of Lemma \ref{lem:foldbin-fibonacci-tail-prefix-recursion}.  Then \(\mathcal B_m(\epsilon)\) is the complete obstruction set for visible \(\epsilon\)-lumpability of the binary fold:
\begin{enumerate}[label=\textup{(\roman*)}]
\item There exists a real matrix \(P\) with \(\|T_mM_m-M_mP\|_\infty\le\epsilon\) if and only if \(\mathcal B_m(\epsilon)=\varnothing\).
\item If \((x,y;\omega_-,\omega_+)\in\mathcal B_m(\epsilon)\), then every real matrix \(P\) satisfies
\[
\max\left\{
\left|\frac{c_{\omega_-}(y)}{m}-P(x,y)\right|,
\left|\frac{c_{\omega_+}(y)}{m}-P(x,y)\right|
\right\}
>
\epsilon.
\]
Thus no hidden higher-order obstruction is needed to refute a visible \(\epsilon\)-intertwiner: one source fiber, one target fiber, and two vertices already give the contradiction.
\item The exact visible quotient criterion is the special case \(\epsilon=0\): \(\Fold_m^{\mathrm{bin}}\) is strongly lumpable on the visible state space if and only if \(\mathcal B_m(0)=\varnothing\).  When this holds, the quotient kernel is uniquely \(P_m^{\mathrm{bin}}\).
\item The optimal real residual radius is attained by the maximal bad skeletons:
\[
\inf_{P\in\RR^{X_m\times X_m}}
\|T_mM_m-M_mP\|_\infty
=
\frac{1}{2m}
\max_{x,y}\max_{\omega_-,\omega_+\in(\Fold_m^{\mathrm{bin}})^{-1}(x)}
\bigl|c_{\omega_+}(y)-c_{\omega_-}(y)\bigr|.
\]
Consequently the window-\(6\) residual witness in Proposition \ref{prop:foldbin6-explicit-nonintertwining-witness} is a member of the same classifying skeleton family, while Theorem \ref{thm:foldbin6-exact-residual-diameter-distribution} identifies the maximal window-\(6\) skeletons and hence the sharp \(1/6\) visible Markov lower bound used in Theorem \ref{thm:main-fold6-nonlumpability}.
\end{enumerate}
\end{theorem}

\begin{proof}
Fix \(x,y\).  On the source fiber \((\Fold_m^{\mathrm{bin}})^{-1}(x)\), the \(y\)-column of \(T_mM_m\) has entries \(c_\omega(y)/m\), while the \(y\)-column of \(M_mP\) is constant and equal to \(P(x,y)\).  Hence the coordinate inequalities for a real \(\epsilon\)-intertwiner are exactly
\[
\left|\frac{c_\omega(y)}{m}-P(x,y)\right|\le\epsilon
\qquad
(\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)).
\]
Such a number \(P(x,y)\) exists if and only if the intervals
\[
\left[\frac{c_\omega(y)}{m}-\epsilon,
\frac{c_\omega(y)}{m}+\epsilon\right]
\]
have common intersection.  Since these are intervals on the real line, Helly's theorem in dimension one, equivalently the elementary max--min criterion, says that the intersection is nonempty if and only if every pair of centers is separated by at most \(2\epsilon\).  After multiplying by \(m\), this is precisely the condition that no quadruple in \(\mathcal B_m(\epsilon)\) exists for the ordered pair \((x,y)\).  The entrywise norm imposes the same independent one-dimensional condition for each \((x,y)\), proving \textup{(i)}.

If a bad skeleton satisfies \(|c_{\omega_+}(y)-c_{\omega_-}(y)|>2m\epsilon\), then two real numbers separated by more than \(2\epsilon\) cannot both lie within \(\epsilon\) of the same value \(P(x,y)\).  This gives the displayed inequality and proves \textup{(ii)}.  Taking \(\epsilon=0\), the condition is that all counts \(c_\omega(y)\) are constant on every source fiber for every target \(y\).  This is exactly the equitable-partition criterion for the hypercube walk, and the unique quotient entries are the common values, equivalently the averaged entries \(P_m^{\mathrm{bin}}(x,y)=N_{xy}/(m d_x)\).  This proves \textup{(iii)}.

The least \(\epsilon\) for which all interval intersections are nonempty is half the largest normalized diameter of a count list.  Writing that diameter as a maximum over pairs \(\omega_-,\omega_+\) in the same source fiber gives the displayed formula.  Lemma \ref{lem:foldbin-fibonacci-tail-prefix-recursion} expresses every count in the formula by the finite Fibonacci-tail indicators, so the obstruction family is a closed finite tensor for each \(m\).  In window \(6\), substituting the residual witness and the residual-diameter distribution cited in the statement gives the announced connection with Theorem \ref{thm:main-fold6-nonlumpability}. \qedhere
\end{proof}

\begin{theorem}[Finite residual package is complete for visible hypercube quotient certificates]\label{thm:finite-residual-package-complete-visible-certificates}
Let \(F:\Omega_m\twoheadrightarrow X\) be a finite fold of the hypercube, with block-indicator matrix \(M\).  For each ordered pair \((x,y)\in X\times X\), write
\[
\mathcal C_{x,y}(F):=\bigl\{c_\omega(y):\omega\in F^{-1}(x)\bigr\}
\]
as a multiset, where
\(
c_\omega(y)=\#\{1\le i\le m:F(\omega+e_i)=y\}
\).
The finite collection
\[
\mathcal R(F):=\bigl(|F^{-1}(x)|,\mathcal C_{x,y}(F)\bigr)_{x,y\in X}
\]
is a complete visible one-step certificate in the following sense.
\begin{enumerate}[label=\textup{(\roman*)}]
\item It decides exact visible strong lumpability: \(F\) is a visible quotient of the simple random walk on \(Q_m\) if and only if every multiset \(\mathcal C_{x,y}(F)\) is a singleton.
\item It determines the full feasible set of real \(\epsilon\)-intertwiners \(P\) satisfying \(\|T_mM-MP\|_\infty\le\epsilon\), and also determines the row-stochastic feasible set after intersecting each row with the probability simplex.
\item It determines the sharp real residual radius
\[
\rho^{\RR}(F)=\frac{1}{2m}\max_{x,y}\Bigl(\max\mathcal C_{x,y}(F)-\min\mathcal C_{x,y}(F)\Bigr),
\]
and a positive value of this radius is always witnessed by a two-vertex, one-target bad-example skeleton contained in one of the multisets \(\mathcal C_{x,y}(F)\).
\item If an exact rational characteristic-polynomial/Sturm transcript for the averaged pushforward \(P_F=D_F^{-1}M^\top T_mM\) is appended to \(\mathcal R(F)\), then the resulting finite package decides the off-grid spectral obstruction for that audited window.
\end{enumerate}
For \(F=\Fold_6^{\mathrm{bin}}\), this complete finite package is exactly the one used in Theorem \ref{thm:main-fold6-nonlumpability}: the residual part gives the visible nonintertwining obstruction and the sharp \(1/6\) Markov lower bound, while the appended Sturm transcript gives the independent off-grid spectral certificate.
\end{theorem}

\begin{proof}
For fixed \((x,y)\), the entries of the column \(T_mM(\cdot,y)\) over the source fiber \(F^{-1}(x)\) are precisely the numbers \(c_\omega(y)/m\).  A visible matrix \(P\) has column value \(P(x,y)\) on that entire source fiber.  Thus the inequalities
\[
\left|\frac{c_\omega(y)}{m}-P(x,y)\right|\le \epsilon
\qquad(\omega\in F^{-1}(x))
\]
are equivalent to the single interval condition
\[
P(x,y)\in
\left[
\frac{1}{m}\max\mathcal C_{x,y}(F)-\epsilon,
\frac{1}{m}\min\mathcal C_{x,y}(F)+\epsilon
\right].
\]
The entrywise norm imposes these conditions independently for all ordered pairs \((x,y)\), proving the real feasible-set assertion.  Intersecting each row with \(P(x,y)\ge0\) and \(\sum_yP(x,y)=1\) is exactly the row-stochastic specialization, so the same finite lists determine the Markov feasible set.

Taking \(\epsilon=0\) shows that an exact visible intertwiner exists if and only if each interval is nonempty at \(
\epsilon=0
\), equivalently if and only if every list \(\mathcal C_{x,y}(F)\) is constant.  This is the equitable-partition criterion for the hypercube walk, and the quotient kernel is then the averaged pushforward \(P_F\).  The smallest \(\epsilon\) for which all real intervals are nonempty is the maximum, over \((x,y)\), of one half of the normalized diameter of \(\mathcal C_{x,y}(F)\), giving the displayed formula for \(\rho^{\RR}(F)\).  If the maximum diameter is positive, choose \(\omega_-,\omega_+\in F^{-1}(x)\) attaining the minimum and maximum in a maximizing list.  These two vertices and the single target \(y\) force the lower bound, because no single value \(P(x,y)\) can be within less than half their normalized separation of both entries.

Finally, the pushforward entries are rational functions of the same finite data:
\[
P_F(x,y)=\frac{1}{m|F^{-1}(x)|}\sum_{a\in\mathcal C_{x,y}(F)}a.
\]
Hence a cleared characteristic polynomial of \(P_F\) is an exact rational computation from \(\mathcal R(F)\).  Sturm's theorem over \(\QQ[t]\) certifies whether a supplied rational interval contains a real root and whether that interval is disjoint from the hypercube grid \(\{1-2k/m:0\le k\le m\}\).  The final Fold\(_6\) statement is obtained by substituting the printed window-\(6\) fiber table, edge-count lists, residual-diameter table, stochastic budget table, and Sturm transcript from Theorem \ref{thm:single-exact-fold6-certificate}, Corollary \ref{cor:foldbin6-visible-markov-lower-bound}, and Lemma \ref{lem:foldbin6-eigenvalue-interval-certificate}. \qedhere
\end{proof}

\begin{theorem}[Exact residual-budget classification for a finite hypercube fold]\label{thm:foldbin-complete-residual-budget-skeleton}
Let \(F:\Omega_m\twoheadrightarrow X\) be any finite hypercube fold with block-indicator matrix \(M\).  For \(x,y\in X\) and \(\omega\in F^{-1}(x)\), put
\[
c_\omega(y):=\#\{1\le i\le m:F(\omega+e_i)=y\}.
\]
Let \(D_F=M^\top M\), let \(P_F:=D_F^{-1}M^\top T_mM\), and define
\[
\Delta_F(x,y):=\max_{\omega\in F^{-1}(x)} c_\omega(y)
-
\min_{\omega\in F^{-1}(x)} c_\omega(y),
\qquad
\Delta_F:=\max_{x,y}\Delta_F(x,y).
\]
For \(\epsilon\ge0\), define
\[
I_\epsilon^F(x,y):=
\left[
\frac{1}{m}\max_{\omega\in F^{-1}(x)}c_\omega(y)-\epsilon,
\frac{1}{m}\min_{\omega\in F^{-1}(x)}c_\omega(y)+\epsilon
\right].
\]
Then:
\begin{enumerate}[label=\textup{(\roman*)}]
\item The fold \(F\) is an equitable, equivalently strongly lumpable, quotient of \(Q_m\) if and only if \(\Delta_F=0\).  In that case the unique visible intertwining matrix is \(P_F\).
\item For an arbitrary real matrix \(P\) on \(X\),
\[
\|T_mM-MP\|_\infty\le\epsilon
\]
holds if and only if
\[
P(x,y)\in I_\epsilon^F(x,y)
\qquad\text{for every }x,y\in X.
\]
Thus the set of all real \(\epsilon\)-intertwiners is the interval product \(\prod_{x,y}I_\epsilon^F(x,y)\), intersected with the row-stochastic simplex if one insists on Markov kernels.
\item The unconstrained visible Chebyshev radius is exactly
\[
\inf_{P\in\RR^{X\times X}}
\|T_mM-MP\|_\infty
=\frac{\Delta_F}{2m}.
\]
It is attained precisely by those real matrices \(P\) with \(P(x,y)\in I_{\Delta_F/(2m)}^F(x,y)\) for every \(x,y\).  In particular, if \(\Delta_F>0\), then every visible Markov kernel has entrywise residual at least \(\Delta_F/(2m)\).
\item For the averaged pushforward \(P_F\),
\[
\frac{\Delta_F}{2m}\le
\|T_mM-MP_F\|_\infty
\le \frac{\Delta_F}{m}.
\]
More precisely, for \(\omega\in F^{-1}(x)\) the residual entry in target column \(y\) is
\[
\frac{1}{m}\left(c_\omega(y)-\frac{1}{|F^{-1}(x)|}
\sum_{\eta\in F^{-1}(x)}c_\eta(y)\right).
\]
\item Every positive residual budget has a classifiable two-row, one-column bad-example skeleton: if \(\Delta_F(x,y)>0\), choose \(\omega_-,\omega_+\in F^{-1}(x)\) attaining the minimum and maximum of \(c_\omega(y)\).  Then \((x,y;\omega_-,\omega_+)\) alone proves that every visible matrix has error at least \(\Delta_F(x,y)/(2m)\) on this source--target coordinate.  Pairs with \(\Delta_F(x,y)=\Delta_F\) are exactly the skeletons forcing the global radius in \textup{(iii)}.
\end{enumerate}
For the binary fold \(F=\Fold_m^{\mathrm{bin}}\), we write \(M_m\), \(P_m^{\mathrm{bin}}\), \(\Delta_m(x,y)\), \(\Delta_m\), and \(I_\epsilon(x,y)\) for these objects.
\end{theorem}

\begin{proof}
For fixed \(x,y\), the entries of the column \(T_mM(\cdot,y)\) on the source fiber over \(x\) are precisely \(c_\omega(y)/m\).  The corresponding column of \(MP\) is constant on that source fiber and has value \(P(x,y)\).  Therefore the single-coordinate residual inequalities are
\[
\left|\frac{c_\omega(y)}{m}-P(x,y)\right|\le\epsilon,
\qquad \omega\in F^{-1}(x),
\]
and their common solution set is the intersection of the intervals
\[
\left[\frac{c_\omega(y)}{m}-\epsilon,
\frac{c_\omega(y)}{m}+\epsilon\right],
\]
which is exactly \(I_\epsilon^F(x,y)\).  Since the entrywise norm imposes these conditions independently for each ordered pair \((x,y)\), the full real feasible set is the displayed interval product.  Adding stochasticity imposes only the independent row-simplex constraints.  This proves \textup{(ii)}.

The interval \(I_\epsilon^F(x,y)\) is nonempty if and only if
\[
\frac{1}{m}\max_{\omega\in F^{-1}(x)}c_\omega(y)-\epsilon
\le
\frac{1}{m}\min_{\omega\in F^{-1}(x)}c_\omega(y)+\epsilon,
\]
which is equivalent to \(\epsilon\ge \Delta_F(x,y)/(2m)\).  Hence all coordinate intervals are simultaneously nonempty if and only if \(\epsilon\ge\Delta_F/(2m)\).  This proves the radius formula and the minimizer description in \textup{(iii)}.  The same inequality restricted to two entries attaining the minimum and maximum proves the two-row skeleton statement in \textup{(v)}.

Taking \(\epsilon=0\) in \textup{(ii)} shows that an exact visible intertwining exists if and only if every source-fiber target-count list is constant, equivalently if and only if \(\Delta_F=0\).  This is the standard equitable-partition criterion recorded in Lemma \ref{lem:equitable-strong-lumpability-audited-pushforward}; the same lemma identifies the unique quotient with \(P_F=D_F^{-1}M^\top T_mM\).  This proves \textup{(i)}.

Finally, \(P_F(x,y)\) is the average of \(c_\eta(y)/m\) over \(\eta\in F^{-1}(x)\).  Substituting this average gives the displayed residual formula.  The lower bound follows from \textup{(iii)} by taking \(P=P_F\).  The upper bound follows because every entry in a fixed list lies within its full diameter of its average:
\[
\left|\frac{c_\omega(y)}{m}-P_F(x,y)\right|
\le \frac{\Delta_F(x,y)}{m}
\le \frac{\Delta_F}{m}.
\]
This proves \textup{(iv)} and completes the classification. \qedhere
\end{proof}

\begin{theorem}[Row-stochastic visible-kernel residual-budget classification]\label{thm:foldbin-stochastic-budget-classification}
Fix \(m\ge1\) and the binary fold \(\Fold_m^{\mathrm{bin}}:\Omega_m\twoheadrightarrow X_m\).  For \(x,y\in X_m\), set
\[

\qquad
\beta_{xy}:=\frac{1}{m}\min_{\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)}c_\omega(y),
\]
and, for \(\epsilon\ge0\), put
\[
J_\epsilon(x,y):=
\bigl[\max\{0,\alpha_{xy}-\epsilon\},\ \min\{1,\beta_{xy}+\epsilon\}\bigr].
\]
Let
\[
L_x(\epsilon):=\sum_{y\in X_m}\max\{0,\alpha_{xy}-\epsilon\},
\qquad
U_x(\epsilon):=\sum_{y\in X_m}\min\{1,\beta_{xy}+\epsilon\}.
\]
This is the row-stochastic specialization needed when the visible compression is required to remain a genuine Markov kernel.  The unconstrained residual-diameter theorem gives the obstruction for arbitrary real visible matrices; the present theorem proves that the same interval data, after intersection with the row simplices, is the exact feasible set for probabilistic visible kernels.  The Markov kernels \(P\) on \(X_m\) with
\[
\|T_mM_m-M_mP\|_\infty\le\epsilon
\]
are exactly the product, over source rows \(x\), of the explicit polytopes
\[
\mathcal K_x(\epsilon)=
\left\{(p_y)_{y\in X_m}:
\sum_y p_y=1,
\ p_y\in J_\epsilon(x,y)\text{ for all }y
\right\}.
\]
In particular, such a Markov kernel exists if and only if
\[
\max\{0,\alpha_{xy}-\epsilon\}\le \min\{1,\beta_{xy}+\epsilon\}
\quad\text{for all }x,y,
\]
and
\[
L_x(\epsilon)\le1\le U_x(\epsilon)
\quad\text{for every }x\in X_m.
\]
Consequently the sharp Markov residual radius is the finite, exact, piecewise-rational quantity
\[
\rho_m^{\mathrm{Markov}}=
\inf\left\{\epsilon\ge0:
\begin{array}{l}

\begin{corollary}[Visible Markov lower bound for the audited Fold\texorpdfstring{$_6$}{6} kernel]\label{cor:foldbin6-visible-markov-lower-bound}
For the audited window-\(6\) binary fold, every row-stochastic visible kernel \(P\) on \(X_6\) satisfies
\[
\|T_6M_6-M_6P\|_\infty\ge \frac16.
\]
Moreover the bound is sharp within the row-stochastic class: there exists a Markov kernel \(P\) with
\[
\|T_6M_6-M_6P\|_\infty= \frac16.
\]
Consequently the visible-kernel residual lower bound in Theorem \ref{thm:main-fold6-nonlumpability}\textup{(ii)} is a Markov-kernel obstruction and not merely an obstruction for signed or non-stochastic visible matrices.
\end{corollary}

\begin{proof}
Theorem \ref{thm:foldbin-stochastic-budget-classification} computes the sharp row-stochastic residual radius for the audited window-\(6\) fold as
\(
\rho_6^{\mathrm{Markov}}=1/6
\).
By definition this number is the infimum of \(\|T_6M_6-M_6P\|_\infty\) over all Markov kernels \(P\) on \(X_6\), so every such kernel has residual at least \(1/6\).
The same theorem also gives the exact feasibility criterion at \(\epsilon=1/6\): every coordinate interval is nonempty and each row satisfies \(L_x(1/6)\le1\le U_x(1/6)\).
For each source row \(x\), the product of the intervals \(J_{1/6}(x,y)\) therefore contains a point whose coordinate sum is \(1\).
Choosing one such point independently for every row gives a row-stochastic matrix \(P\) with \(P(x,y)\in J_{1/6}(x,y)\) for all \((x,y)\).
The classification theorem then gives \(\|T_6M_6-M_6P\|_\infty\le1/6\), and the lower bound forces equality. \qedhere
\end{proof}
