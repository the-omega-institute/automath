\begin{theorem}[Reusable exact certificate interface for hypercube folds]\label{thm:reusable-exact-certificate-interface-hypercube-folds}
Let \(F:\Omega_m\twoheadrightarrow X\) be any finite hypercube fold with block-indicator matrix \(M\).  Suppose an audited certificate supplies the following finite integer data:
\begin{enumerate}[label=\textup{(\alph*)}]
\item the ordered fiber table of \(F\);
\item the neighbor-count lists \(\mathcal C_{x,y}(F)=\bigl(c_\omega(y)\bigr)_{\omega\in F^{-1}(x)}\), where
\[
c_\omega(y)=\#\{1\le i\le m:F(\omega+e_i)=y\};
\]
\item the cleared characteristic polynomial of the averaged pushforward kernel
\[
P_F=D_F^{-1}M^\top T_mM
\]
and a rational Sturm transcript for any asserted real isolating intervals.
\end{enumerate}
Then the certificate has the following referee-checkable consequences.
\begin{enumerate}[label=\textup{(\roman*)}]
\item The fold is strongly lumpable on the visible state space if and only if every integer list \(\mathcal C_{x,y}(F)\) is constant.  In that case the quotient kernel is uniquely \(P_F\), and \(\Spec(P_F)\subseteq\{1-2k/m:0\le k\le m\}\).
\item If some \(\mathcal C_{x,y}(F)\) has diameter \(\delta>0\), then a two-row subcertificate in that single source fiber proves
\[
\inf_{P\in\RR^{X\times X}}\|T_mM-MP\|_\infty\ge \frac{\delta}{2m}.
\]
In particular no visible kernel can satisfy the exact intertwining equation.
\item If the Sturm transcript certifies a real zero of the cleared characteristic polynomial in a rational interval disjoint from \(\{1-2k/m:0\le k\le m\}\), then the exact averaged kernel \(P_F\) is not the transition kernel of any equitable quotient of \(Q_m\) on the same visible blocks.
\end{enumerate}
Consequently the data in \textup{(a)}--\textup{(c)} form a reusable exact certificate interface: the only fold-specific work is finite integer enumeration and exact Sturm verification, while the mathematical conclusions follow uniformly from the hypercube lumpability and spectral-rigidity theorems.
\end{theorem}

\begin{proof}
The fiber table determines \(M\), and the displayed lists are exactly the entries of \(T_mM\) after multiplying by \(m\): for \(\omega\in F^{-1}(x)\), the \((\omega,y)\)-entry of \(T_mM\) is \(c_\omega(y)/m\).  Hence \(T_mM=MP\) can hold for some matrix \(P\) precisely when, for each pair \((x,y)\), this entry is independent of the choice of \(\omega\in F^{-1}(x)\).  This is exactly constancy of every \(\mathcal C_{x,y}(F)\).  When the lists are constant, Lemma \ref{lem:equitable-strong-lumpability-audited-pushforward} identifies the unique quotient with \(P_F\), and Theorem \ref{thm:window6-strong-lumpability-spectral-rigidity} gives the hypercube spectral inclusion.  This proves \textup{(i)}.

If a list has diameter \(\delta\), choose two entries in that list attaining its minimum and maximum.  Theorem \ref{thm:local-residual-certificate-hypercube-folds} applied to these two rows gives the lower bound \(\delta/(2m)\) for every visible compression matrix and rules out exact intertwining.  This proves \textup{(ii)}.

For \textup{(iii)}, clearing denominators in \(\det(tI-P_F)\) does not change the real zeros.  Sturm's theorem counts zeros in a rational interval from the signs of the exact Sturm sequence at the two endpoints.  If such an interval avoids the hypercube grid but contains a zero of the cleared characteristic polynomial, then \(P_F\) has an off-grid eigenvalue.  The contrapositive statement in Theorem \ref{thm:window6-strong-lumpability-spectral-rigidity} therefore excludes \(P_F\) from the class of equitable quotient kernels on the same visible blocks.  The final sentence is only the assembly of these three proved implications. \qedhere
\end{proof}

\begin{theorem}[Fold\texorpdfstring{$_m^{\mathrm{bin}}$}{m bin} finite residual certificate package]\label{thm:foldbin-family-certificate-algorithm}
For every \(m\ge1\), the binary Zeckendorf-prefix fold \(\Fold_m^{\mathrm{bin}}:\Omega_m\twoheadrightarrow X_m\) admits a finite integer residual certificate package deciding strong lumpability on its visible state space and classifying all approximate visible intertwiners.  More precisely, let
\[
d_x=\bigl| (\Fold_m^{\mathrm{bin}})^{-1}(x)\bigr|,
\qquad
N_{xy}=\#\{(\omega,i):\Fold_m^{\mathrm{bin}}(\omega)=x,
\ \Fold_m^{\mathrm{bin}}(\omega+e_i)=y\},
\]
and set \(P_m^{\mathrm{bin}}(x,y)=N_{xy}/(m d_x)\).  For \(\omega\in\Omega_m\) and \(y\in X_m\), put
\[
c_\omega(y)=\#\{1\le i\le m:\Fold_m^{\mathrm{bin}}(\omega+e_i)=y\}.
\]
Then the following effective structural dichotomy holds.
\begin{enumerate}[label=\textup{(\roman*)}]
\item If, for every pair \(x,y\in X_m\), the list \(\bigl(c_\omega(y)\bigr)_{\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)}\) is constant, then \(\Fold_m^{\mathrm{bin}}\) is an equitable quotient of \(Q_m\), its quotient kernel is exactly \(P_m^{\mathrm{bin}}\), and
\[
\Spec(P_m^{\mathrm{bin}})\subseteq\{1-2k/m:0\le k\le m\}.
\]
\item If one such list is not constant, then any two unequal entries give a two-vertex residual certificate: no matrix \(P\) satisfies \(T_mM_m=M_mP\), where \(M_m\) is the block-indicator matrix of \(\Fold_m^{\mathrm{bin}}\).  If the two entries differ by \(\delta\), then every visible matrix has one of the two corresponding entries of absolute residual at least \(\delta/(2m)\).
\item The same enumeration computes the residual diameter tensor \(\Delta_m(x,y)\) of Theorem \ref{thm:foldbin-complete-residual-budget-skeleton}.  Consequently it computes the exact interval product \(\mathcal P_m(\epsilon)\) of all visible matrices with \(\|T_mM_m-M_mP\|_\infty\le\epsilon\), and in particular the sharp unconstrained residual radius \(\Delta_m/(2m)\).
\item Independently, let \(C_m(t)\in\ZZ[t]\) be any nonzero integer multiple of \(\det(tI-P_m^{\mathrm{bin}})\).  If a Sturm sequence for \(C_m\) has a variation drop on a rational interval \((a,b)\) disjoint from \(\{1-2k/m:0\le k\le m\}\), with \(C_m(a)C_m(b)\ne0\), then \(P_m^{\mathrm{bin}}\) has an off-grid eigenvalue and therefore is not an equitable quotient kernel of \(Q_m\).
\end{enumerate}
All entries in this criterion are obtained by finite integer enumeration of the block-indicator encoding
\[
\mathcal F_m=\bigl(x:(\Fold_m^{\mathrm{bin}})^{-1}(x)\bigr)_{x\in X_m},
\]
so the window-\(6\) table in Proposition \ref{prop:foldbin6-canonical-fiber-table}, the matrix of Proposition \ref{prop:foldbin6-exact-pushforward-matrix}, the exact residual distribution in Theorem \ref{thm:foldbin6-exact-residual-diameter-distribution}, and the spectral certificate of Theorem \ref{thm:single-exact-fold6-certificate} are the audited \(m=6\) specialization of this criterion.
Equivalently, they are the audited \(m=6\) specialization of the reusable interface in Theorem \ref{thm:reusable-exact-certificate-interface-hypercube-folds}.
\end{theorem}

\begin{proof}
For fixed \(m\), the set \(\Omega_m\) is finite and Definition \ref{def:audited-binary-fold-certificate} gives an explicit value of \(\Fold_m^{\mathrm{bin}}(\omega)\) for each \(\omega\).  Thus the fiber table \(\mathcal F_m\), the cardinalities \(d_x\), the neighbor-count lists \(c_\omega(y)\), and the edge counts \(N_{xy}\) are finite integer sums.  The formula for \(P_m^{\mathrm{bin}}\) is exactly the audited pushforward formula \(D^{-1}M_m^\top T_mM_m\) from Section \ref{sec:preliminaries}.

The first two alternatives are Theorem \ref{thm:finite-certificate-dichotomy-hypercube-folds} applied to the particular surjection \(F=\Fold_m^{\mathrm{bin}}\).  In the constant-list case, Lemma \ref{lem:equitable-strong-lumpability-audited-pushforward} identifies the unique strong-lumpability kernel with the audited pushforward, and Theorem \ref{thm:window6-strong-lumpability-spectral-rigidity} gives the hypercube spectral inclusion.  In the nonconstant-list case, Theorem \ref{thm:local-residual-certificate-hypercube-folds} gives the nonintertwining conclusion and the residual bound \(\delta/(2m)\).

The tensor \(\Delta_m(x,y)\) is obtained from the same neighbor-count lists by taking integer maxima and minima.  The interval product \(\mathcal P_m(\epsilon)\), the sharp residual radius, and the classifying two-row skeletons are exactly Theorem \ref{thm:foldbin-complete-residual-budget-skeleton} applied to this tensor.  This proves \textup{(iii)}.

For the spectral certificate, multiplying \(\det(tI-P_m^{\mathrm{bin}})\) by a nonzero integer does not change its real zeros.  Since the entries of \(P_m^{\mathrm{bin}}\) are rational, such a clearing denominator exists.  Sturm's theorem applied to \(C_m\) counts the zeros in \((a,b)\) when neither endpoint is a zero; a positive variation drop therefore supplies an eigenvalue of \(P_m^{\mathrm{bin}}\) in that interval.  If the interval is disjoint from the hypercube grid, the spectral inclusion in the equitable case is impossible, so the audited pushforward is not an equitable quotient kernel.  The window-\(6\) certificate is obtained by substituting the printed fiber table, edge-count matrix, and characteristic-polynomial/Sturm data into the same construction. \qedhere
\end{proof}

\begin{theorem}[Exact residual-budget classification for a binary fold]\label{thm:foldbin-complete-residual-budget-skeleton}
For every fixed \(m\ge1\), the visible obstruction to strong lumpability of the binary fold \(\Fold_m^{\mathrm{bin}}:\Omega_m\twoheadrightarrow X_m\) is completely controlled by the integer diameter tensor
\[
\Delta_m(x,y):=\max_{\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)} c_\omega(y)
-
\min_{\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)} c_\omega(y),
\qquad x,y\in X_m,
\]
where \(c_\omega(y)=\#\{1\le i\le m:\Fold_m^{\mathrm{bin}}(\omega+e_i)=y\}\).  Put \(\Delta_m:=\max_{x,y}\Delta_m(x,y)\).  For \(\epsilon\ge0\), define the residual interval
\[
I_\epsilon(x,y):=
\left[
\frac{1}{m}\max_{\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)}c_\omega(y)-\epsilon,
\frac{1}{m}\min_{\omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x)}c_\omega(y)+\epsilon
\right].
\]
Then:
\begin{enumerate}[label=\textup{(\roman*)}]
\item \(\Fold_m^{\mathrm{bin}}\) is an equitable quotient of \(Q_m\) if and only if \(\Delta_m=0\).  In that case the unique visible intertwining matrix is the audited pushforward \(P_m^{\mathrm{bin}}=D^{-1}M_m^\top T_mM_m\).
\item For an arbitrary real matrix \(P\) on \(X_m\),
\[
\|T_mM_m-M_mP\|_\infty\le\epsilon
\]
holds if and only if
\[
P(x,y)\in I_\epsilon(x,y)
\qquad\text{for every }x,y\in X_m.
\]
Consequently the set of all \(\epsilon\)-intertwiners is the explicit interval product
\[
\mathcal P_m(\epsilon):=
\prod_{x,y\in X_m}I_\epsilon(x,y),
\]
intersected, if one insists on Markov kernels, with the row-stochastic simplex.
\item The unconstrained visible Chebyshev radius is exactly
\[
\inf_{P\in\RR^{X_m\times X_m}}
\|T_mM_m-M_mP\|_\infty
=\frac{\Delta_m}{2m}.
\]
It is attained precisely by those real matrices \(P\) with
\[
P(x,y)\in I_{\Delta_m/(2m)}(x,y)
\qquad\text{for every }x,y\in X_m.
\]
In particular, if \(\Delta_m>0\), then every proposed visible Markov kernel satisfies the uniform lower bound
\[
\|T_mM_m-M_mP\|_\infty\ge \frac{\Delta_m}{2m}.
\]
\item For the audited pushforward \(P_m^{\mathrm{bin}}=D^{-1}M_m^\top T_mM_m\), one has
\[
\frac{\Delta_m}{2m}\le
\|T_mM_m-M_mP_m^{\mathrm{bin}}\|_\infty
\le \frac{\Delta_m}{m}.
\]
Moreover the residual entries in a fixed source fiber \(x\) and target column \(y\) are exactly
\[
\frac{1}{m}\left(c_\omega(y)-\frac{1}{d_x}
\sum_{\eta\in(\Fold_m^{\mathrm{bin}})^{-1}(x)}c_\eta(y)\right),
\qquad \omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x).
\]
\item Every positive residual budget has a classifiable two-row, one-column bad-example skeleton: if \(\Delta_m(x,y)>0\), choose \(\omega_-,\omega_+\in(\Fold_m^{\mathrm{bin}})^{-1}(x)\) attaining the minimum and maximum of \(c_\omega(y)\).  Then \((\omega_-,\omega_+;y)\) alone proves that every visible matrix has error at least \(\Delta_m(x,y)/(2m)\) on this source--target coordinate.  Pairs with \(\Delta_m(x,y)=\Delta_m\) are exactly the skeletons that force the global radius in \textup{(iii)}.
\end{enumerate}
Thus the obstruction at each fixed window is not a floating-point or spectral accident: it is an integral diameter tensor whose interval polytope classifies all exact and approximate visible intertwiners.  In window \(6\), Theorem \ref{thm:foldbin6-exact-residual-diameter-distribution} computes this tensor and its extremal skeletons explicitly enough for the main theorem chain.
\end{theorem}

\begin{proof}
For fixed \(x,y\), the entries of the column \(T_mM_m(\cdot,y)\) on the source fiber over \(x\) are precisely \(c_\omega(y)/m\).  Since the column of \(M_mP\) is constant on that same source fiber and has value \(P(x,y)\), the residual inequalities for this single source--target coordinate are
\[
\left|\frac{c_\omega(y)}{m}-P(x,y)\right|\le\epsilon,
\qquad \omega\in(\Fold_m^{\mathrm{bin}})^{-1}(x).
\]
Their common solution set is the intersection of the intervals
\[
\left[\frac{c_\omega(y)}{m}-\epsilon,
\frac{c_\omega(y)}{m}+\epsilon\right],
\]
which is exactly \(I_\epsilon(x,y)\).  The coordinates \((x,y)\) are independent for the entrywise norm, so the product of these intervals is precisely the full set of real matrices satisfying \(\|T_mM_m-M_mP\|_\infty\le\epsilon\).  If stochasticity is imposed, no residual equation changes; one simply intersects this interval product with the affine inequalities defining row-stochastic Markov kernels.  This proves \textup{(ii)}.

The interval \(I_\epsilon(x,y)\) is nonempty if and only if
\[
\frac{1}{m}\max_{\omega}c_\omega(y)-\epsilon
\le
\frac{1}{m}\min_{\omega}c_\omega(y)+\epsilon,
\]
where the extrema are taken over \((\Fold_m^{\mathrm{bin}})^{-1}(x)\).  This is equivalent to
\[
\epsilon\ge \frac{\Delta_m(x,y)}{2m}.
\]
Therefore all coordinate intervals are simultaneously nonempty if and only if \(\epsilon\ge\Delta_m/(2m)\), proving the exact Chebyshev-radius formula and the minimizer description in \textup{(iii)}.  The same argument applied to a single pair \((x,y)\), with two vertices attaining the minimum and maximum, gives the two-row skeleton statement in \textup{(v)} and the lower bound for Markov kernels in \textup{(iii)}.

Taking \(\epsilon=0\) in \textup{(ii)} shows that an exact visible intertwining exists if and only if every interval \(I_0(x,y)\) is nonempty, equivalently if and only if every source-fiber target-count list is constant, equivalently if and only if \(\Delta_m=0\).  By Lemma \ref{lem:equitable-strong-lumpability-audited-pushforward}, this is exactly the equitable, or strongly lumpable, condition.  The same lemma also identifies the exact visible kernel with \(D^{-1}M_m^\top T_mM_m=P_m^{\mathrm{bin}}\).  This proves \textup{(i)}.

For the audited pushforward, the entry \(P_m^{\mathrm{bin}}(x,y)\) is the average of \(c_\eta(y)/m\) over \(\eta\in(\Fold_m^{\mathrm{bin}})^{-1}(x)\).  Substituting this average gives the displayed residual formula.  The lower bound follows from \textup{(iii)} by taking \(P=P_m^{\mathrm{bin}}\).  The upper bound follows because every entry in a fixed list lies within its full diameter of its average, so
\[
\left|\frac{c_\omega(y)}{m}-P_m^{\mathrm{bin}}(x,y)\right|
\le \frac{\Delta_m(x,y)}{m}
\le \frac{\Delta_m}{m}.
\]
This proves \textup{(iv)} and completes the residual-budget classification. \qedhere
\end{proof}

\begin{proposition}[Explicit window-\texorpdfstring{$6$}{6} nonintertwining witness]\label{prop:foldbin6-explicit-nonintertwining-witness}

\[
\omega=000000,
\qquad
\omega'=010101
\]
belong to the same fold fiber, namely
\[
\Fold_6^{\mathrm{bin}}(\omega)=\Fold_6^{\mathrm{bin}}(\omega')=000000.
\]
However their target-fiber neighbor counts differ.  For the target folded state \(y=000100\), one has
\[
c_\omega(y)=\#\{1\le i\le6:\Fold_6^{\mathrm{bin}}(\omega+e_i)=000100\}=0,
\]
whereas
\[
c_{\omega'}(y)=\#\{1\le i\le6:\Fold_6^{\mathrm{bin}}(\omega'+e_i)=000100\}=1.
\]
Consequently the block-indicator matrix \(M\) of \(\Fold_6^{\mathrm{bin}}\) admits no intertwining \(T_6M=MP\).  Moreover, for the audited pushforward residual \(R_6:=T_6M-MP_6\), at least one of the two entries \(|R_6(000000,000100)|\) and \(|R_6(010101,000100)|\) is at least \(1/12\).
\end{proposition}

\begin{proof}
The first vertex has integer code \(N(000000)=0\), hence all initial Zeckendorf digits are zero and \(\Fold_6^{\mathrm{bin}}(000000)=000000\).  The second has
\[
N(010101)=16+4+1=21=F_8.
\]
Thus its greedy Zeckendorf expansion has its first nonzero digit in position \(7\,\), and its length-\(6\) prefix is again \(000000\).  Hence the two vertices lie in the same fiber over \(x=000000\).

It remains to compare their one-step folded neighbor counts.  Flipping the six coordinates of \(000000\) gives folded targets
\[
001010,
010000,
101000,
000010,
100000,
001001,
\]
in coordinate order.  None is \(000100\).  Therefore \(c_{000000}(000100)=0\).  Flipping the six coordinates of \(010101\) gives folded targets
\[
000100,
100101,
010101,
010000,
101001,
000010,
\]
in coordinate order.  Exactly the first of these is \(000100\), so \(c_{010101}(000100)=1\).

Theorem \ref{thm:local-residual-certificate-hypercube-folds}, applied with \(m=6\), now rules out any matrix \(P\) satisfying \(T_6M=MP\).  The same theorem gives the residual lower bound with \(\delta=1\): at least one of the two audited residual entries has absolute value at least \(1/(2\cdot6)=1/12\). \qedhere
\end{proof}

\begin{theorem}[Boundary of the obstruction: no hidden-refinement exclusion]\label{thm:hidden-refinement-boundary}
The window-\(6\) nonlumpability conclusions in Theorem \ref{thm:single-exact-fold6-certificate} and Corollary \ref{cor:terminal-window6-nonlumpable-by-spectrum} are exactly statements about the one-step quotient on the visible state set \(X_6\).  They rule out the existence of a kernel \(P\) on \(X_6\) satisfying
\[
T_6M=MP
\]
for the block-indicator matrix \(M\) of \(\Fold_6^{\mathrm{bin}}\), and they rule out realizing the matrix \(P_6\) itself as an equitable quotient kernel of \(Q_6\) on those same visible blocks.  They do not rule out the existence of a different finite state space \(Y\), a surjection \(H:\Omega_6\twoheadrightarrow Y\), and a factor map \(\rho:Y\twoheadrightarrow X_6\) with \(\Fold_6^{\mathrm{bin}}=\rho\circ H\), for which the partition defined by \(H\) is equitable.
\end{theorem}

\begin{proof}
Theorem \ref{thm:local-residual-certificate-hypercube-folds} applies to a specified surjection \(F:\Omega_m\twoheadrightarrow X\) and the corresponding block-indicator matrix.  In the window-\(6\) application, that specified surjection is \(F=\Fold_6^{\mathrm{bin}}\) and the block-indicator matrix is its visible-fiber matrix \(M\).  Proposition \ref{prop:foldbin6-explicit-nonintertwining-witness} gives two vertices in one visible fiber and one visible target state whose one-step target-fiber counts differ.  Therefore the theorem proves that no kernel on the same visible state set \(X_6\) can satisfy \(T_6M=MP\).

Likewise, the spectral obstruction in Theorem \ref{thm:window6-strong-lumpability-spectral-rigidity} is applied to the pushforward matrix \(P_6=D^{-1}M^\top T_6M\) associated with this same visible matrix \(M\).  Lemma \ref{lem:foldbin6-eigenvalue-interval-certificate} shows that \(P_6\) has off-grid eigenvalues, so \(P_6\) cannot be an equitable quotient kernel on those visible blocks.

A hidden refinement replaces \(M\) by another block-indicator matrix \(M_H\) for a different surjection \(H:\Omega_6\twoheadrightarrow Y\).  The residual counts, the pushforward matrix, and the quotient spectrum tested by the above theorems are then those of \(H\), not those of \(\Fold_6^{\mathrm{bin}}\).  Since the hypotheses and computed certificates in this paper contain no data for all such refinements \(H\), the logical conclusion is exactly the stated visible one-step obstruction and not a universal no-hidden-refinement theorem. \qedhere
\end{proof}
