\section{Population branch certificate only for the diagonal candidate \(z=1/2\)}\label{app:self-contained-diagonal-branch-certificate-main}

This appendix is the finite branch certificate used in
\Cref{def:dmap-diagonal-rank-certificate-main} and
\Cref{rem:worked-diagonal-branch-certificate-main}.  It certifies only the
single diagonal candidate
\[
Z_{\rm cert}=\{1/2\}.
\]
\recordscopebox{\textbf{Scope of Appendix B.}
This transcript certifies only
\(\operatorname{rank}\Sigma_\sigma(1/2)=2\).  It is not a finite-record
inference certificate because it contains neither a critical-value bracket
\([L,U]\) nor a statistic enclosure \([Q]\).  The paper-local replay command is
\texttt{python certificates/diagonal\_branch\_certificate.py --test}.}
No other diagonal point has a printed branch certificate in this article.
This transcript is a population branch certificate only.  It is not a
finite-record critical-value transcript and, by itself, it does not certify a
realized accept/reject/undecided comparison for any retained record.

The arithmetic is interval arithmetic in base-ten decimal arithmetic with
precision \(90\) significant digits.  Every lower endpoint below is rounded
downward and every upper endpoint is rounded upward.  Long decimal strings are
wrapped typographically; the line breaks and indentation inside one endpoint
are not digits.  The supplementary material gives the paper-local replay
script, stored JSON transcript, environment, command lines, and transcript
hash.  The present appendix prints the mathematical transcript used by the
main theorem and should not be read as a finite-record transcript: it contains
no retained-record critical-value bracket \([L,U]\) and no statistic enclosure
\([Q]\).

\begin{lemma}[Certified population full-rank branch at \(z=1/2\)]\label{lem:z-half-diagonal-branch-certificate-main}
Let
\[
z=\frac12,\qquad \theta=\log2,\qquad
g_0=\frac{1-\log2}{2},\qquad g_1=\frac14,
\]
\[
\mu=2+2\log2,\qquad m_2=g_1+g_0^2 .
\]
Evaluate the finite matrices \(A_z,B_z,e_z,d_z\) and the Jacobian
\(D\Phi(r(z))\) in
\Cref{prop:computable-diagonal-covariance-main} by the directed interval
arithmetic transcript in \Cref{tab:diagonal-branch-transcript-main}, with
rounding mode \(R\) equal to downward rounding for lower endpoints and upward
rounding for upper endpoints, and precision \(P=90\) significant decimal
digits.  The supplementary material gives the machine replay of this
population branch transcript, including the exact JSON transcript and
environment.  Those replay files are evidence for the printed interval
arithmetic only; they do not add a retained-record critical-value bracket or
statistic enclosure.
The resulting enclosure for
\[
\Sigma_\sigma(1/2)
=D\Phi(r(1/2))\Sigma_r(1/2)D\Phi(r(1/2))^\top
\]
satisfies
\[
\operatorname{tr}\Sigma_\sigma(1/2)
\in[36.95298777813731,36.95298777813732],
\]
\[
\det\Sigma_\sigma(1/2)
\in[1.372485374000321,1.372485374000322].
\]
Therefore \(z=1/2\) belongs to the certified domain \(Z_{\rm cert}\), and the
certified population branch at this candidate is the full-rank branch:
\[
\operatorname{rank}\Sigma_\sigma(1/2)=2.
\]
This certificate supplies only the population branch input used by
Theorem~E's ideal fixed-null asymptotics.  It supplies no retained-record
critical-value bracket \([L,U]\), no statistic enclosure \([Q]\), and no
complete finite comparison tuple.
\end{lemma}

\begin{proof}
The preceding transcript is an outward-rounded directed interval evaluation of
the finite D-MAP covariance and quotient-sandwich formulas, with the exact
input singleton \([z]=[0.5,0.5]\).  By
\Cref{lem:diagonal-interval-branch-certificate-main}, the determinant
enclosure contains the true determinant
\(\det\Sigma_\sigma(1/2)\).  Its lower endpoint is larger than \(1.37\), and
therefore
\[
[I_{\det}]\subset[1.37,\infty).
\]
Thus the full-rank branch condition in
\Cref{def:dmap-diagonal-rank-certificate-main} holds with branch margin
\(\eta=1.37\).  The mutually exclusive branch classification in
\Cref{lem:dmap-diagonal-covariance-alternatives-main} then gives
\(\operatorname{rank}\Sigma_\sigma(1/2)=2\).  Since the transcript is attached
only to the singleton input interval, it certifies no candidate other than
\(z=1/2\).  There is therefore no terminal subinterval list for a continuum
\(Z_{\rm cert}\) in this appendix; any later interval-valued certified domain
would have to print its terminal subintervals and margins separately.  Since
the transcript contains no record-specific \([L,U]\) or \([Q]\), it is not a
finite comparison certificate for a realized record.
\end{proof}
