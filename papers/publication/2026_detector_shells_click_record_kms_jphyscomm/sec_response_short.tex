\section{External Calibration Note}\label{sec:kms-shells}

This section is not a response-profile appendix and is not part of the
record-law theorem chain.  It only records the following external-calibration
translation: after all record theorems have been proved from the labelled
sampled kernels \(T_0,T_1\), a separately supplied positive \(C^1\) scalar
profile may be evaluated at the record-selected constants.

\begin{assumption}[External supplied-profile calibration]\label{ass:udw-rate-calibration-main}
Fix a \(C^1\) manifold \(U\), a gap \(\Omega>0\), a sampling interval
\(\Delta\tau>0\), and one externally supplied positive \(C^1\) function
\[
R_\Omega:U\to(0,\infty).
\]
For an optional response interpretation impose the scalar closure
\[
\Gamma=R_\Omega(x).
\]
For the sampled boundary-reset memory target, also supply an independently
labelled recovery rate \(\kappa_{\mathrm r}>0\).  That label is not obtained
from one visible sampled record, because
\[
\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma},
\qquad
\text{and the visible law identifies only }
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}.
\]
\end{assumption}

\begin{corollary}[External calibration of the two record-selected constants]
\label{cor:conditional-calibration-bridge-main}\label{thm:response-locus-main}
Assume \Cref{ass:udw-rate-calibration-main}.  The ideal Parry record condition
and the sampled boundary-reset memory condition become, respectively,
\[
R_\Omega(x)=\gamma_\varphi,
\qquad
R_\Omega(x)=\gamma_{\mathrm{mem}},
\]
where
\[
\gamma_\varphi=\frac{\log\varphi}{\Delta\tau},
\qquad
\gamma_{\mathrm{mem}}=
\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau).
\]
Equivalently, the optional response-level sets are
\[
R_\Omega^{-1}(\gamma_\varphi),
\qquad
R_\Omega^{-1}(\gamma_{\mathrm{mem}}),
\]
with the second expression meaningful only after the external
\(\kappa_{\mathrm r}\) label has been supplied.  For any target
\(\gamma>0\), the set \(R_\Omega^{-1}(\gamma)\) is nonempty exactly when
\(\gamma\in R_\Omega(U)\).  If \(dR_\Omega\ne0\) on a component, the ordinary
regular-level-set theorem makes that component a \(C^1\) hypersurface; if this
regularity check fails, no geometric conclusion is asserted.
\end{corollary}

\begin{proof}
\Cref{prop:ideal-main} gives the ideal record condition
\(\Gamma=\log\varphi/\Delta\tau\).  \Cref{thm:recovery-main,lem:one-dep-criterion-main}
give the sampled boundary-reset memory condition
\(\Gamma=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)\), subject to
the external recovery-rate label in
\Cref{ass:udw-rate-calibration-main}.  Substituting the external closure
\(\Gamma=R_\Omega(x)\) gives the two inverse images.  The range statement is
the definition of the image of \(R_\Omega\), and the local hypersurface
statement is the regular-level-set theorem.  No response profile,
microscopic detector dynamics, switching or smearing limit, field update rule,
response-locus estimator, or spatial-location confidence set is proved or
used.
\end{proof}

\begin{remark}[No response-side theorem family]\label{rem:external-calibration-only-main}
The function \(R_\Omega\) is an input, not an output.  KMS detailed balance,
detector switching, smearing, ultraviolet regularization, and any spatial
calibration needed to construct such a function belong to a separate model.
This manuscript proves no theorem transferring a microscopic detector-field
model to \(T_0,T_1\), and no finite record here estimates or localizes the
sets \(R_\Omega^{-1}(\gamma)\).
\end{remark}
