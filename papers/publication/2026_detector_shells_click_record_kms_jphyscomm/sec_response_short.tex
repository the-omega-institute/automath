\section{Conditional response-rate calibration corollary}\label{sec:kms-shells}

The record theorems above are stated for the classical sampled counter before
any detector-response calibration is imposed. This section contains only the
paper-level bridge needed to read those record thresholds as response targets.
Homogeneous-shell, horizon, fixed-radius, Schwarzschild, external-ratio, and
residual-graph algebra is kept outside the present theorem chain. The main
statement in this section is deliberately a conditional corollary of the record
theorems, Assumption~A0, and the ordinary regular-level-set theorem; it is not
a theorem deriving a detector measurement law.

\paragraph{Label boundary before any response statement.}
The exact inverse theorem on the record side recovers only the unordered
survival factors, equivalently only the unordered attempt/recovery rate pair,
from one visible sampled record
\[
\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma},
\qquad
\text{and hence only}\qquad
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}
\]
(\Cref{thm:toeplitz_image_inverse_duality,prop:hidden_label_exchange_nonidentifiability}).
Therefore the response corollary below is not a labelled-rate inverse theorem.
Its memory locus uses the labelled scalar
\(\Gamma_c(\kappa_{\mathrm r},\Delta\tau)\) only after
\(\kappa_{\mathrm r}\) has been supplied by detector calibration, hardware
recovery measurement, or an external experimental protocol not contained in the
single visible record.  Without that independent label, the record-level
critical condition and the response statement must be read on the quotient by
\((\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma)\), and no labelled
memory response locus \(\Sigma_{\mathrm{mem}}\) is asserted.

\begin{assumption}[A0, calibrated attempt-rate closure]\label{ass:udw-rate-calibration-main}
Fix a static region \(U\), a detector gap \(\Omega>0\), a sampling interval
\(\Delta\tau>0\), and, for the sampled boundary-reset memory target, an
independently calibrated labelled recovery rate \(\kappa_{\mathrm r}>0\).
The record process is either the
classical sampled one-recovery-opportunity boundary-reset instrument of
\Cref{prop:instrument-kernels-main} or the stipulated ideal blanking
instrument of \Cref{prop:ideal-main}. A stationary response calculation,
which in the UDW/KMS examples below is the standard stationary UDW calculation,
supplies a positive excitation rate \(\Gamma_+(x,\Omega)\). The only coupling
between the record theorem and that response calculation is the scalar
identification
\[
\Gamma=\Gamma_+(x,\Omega).
\]
Equivalently, after one fixed response profile \(R_\Omega:U\to(0,\infty)\) has
been chosen, the closure is
\[
\Gamma=R_\Omega(x)=\Gamma_+(x,\Omega).
\]
No claim is made that the sampled boundary-reset law, the ideal blanking law,
or their binary HMM records are derived from UDW detector dynamics. For the
memory target this is also a labelled-rate assumption, not an output of the
inverse theorem:
\[
\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma},
\qquad
\text{visible data identify only }
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}.
\]
Thus \(\kappa_{\mathrm r}\) is externally fixed, externally labelled, or
independently calibrated before
\(\Gamma_c(\kappa_{\mathrm r},\Delta\tau)\) is used as a response target.
Without that label, the visible sampled record supplies only the unordered
attempt/recovery rate pair of \Cref{thm:toeplitz_image_inverse_duality}, and
the response theorem is stated only on the quotient by
\((\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma)\).
\end{assumption}

\begin{corollary}[Conditional fixed-response loci under A0]\label{cor:conditional-calibration-bridge-main}\label{thm:response-locus-main}
Let \(U\) be a \(C^1\) manifold and let
\(R_\Omega:U\to(0,\infty)\) be \(C^1\). Under
\Cref{ass:udw-rate-calibration-main}, impose the following named hypotheses:
\begin{enumerate}[label=\textup{(R\arabic*)},leftmargin=2.2em,itemsep=0.2em]
\item one fixed \(C^1\) response profile \(R_\Omega:U\to(0,\infty)\);
\item positivity of that profile on \(U\);
\item the A0 calibration closure \(\Gamma=R_\Omega(x)=\Gamma_+(x,\Omega)\);
\item for a target \(\gamma\), the range condition
\(\gamma\in R_\Omega(U)\);
\item at a point \(x_0\in R_\Omega^{-1}(\gamma)\), the regular value condition
\(dR_\Omega(x_0)\ne0\).
\end{enumerate}
For the memory target, (R3) includes the labelled-rate part of A0: the recovery
rate \(\kappa_{\mathrm r}\) is independently calibrated or externally labelled
before the level \(\Gamma=\Gamma_+(x,\Omega)\) is interpreted as an
attempt-rate locus.
If that label is absent, the record theorem supplies only the quotient datum
\(\{\Gamma,\kappa_{\mathrm r}\}\) of
\Cref{thm:toeplitz_image_inverse_duality,prop:hidden_label_exchange_nonidentifiability},
and no labelled memory response locus is asserted from one visible sampled
record alone.
The record-selected target rates are
\[
\gamma_\varphi=\frac{\log\varphi}{\Delta\tau},
\qquad
\gamma_{\mathrm{mem}}=\Gamma_c(\kappa_{\mathrm r},\Delta\tau),
\]
where the second expression is a labelled target only under the independent
\(\kappa_{\mathrm r}\) calibration in A0. Equivalently, the memory target
\(R_\Omega(x)=\Gamma_c(\kappa_{\mathrm r},\Delta\tau)\) is meaningful only
after \(\kappa_{\mathrm r}\) has been independently labelled by detector
calibration, hardware recovery measurement, or an external experimental
protocol; otherwise it is only a quotient statement under
\((\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma)\). The
corresponding response loci are exactly
\[
\Sigma_\varphi=R_\Omega^{-1}(\gamma_\varphi),
\qquad
\Sigma_{\mathrm{mem}}=R_\Omega^{-1}(\gamma_{\mathrm{mem}}).
\]
For any \(\gamma>0\), \(R_\Omega^{-1}(\gamma)\) is empty if and only if
\(\gamma\notin R_\Omega(U)\). If \(x_0\in R_\Omega^{-1}(\gamma)\) and
\[
dR_\Omega(x_0)\ne0,
\]
then \(R_\Omega^{-1}(\gamma)\) is, near \(x_0\), an embedded \(C^1\)
hypersurface with normal covector \(dR_\Omega(x_0)\). A response-locus
component is called a shell only at points satisfying the range and regularity
conditions (R4)--(R5). If \(dR_\Omega(x_0)=0\), no conclusion is drawn and no
converse regular-level-set implication is asserted.

When the fixed profile is represented by the static KMS response convention
used in this paper,
\[
R_\Omega(x)
=\lambda_{\mathrm{sw}}^2
\frac{\mathcal S_x(\Omega)}
{e^{\beta_\infty\Omega N(x)}-1},
\]
where \(x\mapsto\mathcal S_x(\Omega)\) is a supplied positive one-gap spectral
weight, the differential is
\[
dR_\Omega
=\lambda_{\mathrm{sw}}^2\left[
\frac{d\mathcal S_x(\Omega)}{e^{\beta_\infty\Omega N}-1}
-\frac{\mathcal S_x(\Omega)\beta_\infty\Omega e^{\beta_\infty\Omega N}}
{(e^{\beta_\infty\Omega N}-1)^2}\,dN
\right].
\]
KMS detailed balance fixes the ratio \(\Gamma_-/\Gamma_+\), not this absolute
positive-frequency profile. Thus the corollary is only target-rate level-set
bookkeeping after one response profile has been supplied; it is not a new UDW
response theorem and it does not derive either record law from detector
dynamics.
\end{corollary}

\begin{proof}
\Cref{prop:ideal-main} gives the ideal-counter condition
\(\Gamma\Delta\tau=\log\varphi\), equivalently
\(\Gamma=\gamma_\varphi\). \Cref{thm:recovery-main,lem:one-dep-criterion-main}
give the sampled boundary-reset memory-transition condition
\(\Gamma=\Gamma_c(\kappa_{\mathrm r},\Delta\tau)=\gamma_{\mathrm{mem}}\).
This memory scalar is a labelled response target only after the externally
labelled value of \(\kappa_{\mathrm r}\) in A0 has been supplied by detector
calibration, hardware recovery measurement, or an external experimental
protocol. Without that datum,
\Cref{thm:toeplitz_image_inverse_duality,prop:hidden_label_exchange_nonidentifiability}
recovers the unordered pair of rates but does not choose which member is the
attempt rate to be identified with \(\Gamma_+(x,\Omega)\); the only available
response statement is then the quotient one under
\((\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma)\). Substituting the A0
closure \(\Gamma=R_\Omega(x)\) then gives the two displayed inverse images.

The nonemptiness statement is exactly the definition of the range of the fixed
function \(R_\Omega\). For the regularity statement, write
\(F(x)=R_\Omega(x)-\gamma\). Since \(\gamma\) is constant, \(dF=dR_\Omega\).
The displayed differential is the ordinary product and chain rule applied to
the fixed calibrated KMS response formula. If
\(dF(x_0)=dR_\Omega(x_0)\) is nonzero, the regular-level-set theorem gives
local coordinates \((y^1,\ldots,y^d)\) near \(x_0\) in which \(F=y^d\). Hence
\(F^{-1}(0)=\{y^d=0\}\) in those coordinates, so the level set is an embedded
\(C^1\) hypersurface near \(x_0\), with normal covector \(dR_\Omega(x_0)\).
This is the only regular-level-set implication used here. No converse is
asserted. In particular, when \(dR_\Omega(x_0)=0\), this corollary draws no
conclusion.
\end{proof}

\begin{remark}[Worked calibrated response profile with a regular response shell]\label{ex:worked-regular-response-profile-main}
This example is only a calibrated response profile satisfying the hypotheses of
\Cref{thm:response-locus-main}; it is not derived here as a new UDW measurement
model. Let
\[
U=(0,\infty),\qquad N(r)=1+r,\qquad
\mathcal S_r(\Omega)=S_0e^{\beta_\infty\Omega r},
\]
with \(S_0,\beta_\infty,\Omega,\lambda_{\mathrm{sw}}>0\).  Then the fixed
calibrated response profile
\[
R_\Omega(r)
=\lambda_{\mathrm{sw}}^2
\frac{S_0e^{\beta_\infty\Omega r}}
{e^{\beta_\infty\Omega(1+r)}-1}
\]
is positive and \(C^1\) on \(U\).  It is strictly decreasing, because with
\(B=\beta_\infty\Omega\),
\[
\frac{dR_\Omega}{dr}
=
-\lambda_{\mathrm{sw}}^2 S_0
\frac{B e^{Br}}{\bigl(e^{B(1+r)}-1\bigr)^2}
<0 .
\]
Moreover
\[
\lim_{r\downarrow0}R_\Omega(r)
=\frac{\lambda_{\mathrm{sw}}^2S_0}{e^B-1},
\qquad
\lim_{r\to\infty}R_\Omega(r)
=\lambda_{\mathrm{sw}}^2S_0e^{-B}.
\]
Hence every target
\[
\gamma\in
\left(
\lambda_{\mathrm{sw}}^2S_0e^{-B},
\frac{\lambda_{\mathrm{sw}}^2S_0}{e^B-1}
\right)
\]
lies in the range of \(R_\Omega\), has a unique solution
\[
r_\gamma
=\frac1B
\log\!\left(
\frac{\gamma}
{\gamma e^B-\lambda_{\mathrm{sw}}^2S_0}
\right),
\]
and satisfies \(dR_\Omega(r_\gamma)\ne0\).  Therefore
\(R_\Omega^{-1}(\gamma)=\{r_\gamma\}\) is a regular response shell in this
one-dimensional calibrated model.  If the detector parameters are chosen so
that either \(\gamma_\varphi\) or \(\gamma_{\mathrm{mem}}\) lies in the displayed
open interval, the corresponding record-selected response locus is a worked
regular shell of the kind allowed by \Cref{thm:response-locus-main}.  If a target
lies outside that interval, the range check fails and no shell is asserted.
\end{remark}

\begin{assumption}[Stationary one-gap UDW input used for calibration]\label{ass:kms-response-main}\label{ass:long-time-switch-main}
For each static worldline \(x\in U\) under discussion, let
\[
W_x(s)=\omega\!\left(\Phi_x(\tau)\Phi_x(\tau-s)\right)
\]
denote the stationary pulled-back two-point distribution, written as a function
of the proper-time difference \(s\). The Fourier convention in this paper is
\[
F_x(\omega)
=\int_{\mathbb R}e^{-i\omega s}W_x(s)\,ds
\]
whenever \(W_x\) is integrable, with the same sign convention understood
distributionally. Thus \(F_x=\widehat W_x\) in the earlier spectral-density
notation. Assume the stationary UDW detector response theorem applies with a
fixed nonzero smooth switching shape \(\chi\), detector profile, coupling scale
\(\lambda_c\), and gap \(\Omega>0\). The pulled-back spectral measure has a
restriction to a neighborhood of \(\pm\Omega\) that is absolutely continuous
with finite continuous density \(F_x(\nu)\), and has no atom or singular
component at either gap frequency. Assume also that the one-gap map
\[
x\longmapsto F_x(\Omega)
\]
is \(C^1\) on the static region \(U\) under consideration; in the KMS part
below we likewise assume \(x\mapsto F_x(-\Omega)\) is continuous at the gap.
The long-time switching limit is taken in the stationary window
convention
\[
\chi_T(\tau)=\chi(\tau/T),
\qquad
\lambda_{\mathrm{sw}}^2=\lambda_c^2\|\chi\|_2^2,
\]
so that the first-order transition probability divided by \(T\) has the rate
limit stated in \Cref{prop:stationary-udw-response-main}. If the state is KMS
with respect to static Killing time at inverse temperature \(\beta_\infty\), the
proper-time KMS parameter on the static orbit is
\(\beta_{\mathrm{loc}}(x)=\beta_\infty N(x)\).
\end{assumption}

\begin{proposition}[Stationary UDW response input at one gap]\label{prop:stationary-udw-response-main}
Under \Cref{ass:kms-response-main}, the long-time weak-coupling excitation and
de-excitation rates at the fixed detector gap are
\begin{equation}\label{eq:stationary-udw-rate-input-main}
\Gamma_+(x,\Omega)=\lambda_{\mathrm{sw}}^2F_x(\Omega),
\qquad
\Gamma_-(x,\Omega)=\lambda_{\mathrm{sw}}^2F_x(-\Omega),
\end{equation}
where excitation uses the positive argument \(F_x(\Omega)\) in the Fourier
convention above, and de-excitation uses \(F_x(-\Omega)\). More explicitly, the
switched first-order probabilities satisfy
\[
\lim_{T\to\infty}
\frac{P_{+,T}(x,\Omega)}{T}
=\lambda_{\mathrm{sw}}^2F_x(\Omega),
\qquad
\lim_{T\to\infty}
\frac{P_{-,T}(x,\Omega)}{T}
=\lambda_{\mathrm{sw}}^2F_x(-\Omega),
\]
which is \eqref{eq:stationary-udw-rate-input-main}. Equivalently,
\(P_{\pm,T}/(\lambda_c^2\|\chi_T\|_2^2)\to F_x(\pm\Omega)\), since
\(\|\chi_T\|_2^2=T\|\chi\|_2^2\). The excitation profile
\[
R_\Omega(x)=\Gamma_+(x,\Omega)=\lambda_{\mathrm{sw}}^2F_x(\Omega)
\]
is \(C^1\) by the one-gap differentiability hypothesis in
\Cref{ass:kms-response-main}. If the same stationary input is KMS, then
\begin{equation}\label{eq:kms-rate-main}
\frac{\Gamma_-(x,\Omega)}{\Gamma_+(x,\Omega)}
=e^{\beta_\infty N(x)\Omega},
\qquad
\Gamma_+(x,\Omega)=
\lambda_{\mathrm{sw}}^2
\frac{\mathcal S_x(\Omega)}{e^{\beta_\infty N(x)\Omega}-1}
\end{equation}
for the positive one-gap spectral weight
\[
\mathcal S_x(\Omega)
=\bigl(e^{\beta_\infty N(x)\Omega}-1\bigr)F_x(\Omega).
\]
This is the only UDW/KMS input used by the response bridge.
\end{proposition}

\begin{proof}
The standard stationary Unruh--DeWitt response theorem with smooth switching
and finite-size regularization identifies the long-window transition rate with
the absolutely continuous spectral density of the pulled-back two-point
function at the detector gap
\cite{Letaw1981,Schlicht2004,Satz2007,LoukoSatz2006,LoukoSatz2008,FewsterJuarezLouko2016}.
With the sign convention in \Cref{ass:kms-response-main}, the excitation
phase is \(e^{-i\Omega s}\), hence the excitation limit samples
\(F_x(\Omega)\); reversing the gap samples \(F_x(-\Omega)\) for
de-excitation. The normalized switching family is an approximate identity at
the corresponding frequency, so the displayed limits for \(P_{\pm,T}\) are
exactly the assumed stationary response input. The gap-regularity assumption
excludes atomic or singular contributions at \(\pm\Omega\), so no additional
distributional evaluation is being used. Since
\(\lambda_{\mathrm{sw}}^2\) is fixed and \(x\mapsto F_x(\Omega)\) is \(C^1\),
the calibrated excitation profile \(R_\Omega=\lambda_{\mathrm{sw}}^2F_x(\Omega)\)
is \(C^1\), as required by \Cref{thm:response-locus-main}.

The KMS condition for static Killing time, together with Tolman scaling of
proper time on the static orbit, gives the local detailed-balance relation
\(F_x(-\Omega)=e^{\beta_\infty N(x)\Omega}F_x(\Omega)\). Multiplication by the
common positive factor \(\lambda_{\mathrm{sw}}^2\) gives the rate ratio in
\eqref{eq:kms-rate-main}. The displayed form of \(\Gamma_+\) is then just the
definition of \(\mathcal S_x(\Omega)\), and no claim is made that KMS detailed
balance determines that positive function.
\end{proof}

\begin{lemma}[One-gap KMS underdetermination]\label{lem:one-gap-kms-underdetermination-main}
Fix the static lapse \(N\), inverse temperature \(\beta_\infty\), switching
scale \(\lambda_{\mathrm{sw}}>0\), and gap \(\Omega>0\). KMS detailed balance at
this one gap does not determine the positive excitation profile
\(x\mapsto\Gamma_+(x,\Omega)\). More precisely, for every positive \(C^1\)
function \(G:U\to(0,\infty)\), the one-gap assignments
\[
\Gamma_+^G(x,\Omega)=G(x),
\qquad
\Gamma_-^G(x,\Omega)=e^{\beta_\infty N(x)\Omega}G(x),
\qquad
\mathcal S_x^G(\Omega)=
\frac{e^{\beta_\infty N(x)\Omega}-1}{\lambda_{\mathrm{sw}}^2}G(x)
\]
satisfy the same KMS detailed-balance ratio and the same calibrated response
form \eqref{eq:kms-rate-main}. Consequently detailed balance plus Tolman
scaling alone cannot determine the response loci
\(R_\Omega^{-1}(\gamma)\); the positive profile \(R_\Omega=\Gamma_+\) is an
external calibration input.
\end{lemma}

\begin{proof}
The displayed assignments give
\(\Gamma_-^G/\Gamma_+^G=e^{\beta_\infty N(x)\Omega}\), so they obey the same
one-gap KMS detailed-balance relation for every choice of \(G\). Substituting
\(\mathcal S_x^G(\Omega)\) into \eqref{eq:kms-rate-main} gives
\(\Gamma_+^G(x,\Omega)=G(x)\). Because \(G\) was arbitrary among positive
\(C^1\) functions, the level set \(G^{-1}(\gamma)\) may have whatever range and
regularity behavior that chosen profile supplies. Hence KMS detailed balance
and Tolman scaling fix only the ratio of de-excitation to excitation rates, not
the positive excitation profile or its response loci.
\end{proof}

\begin{corollary}[Default fixed-response spectral transport identity]\label{cor:spectral-transport-main}
Work inside one fixed calibrated response profile of
\Cref{ass:udw-rate-calibration-main}, and for the memory member assume the
recovery rate has been independently labelled by detector calibration, hardware
recovery measurement, or an external experimental protocol. Without that label,
the memory member below is only a quotient statement under
\((\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma)\), since
\(\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma}\) and the
visible record identifies only
\(\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}\). Suppose
\(x_\varphi,x_{\mathrm{mem}}\in U\) satisfy the two record-selected response equations
\begin{equation}\label{eq:general-transport-source-main}
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_\varphi}(\Omega)\Delta\tau}
     {D_\varphi}
=\log\varphi,
\qquad
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_{\mathrm{mem}}}(\Omega)}
     {D_{\mathrm{mem}}}
=\Gamma_c(\kappa_{\mathrm r},\Delta\tau),
\end{equation}
where
\[
D_\varphi=e^{\beta_\infty\Omega N(x_\varphi)}-1,
\qquad
D_{\mathrm{mem}}=e^{\beta_\infty\Omega N(x_{\mathrm{mem}})}-1.
\]
Then the default common-core fixed-response transport identity is
\begin{equation}\label{eq:spectral-transport-main}
\frac{D_\varphi}{D_{\mathrm{mem}}}
=
\frac{\Delta\tau\,\Gamma_c(\kappa_{\mathrm r},\Delta\tau)}{\log\varphi}
\frac{\mathcal S_{x_\varphi}(\Omega)}
     {\mathcal S_{x_{\mathrm{mem}}}(\Omega)}.
\end{equation}
The second source equation is a labelled memory equation only under that
independent \(\kappa_{\mathrm r}\) label. If the two points also pass the range and regularity checks of
\Cref{thm:response-locus-main}, this identity is the corresponding local
transport identity for the two regular response loci. It is conditional algebra
inside one chosen calibrated response profile, not a new shell-geometry or UDW
measurement theorem.
\end{corollary}

\begin{proof}
All factors in \eqref{eq:general-transport-source-main} are positive under the
standing fixed-response hypotheses and the externally supplied recovery label
for the memory member. Solving the two source equations for the
Planck denominators gives
\[
D_\varphi=
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_\varphi}(\Omega)\Delta\tau}
     {\log\varphi},
\qquad
D_{\mathrm{mem}}=
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_{\mathrm{mem}}}(\Omega)}
     {\Gamma_c(\kappa_{\mathrm r},\Delta\tau)}.
\]
Dividing the first expression by the second cancels the common switched
detector factor \(\lambda_{\mathrm{sw}}^2\) and gives
\eqref{eq:spectral-transport-main}. The final sentence only applies the
regular-level-set conclusion of \Cref{thm:response-locus-main} to the two
already selected levels.
\end{proof}
