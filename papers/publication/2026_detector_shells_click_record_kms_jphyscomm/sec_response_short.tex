\section{Optional External Scalar Calibration}\label{sec:kms-shells}

This short closing section contains the only non-record translation used in
the paper.  It does not change the sampled kernels, the visible law, or any
finite-record statement: it merely composes record-selected scalar constants
with a supplied positive \(C^1\) function.  The symbols \(U\) and
\(R_\Omega\) below may come from any external calibration protocol; no KMS,
Unruh, detector, or thermodynamic structure is assumed or proved here.

\begin{assumption}[Supplied scalar calibration]\label{ass:udw-rate-calibration-main}
Let \(U\) be a \(C^1\) manifold and let
\[
R_\Omega:U\to(0,\infty)
\]
be externally specified.  It is not estimated from the sampled record and is
not derived by any theorem in this article.  The optional scalar closure is
\[
\Gamma=R_\Omega(x).
\]
For the sampled boundary-reset memory target, an external separated-root
branch map is also required to name the recovery rate
\(\kappa_{\mathrm r}>0\), since one visible sampled record identifies only
\[
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}
\]
under the exchange
\(\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma}\).
This branch map is a calibration/protocol input assigning the two separated
roots to the attempt and recovery branches; it is not inferred from the
record.  The reporting convention is
\Cref{conv:branch-map-labelled-rates-main}.
\end{assumption}

\begin{corollary}[Inverse images of the two record-selected constants]
\label{cor:conditional-calibration-bridge-main}\label{thm:response-locus-main}
Under \Cref{ass:udw-rate-calibration-main}, the ideal Parry record condition
and the sampled boundary-reset memory condition correspond to the inverse
images
\[
R_\Omega^{-1}(\gamma_\varphi),
\qquad
R_\Omega^{-1}(\gamma_{\mathrm{mem}}),
\]
where
\[
\gamma_\varphi=\frac{\log\varphi}{\Delta\tau},
\qquad
\gamma_{\mathrm{mem}}=
\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau).
\]
The second inverse image is a labelled inverse image only after the external
branch map has fixed which separated root supplies
\(\kappa_{\mathrm r}\).  Without that map the record-level estimand is the
corresponding unordered survival-factor pair, not a labelled recovery-rate
level set, as in \Cref{conv:branch-map-labelled-rates-main}.  For any
\(\gamma>0\), the
inverse image is nonempty exactly when \(\gamma\in R_\Omega(U)\); on any
component where \(dR_\Omega\ne0\), it is a \(C^1\) hypersurface.
\end{corollary}

\begin{proof}
\Cref{prop:ideal-main} gives
\(\Gamma=\log\varphi/\Delta\tau\).  \Cref{thm:main-record-wrapper,lem:one-dep-criterion-main}
give
\(\Gamma=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)\), with the
external recovery-rate branch map required by
\Cref{ass:udw-rate-calibration-main}.  Substituting
\(\Gamma=R_\Omega(x)\) gives the two inverse images.  The range criterion is
the definition of \(R_\Omega(U)\), and the regularity statement is the
regular-level-set theorem.
\end{proof}

\begin{remark}[No physical derivation claim]\label{rem:external-calibration-only-main}
The function \(R_\Omega\) is an input.  The main record analysis neither
constructs it nor estimates its inverse images from one sampled record.  This
corollary also has no reverse direction: observing that an external profile
satisfies \(R_\Omega(x)=\gamma_\varphi\) or
\(R_\Omega(x)=\gamma_{\mathrm{mem}}\) does not derive the killed-leakage
kernels, the renewal law, or the finite-record CLT.
\end{remark}
