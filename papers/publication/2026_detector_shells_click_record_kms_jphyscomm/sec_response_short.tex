\section{Conditional fixed-response level-set theorem}\label{sec:kms-shells}

This appendix is the paper's single response-side boundary.  The record
theorems have already ended before this appendix begins, and their inputs are
the labelled sampled kernels \(T_0,T_1\) rather than a detector-field
construction.  Given a supplied positive \(C^1\) function
\(R_\Omega:U\to(0,\infty)\), an external closure \(\Gamma=R_\Omega(x)\), and,
for the memory target, an externally labelled \(\kappa_{\mathrm r}\), the
record-selected constants define only the inverse images
\[
R_\Omega^{-1}(\log\varphi/\Delta\tau),
\qquad
R_\Omega^{-1}(\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)).
\]
No response profile, microscopic detector dynamics, switching/smearing limit,
field update rule, response-locus estimator, or location confidence set is
derived here.

\begin{assumption}[A0: supplied-profile calibration closure]\label{ass:udw-rate-calibration-main}
Fix a \(C^1\) manifold \(U\), a gap \(\Omega>0\), a sampling interval
\(\Delta\tau>0\), and one positive \(C^1\) function
\[
R_\Omega:U\to(0,\infty).
\]
For the optional response interpretation, impose as external calibration data
the scalar closure
\[
\Gamma=R_\Omega(x)=\Gamma_+(x,\Omega).
\]
For the sampled boundary-reset memory target, also supply an independently
labelled recovery rate \(\kappa_{\mathrm r}>0\).  This label is not obtained
from one visible sampled record, because
\[
\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma},
\qquad
\text{and the visible law identifies only }
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}.
\]
Thus any response equation containing
\(\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)\) assumes an external recovery-rate
label, supplied for example by detector calibration, hardware recovery
measurement, or an experimental protocol not contained in the one visible
record.  Without that label, the response-side memory statement remains only a
quotient statement under
\[
(\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma).
\]
\end{assumption}

\begin{theorem}[Conditional calibration theorem for one supplied response profile]
\label{cor:conditional-calibration-bridge-main}\label{thm:response-locus-main}
Assume \Cref{ass:udw-rate-calibration-main}.  The two record-selected target
rates are
\begin{equation}\label{eq:target-rates-main}
\gamma_\varphi=\frac{\log\varphi}{\Delta\tau},
\qquad
\gamma_{\mathrm{mem}}=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau),
\end{equation}
where the second target is labelled only after the external
\(\kappa_{\mathrm r}\) label in \Cref{ass:udw-rate-calibration-main} has been
supplied.  Under the closure \(\Gamma=R_\Omega(x)\), the ideal Parry condition
\(\Gamma\Delta\tau=\log\varphi\) is equivalent to
\[
\Sigma_\varphi=R_\Omega^{-1}(\gamma_\varphi),
\]
and the sampled boundary-reset memory condition
\(\Gamma=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)\) is equivalent, with the
external \(\kappa_{\mathrm r}\) label, to
\[
\Sigma_{\mathrm{mem}}=R_\Omega^{-1}(\gamma_{\mathrm{mem}}).
\]
More generally, for any \(\gamma>0\),
\[
L_\gamma=R_\Omega^{-1}(\gamma)
\]
is nonempty exactly when the range condition
\[
\gamma\in R_\Omega(U)
\]
holds.  If \(x_0\in L_\gamma\) and the regularity condition
\[
dR_\Omega(x_0)\ne0
\]
holds, then the ordinary regular-level-set theorem applied to
\[
F(x)=R_\Omega(x)-\gamma
\]
gives local coordinates near \(x_0\) in which \(F=y^d\).  Hence \(L_\gamma\) is
locally an embedded \(C^1\) level set with normal covector \(dR_\Omega(x_0)\).
If \(dR_\Omega(x_0)=0\), this theorem draws no geometric conclusion and asserts
no converse regularity criterion.

The conclusion is exactly the conditional inverse image
\(R_\Omega^{-1}(\gamma)\) together with the displayed range and regularity
checks.  It is not a theorem about microscopic detector dynamics, a response
profile calculation, a field update rule, a response-locus estimator, or a
spatial-location confidence set.
\end{theorem}

\begin{proof}
\Cref{prop:ideal-main} gives the ideal-counter record condition
\(\Gamma\Delta\tau=\log\varphi\), equivalently
\(\Gamma=\gamma_\varphi\).  \Cref{thm:recovery-main,lem:one-dep-criterion-main}
give the sampled boundary-reset memory condition
\(\Gamma=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)=\gamma_{\mathrm{mem}}\), with
the recovery-rate label subject to the exchange quotient stated in
\Cref{ass:udw-rate-calibration-main}.  Substituting the external closure
\(\Gamma=R_\Omega(x)\) gives exactly the two inverse images above.  The range
condition is the definition of the image \(R_\Omega(U)\).  The local statement
is the standard regular-level-set theorem for the \(C^1\) function
\(F=R_\Omega-\gamma\).  No other detector or field input is used.
\end{proof}

\paragraph{Optional stationary one-gap profile data.}
\label{ass:kms-response-main}\label{ass:long-time-switch-main}
One possible source of the supplied profile is a separate stationary detector
response calculation.  For each static worldline \(x\in U\), suppose such an
external calculation supplies finite positive rates
\[
\Gamma_+(x,\Omega),\qquad \Gamma_-(x,\Omega),
\]
and suppose the excitation profile
\[
R_\Omega(x)=\Gamma_+(x,\Omega)
\]
is the positive \(C^1\) function required in A0.  In common KMS notation this
externally supplied profile may be written
\begin{equation}\label{eq:kms-rate-main}
R_\Omega(x)=\Gamma_+(x,\Omega)
=\lambda_{\mathrm{sw}}^2
\frac{\mathcal S_x(\Omega)}
{e^{\beta_\infty\Omega N(x)}-1},
\end{equation}
where \(\lambda_{\mathrm{sw}}>0\), \(\beta_\infty>0\), \(N(x)>0\), and the
one-gap spectral weight \(x\mapsto\mathcal S_x(\Omega)\) is supplied as a
positive \(C^1\) function on the region under study.

\paragraph{Imported response formulas are only profile data.}
\label{prop:stationary-udw-response-main}\label{lem:gap-regular-approx-identity-main}
The UDW/KMS literature supplies stationary response formulas under hypotheses
such as smooth switching, detector smearing or another ultraviolet
regularization, scaling limits, and gap-regular absolutely continuous spectral density
\cite{Letaw1981,Schlicht2004,Satz2007,LoukoSatz2006,LoukoSatz2008,FewsterJuarezLouko2016,TjoaGray2024UDWJointHilbert}.
When those hypotheses are verified in a separate detector model, the resulting
rate profile may be inserted into A0.  This imported profile data does not
derive the sampled kernels \(T_0,T_1\), an update rule, or an error bound
between a microscopic detector-field model and the record law.

\paragraph{One-gap KMS underdetermination.}
\label{lem:one-gap-kms-underdetermination-main}
At the one-gap rate level used here, detailed balance does not determine the
positive excitation profile.  Fix \(N\), \(\beta_\infty\), \(\Omega\), and
\(\lambda_{\mathrm{sw}}\).  For every positive \(C^1\) function
\(G:U\to(0,\infty)\), the assignments
\[
\Gamma_+^G(x,\Omega)=G(x),
\qquad
\Gamma_-^G(x,\Omega)=e^{\beta_\infty N(x)\Omega}G(x),
\qquad
\mathcal S_x^G(\Omega)=
\lambda_{\mathrm{sw}}^{-2}
\bigl(e^{\beta_\infty N(x)\Omega}-1\bigr)G(x)
\]
have the same one-gap detailed-balance ratio
\[
\Gamma_-^G(x,\Omega)/\Gamma_+^G(x,\Omega)
=e^{\beta_\infty N(x)\Omega}
\]
and fit the profile form \eqref{eq:kms-rate-main}.  Thus KMS detailed balance
and Tolman scaling alone do not select \(R_\Omega^{-1}(\gamma)\); the level
sets above depend on the supplied positive profile \(R_\Omega\).

\paragraph{Conditional fixed-response transport bookkeeping.}
\label{rem:response-transport-bookkeeping-main}
Assume A0 and the optional profile form \eqref{eq:kms-rate-main}.  For the
memory member assume the recovery rate has been independently labelled; without
that label, the statement is only the quotient statement from A0.  If
\(x_\varphi,x_{\mathrm{mem}}\in U\) satisfy
\[
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_\varphi}(\Omega)\Delta\tau}
     {D_\varphi}
=\log\varphi,
\qquad
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_{\mathrm{mem}}}(\Omega)}
     {D_{\mathrm{mem}}}
=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau),
\]
where
\[
D_\varphi=e^{\beta_\infty\Omega N(x_\varphi)}-1,
\qquad
D_{\mathrm{mem}}=e^{\beta_\infty\Omega N(x_{\mathrm{mem}})}-1,
\]
then direct division gives
\begin{equation}\label{eq:spectral-transport-main}
\frac{D_\varphi}{D_{\mathrm{mem}}}
=
\frac{\Delta\tau\,\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)}{\log\varphi}
\frac{\mathcal S_{x_\varphi}(\Omega)}
     {\mathcal S_{x_{\mathrm{mem}}}(\Omega)}.
\end{equation}
If the two points also pass the range and regularity checks above, this identity
is algebra along the corresponding regular response loci.

\paragraph{Schwarzschild fixed-profile illustration.}
\label{ex:worked-regular-response-profile-main}
As an illustration of the preceding conditional calculus, one may supply the
\(C^1\) response profile
\[
N(r)=\sqrt{1-\frac{r_{\mathrm s}}{r}},
\qquad
R_\Omega(r)=\frac{\mathcal A}{e^{B N(r)}-1}
\]
on the exterior static region \(U=\{(r,\theta,\phi):r>r_{\mathrm s}\}\), with
\(r_{\mathrm s},\mathcal A,B>0\).  For \(r>r_{\mathrm s}\),
\[
\frac{dR_\Omega}{dr}
=-\mathcal A\,\frac{B e^{B N(r)}}{(e^{B N(r)}-1)^2}
\frac{r_{\mathrm s}}{2r^2N(r)}<0,
\]
and
\[
\lim_{r\downarrow r_{\mathrm s}}R_\Omega(r)=+\infty,
\qquad
\lim_{r\to\infty}R_\Omega(r)=\frac{\mathcal A}{e^B-1}.
\]
Thus \(R_\Omega(U)=(\mathcal A/(e^B-1),\infty)\).  For any target
\(\gamma>\mathcal A/(e^B-1)\), including \(\gamma_\varphi\) or the externally
labelled \(\gamma_{\mathrm{mem}}\) when that range condition holds, the
response equation has the unique radius
\[
N_\gamma=\frac1B\log\!\left(1+\frac{\mathcal A}{\gamma}\right),
\qquad
r_\gamma=\frac{r_{\mathrm s}}{1-N_\gamma^2}.
\]
Since \(dR_\Omega(r_\gamma)\ne0\), the level set \(\{r=r_\gamma\}\) is a
regular level set of the supplied illustrative profile.  This statement is
only the identity \(R_\Omega^{-1}(\gamma)=\{r=r_\gamma\}\) after the example's
range and regularity checks; it is not an estimator or localization theorem.

\paragraph{Terminology.}
The default output of this section is \(R_\Omega^{-1}(\gamma)\) for one supplied
response profile and one selected target.  The default term is \emph{response
locus}.  Any additional geometric wording is merely a description of that
inverse image inside an already specified profile and only after the target has
passed the range condition and the component has passed the regularity check
\(dR_\Omega\ne0\).  Without those checks the paper asserts only the conditional
set \(R_\Omega^{-1}(\gamma)\), and no finite record in this paper estimates or
locates that set.
