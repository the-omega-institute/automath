\section{Purely conditional response-level-set example}\label{sec:kms-shells}

No response-level theorem is proved here.  The only statement is the following
conditional regular-level-set observation: given a positive \(C^1\) function
\[
R_\Omega:U\to(0,\infty),
\]
an external closure
\[
\Gamma=R_\Omega(x),
\]
and an externally labelled \(\kappa_{\mathrm r}\), the record-selected
constants define the level sets
\[
R_\Omega^{-1}(\log\varphi/\Delta\tau),
\qquad
R_\Omega^{-1}(\Gamma_c(\kappa_{\mathrm r},\Delta\tau)).
\]
If \(dR_\Omega(x_0)\neq0\) at a point of one of these level sets, the ordinary
regular-level-set theorem gives a local \(C^1\) hypersurface there.  If
\(dR_\Omega(x_0)=0\), this appendix draws no geometric conclusion.  The
sampled-record theorem does not derive \(R_\Omega\), the closure
\(\Gamma=R_\Omega(x)\), the recovery label \(\kappa_{\mathrm r}\), sampled
detector kernels from a microscopic detector model, or a finite-record
response-location inference.

Thus the appendix is only an optional example after the record-law theorem
chain.  It states what the already proved record-selected constants become
after the external response data above have been supplied; the nonclaims are
those in \Cref{subsec:scope-nonclaims}.

The response notation below is local to this appendix.  We write
\(\Gamma_\pm(x,\Omega)\) for externally supplied excitation/de-excitation
rates, \(R_\Omega(x)=\Gamma_+(x,\Omega)\) for the chosen scalar excitation
profile, \(\lambda_{\mathrm{sw}}\) for an effective switched coupling when a
KMS example is displayed, \(N(x)\) for the static lapse, and
\(\mathcal S_x(\Omega)\) for a supplied one-gap spectral weight.  The record
symbols \(A_n,p,c,\lambda_{\mathrm{hid}}\) retain their meanings from
\Cref{sec:records}.

\begin{assumption}[A0, supplied-profile calibration closure]\label{ass:udw-rate-calibration-main}
Fix a \(C^1\) manifold \(U\), a detector gap \(\Omega>0\), a sampling interval
\(\Delta\tau>0\), and a positive \(C^1\) function
\[
R_\Omega:U\to(0,\infty).
\]
For the optional response interpretation, impose the external scalar closure
\[
\Gamma=R_\Omega(x)=\Gamma_+(x,\Omega).
\]
For the sampled boundary-reset memory target, also supply an independently
labelled recovery rate \(\kappa_{\mathrm r}>0\).  That label is not obtained
from a single visible sampled record, because
\[
\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma},
\qquad
\text{and the visible law identifies only }
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}.
\]
Thus any response equation containing
\(\Gamma_c(\kappa_{\mathrm r},\Delta\tau)\) assumes an external recovery-rate
label, supplied for example by detector calibration, hardware recovery
measurement, or an experimental protocol not contained in the one visible
record.  Without that label, the memory statement is only a quotient statement
under
\[
(\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma).
\]
\end{assumption}

\begin{corollary}[Conditional regular-level-set observation under A0]\label{cor:conditional-calibration-bridge-main}\label{thm:response-locus-main}
Assume A0.  The two record-selected target rates are
\begin{equation}\label{eq:target-rates-main}
\gamma_\varphi=\frac{\log\varphi}{\Delta\tau},
\qquad
\gamma_{\mathrm{mem}}=\Gamma_c(\kappa_{\mathrm r},\Delta\tau),
\end{equation}
where the second target is labelled only when the external
\(\kappa_{\mathrm r}\) label in A0 has been supplied.  The corresponding level
sets for the already chosen function \(R_\Omega\) are
\[
\Sigma_\varphi=R_\Omega^{-1}(\gamma_\varphi),
\qquad
\Sigma_{\mathrm{mem}}=R_\Omega^{-1}(\gamma_{\mathrm{mem}}).
\]
More generally, for any \(\gamma>0\),
\[
L_\gamma=R_\Omega^{-1}(\gamma)
\]
is empty exactly when \(\gamma\notin R_\Omega(U)\).  If
\(x_0\in L_\gamma\) and
\[
dR_\Omega(x_0)\ne0,
\]
then \(L_\gamma\) is, near \(x_0\), an embedded \(C^1\) hypersurface with normal
covector \(dR_\Omega(x_0)\).  If \(dR_\Omega(x_0)=0\), no conclusion is drawn
and no converse regular-level-set implication is asserted.

This is only a conditional regular-level-set observation.  The hypotheses are
exactly the supplied \(C^1\) response profile, positivity, A0, the range check
\(\gamma\in R_\Omega(U)\), and the regularity check
\(dR_\Omega(x_0)\ne0\).  None of these hypotheses is derived from the sampled
record in this paper.
\end{corollary}

\begin{proof}
\Cref{prop:ideal-main} gives the ideal one-step blanking condition
\(\Gamma\Delta\tau=\log\varphi\), equivalently
\(\Gamma=\gamma_\varphi\).  \Cref{thm:recovery-main,lem:one-dep-criterion-main}
give the sampled boundary-reset memory-transition condition
\(\Gamma=\Gamma_c(\kappa_{\mathrm r},\Delta\tau)\), with the label boundary for
\(\kappa_{\mathrm r}\) stated in A0.  Substituting the external closure
\(\Gamma=R_\Omega(x)\) gives the two inverse images displayed above.

The range statement is the definition of the range of the already supplied
function \(R_\Omega\).  For the regularity statement, put
\(F(x)=R_\Omega(x)-\gamma\).  Then \(dF=dR_\Omega\), and the ordinary
regular-level-set theorem gives local coordinates
\((y^1,\ldots,y^d)\) near \(x_0\) in which \(F=y^d\).  Hence
\(F^{-1}(0)=\{y^d=0\}\) locally, with normal covector \(dR_\Omega(x_0)\).
This proves the stated hypersurface conclusion and nothing beyond it.
\end{proof}

\subsection{Optional KMS/UDW profile data}\label{subsec:optional-kms-profile-data}

One possible source of a supplied profile is a separate stationary detector
response calculation.  The following convention records the formula used when
such a calculation has already been performed elsewhere; it is not a
measurement theorem proved here.

\begin{assumption}[Optional stationary one-gap profile input]\label{ass:kms-response-main}\label{ass:long-time-switch-main}
For each static worldline \(x\in U\), suppose an external stationary detector
response calculation supplies finite positive rates
\[
\Gamma_+(x,\Omega),\qquad \Gamma_-(x,\Omega),
\]
and suppose the excitation profile
\[
R_\Omega(x)=\Gamma_+(x,\Omega)
\]
is the positive \(C^1\) function required in A0.  In the common KMS notation,
one may write this supplied profile in the form
\begin{equation}\label{eq:kms-rate-main}
R_\Omega(x)=\Gamma_+(x,\Omega)
=\lambda_{\mathrm{sw}}^2
\frac{\mathcal S_x(\Omega)}
{e^{\beta_\infty\Omega N(x)}-1},
\end{equation}
where \(\lambda_{\mathrm{sw}}>0\), \(\beta_\infty>0\), \(N(x)>0\), and the
one-gap spectral weight \(x\mapsto\mathcal S_x(\Omega)\) is supplied as a
positive \(C^1\) function on the region under study.

If this profile comes from a standard stationary UDW/KMS calculation, all
gap-regularity, switching, absolute-continuity, spatial-smearing, positivity,
and \(C^1\) hypotheses needed to justify the displayed rate formula belong to
that external response calculation.  They are not derived from the sampled
counter law here.
\end{assumption}

\begin{remark}[Imported response formulas are only profile data]\label{prop:stationary-udw-response-main}\label{lem:gap-regular-approx-identity-main}
The UDW/KMS literature supplies stationary response formulas under hypotheses
such as smooth switching, detector smearing or another ultraviolet
regularization, and gap-regular absolutely continuous spectral density
\cite{Letaw1981,Schlicht2004,Satz2007,LoukoSatz2006,LoukoSatz2008,FewsterJuarezLouko2016,TjoaGray2024UDWJointHilbert}.
When those hypotheses are verified in a separate detector model, the rate
profile may be inserted into A0.  The present paper does not prove those
hypotheses, does not construct the joint detector-field dynamics, and does not
turn the classical sampled HMM into a UDW measurement process.
\end{remark}

\begin{lemma}[One-gap KMS underdetermination]\label{lem:one-gap-kms-underdetermination-main}
At the one-gap rate level used in this optional appendix, detailed balance
does not determine the positive excitation profile.  Fix \(N\),
\(\beta_\infty\), \(\Omega\), and \(\lambda_{\mathrm{sw}}\).  For every positive
\(C^1\) function \(G:U\to(0,\infty)\), the assignments
\[
\Gamma_+^G(x,\Omega)=G(x),
\qquad
\Gamma_-^G(x,\Omega)=e^{\beta_\infty N(x)\Omega}G(x),
\qquad
\mathcal S_x^G(\Omega)=
\lambda_{\mathrm{sw}}^{-2}
\bigl(e^{\beta_\infty N(x)\Omega}-1\bigr)G(x)
\]
have the same one-gap detailed-balance ratio
\[
\Gamma_-^G(x,\Omega)/\Gamma_+^G(x,\Omega)
=e^{\beta_\infty N(x)\Omega}
\]
and fit the profile form \eqref{eq:kms-rate-main}.  Thus KMS detailed balance
and Tolman scaling alone do not select \(R_\Omega^{-1}(\gamma)\).  The level
sets in \Cref{thm:response-locus-main} depend on the supplied positive profile
\(R_\Omega\).
\end{lemma}

\begin{proof}
The displayed ratio is immediate.  Substitution of
\(\mathcal S_x^G(\Omega)\) into \eqref{eq:kms-rate-main} gives
\(\Gamma_+^G(x,\Omega)=G(x)\).  Since \(G\) is arbitrary among positive
\(C^1\) functions, the range and regularity of \(G^{-1}(\gamma)\) are not fixed
by the detailed-balance ratio.
\end{proof}

\subsection{Algebra inside one supplied profile}

The next identity is only bookkeeping after two points have already been
chosen in the same supplied response model.  It is not a new detector-location
theorem and not a measurement-level comparison.

\begin{corollary}[Conditional fixed-response transport identity]\label{cor:spectral-transport-main}
Assume A0 and the optional profile form \eqref{eq:kms-rate-main}.  For the
memory member assume the recovery rate has been independently labelled; without
that label, the statement is only the quotient statement from A0.  Suppose
\(x_\varphi,x_{\mathrm{mem}}\in U\) satisfy
\[
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_\varphi}(\Omega)\Delta\tau}
     {D_\varphi}
=\log\varphi,
\qquad
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_{\mathrm{mem}}}(\Omega)}
     {D_{\mathrm{mem}}}
=\Gamma_c(\kappa_{\mathrm r},\Delta\tau),
\]
where
\[
D_\varphi=e^{\beta_\infty\Omega N(x_\varphi)}-1,
\qquad
D_{\mathrm{mem}}=e^{\beta_\infty\Omega N(x_{\mathrm{mem}})}-1.
\]
Then
\begin{equation}\label{eq:spectral-transport-main}
\frac{D_\varphi}{D_{\mathrm{mem}}}
=
\frac{\Delta\tau\,\Gamma_c(\kappa_{\mathrm r},\Delta\tau)}{\log\varphi}
\frac{\mathcal S_{x_\varphi}(\Omega)}
     {\mathcal S_{x_{\mathrm{mem}}}(\Omega)}.
\end{equation}
If the two points also pass the range and regularity checks of
\Cref{thm:response-locus-main}, this identity is algebra along the corresponding
regular response loci.
\end{corollary}

\begin{proof}
Solving the two source equations for the denominators gives
\[
D_\varphi=
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_\varphi}(\Omega)\Delta\tau}
     {\log\varphi},
\qquad
D_{\mathrm{mem}}=
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_{x_{\mathrm{mem}}}(\Omega)}
     {\Gamma_c(\kappa_{\mathrm r},\Delta\tau)}.
\]
Dividing cancels the common switched coupling and yields
\eqref{eq:spectral-transport-main}.
\end{proof}

\begin{remark}[Schwarzschild fixed-profile example]\label{ex:worked-regular-response-profile-main}
This example is a supplied \(C^1\) response profile satisfying the hypotheses of
\Cref{thm:response-locus-main}; it is not derived as a UDW measurement model.
On the exterior static region \(U=\{(r,\theta,\phi):r>r_{\mathrm s}\}\), set
\[
N(r)=\sqrt{1-\frac{r_{\mathrm s}}{r}},
\qquad
R_\Omega(r)=\frac{\mathcal A}{e^{B N(r)}-1},
\]
with \(r_{\mathrm s},\mathcal A,B>0\).  Then \(R_\Omega\) is positive and
\(C^1\), and
\[
\frac{dR_\Omega}{dr}
=-\mathcal A\,\frac{B e^{B N(r)}}{(e^{B N(r)}-1)^2}
\frac{r_{\mathrm s}}{2r^2N(r)}<0
\qquad (r>r_{\mathrm s}).
\]
Moreover
\[
\lim_{r\downarrow r_{\mathrm s}}R_\Omega(r)=+\infty,
\qquad
\lim_{r\to\infty}R_\Omega(r)=\frac{\mathcal A}{e^B-1},
\]
so
\[
R_\Omega(U)=\left(\frac{\mathcal A}{e^B-1},\infty\right).
\]
For any target \(\gamma>\mathcal A/(e^B-1)\), including
\(\gamma_\varphi\) or the externally labelled \(\gamma_{\mathrm{mem}}\) when
that range condition holds, the response equation has the unique radius
\[
N_\gamma=\frac1B\log\!\left(1+\frac{\mathcal A}{\gamma}\right),
\qquad
r_\gamma=\frac{r_{\mathrm s}}{1-N_\gamma^2}.
\]
Since \(dR_\Omega(r_\gamma)\ne0\), the level set
\(\{r=r_\gamma\}\) is a regular spatial sphere.  This last geometric
description is available only because the example has specified a spatial
profile, verified the range condition, and checked regularity.
\end{remark}

\subsection{Terminology for spatial regular level sets}

The output of this appendix is \(R_\Omega^{-1}(\gamma)\) for one supplied
response profile and one selected target.  The default term is
\emph{response locus}.  A component may be given a spatial name only when the
chosen response model includes a spatial profile, the target has passed the
range condition, and the component is a regular codimension-one spatial
hypersurface by the check \(dR_\Omega\ne0\).  Without all three ingredients the
paper asserts only a conditional response locus.
