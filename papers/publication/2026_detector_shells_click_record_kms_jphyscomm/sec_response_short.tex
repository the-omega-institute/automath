\section{Short calibrated-response corollary}\label{sec:kms-shells}

The record theorems above are stated for the classical sampled counter before
any detector-response calibration is imposed. This section contains only the
paper-level bridge needed to read those record thresholds as response targets.
All homogeneous-shell, horizon, fixed-radius, and Schwarzschild algebra is
left to the supplementary source files.
The assumptions used below have three different statuses. The sampled-counter
laws and the range condition for a chosen \(R_\Omega\) are verifiable inside
the specified model. The \(C^1\) and \(dR_\Omega\neq 0\) clauses are generic
regularity checks for the chosen response profile. The closure
\(\Gamma=R_\Omega(x)=\Gamma_+(x,\Omega)\) and any positive one-gap spectral
weight \(x\mapsto\mathcal S_x(\Omega)\) are open calibration inputs: KMS
detailed balance fixes the ratio \(\Gamma_-/\Gamma_+\), not those absolute
positive-frequency data. No result in this section depends on an unpublished
companion theorem; a companion statement cited elsewhere only as reference
[1] is unavailable to the present proof unless its proof is included in these
paper sources.

\begin{assumption}[Model A: one fixed response closure]\label{ass:udw-rate-calibration-main}
Fix a static region $U$, a detector gap $\Omega>0$, and one calibrated
stationary excitation-rate profile
\[
R_\Omega:U\to(0,\infty).
\]
The sampled counter is coupled to this profile only through the closure
\[
\Gamma=R_\Omega(x).
\]
When the profile is represented by a static KMS response model, we write
\[
R_\Omega(x)=\Gamma_+(x,\Omega)
=\lambda_{\mathrm{sw}}^2
\frac{\mathcal S_x(\Omega)}
{e^{\beta_\infty N(x)\Omega}-1}.
\]
This formula is a calibration input, not a derivation of the sampled HMM.
\end{assumption}

\begin{proposition}[Fixed-response loci selected by the record law]\label{cor:conditional-calibration-bridge-main}\label{thm:response-locus-main}
Let
\[
R_\Omega(x)=
\lambda_{\mathrm{sw}}^2
\frac{\mathcal S_x(\Omega)}
{e^{\beta_\infty\Omega N(x)}-1}
\]
be a fixed positive $C^1$ function on $U$. For $\gamma>0$, the level set
$R_\Omega^{-1}(\gamma)$ is empty if and only if
$\gamma\notin R_\Omega(U)$. If $x_0\in R_\Omega^{-1}(\gamma)$, then
$R_\Omega^{-1}(\gamma)$ is, near $x_0$, a $C^1$ hypersurface if and only if
\[
dR_\Omega(x_0)\ne0,
\]
where
\[
dR_\Omega
=\lambda_{\mathrm{sw}}^2\left[
\frac{d\mathcal S_x(\Omega)}{e^{\beta_\infty\Omega N}-1}
-\frac{\mathcal S_x(\Omega)\beta_\infty\Omega e^{\beta_\infty\Omega N}}
{(e^{\beta_\infty\Omega N}-1)^2}\,dN
\right].
\]
The two record-selected target rates inserted into this fixed response
function are only
\[
\gamma_\varphi=\frac{\log\varphi}{\Delta\tau},
\qquad
\gamma_{\mathrm{mem}}=\Gamma_c(\kappa_{\mathrm r},\Delta\tau).
\]
\end{proposition}

\begin{proof}
\Cref{prop:ideal-main} gives the ideal-counter condition
$\Gamma\Delta\tau=\log\varphi$, equivalently
$\Gamma=\gamma_\varphi$. \Cref{thm:recovery-main,lem:one-dep-criterion-main}
give the sampled boundary-reset memory-transition condition
$\Gamma=\Gamma_c(\kappa_{\mathrm r},\Delta\tau)=\gamma_{\mathrm{mem}}$.
Substituting the closure $\Gamma=R_\Omega(x)$ gives the two inverse images.
The nonemptiness statement is exactly the definition of the range of the fixed
function $R_\Omega$.

For the regularity statement, write
$F(x)=R_\Omega(x)-\gamma$. Since $\gamma$ is constant, $dF=dR_\Omega$.
The displayed differential is the ordinary product and chain rule applied to
the fixed calibrated response formula. The regular level-set theorem gives a
local $C^1$ hypersurface at $x_0\in F^{-1}(0)$ precisely when
$dF(x_0)=dR_\Omega(x_0)$ is nonzero. Only in this regular case do we call the
response locus a shell.
\end{proof}

\begin{remark}[Scope of the response bridge]\label{rem:response-bridge-scope-main}
KMS detailed balance fixes the ratio $\Gamma_-/\Gamma_+$ at a fixed gap once
the stationary response calculation is supplied; it does not by itself specify
the positive excitation profile $R_\Omega$, the sampled readout instrument, or
the record thresholds. The main theorem-level contribution therefore remains
the sampled-record law. The response loci above are conditional consequences
of applying one calibrated profile to those record-selected target rates.
\end{remark}
