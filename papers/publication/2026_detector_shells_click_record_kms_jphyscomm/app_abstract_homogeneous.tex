\section{Appendix-only calibrated response-locus corollaries and homogeneous level-set bookkeeping}\label{app:abstract-homogeneous-main}

The main response material contains one constant-lapse symmetry example for a
homogeneous spectral-weight profile in \Cref{prop:symmetry-homogeneous-main}.
It is not a derivation of the sampled kernels \(T_0,T_1\).  Everything
collected here is therefore only appendix-level algebra for one fixed
calibrated response function. No separate exact nonconstant-lapse UDW model
with
\[
\mathcal S_x(\Omega)\equiv\mathcal S(\Omega)
\]
is constructed here.

\begin{assumption}[Appendix-only homogeneous spectral-weight regime]\label{ass:homogeneous-spectral-main}
When the static response regularity and calibration of
\Cref{ass:kms-response-main} are imposed at a fixed gap $\Omega$ on a region
$U$, the homogeneous spectral-weight regime means
\[
\mathcal S_x(\Omega)\equiv\mathcal S(\Omega)>0\qquad(x\in U).
\]
This is a calibration hypothesis on the response model, not a consequence of
KMS detailed balance. In response-locus-pair statements it is used together with a
common detector-core calibration, so that the same positive response amplitude
$\lambda_{\mathrm{sw}}^2\mathcal S(\Omega)$ enters the ideal-benchmark and
memory-transition source equations. It holds exactly at the amplitude level in
the symmetry model of \Cref{prop:symmetry-homogeneous-main}, although that
ultrastatic example has constant lapse and hence no nontrivial spatial
level-set geometry
by itself. Accordingly, any nonconstant-lapse homogeneous shell arguments below
are appendix-only calibrated level-set algebra for a fixed response function,
while \Cref{prop:spectral-stability-main,cor:asymptotic-horizon-main} record
the slow-variation substitute used when the shell pair is only asymptotically
homogeneous.
\end{assumption}

\begin{definition}[Appendix-only common-core response-locus data]\label{def:common-core-shell-data-main}
A response-locus pair is \emph{common-core} when the two records use the same
externally supplied detector-core calibration: gap, coupling scale, detector
profile, and field state are fixed, while the counter mode is changed from
ideal one-step blanking to the sampled one-recovery-opportunity boundary-reset mode. A two-mode radius
record is a \emph{full common-core spatial level-set record} only when the
undivided response-locus equations recover one positive common response
amplitude for all ideal-benchmark and memory-transition members, the four radii
lie in the allowed exterior coordinate range of the background family, and the
regular codimension-one spatial level-set checks needed for shell language have
also been verified. The weaker ratio equations alone give only
ratio-admissible data.
\end{definition}

\subsection{Threshold-selected response loci for one fixed calibrated response function}

This subsection only inserts the two already selected record thresholds into
one prescribed calibrated response profile and then invokes
\Cref{thm:response-locus-main} for range and regularity.  No new detector
dynamics enter this appendix; every statement below is algebra inside the
already fixed function $R_\Omega$.  For the memory target the inverse-theorem
warning is part of the statement:
\[
\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma},
\qquad
\text{so the visible record identifies only }
\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}.
\]
Thus \(R_\Omega(x)=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)\) is a labelled
response target only after \(\kappa_{\mathrm r}\) has been independently
labelled by detector calibration, hardware recovery measurement, or an
external experimental protocol.  Without this label the response statement is
only a quotient statement under
\((\Gamma,\kappa_{\mathrm r})\sim(\kappa_{\mathrm r},\Gamma)\).
No branch map, no labelled rates.
Even with the label, a finite click record from one setting supplies only the
fixed-setting record inference stated in \Cref{thm:one-record-estimates-main};
it does not locate this response locus or infer a shell.

\begin{corollary}[Conditional level-set insertion for the classical sampled-counter thresholds]\label{thm:shells-general-main}
\ResponseStandingClause the two classical record thresholds
from \Cref{sec:records} lift to the following response loci for one fixed
stationary detector response model. Fix a detector design
$(\Omega,\lambda_c,\Delta\tau,\kappa_{\mathrm r})$ in a static KMS background,
so that \Cref{ass:response-standing-main} supplies the gap-regular absolutely
continuous spectrum near $\pm\Omega$, the absence of atoms there, the
positivity of $\widehat W_x(\Omega)$, and the $C^1$ regularity of
$x\mapsto\mathcal S_x(\Omega)$ and $R_\Omega$ on the region of interest. For
that fixed response function $R_\Omega$, the two record benchmarks are
equivalent to the following response loci. Their
nonemptiness is exactly the range check
$\gamma_\varphi,\gamma_{\mathrm{mem}}\in\operatorname{range}(R_\Omega)$, and
spatial shell language applies only when a spatial profile has been specified
and at points where $dR_\Omega\neq 0$.  This corollary does not assert a
detector-dynamics theorem beyond the standing calibrated response input.
\begin{enumerate}[label=\textup{(\roman*)},leftmargin=2.2em,itemsep=0.25em]
\item The ideal one-step blanking counter mode reaches the Parry benchmark
exactly on the response locus
\begin{equation}\label{eq:shell-phi-general-main}
\Sigma_{\varphi}=
\left\{x:
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_x(\Omega)\Delta\tau}{e^{\beta_\infty N(x)\Omega}-1}=\log\varphi
\right\}.
\end{equation}
Equivalently, this is the fixed-response locus $R_\Omega^{-1}(\gamma_\varphi)$.
Wherever a spatial profile has been specified and \(dR_\Omega\neq0\) on this
locus, \Cref{thm:response-locus-main} upgrades the corresponding component to
a smooth codimension-one spatial level set; otherwise it remains only a
response locus inside the chosen calibrated model.

\item The sampled one-recovery-opportunity boundary-reset counter mode reaches
the memory-transition point exactly on the response locus
\begin{equation}\label{eq:shell-mem-general-main}
\Sigma_{\mathrm{mem}}=
\left\{x:
\frac{\lambda_{\mathrm{sw}}^2\mathcal S_x(\Omega)}{e^{\beta_\infty N(x)\Omega}-1}
=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)
\right\}.
\end{equation}
Equivalently, this is the fixed-response locus
$R_\Omega^{-1}(\gamma_{\mathrm{mem}})$. Wherever a spatial profile has been
specified and \(dR_\Omega\neq0\) on this locus, the corresponding component is
a smooth codimension-one spatial level set. On the locus itself, the sampled
record is exact $1$-dependent.
\end{enumerate}
\end{corollary}

\begin{proof}
For the ideal counter mode, Lemma~\ref{prop:ideal-main} says that the
Parry benchmark is equivalent to $\Gamma\Delta\tau=\log\varphi$. Under the
Model~A assumption of \Cref{ass:udw-rate-calibration-main}, this becomes
$R_\Omega(x)\Delta\tau=\log\varphi$, i.e. $R_\Omega(x)=\gamma_\varphi$ with
the standing shorthand from \eqref{eq:target-rates-main}. This condition is
exactly \eqref{eq:shell-phi-general-main}, so the locus is
$R_\Omega^{-1}(\gamma_\varphi)$. The range and regularity statements are then
exactly the content of \Cref{thm:response-locus-main}.

For the sampled one-recovery-opportunity boundary-reset model,
\Cref{thm:recovery-main,lem:one-dep-criterion-main} say that the memory
transition is equivalent to $\Gamma=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)$
only after the recovery rate has been independently labelled.  The visible
record itself obeys
\(\mu_{\Gamma,\kappa_{\mathrm r}}=\mu_{\kappa_{\mathrm r},\Gamma}\) and
identifies only
\(\{e^{-\Gamma\Delta\tau},e^{-\kappa_{\mathrm r}\Delta\tau}\}\), so without
that label the memory transition is a quotient statement.  No branch map, no
labelled rates.
Under the same Model~A assumption, this becomes
$R_\Omega(x)=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)$, i.e.
$R_\Omega(x)=\gamma_{\mathrm{mem}}$. With the same fixed calibrated response
function, this is exactly \eqref{eq:shell-mem-general-main}, so the locus is
$R_\Omega^{-1}(\gamma_{\mathrm{mem}})$. Every point satisfying that equation
has an exact $1$-dependent sampled record in that model. The
\Cref{lem:one-gap-kms-underdetermination-main} explains why this corollary is
only conditional on one fixed calibrated response function: changing
$\mathcal S_x(\Omega)$ changes the loci while preserving one-gap detailed
balance.
\end{proof}

\subsection{Homogeneous specialization of the fixed calibrated response theorem}

No new detector-field input is added below. The remaining statements start from
\Cref{thm:response-locus-main,thm:shells-general-main} and then impose extra
calibration or background hypotheses in the one-way order
\[
\text{fixed }R_\Omega
\Longrightarrow
\text{response loci}
\Longrightarrow
\text{pair transport}
\Longrightarrow
\text{homogeneous toy-model specializations}.
\]
Any nonconstant lapse is inserted only at the last stage of that chain.

\begin{lemma}[Abstract calibrated toy-model corollary: homogeneous specialization]\label{lem:abstract-homogeneous-specialization-main}
\ResponseStandingClause specialize the fixed calibrated response function $R_\Omega$ to the homogeneous form
below. Fix a static region $U$, a gap $\Omega>0$, a Tolman parameter
$\beta_\infty>0$, a positive constant \(\mathcal A\), and a $C^1$ lapse
$N:U\to(0,\infty)$. Define the calibrated response function
\[
R_\Omega^{\mathrm{hom}}(x)=\frac{\mathcal A}{e^{\beta_\infty N(x)\Omega}-1}.
\]
Then for any target rate $\gamma>0$ the response locus
\[
L_\gamma^{\mathrm{hom}}
=\{x\in U:R_\Omega^{\mathrm{hom}}(x)=\gamma\}
\]
is exactly the lapse level set
\[
\beta_\infty N(x)=\frac{1}{\Omega}\log\!\left(1+\frac{\mathcal A}{\gamma}\right).
\]
If $dN(x_0)\neq0$ at $x_0\in L_\gamma^{\mathrm{hom}}$, then
$L_\gamma^{\mathrm{hom}}$ is near $x_0$ a $C^1$ codimension-one spatial level
set. This is
an abstract calibrated toy-model specialization of a fixed response function.
The only profile-supporting example used here is
\Cref{prop:symmetry-homogeneous-main}, where the lapse is constant; whenever
later appendices use homogeneous nonconstant-lapse spatial level-set geometry,
they do so through this level-set specialization rather than through a separate
exact UDW construction or a derivation of the sampled kernels.
\end{lemma}

\begin{proof}
Solving $R_\Omega^{\mathrm{hom}}(x)=\gamma$ gives
\[
e^{\beta_\infty N(x)\Omega}=1+\frac{\mathcal A}{\gamma},
\]
hence the displayed lapse level set. Differentiating yields
\[
dR_\Omega^{\mathrm{hom}}
=-\mathcal A\frac{\beta_\infty\Omega e^{\beta_\infty N\Omega}}
{(e^{\beta_\infty N\Omega}-1)^2}\,dN,
\]
whose scalar prefactor is strictly negative. Therefore
$dR_\Omega^{\mathrm{hom}}(x_0)\neq 0$ exactly when $dN(x_0)\neq0$, and the
regular level-set theorem gives the spatial level-set statement.
\end{proof}

\begin{corollary}[Abstract calibrated toy-model corollary: homogeneous lapse-level sets]\label{cor:homogeneous-main}
\ResponseStandingClause assume in addition the calibrated homogeneous spectral-weight regime.
Assume in addition that $\mathcal S_x(\Omega)\equiv\mathcal S(\Omega)$ on the
region under study. Then both response loci are pure lapse level sets, with local inverse
temperatures
\begin{equation}\label{eq:betaphi-betamem-main}
\beta_{\varphi}=
\frac{1}{\Omega}
\log\!\left(1+\frac{\lambda_{\mathrm{sw}}^2\mathcal S(\Omega)\Delta\tau}{\log\varphi}\right),
\qquad
\beta_{\mathrm{mem}}=
\frac{1}{\Omega}
\log\!\left(1+\frac{\lambda_{\mathrm{sw}}^2\mathcal S(\Omega)}
{\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)}\right),
\end{equation}
so that
\begin{equation}\label{eq:lapse-level-main}
\Sigma_{\varphi}=\{x:\beta_{\mathrm{loc}}(x)=\beta_{\varphi}\},
\qquad
\Sigma_{\mathrm{mem}}=\{x:\beta_{\mathrm{loc}}(x)=\beta_{\mathrm{mem}}\}.
\end{equation}
If $dN\neq0$ on one of these level sets, then
\Cref{thm:response-locus-main,lem:abstract-homogeneous-specialization-main}
identify it as the corresponding regular spatial level set; for nonconstant lapse this remains an
abstract calibrated toy-model specialization.
No companion homogeneous spatial theorem is invoked here: the conclusion is only
the regular level-set theorem applied to the displayed homogeneous response
function.
\end{corollary}

\begin{proof}
With $\mathcal S_x(\Omega)\equiv\mathcal S(\Omega)$, the two response-locus
equations contain $x$ only through $\beta_\infty N(x)$. Solving the
ideal-benchmark equation for $\beta_\infty N(x)$ gives $\beta_\varphi$, and
solving the memory equation gives $\beta_{\mathrm{mem}}$. Hence the loci are
the lapse level sets in~\eqref{eq:lapse-level-main}.
\end{proof}

For later pair comparisons write $r_\varphi$ and
$r_{\mathrm{mem}}$ for the homogeneous ideal-benchmark and
memory-transition radii, and set
\[
D_\varphi=e^{\beta_\infty\Omega N(r_\varphi)}-1,
\qquad
D_{\mathrm{mem}}=e^{\beta_\infty\Omega N(r_{\mathrm{mem}})}-1,
\qquad
Q_{\varphi/\mathrm{mem}}=\frac{D_\varphi}{D_{\mathrm{mem}}}.
\]
The target-rate quotient used later is recorded in \Cref{thm:ratio-main}; here
we use only the level-set formulas above.

\subsection{Monotone spherical lapse bookkeeping in the abstract calibrated toy model}

Everything here stays at the level of
\Cref{lem:abstract-homogeneous-specialization-main}. No new exact
detector-field realization with
$\mathcal S_x(\Omega)\equiv\mathcal S(\Omega)$ is being claimed here.
Any nonconstant-lapse insertion is only bookkeeping for a fixed calibrated
response function.

\begin{proposition}[Abstract calibrated toy-model corollary: monotone spherical existence]\label{prop:existence-main}
\ResponseStandingClause assume in addition the homogeneous
specialization on a monotone spherical region.
Assume the homogeneous specialization of \Cref{cor:homogeneous-main} in a static
spherically symmetric region $r\in I$. Suppose
$N:I\to N(I)$ is $C^1$ and strictly monotone. For either threshold
$\star\in\{\varphi,\mathrm{mem}\}$, the corresponding response locus exists in $I$ if
and only if
\[
\frac{\beta_\star}{\beta_\infty}\in N(I),
\]
where $\beta_\varphi$ and $\beta_{\mathrm{mem}}$ are defined in~\eqref{eq:betaphi-betamem-main}. When it exists, its radius is unique and equals
\[
r_\star=N^{-1}\!\left(\frac{\beta_\star}{\beta_\infty}\right).
\]
If $N'(r_\star)\neq0$, this response locus is a regular spherical spatial
level set inside the abstract calibrated toy model.
\end{proposition}

\begin{proof}
By \Cref{cor:homogeneous-main}, the response-locus equation is exactly
$\beta_\infty N(r)=\beta_\star$. Since $N$ is strictly monotone on $I$, it is
one-to-one onto its range. Hence the equation has a solution precisely when
$\beta_\star/\beta_\infty$ lies in $N(I)$, and the solution is then the
displayed inverse image. Thus response-locus existence on a monotone spherical region is
completely equivalent to the calibrated target lapse lying in the available
range of $N$. The nonzero derivative condition is the one-dimensional form of
the regular level-set condition.
\end{proof}

Under this homogeneous specialization, both response loci are lapse level sets
selected by the two record thresholds and become spatial shells only after the
spatial profile, range, and regular level-set checks for the supplied response
function have all been supplied externally.  No finite record in this paper
estimates, locates, or supplies a confidence set for those loci. The default
comparison remains the transport identity
\Cref{cor:spectral-transport-main}; Appendix~\ref{app:schwarzschild-toy}
records a further Schwarzschild-lapse toy specialization.

\begin{proposition}[Abstract calibrated toy-model corollary: detector-controlled ordering]\label{prop:order-main}
\ResponseStandingClause assume in addition the homogeneous
specialization. Assume the calibrated
homogeneous spectral-weight regime, and define
\[
\Gamma_{\varphi}=\frac{\log\varphi}{\Delta\tau}.
\]
Let $N_{\varphi}$ and $N_{\mathrm{mem}}$ denote the lapse values of the two
response loci $\Sigma_{\varphi}$ and $\Sigma_{\mathrm{mem}}$. Then
\begin{equation}\label{eq:order-main}
N_{\varphi}<N_{\mathrm{mem}}
\iff
\Gamma_{\varphi}>\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau),
\end{equation}
with equality if and only if $\Gamma_{\varphi}=\Gamma_{\mathrm{crit}}(\kappa_{\mathrm r},\Delta\tau)$. Thus the ordering of the two homogeneous response loci is detector controlled; when a spatial profile and the regularity condition are both present, this is the corresponding spatial-level-set ordering inside the abstract calibrated toy model.
\end{proposition}

\begin{proof}
Both response loci are lapse level sets in the calibrated homogeneous
spectral-weight regime. Writing
\(\mathcal A=\lambda_{\mathrm{sw}}^2\mathcal S(\Omega)>0\),
the local excitation rate as a function of the lapse is
\[
\Gamma_+(N)=\frac{\mathcal A}{e^{\beta_\infty\Omega N}-1}.
\]
For $\beta_\infty,\Omega,N>0$,
\[
\frac{d\Gamma_+}{dN}
=
-\mathcal A\,\frac{\beta_\infty\Omega e^{\beta_\infty\Omega N}}
{(e^{\beta_\infty\Omega N}-1)^2}<0 .
\]
Hence the higher threshold rate corresponds exactly to the smaller lapse value, giving~\eqref{eq:order-main} and the equality statement.
\end{proof}
