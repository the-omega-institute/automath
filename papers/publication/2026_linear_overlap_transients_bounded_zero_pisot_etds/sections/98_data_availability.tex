\section*{Data and code availability}

No external data sets were used.  Code verifying the finite computations in
Section~\ref{sec:fixed-cubic-sharpness} is included in the accompanying
source archive.  The script
\path{artifacts/verify_fixed_cubic_audit.py} checks the aperture-two
identity, the aperture-three constant branch, the recursive terminal words,
and finite obstruction calculations from aperture four onward.  The script
\path{artifacts/test_bounded_zero_arbitrary_D.py} checks finite instances of
the arbitrary-alphabet adjacent collapse and the aperture-two edge
enumeration.  The script
\path{artifacts/verify_eventual_acyclicity.py} constructs complete
overlap graphs at representative apertures and checks their cycles and
longest paths.  These computations support, but are not used in place of,
the uniform analytic proofs.
