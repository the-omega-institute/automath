\section*{Data and code availability}

No external data sets were used.  Code verifying the finite computations in
Section~\ref{sec:fixed-cubic-sharpness} is included in the accompanying
source archive.  The script
\path{artifacts/verify_fixed_cubic_audit.py} checks the cases $m=4,5$, the
recursive terminal words, and finite obstruction calculations.  The script
\path{artifacts/test_bounded_zero_arbitrary_D.py} checks finite instances of
the arbitrary-alphabet adjacent collapse and the aperture-two edge
enumeration.  These computations support, but are not used in place of, the
uniform analytic proofs.
