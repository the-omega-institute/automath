\section*{Data and code availability}

No external data sets were used.  The proofs are analytic.  The accompanying
source archive contains exact finite computations used as regression and
falsification checks, not as substitutes for the parameter-uniform proofs.
The script \path{artifacts/verify_fixed_cubic_audit.py} checks the two small
apertures, the recursive terminal words, and the exact next-obstruction
emptiness over the audited range.  The script
\path{artifacts/test_bounded_zero_arbitrary_D.py} includes the seven-edge
regression for the anchored edge formulation and exhausts arbitrary-$D$
adjacent-window cases for a non-Condition-F cubic recurrence.  Saved outputs,
reproduction commands, and checksums are included under \path{artifacts/}.
