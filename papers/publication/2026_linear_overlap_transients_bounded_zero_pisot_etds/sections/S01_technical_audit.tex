\section{Scope of the audit}

This document records finite checks supporting implementation and
reproducibility.  None of the checks replaces a proof in the article.  In
particular, the arbitrary-alphabet adjacent collapse, the linear transient
bound, the exact collision quotient, and the fixed cubic terminal
classification are all proved in the main text.

\section{Small-aperture cubic records}

For the recurrence
\[
Q_0=1,\quad Q_1=2,\quad Q_2=4,\qquad
Q_{j+3}=2Q_{j+2}-Q_{j+1}+Q_j,
\]
the first values are
\[
1,2,4,7,12,21,37,65,114,200,351.
\]
At aperture four the asserted causal length is three.  Exhaustive integer
division of the two collision rows over $\{-1,0,1\}$ gives
\[
\mathcal N_{\theta,4,2}
=\{\pm(1,-1,-1,-1,1)\},
\qquad
\mathcal N_{\theta,4,3}=\varnothing.
\]
At aperture five the asserted causal length is three, and the corresponding
record is
\[
\mathcal N_{\theta,5,2}
=\{\pm(1,-1,-1,-1,1,0)\},
\qquad
\mathcal N_{\theta,5,3}=\varnothing.
\]
The verification script enumerates the bounded coefficient vectors directly,
checks divisibility of each consecutive window sum by $Q_m$, and compares
the resulting sets with these signed terminal words.

For $6\le m\le12$, the script constructs $E_m$ from its recursion and checks
all of the following exact integer assertions: every coefficient belongs to
$\{-1,0,1\}$; the first coefficient is nonzero; the first
$\lambda_m-1$ window sums are multiples of $Q_m$; the signed pair
$\{E_m,-E_m\}$ exhausts the penultimate obstruction set; and the next
obstruction set is empty.  The finite range is a regression boundary only.
The proof for all $m$ is the suffix-sum argument in the main article.

\section{Root-isolation arithmetic}

The cubic $f(x)=x^3-2x^2+x-1$ satisfies
\[
f(7/4)=-\frac1{64}<0,
\qquad
f(351/200)=\frac{3151}{8000000}>0.
\]
Its derivative has critical points $1/3$ and $1$, and $f$ is negative at
both; hence the interval isolates its only real root $\theta$.  If
$\rho,\overline\rho$ are the other roots, Vieta's formula gives
$|\rho|^2=1/\theta$ and therefore $|\rho|<0.756$ on the isolating interval.

The generating function
\[
\sum_{n\ge0}Q_nz^n=\frac{1+z^2}{1-2z+z^2-z^3}
\]
gives, by residues,
\[
c_\alpha=\frac{\alpha^2+1}{3\alpha^2-4\alpha+1}
\]
for every root $\alpha$.  Exact rational endpoint substitution, together
with the conjugate relation, yields
\[
1.26<c_\theta<1.27,qquad |c_\rho|<0.19.
\]
Consequently the nondominant contribution in either adjacent window is less
than $1.54$.  The exact finite separation for
$a,k,l\in\{-1,0,1\}$ is bounded below by
$2-\theta>0.245$, and endpoint arithmetic gives
\[
\theta^6(2-\theta)>7.03
>1+(1+\theta)1.54.
\]
These inequalities audit the claim that adjacent collapse holds from
aperture six onward.  The small-aperture enumeration above handles four and
five; no floating-point comparison enters the proof.

\section{Seven-edge anchored regression}

The repaired edge definition allows a body coefficient bound $D$ and a
separately bounded completing coefficient.  For the nonstandard initial
values $(u_0,u_1,u_2)=(1,2,4)$, aperture $m=2$, and $D=2$, direct enumeration
finds exactly the seven triples $(e_0,e_1,c)$ satisfying
\[
e_0u_0+e_1u_1+cu_2=0:
\]
\[
(-2,-1,1),\ (-2,1,0),\ (0,-2,1),\ (0,0,0),\
(0,2,-1),\ (2,-1,0),\ (2,1,-1).
\]
The induced nonzero transitions are
\[
-2\longrightarrow\{-1,1\},\qquad
2\longrightarrow\{-1,1\},
\]
while $-1$ and $1$ have no outgoing edges.  Thus no directed cycle is
reachable from a nonzero vertex.  An unanchored formulation would nevertheless
admit arbitrarily long zero padding before the nonzero transition.  The main
article avoids that false equivalence by shifting the chain so that its
initial exposed coefficient is nonzero.  The test reports the literal marker
\path{unanchored-chain regression edges=7} only after comparing the full
edge set above.

\section{Arbitrary-alphabet falsification battery}

The second audit uses the Pisot root of
$x^3-3x^2+2x-1$, which does not satisfy Condition~F.  It checks coefficient
bounds $D=2,3$ for both the canonical count recurrence and the nonstandard
initial values $(1,2,4)$.  For each of twelve adjacent-window cases, the
script enumerates the body coefficients and integer quotients and verifies
the conclusion
\[
k_{t+1}=0,\qquad e_{t+m}=-k_t
\]
at and beyond the audited contraction thresholds.  Testing a
non-Condition-F system guards against accidentally importing zero
preservation into the implementation.  The proof in the article uses only
the Pisot embeddings and the finite algebraic separation.
