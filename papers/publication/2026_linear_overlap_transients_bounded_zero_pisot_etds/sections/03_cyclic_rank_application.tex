\section{Cyclic rank recodings and the collision quotient}
\label{sec:cyclic-rank-application}

We now code the full shift on the canonical digit alphabet by replacing each
raw length-$m$ window with the legal word of the same cyclic rank.  A
future-only inverse recovers the raw symbol at time zero from output windows
beginning at time zero, without using past output.  Equality of two folded
windows says precisely that their raw ranks are congruent modulo $u_m$.
Taking coordinatewise differences converts a run of such congruences into
overlapping bounded representations of zero.  The exactness of this quotient
is crucial: it identifies all collisions, so path length in the arithmetic
graph measures inverse depth rather than merely bounding it.

A Pisot linear numeration system is a sequence $U=(u_j)_{j\ge0}$ of positive
integers satisfying the recurrence whose characteristic polynomial is the
minimal polynomial of a Pisot number.  We allow nonstandard initial values
and assume that $U$ is strictly increasing with $u_0=1$.  Let
\[
D_U=\{0,\ldots,d_U\}
\]
be its canonical greedy digit set.  The canonical greedy $U$-normal words of
length $m$ are
\begin{equation}
X_{U,m}=\left\{x\in D_U^m:
 \sum_{j=0}^k x_ju_j<u_{k+1}\quad(0\le k<m)\right\}.
\label{eq:pisot-canonical-words}
\end{equation}
Consequently
\[
\Val_{U,m}(x)=\sum_{j=0}^{m-1}x_ju_j
\]
maps $X_{U,m}$ bijectively onto $\{0,\ldots,u_m-1\}$.  Define
\begin{equation}
\Fold_{U,m}(w)=
(\Val_{U,m}|_{X_{U,m}})^{-1}
       (\Val_{U,m}(w)\bmod u_m)
\label{eq:pisot-canonical-fold}
\end{equation}
and let $\Phi_{U,m}$ be the corresponding sliding code on
$D_U^{\mathbb Z}$.  This is the cyclic language-rank recoding: each output
word is the unique legal word having the cyclically reduced rank of the raw
window.

Define $\ell_{\rm cau}(U,m)$ to be the least $L\ge1$ for which the raw digit
at time zero is determined, on the image of $\Phi_{U,m}$, by the output
windows at times $0,\ldots,L-1$; set it to $\infty$ if no such $L$ exists.
Thus $\ell_{\rm cau}(U,m)-1$ is the least anticipation of an inverse
constrained to have memory zero.  Relabeling each output by its canonical
rank turns the local rule into
\[
(x_0,\ldots,x_{m-1})\longmapsto
\sum_{j=0}^{m-1}u_jx_j\pmod {u_m}.
\]
This symbolwise relabeling is bijective.

Put $\Delta_U=[-d_U,d_U]\cap\mathbb Z$ and, for $L\ge1$, set
\begin{equation}
\mathcal N_{U,m,L}=\left\{e\in\Delta_U^{m+L-1}:
 e_0\ne0,\quad
 \sum_{j=0}^{m-1}u_je_{t+j}\equiv0\pmod {u_m}
 \ (0\le t<L)\right\}.
\label{eq:pisot-bad-sliding-set}
\end{equation}
Equivalently, $\mathcal N_{U,m,L}$ is the finite-block kernel of the
$L$-row banded Toeplitz operator with kernel
$(u_0,\ldots,u_{m-1})$ over $\mathbb Z/u_m\mathbb Z$, restricted by
$e_0\ne0$ and by the coefficient bound $\Delta_U$.  Every row has a unique
integer quotient $k_t$:
\begin{equation}
\sum_{j=0}^{m-1}u_je_{t+j}=k_tu_m.
\label{eq:pisot-window-carry}
\end{equation}
Equivalently,
\begin{equation}
[e_t,e_{t+1},\ldots,e_{t+m-1},-k_t]_U=0,
\label{eq:pisot-zero-word-bridge}
\end{equation}
where the last coordinate has weight $u_m$.  Thus every collision row is an
edge of $G_m(U,d_U)$, with completing coefficient $-k_t$.

\begin{lemma}[Exact collision quotient for $U$]
\label{lem:pisot-exact-collision-quotient}
For every $m\ge2$,
\begin{equation}
\ell_{\rm cau}(U,m)
=\min\{L\ge1:\mathcal N_{U,m,L}=\varnothing\}.
\label{eq:pisot-exact-depth}
\end{equation}
Let $\Gamma_{U,m}$ have vertex set $\Delta_U^{m-1}$ and an edge
$(v_0,\ldots,v_{m-2})\to(v_1,\ldots,v_{m-2},a)$ exactly when
\[
\sum_{j=0}^{m-2}u_jv_j+u_{m-1}a\equiv0\pmod {u_m}.
\]
If $B_{U,m}$ is the set of vertices with first coordinate nonzero, then
\begin{equation}
\ell_{\rm cau}(U,m)=1+\sup\{\text{edge length of a path from }B_{U,m}\}.
\label{eq:pisot-longest-path}
\end{equation}
Moreover, $\Phi_{U,m}$ is injective if and only if no directed cycle of
$\Gamma_{U,m}$ is reachable from $B_{U,m}$.
\end{lemma}

\begin{proof}
Two folded windows agree exactly when the difference of their raw values is
divisible by $u_m$, because the canonical normal words represent
$0,\ldots,u_m-1$ bijectively.  Every $e\in\Delta_U$ is realized as a
difference of two digits by taking its positive and negative parts in
$D_U$.  Hence two output $L$-blocks with distinct initial raw digits are
equivalent to a vector in $\mathcal N_{U,m,L}$, with no lost collisions.
Reading consecutive difference windows gives precisely the paths from
$B_{U,m}$ in $\Gamma_{U,m}$, proving \eqref{eq:pisot-exact-depth} and
\eqref{eq:pisot-longest-path}.  A reachable nonzero cycle can be repeated
periodically and is realized by two raw points.

It remains only to note why injectivity rules out the zero loop as a
reachable cycle.  If $d_U\ge u_m$, the constant nonzero difference sequence
$e_t=u_m$ belongs to $\Delta_U^{\mathbb Z}$ and every window sum is divisible
by $u_m$; hence $\Phi_{U,m}$ is noninjective and the difference graph has a
nonzero loop.  In the only remaining case, $d_U<u_m$.  If a vertex has an
edge to the zero vertex, its overlap coordinates vanish and its first
coordinate $a$ satisfies $a\equiv0\pmod {u_m}$.  The bound
$|a|\le d_U<u_m$ gives $a=0$, so the zero vertex is its own unique
predecessor.  This proves the last assertion without imposing a restriction
on the allowed nonstandard initial values.
\end{proof}

\begin{corollary}[Eventual injectivity and sharp asymptotic inverse bound]
\label{cor:pisot-linear-causal-depth}
Let $U$ be any strictly increasing Pisot numeration system with $u_0=1$,
canonical greedy digit set and canonical normal words.  There is an
effectively computable $C_U<\infty$ such that, for every $m\ge2$,
\begin{equation*}
\Phi_{U,m}\text{ injective}
\quad\Longrightarrow\quad
\ell_{\rm cau}(U,m)\le C_Um.
\tag{A1}\label{eq:pisot-linear-A1}
\end{equation*}
There is also an effectively computable $m_U$ such that, for every
$m\ge m_U$,
\begin{equation}
\Phi_{U,m}\text{ is injective},\qquad
\ell_{\rm cau}(U,m)\le m+1.
\label{eq:pisot-eventual-injectivity}
\end{equation}
Consequently
\begin{equation}
\limsup_{m\to\infty}\frac{\ell_{\rm cau}(U,m)}m\le1.
\label{eq:pisot-universal-asymptotic-slope}
\end{equation}
\end{corollary}

\begin{proof}
If the Pisot root has degree one, then $u_j=b^j$,
$D_U=\{0,\ldots,b-1\}$, the fold is the identity, and
$\ell_{\rm cau}(U,m)=1$; take $C_U=1$ and $m_U=2$.  Otherwise apply
Theorem~\ref{thm:bounded-zero-linear-transient} with $D=d_U$.  Its graph is
exactly $\Gamma_{U,m}$, because \eqref{eq:pisot-zero-word-bridge} is the
edge condition \eqref{eq:bounded-zero-overlap-edge}.  By Lemma
\ref{lem:pisot-exact-collision-quotient}, injectivity is equivalent to the
absence of a reachable cycle and the causal length is one plus the longest
path length.  Since the theorem gives fewer than $C(U,d_U)m$ edges, the
integer path length is at most $C(U,d_U)m-1$.  Taking
$C_U=C(U,d_U)$ proves \eqref{eq:pisot-linear-A1}.  For
$m\ge m_*(U,d_U)$, the same theorem says that the zero loop is the only
cycle and that every path from a first-coordinate-nonzero state has at most
$m$ edges.  Lemma~\ref{lem:pisot-exact-collision-quotient} then gives
\eqref{eq:pisot-eventual-injectivity} with
$m_U=m_*(U,d_U)$.  Dividing by $m$ and letting $m$ tend to infinity gives
\eqref{eq:pisot-universal-asymptotic-slope}.
\end{proof}

The corollary applies to nonstandard initial values whenever the resulting
sequence is strictly increasing; for example, the customary shifted
$k$-bonacci sequence beginning $1,2,\ldots$ belongs to this class.  It also
applies beyond Condition~F: the principal root of $x^3-3x^2+2x-1$ is Pisot
but does not satisfy Condition~F \cite[Theorem~3]{Akiyama2000}.  The proof
uses only the Pisot embeddings and the recurrence weights.
