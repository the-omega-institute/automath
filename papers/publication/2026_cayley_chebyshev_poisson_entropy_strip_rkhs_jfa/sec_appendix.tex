\section{Endpoint-normalized Haar-pullback uniqueness}%
\label{app:haar-pullback-uniqueness}

The entropy coefficient calculation uses only the pullback identity
\(\iota^*m_{\TT}=\omega\).  The following elementary normalization removes
the only possible ambiguity in the chosen Cayley chart.

\begin{proposition}[Endpoint-normalized Haar-pullback uniqueness]%
\label{prop:haar-pullback-uniqueness}
Let \(\varphi:\overline\RR\to\TT\) be an orientation-preserving homeomorphism
such that \(\varphi|_{\RR}\) is \(C^1\), \(\varphi(0)=1\), and
\(\varphi(\infty)=-1\).  Then \(\varphi^*m_{\TT}=\omega\) if and only if
\(\varphi=\iota\).  Without the orientation assumption, the only additional
possibility is complex conjugation.
\end{proposition}

\begin{proof}
Write \(\varphi(x)=e^{\ii\alpha(x)}\), where
\(\alpha:\RR\to(-\pi,\pi)\) is increasing and \(\alpha(0)=0\).  Pullback of
normalized arc length is \((2\pi)^{-1}\alpha'(x)\dd x\).  Therefore
\(\varphi^*m_{\TT}=\omega\) is equivalent to
\(\alpha'(x)=2/(1+x^2)\).  Integration gives
\(\alpha(x)=2\arctan x\), hence \(\varphi=\iota\).  The reversed-orientation
case follows by applying the same argument to \(\overline\varphi\).
\end{proof}

\section{Related work and theorem map}%
\label{app:related-work-scope}

The introduction contains the theorem-indexed comparison table used for the
main argument.  The detailed source notes are kept outside the compiled
manuscript.  The separation relevant to the proofs is the following.  Fixed
parametric Cauchy information formulae concern Cauchy laws, whereas
\(P_t*\nu\) is generally not Cauchy.  Entropy, Fisher-information, de Bruijn,
and R\'enyi CLT papers concern changing-law normalized-sum or stable-limit
asymptotics.  Heat and fractional-heat papers concern linear or nonlinear
large-time profile expansions in PDE norms.  Hardy--Stein and
Sobolev--Bregman papers supply the abstract Bregman identity used in
Section~\ref{sec:doob-phi-entropy}.  Stability and transport papers concern
functional-inequality deficits or transport estimates.  None of these sources
contains the fixed input-law Cauchy quotient, the Cayley--Chebyshev
coefficient algebra, the borderline \(t^{-2N}\log t\) power-tail layer, or
the finite Laurent constant-term evaluation used here.

\section{Weighted trigonometric normalization}%
\label{app:entropy-integrals}

This appendix records the change of variables behind the Laurent coefficient
normalization.  Set \(y=\tan\theta\),
\(-\pi/2<\theta<\pi/2\).  Then
\[
  \frac{\dd y}{\pi(1+y^2)}=\frac{\dd\theta}{\pi}.
\]
With \(z=e^{2\ii\theta}\),
\[
  \cos(2k\theta)=\frac{z^k+z^{-k}}2,\qquad
  \sin(2k\theta)=\frac{z^k-z^{-k}}{2\ii}.
\]
Thus the Cauchy mode integrals in
Theorem~\ref{thm:finite-fourier-mode-integral-algorithm} are exactly Haar
constant terms:
\[
  \int_{\RR}\prod_j u_{n_j}(y)\,\omega(\dd y)
  =[z^0]\prod_j Q_{n_j}(z).
\]
The finite order-eight arithmetic used in
Theorem~\ref{thm:poisson-kl-eighth} is the table in
Lemma~\ref{lem:eighth-order-coefficient-arithmetic}.
