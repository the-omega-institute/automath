\section{Finite Phase Checks}\label{sec:finite-phase-checks}

The coefficient calculus in Section~\ref{sec:entropy-asymptotics} uses exact
Laurent constant-coefficient extraction.  Appendix~\ref{sec:finite-phase-sampling}
records root-of-unity grids as an alias-free finite check for those same
Cayley phase polynomials.  The check verifies the normalized Laurent
constant terms used in Lemma~\ref{lem:eighth-order-coefficient-arithmetic};
it is not a separate normalization of the displayed coefficient arithmetic.
