\section{Supplementary note on optional auxiliary data}%
\label{sec:strip-lattice}

This note is deliberately not input by the compiled manuscript.  The entropy
expansion, the sixth-order coefficient-defect identity, the Doob-tail
identity, and conditional finite-time post-processing use only the centred
moment jet, the displayed Laurent constant-term table, and independently
supplied error bounds.
Optional observation interfaces are therefore kept as supplementary source
material rather than as another theorem layer in the paper.

For finite Laurent arithmetic, the compiled text already records the complete
coefficient vectors and zero-sum convolution sums in
Lemma~\ref{lem:eighth-order-coefficient-arithmetic}.  The certificate used by
the manuscript is therefore the displayed finite arithmetic itself: reconstruct
\(Q_2,\ldots,Q_6\), enumerate every zero-sum row through total order eight,
and check in particular the two sign-sensitive rows
\[
I(3,5)=-\frac{15}{128},\qquad
I(2,3,3)=-\frac{9}{128}.
\]

If an external observation channel is used only to supply moments, the entropy
layer needs no sampling theorem.  It needs the finite centred jet
\[
\mu_j=\int_{\RR}(\gamma-\bar{\gamma})^j\,\dd\nu(\gamma),
\qquad 2\le j\le6,
\]
and, for the quantitative seventh-moment remainder, the corresponding seventh
absolute moment bound.  One possible full-profile route is the following
Fourier identity.  For fixed \(t_0>0\), let
\(\kappa_{t_0}=\operatorname{Law}((\gamma-\bar{\gamma})/t_0)\) and
\(\lambda_{t_0}(\dd s)=s\,\kappa_{t_0}(\dd s)\).  If the sixth centred
absolute moment is finite, then
\[
q_{t_0}(\xi)=\pi\int_{\RR}e^{-\ii s\xi}\lambda_{t_0}(\dd s)
\]
has five derivatives at the origin and
\[
\mu_j=t_0^j\,\frac{\ii^{\,j-1}}{\pi}\,q_{t_0}^{(j-1)}(0),
\qquad 2\le j\le6.
\]
This is only a moment-supply identity.  Integer samples give the same jet only
under an additional exact support condition
\(\nu\{\gamma:\gamma-\bar{\gamma}\in t_0\ZZ\}=1\), where the convolution symbol
\[
\sum_{k\in\ZZ}\frac{2}{4+k^2}e^{-\ii k\theta}
=\pi\frac{\cosh(2(\pi-|\theta|))}{\sinh(2\pi)}
\]
is positive and hence invertible.  Without that support condition, integer
samples are projection data and are not an input to the entropy theorem chain.
