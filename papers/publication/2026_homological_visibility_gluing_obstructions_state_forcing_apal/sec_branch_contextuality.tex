\section{Boundary with empirical-model obstructions}
\label{sec:empirical-boundary}

Let \(X\) be a finite set of measurements, let \(O_x\) be a finite nonempty
outcome set for each \(x\in X\), and let \(\mathcal M\) be a finite antichain
of contexts covering \(X\).  For a finite empirical model \(e\), write
\(S_e(U)=\operatorname{supp}(e_U)\) for its support presheaf.  Adjoin a
terminal object \(X\), declare \(\mathcal M\) to cover it, and set
\[
 \widehat S_e(X)=\varprojlim_U S_e(U).
\]
Thus \(\widehat S_e(X)\) is the set of compatible supported local
assignments.  Let \(aS_e\) be the associated sheaf on this augmented site.

\subsection*{The terminal augmentation}

Because the event sheaf has unique gluing, restriction gives a natural
bijection
\begin{equation}\label{eq:contextual-global-set}
 \widehat S_e(X)
 \cong
 \left\{s\in\prod_{x\in X}O_x:
 s|_C\in S_e(C)\text{ for every }C\in\mathcal M\right\}.
\end{equation}
The plus construction for \(\mathcal M\to X\) produces the same set, so
\((aS_e)(X)\cong\widehat S_e(X)\).  Strong contextuality therefore gives an
empty set of global component sections in the canonical support construction.

\begin{theorem}[Empirical-model boundary]
\label{thm:empirical-model-boundary}
For every finite empirical model \(e\):
\begin{enumerate}[label=(\roman*),nosep]
\item compatible supported families, globally supported assignments, global
      sections in the Abramsky--Brandenburger sense, and elements of
      \(\widehat S_e(X)\cong(aS_e)(X)\) are naturally the same set.  Hence
      strong contextuality is absence of a matching family at this
      set-valued level, not matching without amalgamation;
\item for every supplied abelian sheaf \(\mathscr A\),
      \[
      \operatorname{Disc}(aS_e)\times\mathsf B\mathscr A
      \]
      is a canonical split \(\mathscr A\)-banded stack lift of \(aS_e\),
      and every one of its component gerbes is neutral;
\item the Abramsky--Mansfield--Barbosa obstruction attached to
      \(s\in S_e(C_0)\) is a relative class
      \[
      \gamma_e(s)\in
      \check H^1(\mathcal M,\mathcal F_{e,\overline C_0}),
      \]
      equivalently a torsor class.  It is not the Giraud \(H^2\)-class of a
      component gerbe.  There can be no construction recovering all such
      classes from a component-section map with component sheaf \(aS_e\):
      for a strongly contextual model the latter map has empty domain
      \((aS_e)(X)=\varnothing\), whereas the AMB classes remain indexed by
      local sections;
\item the homological images and the two-component criterion of
      \Cref{thm:wedge-sphere-two-component-label-loss} apply to an empirical
      model only after a band and a non-split banded prestack lift have been
      supplied as additional data.  They are not invariants of a bare
      empirical model.
\end{enumerate}
\end{theorem}

\begin{proof}
The event presheaf \(\mathcal E(U)=\prod_{x\in U}O_x\) is a sheaf.  Its
unique gluing proves \eqref{eq:contextual-global-set}; the terminal inverse
limit and the plus construction give the same compatible families.  This is
the standard support formulation of contextuality
\cite{AbramskyBrandenburger2011}, proving (i).

The discrete-groupoid functor sends \(aS_e\) to a stack with that component
sheaf, and \(\mathsf B\mathscr A\) has one component and automorphism sheaf
\(\mathscr A\).  In the product stack an object has the form \((s,T)\),
where \(T\) is an \(\mathscr A\)-torsor.  For every global component \(s\),
the trivial torsor gives a global object \((s,\mathscr A)\); hence each
component gerbe is neutral.  This proves (ii).

Abramsky--Mansfield--Barbosa apply the free-abelian presheaf
\(\mathcal F_e=\mathbb Z[S_e]\) and a relative kernel presheaf to obtain the
class in (iii) \cite[Sec.~4]{AbramskyMansfieldSoaresBarbosa2012}.  Car\`u
identifies it with a torsor trivialized by the measurement cover
\cite[Prop.~6.3]{Caru2017}.  A component-gerbe class is instead indexed by a
global section of the component sheaf.  When \(e\) is strongly contextual,
(i) makes that index set empty while local sections can still index AMB
classes.  This proves (iii).

The split lift in (ii) has zero component classes.  The non-split lift,
finite good-cover nerve, and prescribed maps used by
\Cref{thm:prescribed-component-image-construction} are additional data, which
proves (iv).
\end{proof}

The indexing and degree distinctions are summarized by
\[
\begin{array}{c|c|c}
 &\text{AMB obstruction}&\text{component-gerbe obstruction}\\ \hline
\text{index}&s\in S_e(C_0)&v\in(aS_e)(X)\\
\text{degree}&\check H^1&H^2\\
\text{object}&\text{relative torsor}&\text{banded gerbe}\\
\text{canonical lift}&\text{relative kernel data}&\text{split stack.}
\end{array}
\]

\subsection*{Degree-two contextuality classes}

Degree-two contextuality obstructions arise from source-side structure not
present in a bare support presheaf.  Operator-phase data give a normalized
\(2\)-cocycle whose class obstructs a noncontextual value assignment
\cite[Thm.~1]{OkayRobertsBartlettRaussendorf2017}; commutative partial-monoid
and simplicial formulations provide related degree-two witnesses
\cite[Secs.~3--4]{Aasnaess2022}\cite[Cor.~5.7]{OkayKharoofIpek2023}.  On the
common algebraic domain, Aasn{\ae}ss proves
\[
 \gamma(1\mathbin{\cdot}s_0)=0
 \quad\Longrightarrow\quad
 [\beta_{s_0}]=0
\]
\cite[Thm.~4.1]{Aasnaess2022}.  The operator-phase class therefore does not
separate an AMB-blind local section.  The AMB obstruction itself is
incomplete: Car\`u gives a strongly contextual model on which it vanishes
\cite[Sec.~4]{Caru2017}, while the later joint-model construction is complete
under the cyclic contextuality property \cite[Thm.~8.4]{Caru2018}.  These
results leave no construction here that takes bare empirical-model data to
the \(2\)-cocycles required by Theorem B.

Automorphism symmetry imposes a further elementary restriction.

\begin{proposition}[Equivariant no-selection]
\label{prop:equivariant-no-selection}
Suppose that coefficient groups \(A_e\) and the cohomology groups
\(H^2(N(\mathcal M_e);A_e)\) are functorial under isomorphisms of empirical
models.  If an assignment
\[
 e\longmapsto
 \Theta(e)\in H^2(N(\mathcal M_e);A_e)
\]
is natural under those isomorphisms, then
\[
 \Theta(e)\in
 H^2(N(\mathcal M_e);A_e)^{\operatorname{Aut}(e)}.
\]
Consequently, if this invariant subgroup is zero, every such natural
degree-two obstruction vanishes on \(e\).
\end{proposition}

\begin{proof}
For every \(g\in\operatorname{Aut}(e)\), naturality gives
\(g_*\Theta(e)=\Theta(e)\).  Thus \(\Theta(e)\) is fixed by every
automorphism, and it is zero when the fixed subgroup is zero.
\end{proof}

Applying the prescribed-realization theorem to an empirical model therefore
requires a chosen finite intersection site with connected nonempty overlaps,
a finite abelian band, a non-split banded prestack related to the support
data, and normalized Cech \(2\)-cocycles or maps
\(H_2(N,\mathbb Z)\to A\).  The support presheaf selects only the split
product lift, for which all component classes vanish.  Any homological images
obtained after supplying the additional data belong to that finite
presentation and lift.
