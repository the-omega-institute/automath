\section{Boundary with empirical-model obstructions}
\label{sec:empirical-boundary}

Let \(X\) be a finite set of measurements, let \(O_x\) be a finite nonempty
outcome set for each \(x\in X\), and let \(\mathcal M\) be a finite antichain
of contexts covering \(X\).  For a finite empirical model \(e\), write
\[
 S_e(U)=\operatorname{supp}(e_U)
\]
for its support presheaf on the downward-closed context category.  Adjoin a
terminal object \(X\), declare \(\mathcal M\) to cover it, and set
\[
 \widehat S_e(X)=\varprojlim_{U}S_e(U).
\]
Thus \(\widehat S_e(X)\) is the set of compatible supported local
assignments.  Let \(aS_e\) be the associated sheaf on this terminally
augmented context site.

\subsection*{The terminal augmentation}

On the original downward-closed context category, a global assignment is a
compatible family rather than a section over a named terminal context,
because the full measurement set \(X\) need not belong to the measurement
cover.  The augmentation adjoins \(X\) as a bookkeeping object and declares
the maximal contexts to cover it.  Its value is
\[
 \widehat S_e(X)
 =\left\{(s_C)_{C\in\mathcal M}:
 \begin{array}{l}
 s_C\in S_e(C),\\
 s_C|_{C\cap D}=s_D|_{C\cap D}
 \text{ for all }C,D
 \end{array}\right\}.
\]

Because the event sheaf has unique gluing, a compatible family determines a
unique outcome assignment \(s\in\prod_{x\in X}O_x\) whose restriction to
each \(C\) is \(s_C\).  Conversely, any assignment whose restriction lies
in every specified support gives such a family.  Hence
\begin{equation}\label{eq:contextual-global-set}
 \widehat S_e(X)
 \cong
 \left\{s\in\prod_{x\in X}O_x:
 s|_C\in S_e(C)\ \text{for all }C\in\mathcal M\right\}.
\end{equation}

The plus construction for the cover \(\mathcal M\to X\) produces the same
set.  All members of a matching family agree strictly on intersections, and
the event sheaf supplies their unique outcome assignment.  Thus
\[
 (aS_e)(X)\cong\widehat S_e(X).
\]
Strong contextuality therefore gives an empty set of global component
sections in the canonical support construction, not a nonempty set of
components carrying non-neutral gerbes.

\begin{theorem}[Empirical-model boundary]
\label{thm:empirical-model-boundary}
For every finite empirical model \(e\):
\begin{enumerate}[label=(\roman*),nosep]
\item compatible supported families, globally supported assignments, global
      sections in the Abramsky--Brandenburger sense, and elements of
      \(\widehat S_e(X)\cong(aS_e)(X)\) are naturally the same set.  Hence
      strong contextuality is absence of a matching family at this
      set-valued level, not matching without amalgamation;
\item for every supplied abelian sheaf \(\mathscr A\),
      \[
      \operatorname{Disc}(aS_e)\times\mathsf B\mathscr A
      \]
      is a canonical split \(\mathscr A\)-banded stack lift of \(aS_e\),
      and every one of its component gerbes is neutral;
\item the Abramsky--Mansfield--Barbosa obstruction attached to
      \(s\in S_e(C_0)\) is a relative class
      \[
      \gamma_e(s)\in
      \check H^1(\mathcal M,\mathcal F_{e,\overline C_0}),
      \]
      equivalently a torsor class.  It is not the Giraud \(H^2\)-class of a
      component gerbe.  There can be no construction recovering all such
      classes from a component-section map with component sheaf \(aS_e\):
      for a strongly contextual model the latter map has empty domain
      \((aS_e)(X)=\varnothing\), whereas the AMB classes remain indexed by
      local sections;
\item the homological images and the two-component criterion of
      \Cref{thm:wedge-sphere-two-component-label-loss} apply to an empirical
      model only after a band and a non-split banded prestack lift have been
      supplied as additional data.  They are not invariants of a bare
      empirical model.
\end{enumerate}
\end{theorem}

\begin{proof}
The event presheaf
\(\mathcal E(U)=\prod_{x\in U}O_x\) is a sheaf.  A compatible family
\((s_C)_{C\in\mathcal M}\), with \(s_C\in S_e(C)\), therefore glues
uniquely to an assignment \(s\in\prod_{x\in X}O_x\), and its restrictions
lie in the stated supports.  Conversely, restricting such an assignment
gives the compatible family.  The terminal right Kan extension is the same
limit by definition, and the plus construction on the cover
\(\mathcal M\to X\) gives the same set in \((aS_e)(X)\).  This proves (i)
and agrees with the standard support formulation of contextuality
\cite{AbramskyBrandenburger2011}.

The four descriptions in (i) fit into a commutative square:
\[
\begin{array}{ccc}
\{\text{compatible support families}\}
 &\longrightarrow&
\{\text{outcome assignments locally in the support}\}\\
\big\downarrow&&\big\downarrow\\
\widehat S_e(X)&\longrightarrow&(aS_e)(X).
\end{array}
\]
The upper arrow is unique gluing in \(\mathcal E\), the left arrow is the
definition of the inverse limit, and the lower arrow is the plus-construction
map.  Every arrow is a bijection.  No groupoid or band enters this set-level
statement.

The discrete-groupoid functor sends a sheaf of sets to a stack with that
component sheaf and zero automorphism sheaves.  The classifying stack
\(\mathsf B\mathscr A\) has one component and automorphism sheaf
\(\mathscr A\).  Their product is therefore a split banded lift of
\(aS_e\).  In each component, the identity \(\mathscr A\)-torsor is a
global object, so the component gerbe is neutral and its Giraud class is
zero.  This proves (ii).

Objectwise, the product stack has objects
\[
 (s,T),
 \qquad
 s\in(aS_e)(U),\quad
 T\text{ an }\mathscr A|_U\text{-torsor}.
\]
Two objects can be isomorphic only when their first coordinates agree.
Consequently the component sheaf is \(aS_e\).  The automorphism sheaf of
\((s,T)\) is canonically \(\mathscr A|_U\).  For a global component
section \(s\), the object
\[
 (s,\mathscr A)
\]
with the trivial torsor lies globally in the corresponding full component.
This identifies the neutralizing object directly.

Abramsky--Mansfield--Barbosa apply the free-abelian presheaf
\(\mathcal F_e=\mathbb Z[S_e]\) and a relative kernel presheaf to obtain
the displayed degree-one Cech class
\cite[Sec.~4]{AbramskyMansfieldSoaresBarbosa2012}.  Car\`u identifies this
class with an appropriate torsor trivialized by the measurement cover
\cite[Prop.~6.3]{Caru2017}.  By contrast, the map in
\Cref{prop:standard-component-gerbe-package} is indexed by global sections
of the component sheaf and takes values in derived \(H^2\) of a sheaf band.
If \(e\) is strongly contextual, (i) gives
\((aS_e)(X)=\varnothing\), so every such component-section map has empty
domain.  Local sections \(s\in S_e(C_0)\) can still exist and index AMB
classes.  This degree and indexing mismatch proves (iii).

The mismatch has two independent parts:
\[
\begin{array}{c|c|c}
 &\text{AMB obstruction}&\text{component-gerbe obstruction}\\ \hline
\text{index}&s\in S_e(C_0)&v\in(aS_e)(X)\\
\text{degree}&\check H^1&H^2\\
\text{object}&\text{relative torsor}&\text{banded gerbe}\\
\text{canonical lift}&\text{relative kernel data}&\text{split stack.}
\end{array}
\]
Changing degree by a formal shift would not repair the indexing difference.
In a strongly contextual model the right-hand index set is empty, while the
left-hand index set can contain many local sections.  When a global support
assignment does exist, the canonical component indexed by it is neutral.
A nonzero degree-two class requires additional lift data in either case.

Finally, the canonical lift in (ii) has zero component classes and zero
homological image subgroups.  A non-split lift, a finite good-cover nerve,
and prescribed maps \(H_2(N,\mathbb Z)\to A\) are additional inputs to
\Cref{thm:prescribed-component-image-construction}; none is selected by the
support presheaf of a bare empirical model.  This proves (iv).
\end{proof}

\subsection*{Additional data required for the finite-site construction}

To apply the prescribed-realization theorem to an empirical model, one would
have to supply, at minimum:
\begin{enumerate}[label=(\roman*),nosep]
\item a finite intersection site with connected nonempty overlaps and a
      connected nerve;
\item a finite abelian band \(A\);
\item an \(A\)-banded prestack whose component presheaf is related to the
      chosen support data;
\item normalized Cech \(2\)-cocycles, or prescribed maps
      \(H_2(N,\mathbb Z)\to A\), for its component labels;
\item the terminal-fibre behavior required by the comparison criterion.
\end{enumerate}
The support presheaf supplies none of (ii)--(iv).  It supplies a canonical
answer only after one chooses the split product stack, and that answer sets
every degree-two component class to zero.  No construction established here
maps bare support presheaves to the non-split data used by the wedge
corollary.

One may postulate such lift data for a particular empirical model and then
apply the article's theorems conditionally.  The resulting homological images
belong to that supplied finite presentation and lift, not to the empirical
model alone.  The distinction is the same as in the opening interface: the
paper begins after the site, band, and prestack have been specified.

The theorem concerns possibilistic support.  Probabilistic
noncontextuality asks for a distribution on the global assignment set with
the given marginals, a different extension problem which is not determined
by \(S_e\).  This distinction is independent of the degree mismatch above.
