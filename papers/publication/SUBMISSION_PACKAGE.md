# 投稿包清单（所有论文适用）

A4 的外审报告暴露了一个我们自己造成的缺口。审稿人写道：

> 本次实际可得附件只有正文 PDF；所谓独立补充材料、Python 脚本、单元测试和存档输出均未随附件提供。下述对补充材料和机器核验的意见只能根据正文及来稿说明作程序性判断，不能替代对相应文件的正式审查。

**后果**：我们把材料迁进补充文档以压缩正文，又没有在投稿时把补充文档交出去，等于把辛苦建立的机器验证信用全部作废——审稿人只能"程序性判断"，不能给我们任何核验分。

## 每次投稿必须提交的内容

| # | 内容 | 说明 |
|--:|---|---|
| 1 | `main.pdf` | 正文 |
| 2 | `supplement.pdf` | **迁出正文的章节所在文档**。若正文有指向补充材料的指针而未提交此文件，那些指针即为悬空 |
| 3 | `artifacts/*.py` | 全部验证脚本 |
| 4 | `artifacts/test_*.py` | 全部测试 |
| 5 | 验证输出存档 | 脚本运行结果（`*.txt` / `*.csv`），使审稿人无需运行即可看到结论 |
| 6 | `artifacts/literature_check.md` | 文献核查记录，支撑优先权叙述 |
| 7 | `REPRODUCE.md` | 一键复现说明：装什么、跑什么命令、预期输出 |

## 投前自检

- [ ] 正文中每一处指向补充材料的指针，其目标是否在提交包内？
- [ ] `supplement.pdf` 是否为**清空 `.aux` 后从零重建**的产物？（增量编译会靠陈旧辅助文件报假成功）
- [ ] 正文对补充材料的**硬编码编号**是否与补充材料实际编号一致？`\suppref{Theorem~1.11}` 这类写法编号写错**不触发任何 LaTeX 告警**，须逐条按编号与类型核对
- [ ] 验证脚本能否在干净环境跑通？输出是否已随包提交？
- [ ] 期刊是否允许补充材料？若不允许，须把被迁出的内容**移回正文**，而不是留下悬空指针
