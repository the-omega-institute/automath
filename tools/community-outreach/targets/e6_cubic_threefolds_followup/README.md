# Stage-1 verification artifact for arXiv:2604.20970

This directory contains an independent Stage-1 computational artifact for:

> D. Litt, T. Krämer, G. Maculan. E6 local systems from cubic threefolds. arXiv:2604.20970, 2026.

The target is Proposition 3.6, specifically the Fermat-cubic Jacobian-ring cup-product rank claim.

## Stage-1 scope

The checker `check_2604_20970_fermat_jacobian_stage1.py` uses only Python's standard library. It builds the Jacobian ring of the Fermat cubic threefold

```text
F = x0^3 + x1^3 + x2^3 + x3^3 + x4^3
R = Z[x0,...,x4] / (x0^2, x1^2, x2^2, x3^2, x4^2).
```

Since every `x_i^2` is zero in `R`, the checker represents `R` by squarefree monomials. It verifies the Hilbert series

```text
[1, 5, 10, 10, 5, 1]
```

and computes exact rational ranks for every ordered naive graded multiplication map

```text
R_a tensor R_b -> R_{a+b}
```

with `0 <= a,b <= 5` and `a+b <= 5`. It also computes the corresponding `phi` form

```text
R_a -> Hom(R_b, R_{a+b})
```

and records the specific candidate `R_2 tensor R_2 -> R_4`.

## What this does not claim

This is Stage-1 evidence only, not a proof of Proposition 3.6. The exact paper-specific map `mu` has not been extracted from Section 3 of the PDF here. If none of the naive graded multiplication or `phi` candidates has rank `50`, the checker reports `INCONCLUSIVE_NEED_PDF_DEEP_READ` rather than rebranding the result.

The JSON file `check_2604_20970_fermat_jacobian_stage1_output.json` is generated by running the checker.
