TARGET - Theorem A: fixed-base linear causal depth and sharpness for Pisot numeration.

Let U = (u_j) be a strictly increasing Pisot numeration system, non-standard initial values
allowed, u_0 = 1, with canonical greedy digit set D_U = {0,...,d_U}. Let X_{U,m} be the
canonical greedy U-normal words of length m, i.e. x in D_U^m with sum_{j<=k} x_j u_j <
u_{k+1} for 0 <= k < m, so Val_{U,m} bijects X_{U,m} onto {0,...,u_m - 1}. Define
Fold_{U,m}(w) = (Val_{U,m}|_{X_{U,m}})^{-1}(Val_{U,m}(w) mod u_m) and the sliding code
Phi_{U,m}. Assume U preserves zeros, i.e. its leading Pisot root satisfies Condition F.

Prove:

 (A1) There is a constant C_U < infinity, EFFECTIVELY COMPUTABLE from the recurrence, the
      canonical digit set and the bounded-zero normalization automaton, such that for every
      m >= 2, Phi_{U,m} injective implies l_cau(U,m) <= C_U m. Equivalently, in the
      corresponding difference-collision graph, if no first-coordinate-nonzero state can
      reach a directed cycle, every directed path from that initial state set has length at
      most C_U m - 1.

 (A2) For theta the real root of x^3 - 2x^2 + x - 1 and U_theta = (Q_j(theta))_j, for all
      m >= 4: Phi_{theta,m} is injective and l_cau(theta,m) = 2*floor(m/2) - 1.

 (A3) With lambda_m = 2*floor(m/2) - 1, prove N_{theta,m,lambda_m - 1} nonempty and
      N_{theta,m,lambda_m} empty, and preferably classify the unique terminal collision pair
      N_{theta,m,lambda_m - 1} = {±E_m}.

Hence lim_{m->infinity} l_cau(theta,m)/m = 1, so the linear upper bound under a fixed Pisot
numeration cannot be improved to o(m) in growth order.
