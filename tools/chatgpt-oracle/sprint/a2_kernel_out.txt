# Verification Before Completion

## Overview

Claiming work is complete without verification is dishonesty, not efficiency.

**Core principle:** Evidence before claims, always.

**Violating the letter of this rule is violating the spirit of this rule.**

## The Iron Law

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

If you haven't run the verification command in this message, you cannot claim it passes.

## The Gate Function

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

## Common Failures

| Claim | Requires | Not Sufficient |
|-------|----------|----------------|
| Tests pass | Test command output: 0 failures | Previous run, "should pass" |
| Linter clean | Linter output: 0 errors | Partial check, extrapolation |
| Build succeeds | Build command: exit 0 | Linter passing, logs look good |
| Bug fixed | Test original symptom: passes | Code changed, assumed fixed |
| Regression test works | Red-green cycle verified | Test passes once |
| Agent completed | VCS diff shows changes | Agent reports "success" |
| Requirements met | Line-by-line checklist | Tests passing |

## Red Flags - STOP

- Using "should", "probably", "seems to"
- Expressing satisfaction before verification ("Great!", "Perfect!", "Done!", etc.)
- About to commit/push/PR without verification
- Trusting agent success reports
- Relying on partial verification
- Thinking "just this once"
- Tired and wanting work over
- **ANY wording implying success without having run verification**

## Rationalization Prevention

| Excuse | Reality |
|--------|---------|
| "Should work now" | RUN the verification |
| "I'm confident" | Confidence â‰  evidence |
| "Just this once" | No exceptions |
| "Linter passed" | Linter â‰  compiler |
| "Agent said success" | Verify independently |
| "I'm tired" | Exhaustion â‰  excuse |
| "Partial check is enough" | Partial proves nothing |
| "Different words so rule doesn't apply" | Spirit over letter |

   2: Let \((E,\Omega)\) be a probability space and let
   3: \(\epsilon_s\downarrow0\).  For \(i=1,2\), let \(A_{i,s}\) be probability
   4: densities such that, for one constant \(c>0\) and all sufficiently large
   5: \(s\),
   6: \begin{equation}\label{eq:abstract-two-background-hypotheses}
   7:  A_{i,s}\ge c,\qquad
   8:  \|A_{i,s}-1\|_1=o(1),\qquad
   9:  \|A_{1,s}-A_{2,s}\|_1=o(\epsilon_s).
  10: \end{equation}
  11: Let \(U_{i,s}=\epsilon_sB_{i,s}\), where
  12: \begin{equation}\label{eq:abstract-two-background-modes}
  13:  \sup_s\bigl(\|B_{1,s}\|_\infty+\|B_{2,s}\|_\infty\bigr)<\infty,
  14:  \qquad \int B_{i,s}\dd\Omega=0.
  15: \end{equation}
  16: Suppose
  17: \[
  18:  q_{i,s}=A_{i,s}+U_{i,s}+R_{i,s}
  19: \]
  20: are probability densities, uniformly bounded below by a positive constant,
  21: and
  22: \begin{equation}\label{eq:abstract-two-background-remainders}
  23:  \|R_{i,s}\|_\infty+\|R_{i,s}\|_1=o(\epsilon_s).
  24: \end{equation}
  25: Assume also that
  26: \(\int A_{1,s}\log^+A_{1,s}\dd\Omega<\infty\) for every sufficiently
  27: large \(s\).  Then all relative entropies below are finite and
  28: \begin{equation}\label{eq:abstract-two-background-conclusion}
  29:  D_{\rm KL}(q_{1,s}\Omega\|q_{2,s}\Omega)
  30:  =D_{\rm KL}(A_{1,s}\Omega\|A_{2,s}\Omega)
  31:  +\frac{\epsilon_s^2}{2}
  32:    \int(B_{1,s}-B_{2,s})^2\dd\Omega+o(\epsilon_s^2).
  33: \end{equation}
  34: \end{unnumberedlemma}

  36: \begin{proof}
  37: Suppress \(s\), write \(P_i=A_i+U_i\), and put
  38: \[
  39:  f(a,b)=a\log(a/b)-a+b.
  40: \]

  42: bounded below, the segments \(P_i+tR_i\), \(0\le t\le1\), have a common
  43: positive lower bound.  On any such region,
  44: \begin{equation}\label{eq:abstract-two-background-first-partials}
  45:  f_a(a,b)=\log(a/b),\qquad f_b(a,b)=1-a/b,
  46:  \qquad |f_a(a,b)|+|f_b(a,b)|\le C|a-b|.
  47: \end{equation}
  48: The mean-value theorem and
  49: \[
  50:  |(P_1+tR_1)-(P_2+tR_2)|
  51:  \le |A_1-A_2|+|U_1-U_2|+|R_1|+|R_2|
  52: \]
  53: therefore give the explicit remainder-removal bound
  54: \begin{align}
  55:  &\left|\int f(q_1,q_2)\dd\Omega-
  56:               \int f(P_1,P_2)\dd\Omega\right|\notag\\
  57:  &\quad\le
  58:  C(\|R_1\|_\infty+\|R_2\|_\infty)\|A_1-A_2\|_1\notag\\
  59:  &\qquad+C(\|U_1\|_\infty+\|U_2\|_\infty)
  60:           (\|R_1\|_1+\|R_2\|_1)\notag\\
  61:  &\qquad+C(\|R_1\|_\infty+\|R_2\|_\infty)
  62:           (\|R_1\|_1+\|R_2\|_1)
  63:  =o(\epsilon_s^2).
  64:  \label{eq:abstract-two-background-remove-remainders}
  65: \end{align}

  69:  a_t=A_1+tU_1,\qquad b_t=A_2+tU_2,

  71: \]

  98:  =o(\epsilon_s^2).

 124: \[
 125:  \left|\frac{\dd^3}{\dd t^3}f(a_t,b_t)\right|
 126:  \le C\epsilon_s^3(1+a_t).
 127: \]

 129: \begin{equation}\label{eq:abstract-two-background-cubic-bound}
 130:  \sup_{0\le t\le1}|H'''(t)|\le C\epsilon_s^3
 131:  =o(\epsilon_s^2).
 132: \end{equation}
 133: Taylor's theorem, \eqref{eq:abstract-two-background-first-variation},
 134: \eqref{eq:abstract-two-background-hessian-limit}, and

 137: \eqref{eq:abstract-two-background-remove-remainders} proves

 143: \end{proof}

  85: \begin{abstract}
  86: Arbitrary-order first unmatched moment relative-entropy asymptotics under
  87: Gaussian smoothing are due to Chen and Niles-Weed
  88: \cite{ChenNilesWeed2022SmoothedWasserstein}, while all-order
  89: stable/fractional heat-kernel density expansions are also prior work
  90: \cite{IshigeKawakamiMichihisa2017,
  91: IshigeKawakamiMichihisa2022RefinedFractional}.  Neither result is claimed as
  92: new.  For the heavy-tailed isotropic strictly \(\alpha\)-stable kernels,
  93: \(0<\alpha<2\), we identify the optimal complete-moment condition that
  94: transfers the density expansion through relative entropy.
  95: If two
  96: laws on \(\RR^d\) match all tensor moments below the integer order \(r\ge1\),
  97: have a nonzero order-\(r\) difference \(\Delta_r\), and have finite
  98: \(p_{r,\alpha,d}\)th absolute moments, where
  99: \[
 100:  p_{r,\alpha,d}=\max\left\{r,
 101:  \frac{2r(d+\alpha)}{d+\alpha+2r}\right\},
 102: \]
 103: then
 104: \[
 105:  D_{\rm KL}(p_s^{(\alpha,d)}*\nu\|p_s^{(\alpha,d)}*\eta)
 106:  =\mathcal Q_{\alpha,d,r}(\Delta_r)s^{-2r}+o(s^{-2r}).
 107: \]
 108: The coefficient is an orthogonally invariant positive-definite quadratic
 109: form on symmetric order-\(r\) tensors.  The endpoint moment is sufficient.
 110: When \(d+\alpha>2r\), every exponent
 111: \(\rho\in[r,p_{r,\alpha,d})\) fails uniformly even for pairs with finite
 112: nonzero \(\Delta_r\); when \(d+\alpha\le2r\), the threshold equals \(r\), and
 113: smaller exponents fail only to define \(\Delta_r\) throughout the moment
 114: class.  Thus the contribution is the heavy-tailed critical exponent,
 115: endpoint sufficiency, and uniform sharpness, not the Gaussian quadratic
 116: mechanism itself.
 117: 
 118: At every order \(r\), finite \(r\)th moments alone also give a law-by-law
 119: decomposition: the universal quadratic tensor term plus a nonnegative
 120: relative \(\Phi\)-energy between two positive proxies that retain each law's
 121: unexpanded tail beyond the smoothing scale and their common lower-order jet.
 122: To the best of our knowledge, this explicit positive proxy decomposition,
 123: with vanishing of its KL term as an exact necessary and sufficient condition
 124: for attainment of the universal coefficient, is new; no uniqueness or
 125: canonicity of the proxy is asserted.  The defect is nevertheless unchanged
 126: up to \(o(s^{-2r})\) by separate comparable hard or smooth retention profiles,
 127: by either additive or multiplicative mass normalization, and by common
 128: bounded order-\(r\) proxy gauges.  Among order-\(r\) jet-faithful proxies in
 129: the prescribed retained-tail/common-core ansatz, asymptotic coefficient
 130: rigidity identifies this gauge as the remaining freedom; no classification
 131: of all reasonable proxy conventions is claimed.
 132: For the Cauchy kernel, the Cayley
 133: transform additionally yields the exact equivalence between finite variance
 134: and bounded \(t^4\) relative entropy, an all-order finite Laurent rule for the
 135: subsequent coefficients, and a fully justified nonlocal Bregman tail identity
 136: for the moving matched quotient.
 137: \end{abstract}

 182: \begin{proposition}[Stable-kernel input package]
 183: \label{prop:stable-kernel-input-package}
 184: Put \(\beta=d+\alpha\).  For every multi-index \(\gamma\), there are positive
 185: constants \(c,C,C_\gamma\), depending on \(d,\alpha\) and the chosen stable
 186: scale, such that
 187: \begin{align}
 188:  c(1+|y|)^{-\beta}&\le p_1^{(\alpha,d)}(y)
 189:  \le C(1+|y|)^{-\beta},\label{eq:stable-input-density}\\
 190:  |\partial^\gamma p_1^{(\alpha,d)}(y)|
 191:  &\le C_\gamma(1+|y|)^{-\beta-|\gamma|},\label{eq:stable-input-derivative}\\
 192:  \frac{|\partial^\gamma p_1^{(\alpha,d)}(y)|}
 193:  {p_1^{(\alpha,d)}(y)}
 194:  &\le C_\gamma(1+|y|)^{-|\gamma|}.
 195:  \label{eq:stable-input-derivative-quotient}
 196: \end{align}
 197: In particular, \(p_1^{(\alpha,d)}\) is strictly positive and smooth,
 198: \(\|\nabla\log p_1^{(\alpha,d)}\|_\infty<\infty\), and
 199: \begin{equation}\label{eq:stable-input-translation-continuity}
 200:  \|\partial^\gamma p_1^{(\alpha,d)}(\mathord\cdot-z)
 201:        -\partial^\gamma p_1^{(\alpha,d)}\|_1\longrightarrow0
 202:  \qquad(z\to0).
 203: \end{equation}
 204: If the characteristic exponent is changed from \(|\xi|^\alpha\) to
 205: \(a|\xi|^\alpha\), put \(\lambda=a^{1/\alpha}\).  The new unit-scale density
 206: is \(p_{1,a}(y)=\lambda^{-d}p_1(y/\lambda)\).  Thus the density bound has
 207: factor \(\lambda^{-d}\), the derivative bound has factor
 208: \(\lambda^{-d-|\gamma|}\), and the quotient bound has factor
 209: \(\lambda^{-|\gamma|}\), with \(1+|y|\) replaced throughout by
 210: \(1+|y|/\lambda\).  Equivalently, all later
 211: constants are locally uniform when \(a\) ranges in a compact subset of
 212: \((0,\infty)\).

 268: \]

 270: \(1+|y|\le(1+|z|)(1+|y-z|)\).  The final integral is finite because
 271: \(\beta>d\).  For the lower bound, integrate over \(|y-z|\le1\) and use
 272: \eqref{eq:stable-input-density}; this gives the claimed power
 273: for \(|z|\ge2\).  Positivity and continuity on bounded \(z\)-sets complete
 274: the estimate.
 275: 
 276: For \(|z|\le1\), Proposition~\ref{prop:stable-kernel-input-package} also gives
 277: \(p_1(y-\theta z)\le C p_1(y)\), uniformly in \(0\le\theta\le1\).
 278: Taylor's formula along the segment from \(y\) to \(y-z\), followed by the
 279: derivative bound in \eqref{eq:stable-input-derivative}, therefore
 280: gives the pointwise bound
 281: \(|F_y^{(\alpha,d)}(z)-T_m^{(\alpha,d)}(y,z)|\le C|z|^{m+1}\), uniformly
 282: in \(y\).  For \(|z|>1\), \eqref{eq:stable-translation-lq-growth} gives
 283: \(\|F_\cdot^{(\alpha,d)}(z)\|_q\le C|z|^{\beta(1-1/q)}\).  The Taylor
 284: coefficients are bounded, so
 285: \(\|T_m^{(\alpha,d)}(\cdot,z)\|_q\le C|z|^m\).  Finally,
 286: \[
 287:  \beta(1-1/q)\le p,\qquad m\le p<m+1,
 288: \]
 289: with equality in the first relation when \(\beta>4\).  These observations
 290: prove \eqref{eq:stable-critical-global-remainder}.
 291: \end{proof}

 293: \begin{lemma}[Critical Bregman perturbation bound]
 294: \label{lem:critical-lq-kl-perturbation}
 295: Let \(1<q\le2\) and
 296: \(\Phi(s)=(1+s)\log(1+s)-s\) on \([-1,\infty)\), with
 297: \(0\log0=0\).  There is a constant \(C_q\) such that
 298: \begin{equation}\label{eq:critical-bregman-pointwise-bound}
 299:  0\le \Phi(u+v)-\Phi(u)-\log(1+u)v\le C_q|v|^q
 300: \end{equation}
 301: whenever \(|u|\le1/4\) and \(u+v\ge-1\).
 302: \end{lemma}
 303: 
 304: \begin{proof}
 305: The lower bound is convexity.  If \(|v|\le1/2\), the segment between
 306: \(u\) and \(u+v\) is contained in \([-3/4,3/4]\).  Since
 307: \(\Phi''(s)=(1+s)^{-1}\) there, Taylor's theorem gives an upper bound
 308: \(C v^2\le C|v|^q\).  If \(v<-1/2\), the admissible pairs
 309: \((u,v)\) range over a compact set and \(|v|^q\ge2^{-q}\); continuity at
 310: \(u+v=-1\) gives the result.  If \(v>1/2\), direct expansion of the left
 311: side shows that it is at most \(C(1+v)\log(1+v)+Cv\), which is bounded by
 312: \(C_qv^q\).  These three regions prove
 313: \eqref{eq:critical-bregman-pointwise-bound}.
 314: \end{proof}

 316: \begin{theorem}[Optimal uniform sufficient moment exponent for stable KL asymptotics]
 317: \label{thm:high-dimensional-kl-moment-threshold}
 318: Let \(d\ge1\), \(0<\alpha<2\), and let \(\nu\) be a probability law on
 319: \(\RR^d\) with mean \(\bar\gamma\).  Put
 320: \(X=\gamma-\bar\gamma\), and assume
 321: \begin{equation}\label{eq:critical-kl-moment-hypothesis}
 322:  \EE|X|^{p_{\alpha,d}}<\infty,
 323:  \qquad
 324:  p_{\alpha,d}=\max\left\{2,
 325:  \frac{4(d+\alpha)}{d+\alpha+4}\right\},
 326: \end{equation}
 327: then the covariance \(\Sigma=\EE[XX^{\mathsf T}]\) is finite and
 328: \begin{equation}\label{eq:critical-kl-leading-asymptotic}
 329:  H_{\alpha,d}(s):=
 330:  D_{\rm KL}\!\left(p_s^{(\alpha,d)}*\nu\,\middle\|\,
 331:  p_s^{(\alpha,d)}(\mathord\cdot-\bar\gamma)\right)
 332:  =\mathcal Q_{\alpha,d}(\Sigma)s^{-4}+o(s^{-4}),
 333: \end{equation}
 334: where
 335: \begin{equation}\label{eq:stable-leading-covariance-functional}
 336:  b_{\alpha,d,\Sigma}(y)
 337:  :=\frac1{2p_1^{(\alpha,d)}(y)}
 338:    \sum_{i,j=1}^d\Sigma_{ij}\partial_{ij}p_1^{(\alpha,d)}(y),
 339:  \qquad
 340:  \mathcal Q_{\alpha,d}(\Sigma)
 341:  :=\frac12\int b_{\alpha,d,\Sigma}^2\dd\Omega_{\alpha,d}.
 342: \end{equation}
 343: The exponent is optimal only in the following uniform sense.  For every
 344: \(0<r<2\), there is a mean-zero law with finite \(r\)th absolute moment
 345: and \(\limsup_{s\to\infty}s^4H_{\alpha,d}(s)=+\infty\).  If
 346: \(d+\alpha>4\), then for every \(2\le r<p_{\alpha,d}\) the counterexample
 347: may additionally be chosen with positive-definite finite covariance.
 348: Thus no smaller moment exponent implies
 349: \eqref{eq:critical-kl-leading-asymptotic} uniformly over its entire moment
 350: class, and the endpoint belongs to the sufficient side.
 351: 
 352: This is not a law-by-law moment criterion.  When \(d+\alpha>4\), finite
 353: \(p_{\alpha,d}\)-moment is not asserted to be necessary for an individual
 354: law; the exact finite-covariance criterion is the nonlinear raw-tail energy
 355: in Theorem~\ref{thm:stable-law-by-law-decomposition} below.  When
 356: \(d+\alpha\le4\), the exponent is two and boundedness of
 357: \(s^4H_{\alpha,d}(s)\) does force finite covariance, as the proof below
 358: shows.  For \(\alpha=1\) with the standard normalization
 359: \(p_1^{(1,d)}=P_1^{(d)}\), one has
 360: \(\mathcal Q_{1,d}=\mathcal Q_d\), so the theorem contains the radial
 361: Poisson result above.
 362: \end{theorem}
 363: 
 364: \begin{proof}
 365: Translation permits us to assume \(\bar\gamma=0\).  Fix
 366: \(q=q_{\alpha,d}\), \(p=p_{\alpha,d}\), and \(m=\lfloor p\rfloor\),
 367: and write
 368: \[
 369:  R_m(y,z)=F_y^{(\alpha,d)}(z)-T_m^{(\alpha,d)}(y,z),
 370:  \qquad r_s(y)=\EE R_m(y,X/s).
 371: \]
 372: Minkowski's inequality and
 373: \eqref{eq:stable-critical-global-remainder} give
 374: \[
 375:  s^p\|R_m(\cdot,X/s)\|_q\le C_{\alpha,d}|X|^p.
 376: \]
 377: For each fixed \(X\), the local part of the same estimate and \(m+1>p\)
 378: give
 379: \[
 380:  s^p\|R_m(\cdot,X/s)\|_q
 381:  \le C_{\alpha,d}|X|^{m+1}s^{p-m-1}\longrightarrow0.
 382: \]
 383: Dominated convergence therefore yields
 384: \begin{equation}\label{eq:critical-lq-integrated-remainder}
 385:  \|r_s\|_{L^q(\Omega_{\alpha,d})}=o(s^{-p}).
 386: \end{equation}
 387: 
 388: Centering removes the linear Taylor layer.  Averaging the remaining layers
 389: gives
 390: \begin{equation}\label{eq:critical-kl-quotient-decomposition}
 391:  \delta_s^{(\alpha,d)}=u_s+r_s,
 392:  \qquad
 393:  u_s=s^{-2}b_{\alpha,d,\Sigma}
 394:        +\mathbf 1_{\{m=3\}}s^{-3}B_3,
 395: \end{equation}
 396: where \(B_3\) is a bounded linear combination of third-order modes.  In the
 397: second case the required third moments exist because \(p\ge3\).  Hence
 398: \(\|u_s\|_\infty=O(s^{-2})\).  The boundedness of all these modes follows
 399: from Proposition~\ref{prop:stable-kernel-input-package}.
 400: 
 401: The identity
 402: \(F_y^{(\alpha,d)}(z)\Omega_{\alpha,d}(\dd y)
 403: =p_1^{(\alpha,d)}(y-z)\dd y\) shows that every translated quotient has
 404: integral one.  Moreover,
 405: \(\int|F_y^{(\alpha,d)}(z)-1|\Omega_{\alpha,d}(\dd y)\le2\), so Tonelli's
 406: theorem gives \(\delta_s^{(\alpha,d)}\in L^1(\Omega_{\alpha,d})\) with
 407: zero integral.  The KL change of variables is therefore
 408: \[
 409:  H_{\alpha,d}(s)=\int\Phi(\delta_s^{(\alpha,d)})\dd\Omega_{\alpha,d}
 410: \]
 411: in the extended sense.  For all sufficiently large \(s\), apply
 412: Lemma~\ref{lem:critical-lq-kl-perturbation} to \(u=u_s\), \(v=r_s\).
 413: HÃ¶lder's inequality and \eqref{eq:critical-lq-integrated-remainder} give
 414: \begin{align*}
 415:  \left|H_{\alpha,d}(s)-\int\Phi(u_s)\dd\Omega_{\alpha,d}\right|
 416:  &\le \|\log(1+u_s)\|_{q/(q-1)}\|r_s\|_q
 417:        +C_q\|r_s\|_q^q\\
 418:  &\le O(s^{-2})o(s^{-p})+o(s^{-pq})=o(s^{-4}),
 419: \end{align*}
 420: because \(p\ge2\) and \(pq=4\).
 421: This estimate also proves that the extended KL integral is finite for all
 422: sufficiently large \(s\).
 423: 
 424: Finally, the boundedness of the retained modes permits a uniform Taylor
 425: expansion of \(\Phi(u_s)\).  From
 426: \eqref{eq:critical-kl-quotient-decomposition},
 427: \[
 428:  \int\Phi(u_s)\dd\Omega_{\alpha,d}
 429:  =\frac{s^{-4}}2\int b_{\alpha,d,\Sigma}^2\dd\Omega_{\alpha,d}
 430:    +o(s^{-4})
 431:  =\mathcal Q_{\alpha,d}(\Sigma)s^{-4}+o(s^{-4}),
 432: \]
 433: which proves \eqref{eq:critical-kl-leading-asymptotic}.
 434: 
 435: We first prove the obstruction below two moments.  If
 436: \(\limsup_{s\to\infty}s^4H_{\alpha,d}(s)<\infty\), Pinsker's inequality
 437: and scaling give, for every fixed \(\xi\in\RR^d\),
 438: \[
 439:  |\widehat p_1^{(\alpha,d)}(\xi)|
 440:  |\varphi_X(\xi/s)-1|
 441:  \le \|p_1^{(\alpha,d)}*\nu_s-p_1^{(\alpha,d)}\|_1
 442:  \le \sqrt{2H_{\alpha,d}(s)}=O(s^{-2}),
 443: \]
 444: where \(\nu_s\) is the law of \(X/s\).  Since the stable characteristic
 445: function never vanishes, take \(\xi=e\) for a unit vector \(e\), multiply
 446: the real part by \(s^2\), and use Fatou's lemma to obtain
 447: \[
 448:  \frac12\EE(e\cdot X)^2
 449:  \le \liminf_{s\to\infty}s^2
 450:        \EE[1-\cos((e\cdot X)/s)]<\infty.
 451: \]
 452: Thus bounded scaled entropy forces finite covariance.  Given \(0<r<2\),
 453: choose \(a\in(\max\{1,r\},2)\) and put symmetric masses proportional to
 454: \(n^{-a-1}\) at \(\pm ne_1\), with the remaining mass at zero.  This law
 455: has mean zero and finite \(r\)th moment but infinite variance, so its scaled
 456: entropy has infinite limsup.
 457: 
 458: It remains to prove optimality between two and \(p\) when \(\beta>4\).
 459: Fix \(2\le r<p\), choose positive \(a_j\) with \(\sum_ja_j<\infty\), and
 460: put symmetric masses \(w_j/2\) at \(\pm R_je_1\), where
 461: \(w_j=a_jR_j^{-r}\).  Add a sufficiently small bounded symmetric spanning
 462: component.  The resulting law has positive-definite finite covariance and
 463: finite \(r\)th moment.  Set
 464: \[
 465:  s_j=\kappa R_jw_j^{1/\beta},\qquad
 466:  A_j=B(R_je_1,s_j).
 467: \]
 468: The component at \(R_je_1\) gives
 469: \((p_{s_j}^{(\alpha,d)}*\nu)(A_j)\ge c_{\alpha,d}w_j\).  On the other hand,
 470: \eqref{eq:stable-input-density} and \(s_j/R_j\to0\) give
 471: \[
 472:  p_{s_j}^{(\alpha,d)}(A_j)
 473:  \le C_{\alpha,d}(s_j/R_j)^\beta
 474:  =C_{\alpha,d}\kappa^\beta w_j.
 475: \]
 476: Choose \(\kappa\) so that
 477: \(C_{\alpha,d}\kappa^\beta<c_{\alpha,d}\).  Data processing to
 478: \(\{A_j,A_j^c\}\) and
 479: Lemma~\ref{lem:bernoulli-kl-linear-separation} then yield
 480: \(H_{\alpha,d}(s_j)\ge c w_j\), and hence
 481: \[
 482:  s_j^4H_{\alpha,d}(s_j)
 483:  \ge cR_j^4w_j^{1+4/\beta}
 484:  =ca_j^{q_{\alpha,d}}R_j^{4-rq_{\alpha,d}}.
 485: \]
 486: Here \(q_{\alpha,d}=1+4/\beta\) and
 487: \(r<p=4/q_{\alpha,d}\), so the exponent of \(R_j\) is positive.
 488: Recursive choice of the radii makes \(s_j\to\infty\) and the last display
 489: unbounded while preserving all moment assertions.

 492: \begin{lemma}[All-order stable critical remainder]
 493: \label{lem:all-order-stable-critical-remainder}
 494: Let \(r\ge1\), put \(\beta=d+\alpha\), and define
 495: \begin{equation}\label{eq:all-order-stable-critical-exponents}
 496:  q_{r,\alpha,d}:=\min\left\{2,1+\frac{2r}{d+\alpha}\right\},
 497:  \qquad
 498:  p_{r,\alpha,d}:=\frac{2r}{q_{r,\alpha,d}}
 499:  =\max\left\{r,\frac{2r(d+\alpha)}{d+\alpha+2r}\right\}.
 500: \end{equation}
 501: Let \(q=q_{r,\alpha,d}\), \(p=p_{r,\alpha,d}\), and
 502: \(m=\lfloor p\rfloor\).  If \(T_m^{(\alpha,d)}(y,z)\) is the Taylor
 503: polynomial of \(F_y^{(\alpha,d)}(z)\) at zero through degree \(m\), then
 504: \begin{equation}\label{eq:all-order-stable-critical-remainder}
 505:  \|F_\cdot^{(\alpha,d)}(z)-T_m^{(\alpha,d)}(\cdot,z)\|_{L^q(\Omega_{\alpha,d})}
 506:  \le C_{\alpha,d,r}
 507:  \begin{cases}
 508:   |z|^{m+1},&|z|\le1,\\
 509:   |z|^p,&|z|>1,
 510:  \end{cases}
 511:  \le C_{\alpha,d,r}|z|^p.
 512: \end{equation}
 513: Consequently, if a probability law \(\lambda\) on \(\RR^d\) has finite
 514: \(p\)th absolute moment and
 515: \[
 516:  q_s^\lambda(y):=\int F_y^{(\alpha,d)}(x/s)\lambda(\dd x),
 517: \]
 518: then
 519: \begin{equation}\label{eq:all-order-stable-integrated-remainder}
 520:  q_s^\lambda
 521:  =1+\sum_{j=1}^m s^{-j}B_j^\lambda+r_s^\lambda,
 522:  \qquad
 523:  \|r_s^\lambda\|_{L^q(\Omega_{\alpha,d})}=o(s^{-p}),
 524: \end{equation}
 525: where
 526: \begin{equation}\label{eq:all-order-stable-moment-modes}
 527:  B_j^\lambda(y):=
 528:  \frac{(-1)^j}{p_1^{(\alpha,d)}(y)}
 529:  \sum_{|\gamma|=j}\frac{m_\gamma(\lambda)}{\gamma!}
 530:  \partial^\gamma p_1^{(\alpha,d)}(y),
 531:  \qquad
 532:  m_\gamma(\lambda):=\int x^\gamma\lambda(\dd x).
 533: \end{equation}
 534: Every \(B_j^\lambda\) in this display is bounded.
 535: \end{lemma}
 536: 
 537: \begin{proof}
 538: The proof of \eqref{eq:stable-translation-lq-growth} applies verbatim for
 539: every fixed \(1<q\le2\) and gives
 540: \[
 541:  \|F_\cdot^{(\alpha,d)}(z)\|_{L^q(\Omega_{\alpha,d})}
 542:  \le C(1+|z|)^{\beta(1-1/q)}.
 543: \]
 544: The local Taylor argument in the proof of
 545: Lemma~\ref{lem:stable-critical-translation-remainder} gives the first line
 546: of \eqref{eq:all-order-stable-critical-remainder}.  For \(|z|>1\), the
 547: Taylor modes are bounded by
 548: Proposition~\ref{prop:stable-kernel-input-package}, and
 549: hence
 550: \[
 551:  \|F_\cdot^{(\alpha,d)}(z)-T_m^{(\alpha,d)}(\cdot,z)\|_q
 552:  \le C\{|z|^{\beta(1-1/q)}+|z|^m\}\le C|z|^p.
 553: \]
 554: Indeed, \(m\le p\), while
 555: \(\beta(1-1/q)\le p\); in the non-Hilbert regime
 556: \(\beta>2r\), both sides of the latter inequality equal
 557: \(2r\beta/(\beta+2r)\).  Since \(m+1>p\), the final inequality in
 558: \eqref{eq:all-order-stable-critical-remainder} also holds on the unit ball.
 559: 
 560: Taylor's formula gives \eqref{eq:all-order-stable-integrated-remainder}
 561: before its norm assertion.  For fixed \(x\), the local estimate implies
 562: \[
 563:  s^p\|F_\cdot^{(\alpha,d)}(x/s)
 564:        -T_m^{(\alpha,d)}(\cdot,x/s)\|_q\longrightarrow0,
 565: \]
 566: whereas \eqref{eq:all-order-stable-critical-remainder} bounds this expression
 567: by \(C|x|^p\).  Minkowski's inequality and dominated convergence prove the
 568: claimed \(L^q\) remainder.  Boundedness of the modes follows again from
 569: Proposition~\ref{prop:stable-kernel-input-package}.
 570: \end{proof}

 572: \begin{lemma}[Two-background critical Bregman transfer]
 573: \label{lem:two-background-critical-bregman-transfer}
 574: Let \(1<q\le2\), \(p\ge r>0\), and \(pq=2r\).  On a probability space
 575: \((E,\Omega)\), suppose \(g_s\ge c_s>0\),
 576: \[
 577:  \int g_s\dd\Omega=1,\qquad c_s\longrightarrow1,
 578:  \qquad \|g_s-1\|_{L^1(\Omega)}\longrightarrow0.
 579: \]
 580: Let \(B\in L^\infty(\Omega)\), and suppose
 581: \[
 582:  v_s=s^{-r}B+o(s^{-r})\quad\hbox{in }L^\infty(\Omega),
 583:  \qquad \|e_s\|_{L^q(\Omega)}=o(s^{-p}).
 584: \]
 585: If \(g_s+v_s+e_s\ge0\) and both \(g_s\Omega\) and
 586: \((g_s+v_s+e_s)\Omega\) are probability measures, then
 587: \begin{equation}\label{eq:two-background-critical-bregman-transfer}
 588:  D_{\rm KL}((g_s+v_s+e_s)\Omega\|g_s\Omega)
 589:  =\frac{s^{-2r}}2\int B^2\dd\Omega+o(s^{-2r}).
 590: \end{equation}
 591: \end{lemma}
 592: 
 593: The hypotheses on the denominator in this lemma deliberately stop short of
 594: \(L^\infty\)-convergence to one.  They require only a positive lower bound
 595: approaching one, mass normalization, and \(L^1\)-convergence.  This weaker
 596: interface is what permits a heavy-tailed translated mixture to serve as the
 597: background.
 598: 
 599: \begin{proof}
 600: For \(g>0\), write \(\Psi_g(z)=g\Phi(z/g)\).  Scaling
 601: Lemma~\ref{lem:critical-lq-kl-perturbation} shows, whenever
 602: \(|v/g|\le1/4\) and \(g+v+e\ge0\), that
 603: \[
 604:  0\le\Psi_g(v+e)-\Psi_g(v)
 605:       -\log(1+v/g)e\le C_q g^{1-q}|e|^q.
 606: \]
 607: For large \(s\), the hypotheses give \(g_s\ge1/2\) and
 608: \(\|v_s/g_s\|_\infty\le1/4\).  Therefore H\"older's inequality yields
 609: \begin{align*}
 610:  &\left|D_{\rm KL}((g_s+v_s+e_s)\Omega\|g_s\Omega)
 611:        -\int\Psi_{g_s}(v_s)\dd\Omega\right|\\
 612:  &\qquad\le
 613:  C\|v_s\|_{L^{q/(q-1)}}\|e_s\|_{L^q}
 614:  +C\|e_s\|_{L^q}^q
 615:  =o(s^{-r-p})+o(s^{-pq})=o(s^{-2r}).
 616: \end{align*}
 617: Uniform Taylor expansion at zero gives
 618: \[
 619:  \int\Psi_{g_s}(v_s)\dd\Omega
 620:  =\frac12\int\frac{v_s^2}{g_s}\dd\Omega+O(\|v_s\|_\infty^3).
 621: \]
 622: Finally,
 623: \[
 624:  \left|\int B^2(g_s^{-1}-1)\dd\Omega\right|
 625:  \le2\|B\|_\infty^2\|g_s-1\|_1\longrightarrow0,
 626: \]
 627: and \eqref{eq:two-background-critical-bregman-transfer} follows.
 628: \end{proof}

 122: common moments below order \(r\) cancel, so
 123: \begin{equation}\label{eq:all-order-stable-two-quotient-split}
 124:  q_s^\nu-q_s^\eta=v_s+e_s,
 125:  \quad
 126:  v_s=\sum_{j=r}^m s^{-j}(B_j^\nu-B_j^\eta),
 127:  \quad
 128:  e_s=r_s^\nu-r_s^\eta.
 129: \end{equation}
 130: In particular,
 131: \[
 132:  s^rv_s\longrightarrow B_{\Delta_r}\quad\hbox{in }L^\infty,
 133:  \qquad \|e_s\|_q=o(s^{-p}).
 134: \]
 135: The intermediate modes \(r<j\le m\) in
 136: \eqref{eq:all-order-stable-two-quotient-split} are essential: unless their
 137: moments also match, they are not part of the \(o(s^{-p})\) remainder.
 138: 
 139: No part of this argument requires \(r\ge2\).  At \(r=1\), the endpoint
 140: formula still gives \(p\ge1\), hence the assumed \(p\)-moment supplies the
 141: first moments and \(\EE|X|<\infty\); also \(m+1>p\) and \(pq=2\).  Thus the
 142: critical remainder and the two-background transfer have exactly the powers
 143: needed for an \(o(s^{-2})\) error.  Lemma~\ref{lem:stable-finite-difference-blocks}
 144: records the corresponding first-difference block used for sharpness.
 145: 
 146: Proposition~\ref{prop:stable-kernel-input-package} implies
 147: \(\|\nabla\log p_1^{(\alpha,d)}\|_\infty\le L_{\alpha,d}\).  Hence, if
 148: \(X\) has law \(\lambda\),
 149: \[
 150:  q_s^\lambda(y)
 151:  \ge\EE\exp(-L_{\alpha,d}|X|/s)
 152:  \ge\exp(-L_{\alpha,d}\EE|X|/s),
 153: \]
 154: uniformly in \(y\).  The last expression tends to one.  Translation
 155: continuity of \(p_1^{(\alpha,d)}\) in \(L^1\) gives, by Tonelli and dominated
 156: convergence,
 157: \[
 158:  \|q_s^\eta-1\|_{L^1(\Omega_{\alpha,d})}
 159:  \le\int\|p_1^{(\alpha,d)}(\mathord\cdot-x/s)
 160:               -p_1^{(\alpha,d)}\|_1\,\eta(\dd x)\longrightarrow0;
 161: \]
 162: the integrand is bounded by two.  A second Tonelli calculation gives
 163: \(\int q_s^\lambda\dd\Omega_{\alpha,d}=1\) for every probability law
 164: \(\lambda\).  These are precisely the positive lower bound, mass
 165: normalization, and \(L^1\)-convergence required of the denominator by
 166: Lemma~\ref{lem:two-background-critical-bregman-transfer}; no
 167: \(L^\infty\)-convergence of \(q_s^\eta\) to one is used.  Taking
 168: \(g_s=q_s^\eta\) in that lemma proves
 169: \eqref{eq:all-order-stable-first-unmatched-asymptotic}.
 170: 
 171: Boundedness of \(B_{\Delta_r}\) makes
 172: \(\mathcal Q_{\alpha,d,r}\) finite.  If it were zero, then
 173: \[
 174:  \sum_{|\gamma|=r}\frac{\Delta m_\gamma}{\gamma!}
 175:  \partial^\gamma p_1^{(\alpha,d)}=0
 176: \]
 177: almost everywhere.  Fourier transformation in the sense of tempered
 178: distributions gives a homogeneous polynomial in \(\xi\), with coefficients
 179: \(\Delta m_\gamma/\gamma!\), multiplied by the nowhere-vanishing stable
 180: characteristic function.  The polynomial must vanish identically, contrary
 181: to \(\Delta_r\ne0\).  This proves strict positivity.  If \(U\in O(d)\),
 182: isotropy and the tensor chain rule give
 183: \(B_{U^{\otimes r}\Delta_r}(Uy)=B_{\Delta_r}(y)\).  Orthogonal invariance of
 184: \(\Omega_{\alpha,d}\) then proves the asserted invariance of \(\mathcal Q\).
 185: For \(d\ge2\), under the homogeneous-polynomial identification, the standard
 186: trace/harmonic decomposition
 187: \[
 188:  \operatorname{Sym}^r(\RR^d)
 189:  =\bigoplus_{k=0}^{\lfloor r/2\rfloor}
 190:    |x|^{2k}\mathcal H_{r-2k}
 191: \]
 192: is multiplicity-free under \(O(d)\).  Hence the self-adjoint operator of
 193: \(\mathcal Q\) is scalar on each harmonic summand; the positivity just proved
 194: shows that all these scalars are strictly positive.  No formula for the
 195: individual scalars is needed below.
 196: 
 197: It remains to establish sharpness.  Assume \(\beta=d+\alpha>2r\), so
 198: \[
 199:  q=1+\frac{2r}{\beta},\qquad p=\frac{2r}{q}>r.
 200: \]
 201: Fix a unit vector \(e\), and let \(A_R^\pm\) be the probability blocks from
 202: Lemma~\ref{lem:stable-finite-difference-blocks}.
 203: 
 204: Choose \(a_j>0\) with \(\sum_ja_j<\infty\).  Choose the radii recursively so
 205: that
 206: \begin{equation}\label{eq:all-order-separated-block-radii}
 207:  R_{j+1}>4(r+1)R_j,
 208: \end{equation}
 209: and enlarge each new radius further whenever necessary below.  Put
 210: \(w_j=a_jR_j^{-\rho}\), with \(\sum_jw_j<1\), and define
 211: \[
 212:  \nu=\left(1-\sum_jw_j\right)\delta_0+\sum_jw_jA_{R_j}^+,
 213:  \qquad
 214:  \eta=\left(1-\sum_jw_j\right)\delta_0+\sum_jw_jA_{R_j}^-.
 215: \]
 216: They have finite \(\rho\)th moments.  Since \(\rho\ge r\),
 217: \eqref{eq:stable-block-moment-identities} also shows that their
 218: order-\(r\) tensor difference is finite and nonzero.
 219: 
 220: The endpoint \(x_j=(r+1)R_je\) belongs to \(A_{R_j}^+\) and not to
 221: \(A_{R_j}^-\).  Let \(E_j\) be the ball of radius
 222: \[
 223:  s_j=\kappa R_jw_j^{1/\beta}
 224: \]
 225: about \(x_j\).  Recursive enlargement of \(R_j\) makes \(s_j\to\infty\);
 226: also \(s_j/R_j=\kappa w_j^{1/\beta}<1/4\) for all sufficiently large \(j\).
 227: Lemma~\ref{lem:stable-moving-ball-probability-separation} gives both
 228: probability bounds, after explicitly separating \(E_j\) from every
 229: opposite-sign atom in the same, preceding, and succeeding blocks.
 230: Choose \(\kappa\) so that
 231: \(C_{\alpha,d,r}\kappa^\beta<a_r\).  Data processing to
 232: \(\{E_j,E_j^c\}\), followed by
 233: Lemma~\ref{lem:bernoulli-kl-linear-separation}, gives
 234: \[
 235:  D_{\rm KL}(p_{s_j}^{(\alpha,d)}*\nu\|
 236:             p_{s_j}^{(\alpha,d)}*\eta)\ge c w_j.
 237: \]
 238: Consequently,
 239: \[
 240:  s_j^{2r}D_{\rm KL}(p_{s_j}^{(\alpha,d)}*\nu\|
 241:                     p_{s_j}^{(\alpha,d)}*\eta)
 242:  \ge cR_j^{2r}w_j^{1+2r/\beta}
 243:  =ca_j^qR_j^{2r-\rho q}.
 244: \]
 245: The final exponent is positive exactly when \(\rho<p=2r/q\).
 246: Recursive enlargement of \(R_j\) proves
 247: \eqref{eq:all-order-stable-sharpness}.  Finally, for \(\rho<r\), a
 248: one-dimensional Pareto law supported on the \(e\)-axis may have finite
 249: \(\rho\)th and infinite \(r\)th absolute moment, proving the stated domain
 250: obstruction.
 251: \end{proof}
 252: 
 253: \begin{corollary}[Stable Gaussian-quadrature entropy threshold]
 254: \label{cor:stable-gaussian-quadrature-threshold}
 255: Let \(0<\alpha<2\), \(n\ge1\), and let \(\nu\) be a probability law on
 256: \(\RR\) such that
 257: \[
 258:  \EE|X|^{2n-1}<\infty,\qquad |\operatorname{supp}\nu|\ge n.
 259: \]
 260: Let \(G_n\nu\) and \(\pi_n\) be its \(n\)-node Gaussian quadrature law and
 261: monic degree-\(n\) orthogonal polynomial, respectively.  Then
 262: \begin{equation}\label{eq:stable-gaussian-quadrature-finite}
 263:  \EE|X|^{2n}<\infty
 264:  \quad\Longrightarrow\quad
 265:  \lim_{s\to\infty}s^{4n}
 266:  D_{\rm KL}(p_s^{(\alpha,1)}*\nu\|
 267:             p_s^{(\alpha,1)}*G_n\nu)
 268:  =C_{\alpha,n}\|\pi_n\|_{L^2(\nu)}^4,
 269: \end{equation}
 270: where
 271: \begin{equation}\label{eq:stable-gaussian-quadrature-constant}
 272:  C_{\alpha,n}:=
 273:  \frac1{2((2n)!)^2}\int_{\RR}
 274:  \frac{(\partial^{2n}p_1^{(\alpha,1)}(y))^2}
 275:       {p_1^{(\alpha,1)}(y)}\dd y>0.
 276: \end{equation}
 277: On the other hand,
 278: \begin{equation}\label{eq:stable-gaussian-quadrature-infinite}
 279:  \EE|X|^{2n}=\infty
 280:  \quad\Longrightarrow\quad
 281:  s^{4n}D_{\rm KL}(p_s^{(\alpha,1)}*\nu\|
 282:                   p_s^{(\alpha,1)}*G_n\nu)\longrightarrow+\infty.
 283: \end{equation}
 284: Consequently, finiteness of the \(2n\)th absolute moment is equivalent to
 285: boundedness of the scaled relative entropy in
 286: \eqref{eq:stable-gaussian-quadrature-finite}.
 287: \end{corollary}
 288: 
 289: \begin{proof}
 290: Since \(1+\alpha<2(2n)\), the all-order critical exponent at \(r=2n\) is
 291: \(p_{2n,\alpha,1}=2n\).  Gaussian exactness through degree \(2n-1\) and
 292: \eqref{eq:gauss-missing-moment-norm} show that the first unmatched moment is
 293: \(\|\pi_n\|_{L^2(\nu)}^2\).  Theorem
 294: \ref{thm:all-order-stable-first-unmatched-moment} therefore gives
 295: \eqref{eq:stable-gaussian-quadrature-finite} and
 296: \eqref{eq:stable-gaussian-quadrature-constant}.  If this moment difference
 297: vanishes, \(\nu=G_n\nu\), and the same formula holds with both sides zero.
 298: Strict positivity of \(C_{\alpha,n}\) also follows from the Fourier argument
 299: in that theorem.
 300: 
 301: For the converse, define
 302: \[
 303:  R_n(u):=(-1)^n\left\{\cos u-
 304:        \sum_{k=0}^{n-1}\frac{(-1)^ku^{2k}}{(2k)!}\right\}.
 305: \]
 306: One has \(R_1=1-\cos\ge0\), while
 307: \(R_n''=R_{n-1}\) and \(R_n(0)=R_n'(0)=0\).  Induction therefore gives
 308: \(R_n\ge0\) on \(\RR\).  Moreover,
 309: \(s^{2n}R_n(x/s)\to x^{2n}/(2n)!\).  If the \(2n\)th moment of \(\nu\) is
 310: infinite, Fatou's lemma gives
 311: \[
 312:  s^{2n}\int R_n(x/s)\nu(\dd x)\longrightarrow+\infty.
 313: \]
 314: The corresponding integral for the finite-support law \(G_n\nu\) remains
 315: bounded.  Since all even moments below \(2n\) agree, it follows that
 316: \[
 317:  s^{2n}\left|\Re\{\varphi_\nu(1/s)
 318:                  -\varphi_{G_n\nu}(1/s)\}\right|\longrightarrow+\infty.
 319: \]
 320: At frequency \(1/s\), stable smoothing multiplies this difference by the
 321: fixed nonzero number \(\widehat p_1^{(\alpha,1)}(1)\).  The dual
 322: characterization of total variation and Pinsker's inequality now imply
 323: \eqref{eq:stable-gaussian-quadrature-infinite}.
 324: \end{proof}
 325: 
 326: \subsection{The law-by-law finite-covariance decomposition}
 327: 
 328: The preceding theorem optimizes over moment classes.  The next theorem gives
 329: the exact law-by-law interface under finite covariance alone.  It separates
 330: the universal quadratic covariance energy from the full nonlinear energy of
 331: the raw tail beyond the smoothing scale.
 332: 
 333: \begin{theorem}[Stable law-by-law tail decomposition]
 334: \label{thm:stable-law-by-law-decomposition}
 335: Let \(d\ge1\), \(0<\alpha<2\), and let \(\nu\) be a centred probability law
 336: on \(\RR^d\) with finite covariance matrix \(\Sigma\).  Put
 337: \[
 338:  H_{\alpha,d}(s):=
 339:  D_{\rm KL}\!\left(p_s^{(\alpha,d)}*\nu\,\middle\|\,
 340:  p_s^{(\alpha,d)}\right)
 341: \]
 342: and define
 343: \begin{equation}\label{eq:stable-raw-tail-potential}
 344:  V_s^\nu(y):=\int_{\{|x|>s\}}
 345:  \frac{p_1^{(\alpha,d)}(y-x/s)}
 346:       {p_1^{(\alpha,d)}(y)}\,\nu(\dd x).
 347: \end{equation}
 348: Then
 349: \begin{equation}\label{eq:stable-law-by-law-decomposition}
 350:  H_{\alpha,d}(s)=\mathcal Q_{\alpha,d}(\Sigma)s^{-4}
 351:  +\int_{\RR^d}\Phi(V_s^\nu(y))\,\Omega_{\alpha,d}(\dd y)
 352:  +o(s^{-4}).
 353: \end{equation}
 354: Consequently,
 355: \begin{equation}\label{eq:stable-law-by-law-criterion}
 356:  s^4H_{\alpha,d}(s)\longrightarrow\mathcal Q_{\alpha,d}(\Sigma)
 357:  \quad\Longleftrightarrow\quad
 358:  s^4\int_{\RR^d}\Phi(V_s^\nu)\dd\Omega_{\alpha,d}\longrightarrow0.
 359: \end{equation}
 360: No regular-variation, absolute-continuity, or moment hypothesis above order two
 361: is imposed.
 362: \end{theorem}
 363: 
 364: \begin{proof}
 365: For brevity write
 366: \[
 367:  p_1=p_1^{(\alpha,d)},\qquad
 368:  F_y(z)=F_y^{(\alpha,d)}(z)
 369:  =\frac{p_1(y-z)}{p_1(y)}.
 370: \]
 371: Let \(\ell_y(z)\) and \(B_2(y,z)\) denote the homogeneous first- and
 372: second-order Taylor terms of \(F_y(z)\) at zero.  The estimates in
 373: Proposition~\ref{prop:stable-kernel-input-package} and Taylor's formula give, for
 374: \(|z|\le1\),
 375: \begin{equation}\label{eq:stable-local-taylor-modulus}
 376:  \|F_\cdot(z)-1-\ell_\cdot(z)-B_2(\cdot,z)\|_\infty
 377:  +\|F_\cdot(z)-1-\ell_\cdot(z)-B_2(\cdot,z)\|_{L^1(\Omega_{\alpha,d})}
 378:  \le\varepsilon_{\alpha,d}(|z|)|z|^2,
 379: \end{equation}
 380: where \(\varepsilon_{\alpha,d}\) is bounded on \([0,1]\) and tends to zero
 381: at zero.  The uniform term is in fact \(O(|z|^3)\).  For the \(L^1\)
 382: term, multiplication by \(p_1(y)\) turns it into the second-order
 383: translation remainder of \(p_1\).  Since \(D^2p_1\in L^1\), the integral
 384: form of Taylor's theorem and translation continuity in \(L^1\) give
 385: \[
 386:  \int_0^1(1-\theta)|z|^2
 387:  \|D^2p_1(\mathord\cdot-\theta z)-D^2p_1\|_1\dd\theta=o(|z|^2).
 388: \]
 389: The Taylor coefficients also satisfy
 390: \begin{equation}\label{eq:stable-taylor-coefficient-norms}
 391:  \|B_j(\cdot,z)\|_\infty
 392:  +\|B_j(\cdot,z)\|_{L^1(\Omega_{\alpha,d})}
 393:  \le C|z|^j,\qquad j=1,2,\quad B_1=\ell.
 394: \end{equation}
 395: 
 396: Write
 397: \[
 398:  \delta_s(y)=\int\{F_y(x/s)-1\}\nu(\dd x),\qquad
 399:  u_s=s^{-2}b_{\alpha,d,\Sigma},\qquad
 400:  \tau_s=\nu(|x|>s).
 401: \]
 402: Finite covariance implies
 403: \begin{equation}\label{eq:stable-tail-mass-smallness}
 404:  \tau_s\le s^{-2}\int_{|x|>s}|x|^2\nu(\dd x)=o(s^{-2}).
 405: \end{equation}
 406: Centering and the identity
 407: \(\int B_2(y,x)\nu(\dd x)=b_{\alpha,d,\Sigma}(y)\) give the exact split
 408: \begin{equation}\label{eq:stable-raw-tail-split}
 409:  \delta_s=u_s+V_s^\nu-\tau_s+R_s,
 410: \end{equation}
 411: where
 412: \[
 413:  R_s=\int_{|x|\le s}\!
 414:  \{F_\cdot(x/s)-1-\ell_\cdot(x/s)-B_2(\cdot,x/s)\}\nu(\dd x)
 415:  -\int_{|x|>s}\!\{\ell_\cdot(x/s)+B_2(\cdot,x/s)\}\nu(\dd x).
 416: \]
 417: Equations \eqref{eq:stable-local-taylor-modulus} and
 418: \eqref{eq:stable-taylor-coefficient-norms}, followed by dominated
 419: convergence after multiplication by \(s^2\), show that
 420: \begin{equation}\label{eq:stable-raw-tail-remainder-smallness}
 421:  \|R_s\|_\infty+\|R_s\|_{L^1(\Omega_{\alpha,d})}=o(s^{-2}).
 422: \end{equation}
 423: For the omitted tail modes one uses
 424: \[
 425:  s^{-1}\int_{|x|>s}|x|\nu(\dd x)
 426:  \le s^{-2}\int_{|x|>s}|x|^2\nu(\dd x)
 427: \]
 428: and the analogous quadratic bound.
 429: 
 430: The translation identity for \(F_y\) gives the exact normalization
 431: \begin{equation}\label{eq:stable-tail-potential-normalization}
 432:  V_s^\nu\ge0,\qquad
 433:  \int V_s^\nu\dd\Omega_{\alpha,d}=\tau_s.
 434: \end{equation}
 435: All entropy integrals used below are finite.  Indeed,
 436: Proposition~\ref{prop:stable-kernel-input-package} and
 437: \(1+|w+z|\le(1+|w|)(1+|z|)\) give
 438: \[
 439:  D_{\rm KL}\!\left(p_1(\mathord\cdot-z)\,\middle\|\,p_1\right)
 440:  \le C_{\alpha,d}+(d+\alpha)\log(1+|z|).
 441: \]
 442: Convexity of relative entropy and \(\EE|X|^2<\infty\) therefore make
 443: \(H_{\alpha,d}(s)\) finite.  If \(\tau_s>0\), write
 444: \(V_s^\nu=\tau_s q_s\), where \(q_s\) is the quotient of the normalized
 445: tail mixture by \(p_1\).  Convexity gives
 446: \[
 447:  \int q_s\log q_s\dd\Omega_{\alpha,d}
 448:  \le \frac1{\tau_s}\int_{|x|>s}
 449:  \left\{C_{\alpha,d}+(d+\alpha)\log(1+|x|/s)\right\}\nu(\dd x)<\infty.
 450: \]
 451: Since \(\Phi(\tau q)\le\tau q\log(1+q)\) for \(0\le\tau\le1\), and the
 452: negative part of \(q\log q\) is bounded by \(e^{-1}\), this also proves
 453: \(\int\Phi(V_s^\nu)\dd\Omega_{\alpha,d}<\infty\).  The case \(\tau_s=0\)
 454: is immediate.
 455: 
 456: For \(|u|\le1/4\) and \(v\ge0\), two integrations of
 457: \(\Phi''(w)=(1+w)^{-1}\) yield
 458: \begin{equation}\label{eq:stable-phi-interaction}
 459:  |\Phi(u+v)-\Phi(u)-\Phi(v)|\le C|u|v.
 460: \end{equation}
 461: All negative terms in \eqref{eq:stable-raw-tail-split} are uniformly larger
 462: than \(-1/2\) for large \(s\).  The mean-value theorem,
 463: \(\log(1+v)\le v\), and
 464: \eqref{eq:stable-tail-potential-normalization} therefore give
 465: \begin{align}
 466:  \int|\Phi(\delta_s)-\Phi(u_s+V_s^\nu-\tau_s)|
 467:        \dd\Omega_{\alpha,d}&=o(s^{-4}),\label{eq:stable-remove-remainder}\\
 468:  \int|\Phi(u_s+V_s^\nu-\tau_s)-\Phi(u_s+V_s^\nu)|
 469:        \dd\Omega_{\alpha,d}&=o(s^{-4}),\label{eq:stable-remove-mass}\\
 470:  \int|\Phi(u_s+V_s^\nu)-\Phi(u_s)-\Phi(V_s^\nu)|
 471:        \dd\Omega_{\alpha,d}&=o(s^{-4}).\label{eq:stable-remove-interaction}
 472: \end{align}
 473: Indeed, the three left sides are bounded, respectively, by
 474: \[
 475:  C\|R_s\|_\infty\tau_s+Cs^{-2}\|R_s\|_1
 476:  +C\|R_s\|_\infty\|R_s\|_1,
 477:  \quad C\tau_s(\tau_s+s^{-2}),
 478:  \quad C\|u_s\|_\infty\tau_s,
 479: \]
 480: and each is \(o(s^{-4})\).
 481: 
 482: Finally, integration of the second derivatives in
 483: \eqref{eq:stable-leading-covariance-functional} gives
 484: \(\int b_{\alpha,d,\Sigma}\dd\Omega_{\alpha,d}=0\).  Boundedness of the
 485: covariance mode then implies
 486: \begin{equation}\label{eq:stable-covariance-phi-expansion}
 487:  \int\Phi(u_s)\dd\Omega_{\alpha,d}
 488:  =\frac{s^{-4}}2\int b_{\alpha,d,\Sigma}^2\dd\Omega_{\alpha,d}
 489:  +O(s^{-6})
 490:  =\mathcal Q_{\alpha,d}(\Sigma)s^{-4}+O(s^{-6}).
 491: \end{equation}
 492: Since \(H_{\alpha,d}(s)=\int\Phi(\delta_s)\dd\Omega_{\alpha,d}\),
 493: equations \eqref{eq:stable-remove-remainder}--
 494: \eqref{eq:stable-covariance-phi-expansion} prove
 495: \eqref{eq:stable-law-by-law-decomposition}.  The equivalence
 496: \eqref{eq:stable-law-by-law-criterion} follows because the tail energy is
 497: nonnegative.
 498: \end{proof}
 499: 
 500: \begin{remark}[What the decomposition resolves]
 501: When \(d+\alpha\le4\), one has \(p_{\alpha,d}=2\), so every
 502: finite-covariance law makes the tail energy \(o(s^{-4})\) by
 503: Theorem~\ref{thm:high-dimensional-kl-moment-threshold}.  When
 504: \(d+\alpha>4\), finite covariance alone need not do so.  In that regime
 505: \eqref{eq:stable-law-by-law-criterion} is the exact missing law-by-law
 506: condition: it neither replaces the nonlinear tail energy by a moment nor
 507: assumes regular variation.
 508: \end{remark}
 509: 
 510: The finite-covariance proof above uses positivity of the one-sided raw-tail
 511: potential.  At higher order the natural object is a pair of laws, and the
 512: difference of their raw-tail potentials is signed.  Applying \(\Phi\) to that
 513: difference would therefore neither be well-defined in general nor preserve
 514: nonnegativity.  The following relative \(\Phi\)-energy is the replacement.
 515: 
 516: \input{sec_two_background_kl_lemma}

 518: \begin{theorem}[Arbitrary-order law-by-law tail-defect decomposition]
 519: \label{thm:stable-arbitrary-order-law-by-law-decomposition}
 520: Let \(d\ge1\), \(0<\alpha<2\), and let \(r\ge1\) be an integer.  Let
 521: \(\nu,\eta\) be probability laws on \(\RR^d\) satisfying
 522: \begin{equation}\label{eq:arbitrary-tail-moment-hypotheses}
 523:  m_\gamma(\nu)=m_\gamma(\eta)\quad(|\gamma|<r),
 524:  \qquad
 525:  \int_{\RR^d}|x|^r(\nu+\eta)(\dd x)<\infty.
 526: \end{equation}
 527: For \(\lambda\in\{\nu,\eta\}\), put
 528: \[
 529:  \tau_s^\lambda=\lambda(|x|>s),\qquad
 530:  V_s^\lambda(y)=\int_{\{|x|>s\}}
 531:  F_y^{(\alpha,d)}(x/s)\lambda(\dd x),
 532: \]
 533: and use the moment modes \(B_j^\lambda\) from
 534: \eqref{eq:all-order-stable-moment-modes}.  Their values agree for \(j<r\);
 535: write
 536: \[
 537:  C_{r-1,s}(y)=\sum_{j=1}^{r-1}s^{-j}B_j^\nu(y)
 538:              =\sum_{j=1}^{r-1}s^{-j}B_j^\eta(y),
 539: \]
 540: with an empty sum when \(r=1\), and define
 541: \begin{equation}\label{eq:arbitrary-tail-proxy-quotients}
 542:  A_s^\lambda(y)=1+C_{r-1,s}(y)+V_s^\lambda(y)-\tau_s^\lambda.
 543: \end{equation}
 544: For all sufficiently large \(s\), both \(A_s^\lambda\) are positive,
 545: integrate to one against \(\Omega_{\alpha,d}\), and hence define probability
 546: densities
 547: \[
 548:  k_{r,s}^\lambda(x)=s^{-d}p_1^{(\alpha,d)}(x/s)
 549:                     A_s^\lambda(x/s).
 550: \]
 551:  The explicit nonnegative tail-defect energy
 552: \begin{align}
 553:  \mathcal E_{r,s}(\nu,\eta)
 554:  &:=D_{\rm KL}(k_{r,s}^\nu\|k_{r,s}^\eta)\notag\\
 555:  &=\int_{\RR^d}A_s^\eta
 556:  \Phi\!\left(\frac{A_s^\nu-A_s^\eta}{A_s^\eta}\right)
 557:  \dd\Omega_{\alpha,d}
 558:  \label{eq:arbitrary-tail-defect-energy}
 559: \end{align}
 560: is finite, and, with
 561: \(\Delta_r=\int x^{\otimes r}(\nu-\eta)(\dd x)\), one has
 562: \begin{equation}\label{eq:arbitrary-tail-defect-decomposition}
 563:  D_{\rm KL}(p_s^{(\alpha,d)}*\nu\|p_s^{(\alpha,d)}*\eta)
 564:  =\mathcal Q_{\alpha,d,r}(\Delta_r)s^{-2r}
 565:   +\mathcal E_{r,s}(\nu,\eta)+o(s^{-2r}).
 566: \end{equation}
 567: In particular, law by law,
 568: \begin{equation}\label{eq:arbitrary-tail-defect-criterion}
 569:  s^{2r}D_{\rm KL}(p_s^{(\alpha,d)}*\nu\|p_s^{(\alpha,d)}*\eta)
 570:  \longrightarrow\mathcal Q_{\alpha,d,r}(\Delta_r)
 571:  \quad\Longleftrightarrow\quad
 572:  s^{2r}\mathcal E_{r,s}(\nu,\eta)\longrightarrow0.
 573: \end{equation}
 574: No regular-variation or absolute-continuity hypothesis, and no moment above
 575: order \(r\), is required.
 576: \end{theorem}
 577: 
 578: \begin{proof}
 579: Write \(p_1=p_1^{(\alpha,d)}\), \(F_y=F_y^{(\alpha,d)}\), and let
 580: \(\mathsf B_j(y,z)\) be the homogeneous degree-\(j\) Taylor term of
 581: \(F_y(z)\) at zero.  The stable-kernel estimates in
 582: Proposition~\ref{prop:stable-kernel-input-package}, Taylor's formula, and
 583: translation continuity of \(D^rp_1\) in \(L^1\) give, for \(|z|\le1\),
 584: \begin{align}
 585:  &\left\|F_\cdot(z)-\sum_{j=0}^r\mathsf B_j(\cdot,z)\right\|_\infty
 586:  +\left\|F_\cdot(z)-\sum_{j=0}^r\mathsf B_j(\cdot,z)
 587:   \right\|_{L^1(\Omega_{\alpha,d})}
 588:  \le\varepsilon_r(|z|)|z|^r,
 589:  \label{eq:arbitrary-tail-local-remainder}\\
 590:  &\|\mathsf B_j(\cdot,z)\|_\infty
 591:  +\|\mathsf B_j(\cdot,z)\|_{L^1(\Omega_{\alpha,d})}
 592:  \le C_r|z|^j,\qquad 1\le j\le r,
 593:  \label{eq:arbitrary-tail-mode-bounds}
 594: \end{align}
 595: where \(\varepsilon_r\) is bounded on \([0,1]\) and tends to zero at
 596: zero.  For the uniform part one may use the bounded order-\((r+1)\)
 597: derivative quotient, giving the stronger \(O(|z|^{r+1})\) bound.  For the
 598: \(L^1\) part, multiplication by \(p_1(y)\) reduces the integral remainder
 599: to translates of \(D^rp_1\), exactly as in
 600: \eqref{eq:stable-local-taylor-modulus}.
 601: 
 602: Set
 603: \[
 604:  q_s^\lambda(y)=\int F_y(x/s)\lambda(\dd x).
 605: \]
 606: Splitting the integral at \(|x|=s\), retaining the raw exterior translate,
 607: and using the moment identities gives the exact decomposition
 608: \begin{equation}\label{eq:arbitrary-tail-exact-quotient-split}
 609:  q_s^\lambda=A_s^\lambda+s^{-r}B_r^\lambda+R_s^\lambda.
 610: \end{equation}
 611: Here \(R_s^\lambda\) is the interior Taylor remainder through order \(r\)
 612: minus the exterior Taylor modes of orders \(1,\ldots,r\).  Equations
 613: \eqref{eq:arbitrary-tail-local-remainder} and
 614: \eqref{eq:arbitrary-tail-mode-bounds} imply
 615: \begin{equation}\label{eq:arbitrary-tail-remainder-smallness}
 616:  \|R_s^\lambda\|_\infty+
 617:  \|R_s^\lambda\|_{L^1(\Omega_{\alpha,d})}=o(s^{-r}).
 618: \end{equation}
 619: Indeed, after multiplication by \(s^r\), the interior term is dominated by
 620: \(C|x|^r\) and converges pointwise to zero, while for \(j\le r\),
 621: \[
 622:  s^{-j}\int_{|x|>s}|x|^j\lambda(\dd x)
 623:  \le s^{-r}\int_{|x|>s}|x|^r\lambda(\dd x)=o(s^{-r}).
 624: \]
 625: The same last estimate gives
 626: \begin{equation}\label{eq:arbitrary-tail-mass-smallness}
 627:  \tau_s^\lambda=o(s^{-r}).
 628: \end{equation}
 629: 
 630: Translation preserves mass, so
 631: \[
 632:  V_s^\lambda\ge0,\qquad
 633:  \int V_s^\lambda\dd\Omega_{\alpha,d}=\tau_s^\lambda.
 634: \]
 635: Also \(\int B_j^\lambda\dd\Omega_{\alpha,d}=0\), by integration of the
 636: derivatives in \eqref{eq:all-order-stable-moment-modes}.  Therefore
 637: \begin{equation}\label{eq:arbitrary-tail-proxy-normalization}
 638:  \int A_s^\lambda\dd\Omega_{\alpha,d}=1.
 639: \end{equation}
 640: Moreover,
 641: \begin{equation}\label{eq:arbitrary-tail-proxy-positive-lower-bound}
 642:  \inf_yA_s^\lambda(y)
 643:  \ge1-\|C_{r-1,s}\|_\infty-\tau_s^\lambda\longrightarrow1,
 644: \end{equation}
 645: because \(V_s^\lambda\ge0\),
 646: \(\|C_{r-1,s}\|_\infty=O(s^{-1})\) (with value zero when \(r=1\)), and
 647: \eqref{eq:arbitrary-tail-mass-smallness} holds.  This proves positivity,
 648: including at \(r=1\), and gives a common lower bound such as \(1/2\).
 649: 
 650: We next prove proxy-entropy finiteness without appealing to the covariance
 651: case.  The two-sided stable-density bound in
 652: Proposition~\ref{prop:stable-kernel-input-package} and
 653: \(1+|w+z|\le(1+|w|)(1+|z|)\) give
 654: \begin{equation}\label{eq:arbitrary-tail-stable-translate-entropy}
 655:  D_{\rm KL}\!\left(p_1(\mathord\cdot-z)\,\middle\|\,p_1\right)
 656:  \le C_{\alpha,d}+(d+\alpha)\log(1+|z|).
 657: \end{equation}
 658: If \(\tau_s^\lambda>0\), write \(V_s^\lambda=\tau_s^\lambda Q_s^\lambda\),
 659: where \(Q_s^\lambda\) is the quotient, relative to \(p_1\), of the
 660: normalized exterior translate mixture.  Convexity of relative entropy and
 661: \eqref{eq:arbitrary-tail-stable-translate-entropy} imply
 662: \begin{align}
 663:  \int Q_s^\lambda\log Q_s^\lambda\dd\Omega_{\alpha,d}
 664:  &\le\frac1{\tau_s^\lambda}\int_{|x|>s}
 665:  \left\{C_{\alpha,d}+(d+\alpha)\log(1+|x|/s)\right\}
 666:  \lambda(\dd x)\notag\\
 667:  &<\infty,
 668:  \label{eq:arbitrary-tail-normalized-proxy-entropy}
 669: \end{align}
 670: since \(\log(1+|x|/s)\le |x|/s\) and the assumed \(r\)-th moment, with
 671: \(r\ge1\), supplies a finite first moment.  For \(0\le\tau\le1\),
 672: \(\Phi(\tau q)\le\tau q\log(1+q)\); hence
 673: \eqref{eq:arbitrary-tail-normalized-proxy-entropy}, together with the bound
 674: of the negative part of \(q\log q\), proves
 675: \begin{equation}\label{eq:arbitrary-tail-potential-entropy-finite}
 676:  \int\Phi(V_s^\lambda)\dd\Omega_{\alpha,d}<\infty.
 677: \end{equation}
 678: The conclusion is immediate when \(\tau_s^\lambda=0\).
 679: 
 680: For large \(s\), \(|C_{r-1,s}-\tau_s^\lambda|\le1/2\), so
 681: \(A_s^\lambda\le3/2+V_s^\lambda\).  The elementary bound
 682: \[
 683:  (u+v)\log^+(u+v)\le C\{1+v+\Phi(v)\},
 684:  \qquad 0\le u\le3/2,\quad v\ge0,
 685: \]
 686: and \eqref{eq:arbitrary-tail-potential-entropy-finite} show that
 687: \begin{equation}\label{eq:arbitrary-tail-proxy-positive-entropy-finite}
 688:  \int A_s^\lambda\log^+A_s^\lambda\dd\Omega_{\alpha,d}<\infty.
 689: \end{equation}
 690: Finally \(A_s^\eta\ge1/2\).  The positive part of
 691: \(A_s^\nu\log(A_s^\nu/A_s^\eta)\) is bounded by
 692: \(A_s^\nu\log^+(2A_s^\nu)\), while its negative part is bounded in absolute
 693: integral by \(e^{-1}\int A_s^\eta\dd\Omega_{\alpha,d}=e^{-1}\).
 694: Thus \(\mathcal E_{r,s}(\nu,\eta)<\infty\), as asserted.
 695: 
 696: It remains to verify, rather than assume, the hypotheses of the abstract
 697: two-background KL perturbation lemma.  Put
 698: \(\epsilon_s=s^{-r}\), take
 699: \[
 700:  (A_{1,s},A_{2,s})=(A_s^\nu,A_s^\eta),\qquad
 701:  (B_{1,s},B_{2,s})=(B_r^\nu,B_r^\eta),
 702:  \qquad (R_{1,s},R_{2,s})=(R_s^\nu,R_s^\eta).
 703: \]
 704: The modes \(B_r^\lambda\) are bounded by
 705: \eqref{eq:arbitrary-tail-mode-bounds}, and their integrals vanish.  The first
 706: requested background estimate follows directly from the common jet and the
 707: exact tail normalization:
 708: \begin{align}
 709:  \|A_s^\lambda-1\|_{L^1(\Omega_{\alpha,d})}
 710:  &\le\|C_{r-1,s}\|_{L^1(\Omega_{\alpha,d})}
 711:       +\|V_s^\lambda-\tau_s^\lambda\|_{L^1(\Omega_{\alpha,d})}\notag\\
 712:  &\le \sum_{j=1}^{r-1}s^{-j}\|B_j^\lambda\|_{L^1(\Omega_{\alpha,d})}
 713:       +2\tau_s^\lambda=o(1).
 714:  \label{eq:arbitrary-tail-background-to-one}
 715: \end{align}
 716: For \(r=1\), the sum is empty and the same proof applies.  For the second
 717: background estimate, the common jet cancels exactly, and therefore
 718: \begin{align}
 719:  \|A_s^\nu-A_s^\eta\|_{L^1(\Omega_{\alpha,d})}
 720:  &\le\|V_s^\nu-V_s^\eta\|_{L^1(\Omega_{\alpha,d})}
 721:        +|\tau_s^\nu-\tau_s^\eta|\notag\\
 722:  &\le2(\tau_s^\nu+\tau_s^\eta)=o(s^{-r}).
 723:  \label{eq:arbitrary-tail-two-background-separation}
 724: \end{align}
 725: This is the place where retaining the common lower-order jet removes every
 726: interior contribution from the difference of the backgrounds.
 727: 
 728: The proxy lower bound is \eqref{eq:arbitrary-tail-proxy-positive-lower-bound}.
 729: For the actual quotient, the bounded logarithmic gradient of \(p_1\) gives
 730: \(F_y(z)\ge e^{-L|z|}\), uniformly in \(y\).  Jensen's inequality then yields
 731: \begin{equation}\label{eq:arbitrary-tail-quotient-positive-lower-bound}
 732:  q_s^\lambda(y)
 733:  \ge\int e^{-L|x|/s}\lambda(\dd x)
 734:  \ge e^{-L\EE_\lambda|X|/s}\longrightarrow1
 735: \end{equation}
 736: uniformly in \(y\).  Thus the actual quotients have a common positive lower
 737: bound.  Their exact split is
 738: \(q_s^\lambda=A_s^\lambda+\epsilon_sB_r^\lambda+R_s^\lambda\),
 739: and \eqref{eq:arbitrary-tail-remainder-smallness} supplies the required
 740: \(L^1\) and \(L^\infty\) smallness.  Finally,
 741: \eqref{eq:arbitrary-tail-proxy-positive-entropy-finite} verifies the finite
 742: positive entropy hypothesis.  All hypotheses of the two-background KL
 743: perturbation lemma are now proved.  Its conclusion gives
 744: \[
 745:  D_{\rm KL}(p_s^{(\alpha,d)}*\nu\|p_s^{(\alpha,d)}*\eta)
 746:  =\mathcal E_{r,s}(\nu,\eta)
 747:  +\frac{s^{-2r}}2\int(B_r^\nu-B_r^\eta)^2
 748:        \dd\Omega_{\alpha,d}+o(s^{-2r}).
 749: \]
 750: By \eqref{eq:all-order-stable-leading-mode},
 751: \(B_r^\nu-B_r^\eta=B_{\Delta_r}\), so the quadratic integral is
 752: \(\mathcal Q_{\alpha,d,r}(\Delta_r)\).  This proves
 753: \eqref{eq:arbitrary-tail-defect-decomposition}.  Formula
 754: \eqref{eq:arbitrary-tail-defect-energy} is a relative \(\Phi\)-entropy and
 755: is therefore nonnegative; the equivalence
 756: \eqref{eq:arbitrary-tail-defect-criterion} follows immediately.
 757: 
 758: The raw-tail split, its normalization, and the finite-moment dominated
 759: convergence are exactly the steps that survive from the covariance proof.
 760: The new step is the two-background expansion above: it retains the common
 761: lower-order jet inside both positive tail proxies and replaces the
 762: unavailable one-sided \(\Phi\)-energy of a signed tail difference by a
 763: relative \(\Phi\)-energy.  When \(r=2\), \(\eta=\delta_0\), and \(\nu\) is
 764: centred, this energy is \(\int\Phi(V_s^\nu-\tau_s^\nu)\dd\Omega_{\alpha,d}\),
 765: which differs from the energy in
 766: Theorem~\ref{thm:stable-law-by-law-decomposition} by \(o(s^{-4})\), as shown
 767:  in \eqref{eq:stable-remove-mass}.
 768: \end{proof}

from pathlib import Path
import re
import unittest


ROOT = Path(__file__).resolve().parents[1]
INPUT_RE = re.compile(r"\\input\{([^}]+)\}")


def read_tex_source(path: Path) -> str:
    """Read a TeX source together with any local input wrappers."""

    source = path.read_text(encoding="utf-8")

    def expand(match: re.Match[str]) -> str:
        child = ROOT / match.group(1)
        if child.suffix == "":
            child = child.with_suffix(".tex")
        return read_tex_source(child)

    return INPUT_RE.sub(expand, source)
