## File Structure

Before defining tasks, map out which files will be created or modified and what each one is responsible for. This is where decomposition decisions get locked in.

- Design units with clear boundaries and well-defined interfaces. Each file should have one clear responsibility.
- You reason best about code you can hold in context at once, and your edits are more reliable when files are focused. Prefer smaller, focused files over large ones that do too much.

# Verification Before Completion

## Overview

Claiming work is complete without verification is dishonesty, not efficiency.

**Core principle:** Evidence before claims, always.

**Violating the letter of this rule is violating the spirit of this rule.**

## The Iron Law

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

If you haven't run the verification command in this message, you cannot claim it passes.

## The Gate Function

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

## Common Failures

| Claim | Requires | Not Sufficient |
|-------|----------|----------------|
| Tests pass | Test command output: 0 failures | Previous run, "should pass" |
| Linter clean | Linter output: 0 errors | Partial check, extrapolation |
| Build succeeds | Build command: exit 0 | Linter passing, logs look good |
| Bug fixed | Test original symptom: passes | Code changed, assumed fixed |
| Regression test works | Red-green cycle verified | Test passes once |
| Agent completed | VCS diff shows changes | Agent reports "success" |
| Requirements met | Line-by-line checklist | Tests passing |

## Red Flags - STOP

- Using "should", "probably", "seems to"

- About to commit/push/PR without verification
- Trusting agent success reports
- Relying on partial verification
- Thinking "just this once"
- Tired and wanting work over
- **ANY wording implying success without having run verification**

## Abstract

Let E=(C2)^r, and let two one-step E-cocycles lie over primitive edge shifts
whose vertex counts are at most V; the base shifts need not be the same. For
the primitive length-element counts p_(n,g), put E_g(y)=sum_(n>=1)
p_(n,g) log(1-y^n). Without a twisted-gap hypothesis, equality of every
element profile at 2V ceil(log_2(4V)) distinct radii in the common open Perron
interval forces equality of every p_(n,g), provided that one sampled radius
is algebraic. Thus the number of radial locations is independent of r,
although each location supplies the full 2^r-component profile vector. For a
reduced binary character-determinant ratio of total degree D>0, one algebraic
collision identifies the complete real collision set, which has at most
D ceil(log_2(2D))-1 points. The inverse mechanism is arithmetic: determinant
parity, Kumiko Nishioka's special-value theorem, and Keiji Nishioka's
algebraic-solution rationality theorem force a normalized rational Mahler coboundary. A divisor
l1 estimate gives an O(D log D) degree bound and one finite Pade system
reconstructs or rejects the certificate. An exact four-vertex pair shows that
one centered Perron-boundary profile vector does not suffice. For general
finite groups, recovery holds from a radial set with an interior accumulation
point; already for C3, Adams--Mobius inversion exhibits the obstruction to a
finite bound by coupling determinant logarithms at infinitely many powers.

## Abstract

We study a two-state killed-reset discrete-time Markovian arrival process
(D-MAP) through its stationary binary output. The deterministic post-arrival
reset makes the visible process renewal but does not make the hidden
representation identifiable. We derive the Palm gap law, its increasing
zero-run hazard, the one-mode covariance tail, the exact 1-dependence
criterion, and finite-word probabilities. Three visible inclusion
probabilities give a rational inverse to the symmetric survival coordinates.
This three-inclusion formula is presented as a candidate original result
pending complete reduction against canonical DMAP2 coordinates; it identifies
the unordered survival pair, not a labelled realization. Intersecting the
weak-equivalence class with the killed-reset Markov cone gives an explicit
two-state fibre arc whose endpoints are rate-swapped triangular kernels. For
minimal interior higher-state kernels, the fibre contains a local
positivity-preserving similarity manifold, while the pure serial result is a
finite-coordinate sampled-tail specialization of generalized-Erlang and
Coxian theory. For a fixed model and complete-cycle convention, we establish
a three-inclusion central limit theorem, a complete-visible-law specification
test, a root-free physical-image test, and a quotient delta method. Abstract
Markov-Palm tangent calculations, moving-dimensional Gaussian coupling, an
exact complete-Palm-gap split experiment, and a pointwise projection example
are placed in the supplement.

\begin{abstract}
For each positive integer $n$, let $B_n=\alpha^{-1}(n)$ be the exact fiber of
the Fibonacci rank-of-apparition map, and let $\mathcal M_n$ be its
divisibility-minimal elements. We classify
$\mathcal M_n$ exactly by irredundant witness covers of the prime coordinates
of $n$. For prime atoms this is the unordered form of Wagner's minimal
multiplicative cover condition; Fibonacci prime-power ladders replace deletion
of a label by lowering it. We prove the prime-power lifting, prime--ladder
dichotomy, and unique ladder-slot formulas used in the classification and its
upper bounds. The structural reduction is weighted by the multiplicities
$a(d)=\#\{p:\alpha(p)=d\}$ of exact-rank primes. On every odd layer we
construct a rank-pure sector with the exact weighted count
\[
 \sum_{\mathcal C\in
 \operatorname{MinCov}(\mathcal P(n))}
 \prod_{S\in\mathcal C}a(n_S)
 \leq\#\mathcal M_n .
\]
On every squarefree index $n\ge3$ this constructed sector is canonical: it is
exactly the squarefree part of $\mathcal M_n$, equivalently the minimal
squarefree part of $\alpha^{-1}(n)$. For every $n\ge3$ it is also in canonical
bijection with the minimal transversals of a coordinate hypergraph. Thus any
almost-all upper equivalent must control
the simultaneous exact-rank
multiplicities in this weighted cover sum. If $k=\omega(n)$ and $R(n)$ is the largest
atomic rank-window multiplicity, then unconditionally
\[
 \frac{\log2}{4}k^2-O(1)
 \leq\log\#\mathcal M_n
 \leq\frac{\log2}{4}k^2+k\log R(n)+O(k).
\]
The requested almost-all equivalent with coefficient $\log2/4$ is therefore
not proved. It would require an explicit $o((\log\log n)^2)$ bound for the
logarithmic excess of the weighted cover sum over its unweighted counterpart
on almost all odd indices, together with upper control of the complementary
non-rank-pure sector, which is the nonsquarefree sector on squarefree indices.
We isolate these as the open arithmetic interface. We
prove that collecting exact ranks into
support windows costs only $O(x\log\log x)$ in the relevant weighted mean, and
a fibotomic argument gives the unconditional pointwise estimate
$a(d)\leq(\log\varphi/2+o(1))\phi_{\rm E}(d)/\log d$, where
$\varphi=(1+\sqrt5)/2$. These estimates do not control the weighted-cover
excess. A sharp extremal theorem shows that the cumulative datum
$\omega(F_n)=\sum_{d\mid n}a(d)$ alone cannot do so: at fixed total weight,
concentration on the full support minimizes the weighted cover sum exactly.
As a direct corollary of classical exact-rank prime existence, we answer two
questions of FitzGibbons--Javaheri--Miller--Verga affirmatively in the stronger
prime form; no new prime-existence input is proved here.
Connected factorizations, exact support spectra, low-support
classifications, and finite checks are placed in the supplement.
\end{abstract}

Write $\operatorname{Fix}(\alpha)$ for the fixed points of the rank map.  For
$m\geq1$, define its \emph{fixed-point order} by
\[
 h(m):=\min\{k\geq0:\alpha^{\circ k}(m)\in
 \operatorname{Fix}(\alpha)\},
 \qquad
 \Lambda_k:=\{m\geq1:h(m)=k\}.
\]
For $x\in\operatorname{Fix}(\alpha)$, define its basin by
\[
 \Omega_x:=\{m\geq1:\alpha^{\circ j}(m)=x
 \text{ for some }j\geq0\}.
\]
These are the conventions of FitzGibbons--Javaheri--Miller--Verga
\cite{FitzGibbonsJavaheriMillerVerga2025Dynamics}. The fixed-point
classification is due to Marques \cite{Marques2012OrderAppearance}:
\[
 \operatorname{Fix}(\alpha)=\{5^a:a\geq0\}
 \cup\{12\cdot5^a:a\geq0\}
\]
Luca--Tron proved that every orbit reaches one of these fixed points
\cite{LucaTron2015SelfFibonacciDivisors}. In particular, the rank map has no
cycles of length greater than one. FitzGibbons--Javaheri--Miller--Verga are
cited below for their questions and terminology, not as the first source of
these two imported theorems.

No new prime-existence input is proved in this section. Every prime selected
below comes directly from Theorem~\ref{thm:primitive-divisors}.

Let $\varphi=(1+\sqrt5)/2$ and, for $t>0$, set
\[
 E_0(t)=t,\qquad E_{r+1}(t)=\varphi^{E_r(t)}\quad(r\geq0).
\]

\begin{theorem}[Prime inverse rays]\label{thm:prime-inverse-rays}
Let $y\geq7$ be an integer with $y\neq12$.  There are pairwise distinct
primes $p_1,p_2,\ldots$ such that, on putting $p_0=y$,
\[
 \alpha(p_r)=p_{r-1}\qquad(r\geq1).
\]
The primes can be chosen so that
\[
 p_r<E_r(y)\qquad(r\geq1).
\]
\end{theorem}

\begin{proof}
Theorem~\ref{thm:primitive-divisors} gives an exact-rank prime $p_1$ with
$\alpha(p_1)=y$.  Since $y\geq7$, this prime is not $2$, $3$, or $5$, and
hence $p_1\geq7$.  Inductively, if $p_r\geq7$ is chosen, then
$p_r\notin\{6,12\}$, so the same theorem supplies a prime $p_{r+1}$ with
$\alpha(p_{r+1})=p_r$.  This constructs the ray indefinitely.

No $p_r$ equals $5$: for $r=1$ this follows from $\alpha(p_1)=y\neq5$, and
for $r>1$ the equality $p_r=5$ would propagate backwards under $\alpha$ to
$p_1=5$.  If two primes in the ray were equal, that repeated prime would be
periodic under $\alpha$.  The absence of cycles of length greater than one
would make it a fixed prime, whereas the fixed-point classification shows
that the only fixed prime is $5$.  Thus the $p_r$ are pairwise distinct.

Finally, $\alpha(p_r)=p_{r-1}$ implies $p_r\mid F_{p_{r-1}}$.  Since
$F_d<\varphi^d$ for $d\geq1$, we have
\[
 p_r\leq F_{p_{r-1}}<\varphi^{p_{r-1}}.
\]
Induction on $r$ now gives $p_r<E_r(y)$.
\end{proof}

\begin{corollary}[Primes in every nontrivial fixed-point basin]
\label{cor:prime-basins}
For every fixed point $x>5$, the basin $\Omega_x$ contains infinitely many
primes.  More precisely, put
\[
 y_x=\begin{cases}7,&x=12,\\ x,&x\neq12.\end{cases}
\]
Then, for every $X>0$,
\[
 \#\{p\leq X:p\text{ prime},\ p\in\Omega_x\}
 \geq \max\bigl(\{r\geq1:E_r(y_x)\leq X\}\cup\{0\}\bigr).
\]
In particular, the lower bound is $\log^*X-O_x(1)$.
\end{corollary}

\begin{proof}
If $x\neq12$, then $x\geq7$ and Theorem~\ref{thm:prime-inverse-rays}
applied with $y=x$ gives distinct primes whose forward orbits reach $x$.
For the exceptional fixed point $12$, use
\[
 \alpha(7)=8,\qquad \alpha(8)=6,\qquad \alpha(6)=12
\]
and apply Theorem~\ref{thm:prime-inverse-rays} above $y=7$.  In either case,
the bound $p_r<E_r(y_x)$ gives the displayed counting estimate.  The
iterated-logarithm form follows by inverting the fixed-base exponential
recursion; changing the initial value changes the inverse height by
$O_x(1)$.
\end{proof}

\begin{corollary}[Primes of every positive fixed-point order]
\label{cor:prime-fixed-order}
For every $k\geq1$, the class $\Lambda_k$ contains infinitely many primes.
More precisely, for every $X>0$,
\[
 \#\{p\leq X:p\text{ prime},\ h(p)=k\}
 \geq
 \#\{b\geq1:E_k(12\cdot5^b)\leq X\}.
\]
\end{corollary}

\begin{proof}
Fix $b\geq1$ and put $p_{0,b}=12\cdot5^b$.  Repeating the construction in
Theorem~\ref{thm:prime-inverse-rays} for $k$ steps gives primes
$p_{1,b},\ldots,p_{k,b}$ such that
\[
 \alpha(p_{j,b})=p_{j-1,b}\quad(1\leq j\leq k),
 \qquad p_{k,b}<E_k(12\cdot5^b).
\]
The points $p_{1,b},\ldots,p_{k,b}$ are not fixed, so
$h(p_{k,b})=k$.  If $b\neq b'$, then $p_{k,b}\neq p_{k,b'}$, since applying
$\alpha^{\circ k}$ would otherwise give
$12\cdot5^b=12\cdot5^{b'}$.  The asserted bound and infinitude follow.
\end{proof}

FitzGibbons--Javaheri--Miller--Verga asked whether every $\Lambda_k$ with
$k\geq1$ contains infinitely many relatively prime integers, and conjectured
that every $\Omega_x$ with fixed $x>5$ does so
\cite{FitzGibbonsJavaheriMillerVerga2025Dynamics}. As a direct corollary of
classical exact-rank prime existence, Corollaries~
\ref{cor:prime-fixed-order} and \ref{cor:prime-basins} answer both questions
affirmatively in the stronger prime form. The only input needed is the
classical exact-rank existence recorded in
Theorem~\ref{thm:primitive-divisors}; the witness-cover and rank-pure
machinery developed earlier is not used in their proofs.

\section{Introduction}\label{sec:intro}
%% ====================================================================

For an integer $q\ge1$, the \emph{rank of apparition} (or \emph{order of
appearance}) $\alpha(q)$ is the least positive index $r$ such that $q\mid
F_r$, where $F_0=0$ and $F_1=1$.  The existence of this index is recalled in
Lemma~\ref{lem:finite-rank}.  We use the conventions $\alpha(1)=1$ and
$D_1=\operatorname{Div}(F_1)=\{1\}$.  For $n\ge2$, write
\[
 D_n:=\operatorname{Div}(F_n),\qquad
 B_n:=\{q\in D_n:\alpha(q)=n\},\qquad
 \mathcal M_n:=\min_{\mid} B_n .
\]
The rank divisibility criterion gives $B_n=\alpha^{-1}(n)$. Thus $B_n$ is
the standard exact preimage of $n$ under the rank map, equivalently the set
of moduli that first divide a Fibonacci number at index $n$, and
$\mathcal M_n$ is its set of divisibility-minimal elements.
The boundary layer is empty: $B_2=\mathcal M_2=\varnothing$.  Throughout,
$\log$ is natural, $\mathcal P(n)$ is the set of prime divisors of $n$,
$\omega(n)=\#\mathcal P(n)$, and $\Omega(n)$ counts prime factors with
multiplicity.

\subsection*{Prior work and novelty boundary}

The cardinality of $B_n$ is contained in Stroi\'nski's general
$\alpha$-contraction formalism \cite{Stroinski2016AlphaContraction}; classical
M\"obius identities for Fibonacci divisibility appear in
\cite{Halton1966DivisibilityFibonacci,FultonMorris1969ArithmeticalFunctions}.
For primes, nearby arithmetic-distribution results are due to Kiss. His 1988
work treats primitive divisors and accumulated primitive parts
\cite{Kiss1988PrimitiveDivisors}, while his paper on ranks of apparition of
primes in Lucas sequences bounds averages of $\alpha(p)/p$
\cite{Kiss1989RankApparition}.  These results, and Stroi\'nski's cumulative
bound for primes with bounded rank, do not give upper-distribution estimates
for the growing exact fibers
\[
 \Pi_\alpha(d):=\{p\text{ prime}:\alpha(p)=d\},\qquad
 a(d):=\#\Pi_\alpha(d).
\]
The distinction between cumulative rank estimates and the individual
multiplicities $a(d)$ is decisive below.

The nearest structural predecessor is Wagner's theory of minimal
multiplicative covers of an integer \cite{Wagner1978MultiplicativeCovers}.
Wagner studies divisor tuples $(d_1,\ldots,d_r)$ with lcm $n$ such that the
lcm becomes smaller when any one component is deleted, and presents them as
the multiplicative generalization of the minimal covers of finite sets studied
by Hearne--Wagner \cite{HearneWagner1973MinimalCovers}. Proposition~
\ref{prop:wagner-comparison} proves the exact comparison. When all atoms are
prime, $d^-(p)=1$ and our witness condition is Wagner's condition after
forgetting tuple order. A ladder atom has nontrivial $d^-(p^e)$, so deletion
is replaced by lowering one label. The contributions here are this
lowered-label Fibonacci realization, its unique correspondence with
$\mathcal M_n$, the canonical squarefree slice, and the exact arithmetic
weights. The classical minimal-cover skeleton itself is not new.

Other nearby work studies different aspects of the order-of-appearance map.
Luca and Pomerance study its local behavior under additive shifts
\cite{LucaPomerance2014LocalBehavior}; Trojovsk\'a and
FitzGibbons--Javaheri--Miller--Verga study periodic points and dynamics
\cite{Trojovska2020PeriodicPoints,
FitzGibbonsJavaheriMillerVerga2025Dynamics}; and Sanna gives distribution
theorems for rank divisibility and, under GRH, fixed indices of appearance
\cite{Sanna2022RankDivisibility,Sanna2024IndexAppearance}. Cera Da
Concei\c c\~ao subsequently gives explicit densities for fixed rank
divisibility for all Lucas sequences and all fixed divisors
\cite{CeraDaConceicao2026PrimeDensities}. Rank divisibility
$d\mid\alpha(p)$ does not isolate $\alpha(p)=d$, and the fixed-index theorem
does not provide the growing exact-fiber uniformity required here.

FitzGibbons--Javaheri--Miller--Verga ask whether, for each $k\geq1$, there
are infinitely many relatively prime integers of fixed-point order $k$, and
conjecture that the basin of each fixed point $x>5$ contains infinitely many
relatively prime integers.  Theorem~\ref{thm:prime-inverse-rays} constructs
infinite prime inverse rays.  Corollaries~\ref{cor:prime-fixed-order} and
\ref{cor:prime-basins} answer both questions in the stronger prime form.  The
argument is a direct application of exact-rank prime existence and does not
use the weighted-cover theory.

The structural starting points of this paper are classical:
\[
 q\mid F_m\Longleftrightarrow\alpha(q)\mid m,\qquad
 \gcd(F_r,F_s)=F_{\gcd(r,s)},
\]
and
\[
 \alpha(\operatorname{lcm}(u,v))
 =\operatorname{lcm}(\alpha(u),\alpha(v)).
\]
See \cite{Wall1960FibonacciModm,Vinson1963RankApparition}; Luca--Tron record
the last identity for Fibonacci numbers \cite{LucaTron2015SelfFibonacciDivisors},
and Renault proves it for the more general $(a,b)$-Fibonacci sequence
\cite{Renault2013PeriodRankOrder}. Exact-rank prime existence is supplied by
Carmichael and Bilu--Hanrot--Voutier
\cite{Carmichael1913PrimitiveDivisors,
BiluHanrotVoutier2001PrimitiveDivisorsLucas}.  The upper-set identity,
coordinatewise lcm test, prime-power lifting formulas, and private-coordinate
injection are consequences of these inputs.  We record them as lemmas and do
not claim them as independent arithmetic advances.

\subsection*{The reduction to a weighted arithmetic problem}

For a prime power $\theta=p^e$, call $\theta$ atomic when lowering it to
$p^{e-1}$ lowers its rank.  Relative to $n$, its rank has a full-coordinate
support $T_n(\theta)$ and an essential support $E_n(\theta)$, the coordinates
lost on lowering.  An $n$-witness cover is a pairwise coprime collection of
atoms whose full supports cover $\mathcal P(n)$ and in which each atom has an
essential coordinate absent from all other full supports.

\begin{previewtheorem}[Witness-cover classification]
Multiplication is a bijection from $n$-witness covers to $\mathcal M_n$.
Consequently every $m\in\mathcal M_n$ has a unique atomic factorization and
\[
 \omega(m)\le\omega(n).
\]
\end{previewtheorem}

This is Theorem~\ref{thm:witness-classification}.  The classification turns the
counting problem into a minimal-cover problem, but it does not erase the
number of primes available at each exact rank.  The following result gives a
necessary weighted obstruction on a positive-density family.

\begin{previewtheorem}[Weighted odd-layer obstruction]
Let $n\ge3$ be odd, set $V=\mathcal P(n)$, and for
$\varnothing\ne S\subseteq V$ put
$n_S=\prod_{\ell\in S}\ell^{\nu_\ell(n)}$.  If
$\operatorname{MinCov}(V)$ denotes the irredundant covers of $V$ by nonempty
subsets, then
\[
 \sum_{\mathcal C\in\operatorname{MinCov}(V)}
 \prod_{S\in\mathcal C}a(n_S)
 \le\#\mathcal M_n.
\]
\end{previewtheorem}

The general rank-pure embedding is
Theorem~\ref{thm:rank-pure-universality}, and the displayed obstruction is
Corollary~\ref{cor:odd-weighted-cover-obstruction}.  The sum is the exact
cardinality of an explicit rank-pure sector. Corollary~
\ref{cor:rank-pure-minimal-transversals} identifies it with the minimal
transversals of a canonical coordinate hypergraph. More arithmetically, on every
squarefree index Corollary~\ref{cor:canonical-squarefree-slice} identifies
that sector with the divisibility-minimal squarefree part of
$\alpha^{-1}(n)$. Thus the weighted cover polynomial counts standard
transversal objects and a standard slice of the exact fiber, not merely an
auxiliary family. Any upper equivalent for
$\#\mathcal M_n$ must control it. It need not exhaust the full fiber:
$\alpha(13)=7$ and $\alpha(13^2)=91$, so the odd squarefree layer $91$ already
has the ladder generator $169$ outside the rank-pure sector.

\ref{lem:labelled-minimal-cover-comparison} compares that labelled formula

\section{Birth layers and witness covers}\label{sec:upper-fibers}
%% ====================================================================

The first two lemmas in this section use only rank divisibility and the lcm
identity. They are included to fix the structural framework and are not
presented as new Fibonacci identities. The witness-cover theorem packages
their minimality conditions for the subsequent Fibonacci analysis.
The underlying deletion-one-factor condition is classical: Wagner called
divisor tuples satisfying it minimal multiplicative covers of an integer
\cite{Wagner1978MultiplicativeCovers}, as a multiplicative generalization of
the minimal set covers studied by Hearne--Wagner
\cite{HearneWagner1973MinimalCovers}. Proposition~
\ref{prop:wagner-comparison} states the exact boundary between that skeleton
and the lowered-label structure used here.

\begin{definition}\label{def:birth-layer}
For $n\ge2$ let
\[
D_n:=\operatorname{Div}(F_n),\qquad
B_n:=\{q\in D_n:\ \alpha(q)=n\},\qquad
A(n):=\#B_n.
\]
The set $B_n$ is partially ordered by divisibility. Its set of minimal
elements is
\[
\mathcal M_n:=\{m\in B_n:\ \text{there is no }q\in B_n
\text{ with }q\mid m\text{ and }q<m\},
\]
and
\[
\widthop(B_n):=\max\{\#\mathcal A:\ \mathcal A\subseteq B_n
\text{ is an antichain}\}.
\]
We write $\mathcal P(n)$ for the set of prime divisors of $n$. Since
$F_2=1$, we use the boundary convention
\[
B_2=\mathcal M_2=\varnothing,\qquad A(2)=\widthop(B_2)=0.
\]
\end{definition}

\begin{lemma}[Upper-fiber identity]\label{thm:upper-fiber}
For every $n\ge2$,
\[
B_n=D_n\setminus\bigcup_{p\mid n}D_{n/p}.
\]
Moreover $B_n$ is an upper set in $D_n$: if $q\in B_n$, $r\in D_n$, and
$q\mid r$, then $r\in B_n$. Consequently
\[
B_n=\bigcup_{m\in\mathcal M_n}\{q\in D_n:\ m\mid q\}.
\]
\end{lemma}

\begin{proof}
By Proposition~\ref{prop:rank-basics}, an integer $q$ lies in $D_m$ if and
only if $\alpha(q)\mid m$. Thus $q\in D_n$ lies outside
$\bigcup_{p\mid n}D_{n/p}$ precisely when $\alpha(q)\mid n$ but
$\alpha(q)\nmid n/p$ for every prime $p\mid n$.

If $\alpha(q)=n$, then clearly $\alpha(q)\nmid n/p$ for every $p\mid n$, so
$q$ is outside the union. Conversely, suppose $\alpha(q)\mid n$ and
$\alpha(q)<n$. Then $n/\alpha(q)>1$; choose a prime $p$ dividing
$n/\alpha(q)$. Since $\alpha(q)\mid n/p$, Proposition~\ref{prop:rank-basics}
gives $q\in D_{n/p}$, contrary to being outside the union. Hence the
complement is exactly the set of $q\in D_n$ with $\alpha(q)=n$, namely
$B_n$. For $n=2$ this also gives
$B_2=D_2\setminus D_1=\varnothing$ under the boundary convention in
Definition~\ref{def:birth-layer}.

Now let $q\in B_n$, $r\in D_n$, and $q\mid r$. Since $r\in D_n$,
$\alpha(r)\mid n$. Since $q\mid r$, every Fibonacci number divisible by $r$
is divisible by $q$; applying the divisibility criterion to
$F_{\alpha(r)}$ gives $\alpha(q)\mid\alpha(r)$. But $\alpha(q)=n$, so
$n\mid\alpha(r)$ and $\alpha(r)\mid n$, whence $\alpha(r)=n$. Therefore
$r\in B_n$.

Finally $D_n$ is finite, so every element $q\in B_n$ has at least one
minimal element $m$ of $B_n$ below it in the divisibility order. The upper-set
property gives the reverse containment: every element of $D_n$ divisible by
some $m\in\mathcal M_n$ lies again in $B_n$. This proves the displayed
decomposition.
\end{proof}

\begin{lemma}[Minimal-lcm criterion]\label{thm:minimal-generators}
Let $n\ge2$, and let
$m=\prod_{i=1}^r p_i^{e_i}$ be a divisor of $F_n$, with the $p_i$ distinct
and $e_i\ge1$. Put
\[
\lambda_i:=\alpha(p_i^{e_i}),\qquad
\lambda_i^-:=\alpha(p_i^{e_i-1}),
\]
where $\alpha(1)=1$. Then $m\in\mathcal M_n$ if and only if
\begin{equation}\label{eq:lcm-criterion}
\lcmop(\lambda_1,\ldots,\lambda_r)=n
\quad\text{and}\quad
\lcmop(\lambda_1,\ldots,\lambda_{i-1},\lambda_i^-,
\lambda_{i+1},\ldots,\lambda_r)<n
\quad(1\le i\le r).
\end{equation}
\end{lemma}

\begin{proof}
Because $m\mid F_n$, Proposition~\ref{prop:rank-basics} gives
$\lambda_i\mid n$ for every $i$. Applying the lcm identity in
Proposition~\ref{prop:rank-basics} repeatedly gives
\[
\alpha(m)=\lcmop(\lambda_1,\ldots,\lambda_r).
\]
Thus the first condition in \eqref{eq:lcm-criterion} is equivalent to
$m\in B_n$.

Assume first that $m\in\mathcal M_n$. Then $m\in B_n$, so the first lcm is
$n$. For a fixed $i$, the integer $m/p_i$ is a proper divisor of $m$ and is
still a divisor of $F_n$. Minimality of $m$ in $B_n$ implies
$m/p_i\notin B_n$. Since $\alpha(m/p_i)\mid n$, this is equivalent to
$\alpha(m/p_i)<n$. A second application of the lcm identity gives
\[
\alpha(m/p_i)=
\lcmop(\lambda_1,\ldots,\lambda_{i-1},\lambda_i^-,
\lambda_{i+1},\ldots,\lambda_r),
\]
which is the lowered prime-power condition in
\eqref{eq:lcm-criterion}.

Conversely, suppose \eqref{eq:lcm-criterion} holds. The first condition gives
$m\in B_n$. Let $q$ be any proper divisor of $m$. Then for at least one
index $i$ the exponent of $p_i$ in $q$ is at most $e_i-1$. Hence
\[
\alpha(q)\mid
\lcmop(\lambda_1,\ldots,\lambda_{i-1},\lambda_i^-,
\lambda_{i+1},\ldots,\lambda_r),
\]
again by the lcm identity and by monotonicity under divisibility of prime
powers. The right-hand side is $<n$ by
\eqref{eq:lcm-criterion}. Since $q\mid m\mid F_n$, we also have
$\alpha(q)\mid n$, and therefore $\alpha(q)<n$. Thus no proper divisor of
$m$ lies in $B_n$, so $m$ is minimal in $B_n$.
\end{proof}

\subsection*{Witness covers}

\begin{definition}\label{def:witness-cover}
An \emph{$n$-witness cover} is a finite set
$\Theta=\{\theta_1,\ldots,\theta_r\}$ of atomic prime powers satisfying:
\begin{enumerate}[label=(\roman*)]
\item $d(\theta)\mid n$ for every $\theta\in\Theta$;
\item the elements of $\Theta$ are pairwise coprime;
\item the full-coordinate supports cover all prime coordinates of $n$,
\[
\bigcup_{\theta\in\Theta}T_n(\theta)=\mathcal P(n);
\]
\item each atom has an essential coordinate not supplied by the other atoms,
\[
E_n(\theta)\nsubseteq
\bigcup_{\eta\in\Theta,\ \eta\ne\theta}T_n(\eta)
\qquad(\theta\in\Theta).
\]
\end{enumerate}
The last condition is the irredundance condition. It is stated with
$E_n$ rather than $T_n$ because overlapping full-coordinate support is
allowed; what is forbidden is that every coordinate lost by lowering
$\theta$ is already supplied at full exponent by the remaining atoms.
\end{definition}

\begin{lemma}[Coordinate test for lowering one atom]
\label{lem:coordinate-lowering-test}
Let $n\ge2$, and let
$\Theta=\{\theta_1,\ldots,\theta_r\}$ be a pairwise coprime set of atomic
prime powers with $d(\theta_i)\mid n$ and
\[
\lcmop(d(\theta_1),\ldots,d(\theta_r))=n.
\]
Fix $\theta_i=p_i^{e_i}$, and put
\[
N_i^-:=\lcmop\bigl(d^-(\theta_i),\ d(\theta_j):j\ne i\bigr).
\]
Then $N_i^-=n$ if and only if
\[
E_n(\theta_i)\subseteq\bigcup_{j\ne i}T_n(\theta_j).
\]
Equivalently, lowering $\theta_i$ to $p_i^{e_i-1}$ keeps the apparition lcm
equal to $n$ exactly when every coordinate lost by the lowering is supplied at
full exponent by some other atom. If
$\ell\in E_n(\theta_i)\setminus\bigcup_{j\ne i}T_n(\theta_j)$, then
$\nu_\ell(N_i^-)<\nu_\ell(n)$, so $N_i^-<n$.
\end{lemma}

\begin{proof}
Since $d^-(\theta_i)\mid d(\theta_i)\mid n$ and $d(\theta_j)\mid n$ for
$j\ne i$, the integer $N_i^-$ divides $n$. Hence $N_i^-=n$ is equivalent to
saying that every prime coordinate $\ell\in\mathcal P(n)$ occurs in $N_i^-$
with valuation $\nu_\ell(n)$.

Assume first that
$E_n(\theta_i)\subseteq\bigcup_{j\ne i}T_n(\theta_j)$, and fix
$\ell\in\mathcal P(n)$. Because the original lcm is $n$, at least one of the
numbers $d(\theta_1),\ldots,d(\theta_r)$ supplies the full
$\ell$-adic valuation of $n$. If such a supplier is some $d(\theta_j)$ with
$j\ne i$, then $\ell\in T_n(\theta_j)$ and the same full valuation appears in
$N_i^-$. The only remaining case is that $\theta_i$ itself supplies the full
valuation and no other atom does, so $\ell\in T_n(\theta_i)$ and
$\ell\notin\bigcup_{j\ne i}T_n(\theta_j)$. The assumed containment then gives
$\ell\notin E_n(\theta_i)$. By the definition of $E_n(\theta_i)$,
$\nu_\ell(d^-(\theta_i))=\nu_\ell(n)$, so the lowered factor still supplies the
full $\ell$-coordinate in $N_i^-$. Thus every coordinate of $n$ is still
present at full valuation, and $N_i^-=n$.

Conversely, suppose that some coordinate
$\ell\in E_n(\theta_i)$ is not in $\bigcup_{j\ne i}T_n(\theta_j)$. The
membership $\ell\in E_n(\theta_i)$ says
$\nu_\ell(d^-(\theta_i))<\nu_\ell(n)$. For every $j\ne i$, the exclusion
$\ell\notin T_n(\theta_j)$ says
$\nu_\ell(d(\theta_j))<\nu_\ell(n)$. Therefore the lcm defining $N_i^-$ also
has $\ell$-adic valuation strictly below $\nu_\ell(n)$. Since $N_i^-\mid n$,
this proves $N_i^-<n$.
\end{proof}

\begin{proposition}[Wagner comparison and lowered labels]
\label{prop:wagner-comparison}
Let $n\ge2$, and let $\Theta=\{p_1,\ldots,p_r\}$ be a set of distinct prime
atoms with $d_i:=\alpha(p_i)\mid n$. Then $\Theta$ is an $n$-witness cover
if and only if, after forgetting the order of the tuple
$(d_1,\ldots,d_r)$,
\begin{equation}\label{eq:wagner-minimal-multiplicative-cover}
 \lcmop(d_1,\ldots,d_r)=n,
 \qquad
 \lcmop(d_1,\ldots,\widehat{d_i},\ldots,d_r)<n
 \quad(1\le i\le r).
\end{equation}
Thus the prime-atom case is precisely the unordered form of Wagner's minimal
multiplicative cover condition.

For arbitrary pairwise coprime atoms
$\Theta=\{\theta_1,\ldots,\theta_r\}$, the witness condition replaces the
deletion in \eqref{eq:wagner-minimal-multiplicative-cover} by
\begin{equation}\label{eq:lowered-label-multiplicative-cover}
 \lcmop\bigl(d(\theta_1),\ldots,d^-(\theta_i),\ldots,
 d(\theta_r)\bigr)<n
 \quad(1\le i\le r).
\end{equation}
In particular, ladder atoms supply the genuinely additional lowered-label
case: their label is lowered to $d^-(\theta_i)$ rather than deleted.
\end{proposition}

\begin{proof}
For a prime atom $p_i$, one has $d^-(p_i)=\alpha(1)=1$. Hence replacing
$d_i$ by $d^-(p_i)$ in an lcm is identical to omitting $d_i$. Lemma~
\ref{thm:minimal-generators} and Lemma~\ref{lem:coordinate-lowering-test}
then identify the witness-cover conditions with
\eqref{eq:wagner-minimal-multiplicative-cover}. Since the labels form a
minimal cover, no repeated label can occur; forgetting tuple order therefore
produces the corresponding unordered cover without a multiplicity ambiguity.

For arbitrary atoms, the same two lemmas say exactly that the full apparition
lcm is $n$ and that lowering each atom produces
\eqref{eq:lowered-label-multiplicative-cover}. The final assertion is the
distinction between $d^-(p)=1$ for prime atoms and the nontrivial lower rank
of a ladder atom.
\end{proof}

$\mathcal M_n$. The canonical squarefree slice and its exact weighted count

\label{prop:blms-obstructs-mean-window}
Assume Conjecture~5.1 of Bugeaud--Luca--Mignotte--Siksek
\cite{BugeaudLucaMignotteSiksek2005FewPrimeDivisors}, namely that
$\omega(F_n)\gg\log n$ for composite $n$. Then, for every fixed
$\varepsilon$ with $0<\varepsilon<1-\log2$,
\begin{equation}\label{eq:blms-normal-window-obstruction}
 \liminf_{x\to\infty}\frac1x
 \#\{n\le x:\log R(n)>\varepsilon\omega(n)\}
 \ge\frac6{\pi^2},
\end{equation}
and
\begin{equation}\label{eq:blms-mean-window-obstruction}
 \liminf_{x\to\infty}
 \frac{\sum_{3\le n\le x}\omega(n)\log R(n)}
 {x(\log\log x)^2}
 \ge\frac6{\pi^2}(1-\log2)>0.
\end{equation}
In particular, under that published conjecture, both sufficient
maximum-window hypotheses \textup{(H1)} and \textup{(H2)} are false.
\end{proposition}

\begin{proof}
Let $n$ be squarefree and put $k=\omega(n)$. The exact-rank partition of the
prime divisors of $F_n$ gives
\[
 \omega(F_n)=\sum_{d\mid n}a(d).
\]
For squarefree $n$, every nonempty support $J\subseteq\mathcal P(n)$ has the
single rank $d=\prod_{\ell\in J}\ell$ in its window. Since $a(1)=0$, the
pigeonhole principle and \eqref{eq:prime-window-versus-R} give
\begin{equation}\label{eq:squarefree-blms-pigeonhole}
 R(n)\ge\max_{d\mid n}a(d)
 \ge\frac{\omega(F_n)}{2^k-1}.
\end{equation}
Under the stated conjecture, for every sufficiently large squarefree composite
$n$,
\[
 \log R(n)\ge\log\log n-k\log2+O(1).
\]
The Hardy--Ramanujan theorem has an exceptional set of $o(x)$ integers, so on
all but $o(x)$ squarefree integers one has
$k=(1+o(1))\log\log n$. Consequently
\[
 \omega(n)\log R(n)
 \ge(1-\log2+o(1))(\log\log n)^2
\]
on this set. Squarefree integers have density $6/\pi^2$, and squarefree prime
indices have density zero. Moreover,
\[
 \frac{\log R(n)}{\omega(n)}\ge1-\log2+o(1)
\]
on the same set. This proves
\eqref{eq:blms-normal-window-obstruction}; summation over squarefree composite
indices proves \eqref{eq:blms-mean-window-obstruction}.
\end{proof}

\begin{corollary}[Purely conditional consequences of H1 and H2]
\label{cor:conditional-orders}
Assuming hypothesis \textup{(H1)} in Definition~\ref{hyp:normal-window},
\begin{equation}\label{eq:conditional-normal-order}
 L(n)\sim\frac{\log2}{4}(\log\log n)^2
 \quad\text{for almost all }n.
\end{equation}
Assuming hypothesis \textup{(H2)} in Definition~\ref{hyp:mean-window},
\begin{equation}\label{eq:conditional-mean-order}
 \sum_{3\le n\le x}L(n)
 \sim\frac{\log2}{4}x(\log\log x)^2.
\end{equation}
These are implications only: neither conclusion is unconditional, and no
positive arithmetic evidence for either sufficient hypothesis is presently
known. Proposition~\ref{prop:blms-obstructs-mean-window} shows that the
published Bugeaud--Luca--Mignotte--Siksek conjecture predicts that both
hypotheses fail.
\end{corollary}

\begin{proof}
For the first assertion, intersect the density-one set in
Definition~\ref{hyp:normal-window} with the Hardy--Ramanujan normal-order set.
Then the error $\omega(n)\log R(n)+O(\omega(n))$ in
\eqref{eq:private-cover-entropy-order} is $o(\omega(n)^2)$. For the second,
sum the upper bound in \eqref{eq:private-cover-entropy-order}, use
Definition~\ref{hyp:mean-window}, \eqref{eq:omega-second-moment}, and
$\sum_{n\le x}\omega(n)=O(x\log\log x)$, and compare with the unconditional
lower mean bound \eqref{eq:mean-logarithmic-growth}.
\end{proof}
