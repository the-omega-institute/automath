## Anti-Pattern: "This Is Too Simple To Need A Design"

Every project goes through this process. A todo list, a single-function utility, a config change â€” all of them. "Simple" projects are where unexamined assumptions cause the most wasted work. The design can be short (a few sentences for truly simple projects), but you MUST present it and get approval.

## The Process

**Understanding the idea:**

- Check out the current project state first (files, docs, recent commits)
- Before asking detailed questions, assess scope: if the request describes multiple independent subsystems (e.g., "build a platform with chat, file storage, billing, and analytics"), flag this immediately. Don't spend questions refining details of a project that needs to be decomposed first.
- If the project is too large for a single spec, help the user decompose into sub-projects: what are the independent pieces, how do they relate, what order should they be built? Then brainstorm the first sub-project through the normal design flow. Each sub-project gets its own spec â†’ plan â†’ implementation cycle.
- For appropriately-scoped projects, ask questions one at a time to refine the idea
- Prefer multiple choice questions when possible, but open-ended is fine too
- Only one question per message - if a topic needs more exploration, break it into multiple questions
- Focus on understanding: purpose, constraints, success criteria

**Exploring approaches:**

- Propose 2-3 different approaches with trade-offs
- Present options conversationally with your recommendation and reasoning
- Lead with your recommended option and explain why

**Presenting the design:**

- Once you believe you understand what you're building, present the design
- Scale each section to its complexity: a few sentences if straightforward, up to 200-300 words if nuanced
- Ask after each section whether it looks right so far
- Cover: architecture, components, data flow, error handling, testing
- Be ready to go back and clarify if something doesn't make sense

**Design for isolation and clarity:**

- Break the system into smaller units that each have one clear purpose, communicate through well-defined interfaces, and can be understood and tested independently
- For each unit, you should be able to answer: what does it do, how do you use it, and what does it depend on?
- Can someone understand what a unit does without reading its internals? Can you change the internals without breaking consumers? If not, the boundaries need work.
- Smaller, well-bounded units are also easier for you to work with - you reason better about code you can hold in context at once, and your edits are more reliable when files are focused. When a file grows large, that's often a signal that it's doing too much.

**Working in existing codebases:**

- Explore the current structure before proposing changes. Follow existing patterns.
- Where existing code has problems that affect the work (e.g., a file that's grown too large, unclear boundaries, tangled responsibilities), include targeted improvements as part of the design - the way a good developer improves code they're working in.
- Don't propose unrelated refactoring. Stay focused on what serves the current goal.

## After the Design

**Documentation:**

- Write the validated design (spec) to `docs/superpowers/specs/YYYY-MM-DD-<topic>-design.md`
  - (User preferences for spec location override this default)
- Use elements-of-style:writing-clearly-and-concisely skill if available
- Commit the design document to git

**Spec Self-Review:**
After writing the spec document, look at it with fresh eyes:

1. **Placeholder scan:** Any "TBD", "TODO", incomplete sections, or vague requirements? Fix them.
2. **Internal consistency:** Do any sections contradict each other? Does the architecture match the feature descriptions?
3. **Scope check:** Is this focused enough for a single implementation plan, or does it need decomposition?
4. **Ambiguity check:** Could any requirement be interpreted two different ways? If so, pick one and make it explicit.

Fix any issues inline. No need to re-review â€” just fix and move on.

**User Review Gate:**
After the spec review loop passes, ask the user to review the written spec before proceeding:

> "Spec written and committed to `<path>`. Please review it and let me know if you want to make any changes before we start writing out the implementation plan."

Wait for the user's response. If they request changes, make them and re-run the spec review loop. Only proceed once the user approves.

**Implementation:**

- Invoke the writing-plans skill to create a detailed implementation plan
- Do NOT invoke any other skill. writing-plans is the next step.

## Key Principles

- **One question at a time** - Don't overwhelm with multiple questions
- **Multiple choice preferred** - Easier to answer than open-ended when possible
- **YAGNI ruthlessly** - Remove unnecessary features from all designs
- **Explore alternatives** - Always propose 2-3 approaches before settling
- **Incremental validation** - Present design, get approval before moving on
- **Be flexible** - Go back and clarify when something doesn't make sense

\begin{theorem}[Arithmetic denominator-layer theorem]
\label{thm:arithmetic-denominator-layer}
For a finite word \(\mathbf a=(a_1,\ldots,a_r)\) of positive integers, let
\(\mathcal K(\mathbf a)\) be its regular continuant, with
\[
 \begin{gathered}
  \mathcal K(\varnothing)=1,\qquad \mathcal K(a_1)=a_1,\\
  \mathcal K(a_1,\ldots,a_r)
  =a_r\mathcal K(a_1,\ldots,a_{r-1})
   +\mathcal K(a_1,\ldots,a_{r-2}).
 \end{gathered}
\]
Put
\[
 \begin{aligned}
  \mathcal C_{\rm L}&:=\{\varnothing\}\cup
   \bigcup_{r\ge1}\mathbb N^r,\\
  \mathcal C_{\rm R}&:=\{\varnothing\}\cup
   \{(a_1,\ldots,a_r):r\ge1,\ a_i\ge1,\ a_r\ge2\}.
 \end{aligned}
\]
Then, for every fixed \(s>2\),
\begin{equation}
 b_{2d+1}(s)\sim b(s)d^{-s}\qquad(d\to\infty),
 \label{eq:low-temperature-local-layer}
\end{equation}
where the constant is the absolutely convergent one-large-partial-quotient
context sum
\begin{equation}
 \begin{aligned}
 b(s)
 &: =\sum_{\mathbf u\in\mathcal C_{\rm L}}
       \sum_{\mathbf v\in\mathcal C_{\rm R}}
       \{\mathcal K(\mathbf u)\mathcal K(\mathbf v)\}^{-s}\\
 &=2\left(\frac{\zeta(s-1)}{\zeta(s)}\right)^2>0.
 \end{aligned}
 \label{eq:one-large-partial-quotient-context-sum}
\end{equation}
In particular, this identifies the polynomial scale of every fixed
low-temperature denominator layer; no tail hypothesis is used in
\eqref{eq:low-temperature-local-layer}.
\end{theorem}

\begin{proof}
Write \(|\mathbf a|_1=a_1+\cdots+a_r\), with
\(|\varnothing|_1=0\).  The canonical regular continued fraction of a reduced
\(p/q\in(0,1)\) is
\[
 \frac pq=[0;a_1,\ldots,a_r],
 \qquad a_i\ge1,\quad a_r\ge2,
\]
and its denominator is \(\mathcal K(a_1,\ldots,a_r)\).  The conversion formula
used in the proof of \Cref{thm:all-real-pressure} gives
\[
 d(p/q)=|\mathbf a|_1-1.
\]
Consequently, on putting \(n=d+1\), the left side of
\eqref{eq:low-temperature-local-layer} is
\begin{equation}
 A_n(s):=
 \sum_{\substack{\mathbf a\in\mathcal C_{\rm R}\\|\mathbf a|_1=n}}
 \mathcal K(\mathbf a)^{-s}.
 \label{eq:regular-continuant-layer}
\end{equation}

We first evaluate the context mass.  Canonical words in
\(\mathcal C_{\rm R}\) with
denominator \(q\) parameterize the \(\phi_{\rm E}(q)\) reduced fractions in
\((0,1)\).  Hence, for \(s>2\),
\begin{equation}
 R_s:=\sum_{\mathbf v\in\mathcal C_{\rm R}}\mathcal K(\mathbf v)^{-s}
 =1+\sum_{q\ge2}\frac{\phi_{\rm E}(q)}{q^s}
 =\frac{\zeta(s-1)}{\zeta(s)}<\infty.
 \label{eq:right-continuant-context-mass}
\end{equation}
Every nonempty positive word either ends in a digit at least two or has the
form \((a_1,\ldots,a_{r-1},1)\).  The usual terminal move
\[
 (a_1,\ldots,a_{r-1},1)
 \longleftrightarrow
 (a_1,\ldots,a_{r-1}+1)
\]
preserves the continuant.  It pairs the two regular expansions of every
nonempty canonical word; it also pairs \((1)\) with \(\varnothing\).  Therefore
\begin{equation}
 L_s:=\sum_{\mathbf u\in\mathcal C_{\rm L}}\mathcal K(\mathbf u)^{-s}
 =2R_s.
 \label{eq:left-continuant-context-mass}
\end{equation}
This proves the absolute convergence and the evaluation in
\eqref{eq:one-large-partial-quotient-context-sum}.

It remains to prove that this context sum is the whole local main term.  We
give the cutoff argument, including the multiple-large-digit and moderate
parts.  The continuant concatenation formula implies, for finite positive
words \(\mathbf u,\mathbf v\),
\begin{equation}
 \mathcal K(\mathbf u\mathbf v)
 \ge \mathcal K(\mathbf u)\mathcal K(\mathbf v).
 \label{eq:continuant-concatenation-lower-bound}
\end{equation}
Moreover, with the two contexts fixed and \(a\to\infty\), multilinearity of
the tridiagonal determinant defining the continuant gives
\begin{equation}
 \mathcal K(\mathbf u,a,\mathbf v)
 =a\mathcal K(\mathbf u)\mathcal K(\mathbf v)+O_{\mathbf u,\mathbf v}(1).
 \label{eq:continuant-large-digit-affine}
\end{equation}

\(a=n-|\mathbf u|_1-|\mathbf v|_1\).  Equations
\eqref{eq:continuant-concatenation-lower-bound} and
\eqref{eq:continuant-large-digit-affine} give, respectively,
\[
 n^s\mathcal K(\mathbf u,a,\mathbf v)^{-s}
 \le 2^s\{\mathcal K(\mathbf u)\mathcal K(\mathbf v)\}^{-s}
\]
and pointwise convergence of the left side to
\(\{\mathcal K(\mathbf u)\mathcal K(\mathbf v)\}^{-s}\).  Dominated
convergence, using \eqref{eq:right-continuant-context-mass}--
\eqref{eq:left-continuant-context-mass}, therefore yields
\begin{equation}
 n^sP_n(s)\longrightarrow L_sR_s=b(s).
 \label{eq:principal-large-digit-limit}
\end{equation}

We now show that the complementary words have total weight \(o(n^{-s})\).
Choose
\begin{equation}
 \frac{s}{2(s-1)}<\delta<1,
 \qquad h=\lfloor n^\delta\rfloor,
 \label{eq:large-digit-cutoff}
\end{equation}
and set
\[
 \eta_s(h):=
 \sum_{\substack{\mathbf u\in\mathcal C_{\rm L}\\|\mathbf u|_1\ge h}}
 \mathcal K(\mathbf u)^{-s}.
\]
By \eqref{eq:left-continuant-context-mass}, \(\eta_s(h)\to0\).  A word having
at least two digits not smaller than \(h\) can be cut at its first two such
digits.  After dropping the restrictions on the three intervening contexts,
\eqref{eq:continuant-concatenation-lower-bound} bounds its total weight by
\begin{equation}
 L_s^2R_s
 \left(\sum_{a\ge h}a^{-s}\right)^2
 =O_s(h^{2-2s})=o(n^{-s}),
 \label{eq:two-large-digits-negligible}
\end{equation}
where the last equality is precisely the first inequality in
\eqref{eq:large-digit-cutoff}.

For completeness, consider a word all of whose digits are smaller than
\(h\).  Greedily divide it into consecutive blocks: close a block as soon as
its digit sum reaches \(h\), and leave the last remainder unclosed.  Every
closed block has digit sum in \([h,2h)\), and a word of digit sum at least
\(N\) has at least \(\lfloor N/(2h)\rfloor-1\) closed blocks.  The
concatenation bound and the uniqueness of the greedy decomposition show that
the total continuant weight of all such words is at most
\begin{equation}
 \frac{L_s}{1-\eta_s(h)}
 \eta_s(h)^{\lfloor N/(2h)\rfloor-1}
 \label{eq:moderate-block-bound}
\end{equation}
for all sufficiently large \(h\).  When \(N\ge n/4\), this is
\(o(n^{-A})\) for every fixed \(A>0\), because \(n/h\to\infty\) and
\(\eta_s(h)\to0\).

The words not counted by \(P_n(s)\) and not covered by
\eqref{eq:two-large-digits-negligible} have at most one digit at least \(h\).
If there is none, apply \eqref{eq:moderate-block-bound} with \(N=n\).  If
there is exactly one, its value is at most \(n/2\), so the two surrounding
moderate contexts have combined digit sum at least \(n/2\); one has digit sum
at least \(n/4\).  Cutting at the exceptional digit, summing its weight
\(a^{-s}\), and applying \eqref{eq:moderate-block-bound} to that long context
again gives \(o(n^{-A})\) for every fixed \(A\).  Together with
\eqref{eq:two-large-digits-negligible}, this proves
\[
 A_n(s)-P_n(s)=o(n^{-s}).
\]
Combining this with \eqref{eq:principal-large-digit-limit}, and replacing
\(n=d+1\) by \(d\), proves \eqref{eq:low-temperature-local-layer}.
\end{proof}

\begin{theorem}[Arithmetic critical stable renewal]
\label{thm:arithmetic-critical-stable-renewal}
Put \(\alpha:=\sigma_0-1\in(1,2)\), and under the critical letter law put
\[
 \Pr\{(C,H)=(c(p/q),\log q)\}=q^{-\sigma_0}.
\]
Then \(\Pr\{C=2d+1\}=b_{2d+1}(\sigma_0)\), and the explicit constants
\begin{equation}
 \begin{aligned}
 b_C&:=
 \sum_{\mathbf u\in\mathcal C_{\rm L}}
 \sum_{\mathbf v\in\mathcal C_{\rm R}}
 \{\mathcal K(\mathbf u)\mathcal K(\mathbf v)\}^{-\sigma_0}
 =2\left(\frac{\zeta(\sigma_0-1)}{\zeta(\sigma_0)}\right)^2=8,\\
 K_C&:=\frac{2^{\sigma_0-1}}{\sigma_0-1}b_C
 =\frac{2^{\sigma_0+2}}{\sigma_0-1}
 \end{aligned}
 \label{eq:critical-tail-constants}
\end{equation}
are positive.  The double series defining \(b_C\) is absolutely convergent,
and
\begin{align}
 b_{2d+1}(\sigma_0)&\sim b_Cd^{-\sigma_0},
 &&d\to\infty,
 \label{eq:critical-letter-local-tail}\\
 \Pr\{C>x\}
 &=\sum_{q\ge2}q^{-\sigma_0}
   \card{\{1\le p<q:(p,q)=1,\ c(p/q)>x\}},\notag\\
 &\sim K_Cx^{1-\sigma_0},
 &&x\to\infty.
 \label{eq:critical-letter-tail}
\end{align}
If \(u_j=u_j(\sigma_0)\) is the renewal sequence in
\eqref{eq:weighted-renewal-coefficients}, then
\begin{equation}
 u_j=\frac1{\mu_C}
 +\frac{K_C}{\mu_C^2(\sigma_0-2)}j^{2-\sigma_0}
 +o(j^{2-\sigma_0}).
 \label{eq:critical-renewal-second-order}
\end{equation}
Consequently,
\begin{align}
 Z_m^R(-\sigma_0)
 &=\frac{2m}{\mu_C}
 +\frac{2K_C}{\mu_C^2(\sigma_0-2)(3-\sigma_0)}
   m^{3-\sigma_0}+o(m^{3-\sigma_0}),
 \label{eq:standard-layer-critical-second-order}\\
 S_{-\sigma_0}(m)
 &=\frac{4m}{\mu_C}
 +\frac{4K_C}{\mu_C^2(\sigma_0-2)(3-\sigma_0)}
   m^{3-\sigma_0}+o(m^{3-\sigma_0}).
 \label{eq:finite-window-critical-second-order}
\end{align}
Finally, \(C\) belongs to the domain of attraction of a spectrally positive
\(\alpha\)-stable law.  More precisely, if \(a_n>0\) is chosen so that
\(n\Pr\{C>a_n\}\to1\), then for independent copies \(C_1,C_2,\ldots\),
\begin{equation}
 \frac{C_1+\cdots+C_n-n\mu_C}{a_n}
 \xrightarrow{\mathrm d}\mathcal S_\alpha,
 \label{eq:critical-cost-stable-domain}
\end{equation}
where \(\mathcal S_\alpha\) is the spectrally positive \(\alpha\)-stable law
whose L\'evy measure has density \(\alpha x^{-\alpha-1}\) on \((0,\infty)\).
\end{theorem}

\begin{proof}
The critical equation \eqref{eq:weighted-renewal-at-one} makes the displayed
letter law a probability measure.  The local estimate
\eqref{eq:critical-letter-local-tail} and the context-sum evaluation in
\eqref{eq:critical-tail-constants} are \Cref{thm:arithmetic-denominator-layer}
at \(s=\sigma_0\).  Direct summation of that local estimate gives
\[
 \Pr\{C>x\}
 =\sum_{d>(x-1)/2}b_{2d+1}(\sigma_0)
 \sim\frac{b_C}{\sigma_0-1}
      \left(\frac{x}{2}\right)^{1-\sigma_0},
\]
which is \eqref{eq:critical-letter-tail} with the stated \(K_C\).  Thus
regular variation is a conclusion of the arithmetic continuant estimate, not
an assumption.

The distribution of \(C\) has span one, finite mean \(\mu_C\), and tail
\(K_Cj^{-\alpha}\), with \(1<\alpha<2\).  The finite-mean case of the
discrete renewal-sequence theorem \cite{OmeyVanGulck2015} applies.  To make
its constant explicit, write \(\overline F(j)=\Pr\{C>j\}\).  The tail-sum
identity and the Abelian theorem for power series give, as \(z\uparrow1\),
\begin{align*}
 1-B_{\sigma_0}(z)
 &=(1-z)\sum_{j\ge0}\overline F(j)z^j,\\
 \sum_{j\ge0}\overline F(j)z^j
 &=\mu_C+K_C\Gamma(1-\alpha)(1-z)^{\alpha-1}
   +o((1-z)^{\alpha-1}).
\end{align*}
Since \(U_{\sigma_0}(z)=\{1-B_{\sigma_0}(z)\}^{-1}\), it follows that
\[
 U_{\sigma_0}(z)
 =\frac1{\mu_C(1-z)}
 -\frac{K_C\Gamma(1-\alpha)}{\mu_C^2}(1-z)^{\alpha-2}
 +o((1-z)^{\alpha-2}).
\]
The cited arithmetic coefficient theorem, using the span-one hypothesis,
transfers this expansion locally.  As
\(\Gamma(2-\alpha)=(1-\alpha)\Gamma(1-\alpha)\), it gives
\[
 u_j-\frac1{\mu_C}
 \sim\frac{K_C}{\mu_C^2(\alpha-1)}j^{1-\alpha};
\]
see also the generating-function remainder argument for the arithmetic
renewal theorem in \cite[Ch.~XI]{Feller1971}.  Substitution of
\(\alpha=\sigma_0-1\) proves
\eqref{eq:critical-renewal-second-order}.  Summing it and using
\[
 \sum_{j=1}^{m-1}j^{2-\sigma_0}
 \sim\frac{m^{3-\sigma_0}}{3-\sigma_0}
\]
in the exact identities \eqref{eq:standard-layer-renewal} and
\eqref{eq:weighted-window-renewal} proves
\eqref{eq:standard-layer-critical-second-order} and
\eqref{eq:finite-window-critical-second-order}; the boundary terms are
\(O(1)=o(m^{3-\sigma_0})\).

Finally, \eqref{eq:critical-letter-tail}, finite mean, and the absence of a
negative tail are precisely the one-sided domain-of-attraction conditions for
an \(\alpha\)-stable law with the normalization in
\eqref{eq:critical-cost-stable-domain}; see \cite[Ch.~XVII]{Feller1971}.
\end{proof}

\section{Introduction}\label{sec:introduction}

Let \(F_0=0\), \(F_1=F_2=1\), and
\(F_{j+2}=F_{j+1}+F_j\), and put
\(\varphi=(1+\sqrt5)/2\).  Let \(R(n)\) be the classical Fibonacci
partition function: the number of partitions of \(n\) into distinct
Fibonacci numbers, with the two unit terms identified.  Our main
thermodynamic results concern \(R\) on the standard layers
\[
 \mathcal I_m=[F_{m+1}-1,F_{m+2}-1).
\]
The moment pressure for every real tilt and its first-order transition are
already contained, under an affine normalization, in the golden-ratio
Bernoulli-convolution literature \cite{LauNgai1998,FengOlivier2003,Feng2005}.
We make that normalization explicit and use it as the starting point for
finite-window identities, arithmetic critical refinements, and full
large-deviation lower bounds for \(m^{-1}\log R(n)\) under the uniform law on
\(\mathcal I_m\).

A finite-window Zeckendorf fold gives an exact finite model for this standard
object.  A word
\(\omega\in\{0,1\}^m\) determines the raw sum
\[
  N_m(\omega)=\sum_{j=1}^m\omega_jF_{j+1}.
\]
We consider the finite-window fold obtained by reducing this sum modulo
\(F_{m+2}\) and taking the unique legal Zeckendorf word in the visible
window.  If \(d_m(x)\) is the cardinality of the fiber over a legal word
\(x\), the corresponding finite problem is to identify the multiset
\(\{d_m(x):x\in X_m\}\) and its extremal and moment statistics.

The bridge is exact: the complete fiber list is the list of \(R\) on
\(\mathcal I_m\sqcup\mathcal I_{m+1}\).  A second correspondence is an affine
reindexing of a finite subset-sum spectrum.  Both are finite identities and
do not require a normalization transducer.

\subsection{Main results}

Put \(R(n)=0\) for \(n<0\).  Let \(\sigma_0>2\) be the unique solution of
\[
 \frac{\zeta(\sigma_0-1)}{\zeta(\sigma_0)}=2;
 \qquad \sigma_0=2.4787507857\ldots.
\]
For \(t>-\sigma_0\), let \(P(t)>0\) be the unique solution of
\[
 \sum_{q\ge2}\sum_{\substack{1\le p<q\\(p,q)=1}}
 q^t e^{-P(t)c(p/q)}=1,
\]
where \(c(p/q)\) is the odd continued-fraction cost defined before
\Cref{prop:weighted-generator-renewal}, and put \(P(t)=0\) for
\(t\le-\sigma_0\).  Set
\[
 \begin{gathered}
 \mu_C:=\sum_{q\ge2}\sum_{\substack{1\le p<q\\(p,q)=1}}
 c(p/q)q^{-\sigma_0},\\
 v_c:=\frac{\displaystyle
 \sum_{q\ge2}\sum_{\substack{1\le p<q\\(p,q)=1}}
 q^{-\sigma_0}\log q}{\mu_C},
 \qquad
 t_c:=-\sigma_0,\qquad
 \alpha_+:=\frac12\log\varphi.
 \end{gathered}
\]
Define
\[
 Z_m^R(t):=\sum_{n\in\mathcal I_m}R(n)^t.
\]

The arithmetic input at the critical point is a local theorem, rather than a
tail assumption.  For every fixed \(s>2\),
\begin{equation}
 b_{2d+1}(s)
 \sim2\left(\frac{\zeta(s-1)}{\zeta(s)}\right)^2d^{-s}.
 \label{eq:introduction-low-temperature-layer}
\end{equation}
Its proof cuts a canonical regular continued fraction at its unique large
partial quotient and gives the constant as an absolutely convergent left--right
continuant context sum.  At \(s=\sigma_0\), this constant is \(b_C=8\), and
\begin{equation}
 \Pr\{C>x\}\sim K_Cx^{1-\sigma_0},
 \qquad K_C=\frac{2^{\sigma_0-1}}{\sigma_0-1}b_C.
 \label{eq:introduction-critical-cost-tail}
\end{equation}
Consequently, \Cref{thm:arithmetic-critical-stable-renewal} proves
\begin{equation}
 Z_m^R(-\sigma_0)
 =\frac{2m}{\mu_C}
 +\frac{2K_C}{\mu_C^2(\sigma_0-2)(3-\sigma_0)}m^{3-\sigma_0}
 +o(m^{3-\sigma_0}),
 \label{eq:introduction-standard-critical-second-order}
\end{equation}
with the corresponding coefficient doubled for \(S_{-\sigma_0}(m)\).  The
critical cost also lies in the domain of attraction of a spectrally positive
\((\sigma_0-1)\)-stable law.  Regular variation in these statements is derived
from \eqref{eq:introduction-low-temperature-layer}; it is not assumed.

\begin{theoremA}[One-layer Fibonacci partition thermodynamics]
For every \(t\in\RR\),
\[
 \lim_{m\to\infty}\frac1m\log Z_m^R(t)=P(t).
\]
For \(s>\sigma_0\),
\[
 Z_m^R(-s)\longrightarrow
 \frac2{2-\zeta(s-1)/\zeta(s)}-1,
\]
whereas \(Z_m^R(-\sigma_0)\sim2m/\mu_C\).  Under the critical Gibbs law
proportional to \(R(n)^{-\sigma_0}\), the normalized log multiplicity and
generating-layer cost converge jointly to \((v_cU,U)\), with \(U\) uniform on
\([0,1]\).

If \(\mathbf N_m\) is uniform on \(\mathcal I_m\), then
\(m^{-1}\log R(\mathbf N_m)\) satisfies a full large deviation principle
with good rate function
\[
 I(\alpha)=\sup_{t\in\RR}\{t\alpha-P(t)+\log\varphi\}.
\]
Its effective domain is \([0,\alpha_+]\), and
\(I(\alpha)=\log\varphi-\sigma_0\alpha\) on \([0,v_c]\).
\end{theoremA}

This is \Cref{thm:standard-fibonacci-thermodynamics}.  Its pressure assertion
is the Lau--Ngai/Feng spectrum under
\eqref{eq:erdos-pressure-dictionary}; it is included to normalize the critical
finite-size law and the uniform-layer LDP.  The latter statements use the
one-layer orbit weights \(2,1\), rather than a deduction from the two-layer
fiber mixture.

The same renewal representation retains the normalized generating cost
\(B_m^R=m^{-1}\ell_m^R(\mathbf N_m)\).
\Cref{thm:joint-cost-reward-ldp} proves a full LDP for
\((B_m^R,Y_m^R)\).  Its rate is
\[
 J(\beta,\alpha)=
 (1-\beta)\log\varphi+\beta I(\alpha/\beta)
 \quad(0<\beta\le1,\ 0\le\alpha\le\beta\alpha_+),
\]
with \(J(0,0)=\log\varphi\) and \(J=+\infty\) elsewhere.  In particular,
\[
 J(\beta,\alpha)=\log\varphi-\sigma_0\alpha
 \qquad(0\le\alpha\le\beta v_c),
\]
so coexistence is an affine face of the joint rate surface rather than an
artifact of one-dimensional projection.  Fixed-cost exponential tilting
supplies the strictly convex part; an exact one- or two-letter low-reward
suffix fills every sufficiently large remaining cost on the affine face.

For the exact finite-window model, put
\(R^\dagger(n)=R(n)+R(n-1)\).  Let
\[
  \widetilde d_m(n)=[z^n]\prod_{j=1}^m(1+z^{F_j}),
  \qquad 0\le n<F_{m+2}.
\]
For residues modulo \(F_{m+2}\), define
\[
  \pi_m(n)\equiv F_{m+1}n+F_{m+1}-1\pmod{F_{m+2}}.
\]

\begin{theoremB}[Affine fiber--partition correspondence]
For every \(m\ge1\), the map \(\pi_m\) is a permutation and
\[
  d_m^\#(\pi_m(n))
  =\widetilde d_m(n)
  =R^\dagger(n)-R^\dagger(n-F_{m+1})
  \qquad(0\le n<F_{m+2}).
\]
\end{theoremB}

This combines \Cref{thm:affine-transfer,thm:partition-difference}.  It gives a
pointwise correspondence, not only an equality of aggregate moments.

There is also a direct interval description:
\[
 d_m^\#(r)=
 \begin{cases}
 R(F_{m+2}+r),&0\le r\le F_{m+1}-2,\\
 R(r),&F_{m+1}-1\le r<F_{m+2}.
 \end{cases}
\]
The known extremal classification of Koc\'abov\'a, Mas\'akov\'a, and
Pelantov\'a can therefore be transferred exactly after an explicit change of
Fibonacci convention.

\begin{theoremC}[Interval identity and largest fibers]
Let \(D_m=\max_{x\in X_m}d_m(x)\).  Then
\[
 D_0=D_1=1,\qquad D_{2k}=F_{k+2}\ (k\ge0),\qquad
 D_{2k+1}=2F_{k+1}\ (k\ge1),
\]
and \(D_m=D_{m-2}+D_{m-4}\) for every \(m\ge6\).  The maximizing residues,
including the exceptional initial cases, are given in
\Cref{thm:unconditional-extremal-fibers}.
\end{theoremC}

For a real tilt \(t\), put
\[
  S_t(m)=\sum_{x\in X_m}d_m(x)^t.
\]
The identity
\[
  \lim_{m\to\infty}\frac1m\log S_t(m)=0
  \qquad(t\le-\sigma_0)
\]
is recorded in \Cref{prop:negative-temperature-freezing} as a finite-layer
recovery of the frozen branch proved by Feng--Olivier and Feng
\cite{FengOlivier2003,Feng2005}.  The renewal coordinates evaluate the
boundary arithmetically and supply the finite-size consequences below.

The fixed-level information is sharper than the exponential pressure.  Put
\(C_m(k)=\card{\{x\in X_m:d_m(x)=k\}}\), and let \(\Psi(k)\) be Weinstein's
number of generating orbits at level \(k\).

\begin{theoremE}[Local spectrum and critical Gibbs law]
For \(m\ge1\), \(C_m(1)=2\), while for \(k\ge2\),
\[
 C_m(k)\le4\Psi(k),
 \qquad C_m(k)=4\Psi(k)\quad(m\ge2k).
\]
For every \(s>\sigma_0\),
\[
 S_{-s}(m)\longrightarrow
 \mathcal Z(s):=\frac4{2-\zeta(s-1)/\zeta(s)}-2.
\]
This is the exact convergence range for the unnormalized sums.  The function
\(\mathcal Z\) has a simple pole at \(\sigma_0\), and the corresponding
fiber-level Gibbs measures converge in total variation with explicit
critical logarithmic moments.
At the endpoint itself,
\[
 S_{-\sigma_0}(m)\sim\frac{4m}{\mu_C}.
\]
Under the finite-window Gibbs law proportional to
\(d_m(x)^{-\sigma_0}\), the normalized pair consisting of log multiplicity
and generating-layer cost converges in distribution to
\((v_cU,U)\), where \(U\) is uniform on \([0,1]\).
\end{theoremE}

The complete statements are
\Cref{thm:local-fiber-spectrum,thm:spectral-partition-function,thm:critical-gibbs-spectrum,thm:critical-finite-window-gibbs}.
They separate an unnormalized critical phenomenon inside the region where
the exponential pressure vanishes.

\begin{theoremF}[Orbit growth and arithmetic critical refinements]
With
\[
 \kappa=-\left.\frac{d}{ds}\frac{\zeta(s-1)}{\zeta(s)}
 \right|_{s=\sigma_0},
\]
one has
\[
 \sum_{k\le x}\Psi(k)\sim
 \frac{x^{\sigma_0}}{\sigma_0\kappa}.
\]
Moreover, if
\(\beta_*=\log\varphi/\log(2/\varphi)=2.2705594539\ldots\), then
\[
 \liminf_{m\to\infty}\frac1m\log S_t(m)>0
 \qquad(t>-\beta_*).
\]
At the known critical point \(t_c=-\sigma_0\), the renewal equation becomes
\[
 \sum_{q\ge2}\frac{\phi_{\rm E}(q)}{q^{\sigma_0}}=1,
 \qquad
 \frac{\zeta(\sigma_0-1)}{\zeta(\sigma_0)}=2,
\]
and the positive-phase one-sided derivative is the explicitly convergent
ratio
\[
 P'_+(t_c)=
 \frac{\displaystyle\sum_{q\ge2}\phi_{\rm E}(q)q^{-\sigma_0}\log q}
      {\displaystyle\sum_{q\ge2}\sum_{\substack{1\le p<q\\(p,q)=1}}
       c(p/q)q^{-\sigma_0}}.
\]
\end{theoremF}

The all-real existence, implicit branch, frozen phase, and derivative corner
come from Feng's spectrum theorem \cite[Thm.~1.3]{Feng2005} and the
Erd\H{o}s-measure phase transition of Feng--Olivier
\cite[Thms.~2.9--2.10 and App.~A]{FengOlivier2003}.  The theorem above retains
only the Tauberian orbit law, the totient evaluation of the critical equation,
and the one-sided critical moment in the present renewal coordinates.

Let \(\mathbf X_m\) be uniformly distributed on \(X_m\), and put
\[
 Y_m=m^{-1}\log d_m(\mathbf X_m).
\]

\begin{theoremG}[Full large deviations across the freezing corner]
The sequence \((Y_m)\) satisfies a large deviation principle with speed
\(m\) and good rate function
\[
 I(\alpha)=\sup_{t\in\RR}\{t\alpha-P(t)+\log\varphi\}.
\]
Its effective domain is \([0,\alpha_+]\), and
\[
 I(\alpha)=\log\varphi-\sigma_0\alpha
 \qquad(0\le\alpha\le v_c).
\]
For every \(0<\alpha<v_c\), the probabilities of shrinking neighborhoods
have the exact exponential rate \(-I(\alpha)\).
\end{theoremG}

The complete statement and proof are given in \Cref{thm:full-fiber-ldp}.
The new orbit-filling step fills both parities of every sufficiently large
target layer while preserving the source multiplicity.

For a fixed finite set of primes, \Cref{prop:prime-support-interface} gives
the exact joint generating function for multiplier exponents and generator
cost and transfers it to \(C_m(k)\) with the active boundary weights
\(4,3,1\).  We do not assert a directional coefficient or quenched-velocity
asymptotic: the needed parameter-uniform smooth-point estimate and uniform
integrability for the unbounded cost are not supplied by the cited ACSV
results.  \Cref{rem:prime-support-local-open-interface} records the exact
remaining analytic input.

The proof of \Cref{prop:negative-temperature-freezing} includes a separate
layer-count lemma transferring Weinstein's convention \(f_j=F_{j+1}\).  It
distinguishes the levels \(k=1,2\), endpoints, early layers, and the eventual
equality asserted in Weinstein's theorem.

The pressure corner prevents a direct full application of the
G\"artner--Ellis theorem: its lower-bound conclusion does not cover slopes
strictly between the one-sided derivatives at \(-\sigma_0\).  The
orbit-filling argument in \Cref{thm:full-fiber-ldp} supplies those missing
local lower bounds and proves the full large deviation principle, with an
affine rate on the coexistence interval.

\subsection{Contribution boundary}

For auditability, the dependency boundary is summarized before the detailed
discussion.
\noindent\textbf{Koc\'abov\'a--Mas\'akov\'a--Pelantov\'a.}
Imported: extremal values and maximizing integers for the ordinary Fibonacci
partition function.  Proved here from that input: exact convention and

\noindent\textbf{Weinstein.}
Imported: the free generator monoid, multiplier product, orbit decomposition,

\noindent\textbf{Erd\H{o}s measure and Bernoulli convolutions.}
Sidorov--Vershik use Fibonacci numbers
\(F^{\rm SV}_1=1,F^{\rm SV}_2=2\), hence
\(F^{\rm SV}_j=F_{j+1}\) in our convention.  Their level-\(m\) frequency is
therefore exactly
\begin{align*}
 f_m^{\rm SV}(k)
 &=\#\left\{\boldsymbol\varepsilon\in\{0,1\}^m:
   \sum_{j=1}^m\varepsilon_jF_j^{\rm SV}=k\right\}\\
 &=[z^k]\prod_{j=1}^m(1+z^{F_{j+1}})\\
 &=\#\{\omega\in\{0,1\}^m:N_m(\omega)=k\}.
\end{align*}
Thus the difference is the index shift \(F_j^{\rm SV}=F_{j+1}\), not a
different counting object.  They identify \(2^{-m}f_m^{\rm SV}(k)\) with the
finite masses approximating the Erd\H{o}s measure
\cite[Sec.~3]{SidorovVershik1998}.  Hu studied its golden-ratio local dimensions
\cite{Hu1997}; Lau--Ngai gave the exact \(L^q\)-spectrum for \(q>0\)
\cite{LauNgai1998}; Feng--Olivier and Feng gave the complete real spectrum and

\subsection{Related work}

The uniqueness theorem underlying the legal expansion is due to Zeckendorf
\cite{Zeckendorf1972}; Lekkerkerker's work provides classical background on
the same numeration system \cite{Lekkerkerker1952}.  Berstel developed the
normalization and automata viewpoint for Fibonacci representations
\cite{Berstel2001}.  The representation-counting function itself has been
studied through recurrence formulas, partition identities, extremal bounds,
and automata by Carlitz \cite{Carlitz1968}, Robbins \cite{Robbins1996},
Bicknell-Johnson and Fielder \cite{BicknellJohnsonFielder1999}, Stockmeyer
\cite{Stockmeyer2008}, Chow and Slattery \cite{ChowSlattery2021}, and Shallit
\cite{Shallit2021}.  Weinstein's orbit and level-set analysis
\cite{Weinstein2016} and the exact extremal classification of Koc\'abov\'a,
Mas\'akov\'a, and Pelantov\'a \cite{KocabovaMasakovaPelantova2005} are the
specific inputs to \Cref{sec:extremal-ldp}.  Sanna proved the power-sum
asymptotics used here and the endpoint law
\(\lim_{q\to\infty}\lambda_q^{1/q}=\varphi^{1/2}\)
\cite[Thms.~1.1 and~1.2]{Sanna2025}.  Zhou gives a broader treatment of
representation functions for related numeration systems and, in particular,
resolves the logarithmic-average conjecture of Chow and Slattery
\cite[Cor.~1.5]{Zhou2023}.
Chow and Jones obtained the same cubic that appears in the quadratic
finite-window recurrence in their analysis of the variance of the partition
function \cite{ChowJones2024}.
The probabilistic version of these finite counts is the Erd\H{o}s measure:
Sidorov and Vershik identify its level masses as normalized Fibonacci
representation frequencies \cite{SidorovVershik1998}.  Hu's local-dimension
analysis \cite{Hu1997}, Lau and Ngai's exact positive-\(q\) spectrum
\cite{LauNgai1998}, Feng and Olivier's weak-Gibbs phase-transition theorem
\cite{FengOlivier2003}, and Feng's explicit all-real golden-ratio formula
\cite{Feng2005} are the direct priority line for the pressure in this paper.
The Stern--Brocot pressure and its Knauf-model realization are taken from
Kesseb\"ohmer--Stratmann and Fiala--Kleban--\"Ozl\"uk
\cite{KessebohmerStratmann2007,FialaKlebanOzluk2003}.  The earlier
Stern--Brocot multifractal theorem of Kesseb\"ohmer and Stratmann
\cite{KessebohmerStratmann2004} concerns interval growth rates, rather than
Fibonacci partition multiplicities or the finite-window uniform law.  The
critical continued-fraction moment uses the fixed-denominator mean theorem of Panov and
Liehl, as recorded in the quantitative modern treatment of
Aistleitner--Borda--Hauke
\cite{Panov1982,Liehl1983,AistleitnerBordaHauke2023}.

# Verification Before Completion

## Overview

Claiming work is complete without verification is dishonesty, not efficiency.

**Core principle:** Evidence before claims, always.

**Violating the letter of this rule is violating the spirit of this rule.**

## The Iron Law

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

If you haven't run the verification command in this message, you cannot claim it passes.

## The Gate Function

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```
