# Writing Plans

## Overview

Write comprehensive implementation plans assuming the engineer has zero context for our codebase and questionable taste. Document everything they need to know: which files to touch for each task, code, testing, docs they might need to check, how to test it. Give them the whole plan as bite-sized tasks. DRY. YAGNI. TDD. Frequent commits.

Assume they are a skilled developer, but know almost nothing about our toolset or problem domain. Assume they don't know good test design very well.

**Announce at start:** "I'm using the writing-plans skill to create the implementation plan."

**Context:** This should be run in a dedicated worktree (created by brainstorming skill).

**Save plans to:** `docs/superpowers/plans/YYYY-MM-DD-<feature-name>.md`
- (User preferences for plan location override this default)

## Scope Check

If the spec covers multiple independent subsystems, it should have been broken into sub-project specs during brainstorming. If it wasn't, suggest breaking this into separate plans â€” one per subsystem. Each plan should produce working, testable software on its own.

## File Structure

Before defining tasks, map out which files will be created or modified and what each one is responsible for. This is where decomposition decisions get locked in.

- Design units with clear boundaries and well-defined interfaces. Each file should have one clear responsibility.
- You reason best about code you can hold in context at once, and your edits are more reliable when files are focused. Prefer smaller, focused files over large ones that do too much.
- Files that change together should live together. Split by responsibility, not by technical layer.
- In existing codebases, follow established patterns. If the codebase uses large files, don't unilaterally restructure - but if a file you're modifying has grown unwieldy, including a split in the plan is reasonable.

This structure informs the task decomposition. Each task should produce self-contained changes that make sense independently.

## Bite-Sized Task Granularity

**Each step is one action (2-5 minutes):**
- "Write the failing test" - step
- "Run it to make sure it fails" - step
- "Implement the minimal code to make the test pass" - step
- "Run the tests and make sure they pass" - step
- "Commit" - step

## No Placeholders

Every step must contain the actual content an engineer needs. These are **plan failures** â€” never write them:
- "TBD", "TODO", "implement later", "fill in details"
- "Add appropriate error handling" / "add validation" / "handle edge cases"
- "Write tests for the above" (without actual test code)
- "Similar to Task N" (repeat the code â€” the engineer may be reading tasks out of order)
- Steps that describe what to do without showing how (code blocks required for code steps)
- References to types, functions, or methods not defined in any task

## Remember
- Exact file paths always
- Complete code in every step â€” if a step changes code, show the code
- Exact commands with expected output
- DRY, YAGNI, TDD, frequent commits

## Self-Review

After writing the complete plan, look at the spec with fresh eyes and check the plan against it. This is a checklist you run yourself â€” not a subagent dispatch.

**1. Spec coverage:** Skim each section/requirement in the spec. Can you point to a task that implements it? List any gaps.

**2. Placeholder scan:** Search your plan for red flags â€” any of the patterns from the "No Placeholders" section above. Fix them.

**3. Type consistency:** Do the types, method signatures, and property names you used in later tasks match what you defined in earlier tasks? A function called `clearLayers()` in Task 3 but `clearFullLayers()` in Task 7 is a bug.

  77: \begin{abstract}
  78: Let \(R(n)\) be the number of partitions of \(n\) into distinct Fibonacci
  79: numbers, with the two unit terms identified.  Sidorov--Vershik's finite
  80: representation frequencies are the same subset-sum coefficients after the
  81: shift from their convention \(F^{\rm SV}_j=F_{j+1}\).  Their normalized
  82: frequencies approximate the Erd\H{o}s measure.  Consequently the layer moment
  83: pressure is the affine normalization
  84: \(P(t)=t\log2-\tau_\mu(t)\log\varphi\) of the \(L^q\)-spectrum of the
  85: golden-ratio Bernoulli convolution.  Lau--Ngai determined the positive-\(q\)
  86: spectrum, while Feng--Olivier and Feng determined the all-real spectrum and
  87: its negative first-order phase transition.  We record the exact dictionary
  88: and recover those results in Fibonacci-partition coordinates.  The arithmetic
  89: refinements identify the critical parameter by
  90: \(\zeta(\sigma_0-1)/\zeta(\sigma_0)=2\).  At criticality
  91: the one-layer partition sum is asymptotic to \(2m/\mu_C\), and its Gibbs law
  92: converges to a uniform mixture of generating-layer fractions.  Under the
  93:  uniform law on \(\mathcal I_m\), \(m^{-1}\log R(n)\) satisfies a full large
  94:  deviation principle; the rate is affine on the coexistence interval.  Jointly
  95:  with normalized generating cost, it satisfies a two-dimensional large
  96:  deviation principle whose rate surface has an explicit affine coexistence
  97: face.  The inputs specific to these refinements are a weighted renewal identity
  98: for Weinstein's free generators and a parity-free orbit-filling argument for
  99: the nonexposed slopes.
 100: 
 101: A finite-window Zeckendorf fold provides an exact finite model for the same
 102: spectrum: its fiber list is the list of \(R\) on two consecutive layers.
 103: An affine permutation also identifies each fiber with a finite Fibonacci
 104: subset-sum coefficient and a partition-function difference.  This yields the
 105:  exact largest fibers
 106:  \(D_{2k}=F_{k+2}\) for \(k\ge0\), \(D_{2k+1}=2F_{k+1}\) for \(k\ge1\), and
 107:  \(D_m=D_{m-2}+D_{m-4}\) for \(m\ge6\), including every maximizing residue.  The two-layer
 108: model has the same pressure and large-deviation rate, an exact frozen
 109: Dirichlet limit, and a critical finite-size constant \(4/\mu_C\).  On every
 110: fixed finite prime support we retain an exact rational coefficient generating
 111: function; no directional coefficient asymptotic is asserted.
 112: \end{abstract}

  40: partial quotients in its canonical regular continued fraction, so that

  43:  \begin{gathered}
  44:   T(q):=\sum_{\substack{1\le p<q\\(p,q)=1}}S(p/q),
  45:   \qquad
  46:   \mathcal C(q):=2T(q)-\phi_{\rm E}(q),\\
  47:   A(q):=\sum_{n=1}^{q-1}\tau(n)\tau(q-n).
  48:  \end{gathered}

  51: \(S(p/q)-1\) strict ancestor intervals of \(p/q\) in the Stern--Brocot tree
  52: has ordered adjacent endpoints, say \(a/b<c/d\), and there are unique
  53: positive integers \(u,v\) such that
  54: \[
  55:  \frac pq=\frac{ua+vc}{ub+vd}.

  57: Ordered coprime denominators \(b,d\) determine their Farey adjacent interval
  58: uniquely.  Hence the map from a fraction together with one of its strict
  59: ancestors to \((b,u,d,v)\) is injective, and
  60: \begin{equation}
  61:  T(q)-\phi_{\rm E}(q)\le A(q).
  62:  \label{eq:ancestor-divisor-injection}
  63: \end{equation}
  64: Indeed, the quadruples on the right are counted by factoring
  65: \(n=bu\) and \(q-n=dv\).

  67: Use
  68: \(\tau(n)\le2\sum_{e\mid n,\,e\le\sqrt n}1\), and let

  70:  N_q(e,f):=\card{\{1\le n<q:e\mid n,\ f\mid q-n\}}.
  71: \]

  73: gives
  74: \[
  75:  N_q(e,f)\le\frac{q(e,f)}{ef}+1.
  76: \]

  79: \[
  80:  \sum_{\substack{e,f\le\sqrt q\\(e,f)\mid q}}
  81:  \frac{(e,f)}{ef}

 158: has length \(d-1\), and the generator cost is \(c(p/q)=2d+1\).  In particular,
 159: for \(\beta\in\mathbb R\), the even Knauf sum in the convention of
 160: \cite[Sec.~IV]{FialaKlebanOzluk2003} is exactly
 161: \[
 162:  Z^{K,e}_d(2\beta)
 163:  =\sum_{d(p/q)=d}q^{-2\beta}.
 164: \]
 165: There is no \(d=0\) fraction in \((0,1)\); the first four nonempty layers are
 166: \[
 167: \begin{array}{c|c|c|c}
 168: d&\text{words}&q=\|M_w\|_\Sigma\text{ in word order}&c=2d+1\\ \hline
 169: 1&\varnothing&2&3\\
 170: 2&L,R&3,\,3&5\\
 171: 3&LL,LR,RL,RR&4,\,5,\,5,\,4&7\\
 172: 4&\{L,R\}^3&5,\,7,\,8,\,7,\,7,\,8,\,7,\,5&9
 173: \end{array}
 174: \]
 175: \end{lemma}
 176: 
 177: \begin{proof}
 178: Choosing the separator positions of a composition is the standard bijection
 179: between compositions of \(d\) and binary words of length \(d-1\).  Starting
 180: from \(M_\varnothing=I\), simultaneous induction on the word length, using
 181: right multiplication by \(L\) or \(R\), gives the displayed subtractive
 182: Euclidean recursion for the numerator and the negative-continuant recursion
 183: for the denominator.  Explicitly, appending \(L\) replaces the last
 184: composition part \(e_r\) by \(e_r+1\), whereas appending \(R\) replaces it by
 185: \((e_r,1)\); substituting these two operations in
 186: \(\mathcal D(a_1,\ldots,a_r)
 187: =a_r\mathcal D(a_1,\ldots,a_{r-1})
 188: -\mathcal D(a_1,\ldots,a_{r-2})\) agrees with
 189: \(M_{wL}=M_wL\) and \(M_{wR}=M_wR\), respectively.  This proves
 190: \eqref{eq:negative-cf-word-bijection}.
 191: The depth and cost identities follow from the definitions.  The Knauf
 192: identity is then term-by-term: its inverse temperature is \(2\beta\), so its
 193: denominator weight is \(q^{-2\beta}\).  The table also fixes the empty-word
 194: and first-generation conventions explicitly.
 195: \end{proof}

 197: \begin{lemma}[New-denominator layer estimate]
 198: \label{lem:knauf-layer-estimate}
 199: For every fixed real \(s<2\),
 200: \begin{equation}
 201:  a_d(s):=
 202:  \sum_{\substack{0<p<q,\ (p,q)=1\\d(p/q)=d}}q^{-s}
 203:  \asymp_s \exp\{d\mathfrak P(s/2)\}.
 204:  \label{eq:knauf-layer-pressure}
 205: \end{equation}
 206: For every fixed \(s\ge2\), one has instead
 207: \[
 208:  \lim_{d\to\infty}\frac1d\log a_d(s)=0.
 209: \]
 210: \end{lemma}
 211: 
 212: \begin{proof}
 213: First suppose \(0<s<2\), and put \(\beta=s/2\).  The even Knauf
 214: partition function \(Z^{K,e}_d(2\beta)\) is exactly \(a_d(s)\): its
 215: states are the new Stern--Brocot denominators at depth \(d\).  In the
 216: notation of Fiala, Kleban, and \"Ozl\"uk, the first-coordinate identity
 217: for their Knauf vector, its Perron--Frobenius iteration, and its spectral
 218: asymptotic are given in
 219: \cite[Sec.~IV, especially Eqs.~(23), (26), and (28)]{FialaKlebanOzluk2003}.
 220: They give
 221: \[
 222:  a_d(s)=c_s\lambda(s/2)^d(1+o(1)),\qquad c_s>0.
 223: \]
 224: Their free-energy identification, together with the denominator formula
 225: for Stern--Brocot pressure
 226: \cite[Thm.~1.1 and the denominator formula in Sec.~2]{KessebohmerStratmann2007},
 227: gives \(\log\lambda(s/2)=\mathfrak P(s/2)\).  This proves
 228: \eqref{eq:knauf-layer-pressure} in the range \(0<s<2\).  At \(s=0\),
 229: there are exactly \(2^{d-1}\) new denominators and
 230: \(\mathfrak P(0)=\log2\), so the assertion is immediate.
 231: 
 232: It remains to supply the estimate for \(s<0\), a range not covered by
 233: the positive-temperature Perron--Frobenius statement just cited.  Put
 234: \(t=-s>0\), and let
 235: \[
 236:  L=\begin{pmatrix}1&0\\1&1\end{pmatrix},\qquad
 237:  R=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad
 238:  \lVert M\rVert_\Sigma=\sum_{i,j=1}^2M_{ij}.
 239: \]
 240:  By \Cref{lem:continued-fraction-knauf-normalization}, the new denominators at
 241:  depth \(d\) are in bijection with words \(w\in\{L,R\}^{d-1}\), and
 242: \begin{equation}
 243:  q(w)=\lVert M_w\rVert_\Sigma.
 244:  \label{eq:stern-brocot-matrix-denominator}
 245: \end{equation}
 246: Define
 247: \[
 248:  Z_n(t):=\sum_{w\in\{L,R\}^n}\lVert M_w\rVert_\Sigma^t,
 249:  \qquad n\ge0.
 250: \]
 251: For nonnegative matrices \(A,B\),
 252: \(\lVert AB\rVert_\Sigma\le
 253: \lVert A\rVert_\Sigma\lVert B\rVert_\Sigma\), and hence
 254: \begin{equation}
 255:  Z_{m+n}(t)\le Z_m(t)Z_n(t).
 256:  \label{eq:matrix-partition-submultiplicative}
 257: \end{equation}
 258: For the reverse inequality with one bridging letter, write
 259: \(\alpha=A^T(1,1)^T\) and \(\beta=B(1,1)^T\).  Direct multiplication gives
 260: \[
 261:  \lVert ALB\rVert_\Sigma+\lVert ARB\rVert_\Sigma
 262:  =\lVert A\rVert_\Sigma\lVert B\rVert_\Sigma
 263:    +\alpha_1\beta_1+\alpha_2\beta_2.
 264: \]
 265: Thus at least one \(C\in\{L,R\}\) satisfies
 266: \(\lVert ACB\rVert_\Sigma\ge
 267: \frac12\lVert A\rVert_\Sigma\lVert B\rVert_\Sigma\).  Summing over
 268: all pairs of words yields
 269: \begin{equation}
 270:  Z_{m+n+1}(t)\ge2^{-t}Z_m(t)Z_n(t).
 271:  \label{eq:matrix-partition-bridged}
 272: \end{equation}
 273: 
 274: Let \(\lambda_t=\lim_n Z_n(t)^{1/n}\), whose existence follows from
 275: \eqref{eq:matrix-partition-submultiplicative}.  That inequality gives
 276: \(Z_n(t)\ge\lambda_t^n\).  Iterating
 277: \eqref{eq:matrix-partition-bridged} \(k-1\) times and then letting
 278: \(k\to\infty\) gives
 279: \[
 280:  Z_{k(n+1)-1}(t)\ge2^{-t(k-1)}Z_n(t)^k,
 281:  \qquad
 282:  Z_n(t)\le2^t\lambda_t^{n+1}.
 283: \]
 284: Consequently \(Z_n(t)\asymp_t\lambda_t^n\).  By
 285: \eqref{eq:stern-brocot-matrix-denominator} and the denominator form of
 286: Stern--Brocot pressure cited above,
 287: \(\log\lambda_t=\mathfrak P(-t/2)\).  Since
 288: \(a_d(-t)=Z_{d-1}(t)\), this proves
 289: \eqref{eq:knauf-layer-pressure} for \(s<0\).
 290: 
 291: Finally, the logarithmic assertion for \(s\ge2\) is precisely the
 292: denominator formulation of the zero-pressure part of
 293: \cite[Thm.~1.1]{KessebohmerStratmann2007}.
 294: \end{proof}

 297: normalization is used below.  Its existence, implicit branch, frozen phase,
 298: and nondifferentiable critical point recover the golden-ratio
 299: Bernoulli-convolution results of Feng--Olivier and Feng

 301: 
 302: \begin{proposition}[Recovery of the Bernoulli-convolution pressure]
 303: \label{thm:exact-negative-pressure}
 304: \label{thm:all-real-pressure}
 305: For every \(s\in\mathbb R\), the radius of convergence of \(B_s\) is
 306: \begin{equation}
 307:  R_B(s)=\exp\{-\mathfrak P(s/2)/2\}.
 308:  \label{eq:Bs-radius}
 309: \end{equation}
 310: Thus \(R_B(s)<1\) for \(s<2\), and \(R_B(s)=1\) for \(s\ge2\).
 311: The nonnegative real roots of \(B_s(r)=1\) are classified as follows:
 312: \[
 313: \begin{array}{c|c}
 314: s<\sigma_0 & \text{a unique root }r_s\in(0,R_B(s)),\\
 315: s=\sigma_0 & \text{the unique root }r_s=1=R_B(s),\\
 316: s>\sigma_0 & \text{no root in }[0,R_B(s)].
 317: \end{array}
 318: \]
 319: The pressure exists for every real tilt and satisfies
 320: \begin{equation}
 321:  P(-s):=\lim_{m\to\infty}\frac1m\log S_{-s}(m)
 322:  =\begin{cases}
 323:    -\log r_s,&s<\sigma_0,\\
 324:    0,&s\ge\sigma_0.
 325:   \end{cases}
 326:  \label{eq:all-real-pressure}
 327: \end{equation}
 328: Equivalently, for \(t>-\sigma_0\), \(P(t)>0\) is the unique solution of
 329: \begin{equation}
 330:  \sum_{q=2}^{\infty}
 331:  \sum_{\substack{1\le p<q\\(p,q)=1}}
 332:  q^t e^{-P(t)c(p/q)}=1,
 333:  \label{eq:exact-negative-pressure}
 334: \end{equation}
 335: whereas \(P(t)=0\) for \(t\le-\sigma_0\).  In particular,
 336: \begin{equation}
 337:  \{t\in\mathbb R:P(t)>0\}=(-\sigma_0,\infty).
 338:  \label{eq:exact-zero-pressure-set}
 339: \end{equation}
 340: 
 341: The restriction of \(P\) to \((-\sigma_0,\infty)\) is real analytic and
 342: strictly convex.  At \(t_c=-\sigma_0\), it has the finite one-sided
 343: derivatives
 344: \begin{equation}
 345:  P'_-(t_c)=0,
 346:  \qquad
 347:  P'_+(t_c)=
 348:  \frac{\displaystyle
 349:   \sum_{q\ge2}\sum_{\substack{1\le p<q\\(p,q)=1}}
 350:        q^{-\sigma_0}\log q}
 351:  {\displaystyle
 352:   \sum_{q\ge2}\sum_{\substack{1\le p<q\\(p,q)=1}}
 353:        c(p/q)q^{-\sigma_0}}>0.
 354:  \label{eq:critical-pressure-slopes}
 355: \end{equation}
 356: Consequently, \(P\) is not differentiable at the freezing point.
 357: \end{proposition}
 358: 
 359: \begin{proof}
 360: Write \(a_d(s):=b_{2d+1}(s)\).  The negative-continued-fraction
 361: parameterization gives
 362: \[
 363:  a_d(s)=\sum_{\substack{0<p<q,\ (p,q)=1\\d(p/q)=d}}q^{-s}.
 364: \]
 365: There are \(2^{d-1}\) fractions in this layer, and their denominators satisfy
 366: \(d+1\le q\le F_{d+2}\).  In particular, every \(B_s\) has positive finite
 367: radius.  The layer is precisely the new-denominator layer of the Knauf model.
 368:  The precise estimate in \Cref{lem:knauf-layer-estimate} gives, for fixed
 369: \(s<2\), \eqref{eq:knauf-layer-pressure}, and gives
 370: \(d^{-1}\log a_d(s)\to0\) for \(s\ge2\).  Cauchy--Hadamard now proves
 371: \eqref{eq:Bs-radius}: explicitly,
 372: \(B_s(z)=\sum_{d\ge1}a_d(s)z^{2d+1}\), so the cost \(2d+1\) contributes the
 373: factor \(1/2\) in the radius exponent.  Moreover,
 374: \eqref{eq:knauf-layer-pressure} shows that
 375: the terms of \(B_s\) do not tend to zero on \(|z|=R_B(s)\) when \(s<2\).
 376: At \(s=2\), the positive real boundary also diverges.  For \(s>2\), Tonelli's
 377: theorem gives
 378: \begin{equation}
 379:  B_s(1)=\sum_{q\ge2}\frac{\phi_{\rm E}(q)}{q^s}
 380:  =\frac{\zeta(s-1)}{\zeta(s)}-1<\infty.
 381:  \label{eq:weighted-renewal-at-one}
 382: \end{equation}
 383: 
 384: The coefficients are nonnegative and the support contains both \(3\) and
 385: \(5\), so \(B_s\) is strictly increasing on its positive interval of
 386: convergence.  If \(s\le2\), its positive boundary value is infinite; if
 387: \(2<s<\sigma_0\), \eqref{eq:weighted-renewal-at-one} is greater than one.
 388: These facts give the unique interior root for \(s<\sigma_0\).  At
 389: \(s=\sigma_0\), the boundary value is one, while it is less than one for
 390: \(s>\sigma_0\).  This proves the asserted real-root classification.  The
 391: triangle inequality also shows that, for \(s<\sigma_0\), the only zero of
 392: \(1-B_s(z)\) in \(|z|\le r_s\) is the simple zero \(r_s\): equality forces
 393: the degree-three and degree-five terms to have the same positive phase, and
 394: \(\gcd(3,5)=1\).
 395: 
 396: Concatenation of generating words gives
 397: \(u_{m+n}(s)\ge u_m(s)u_n(s)\).  The letters of costs \(3\) and \(5\) imply
 398: \(u_j(s)>0\) for every \(j\ge8\).  The shifted Fekete argument used in the
 399: proof of the strip result therefore applies without any restriction on
 400: \(s\), and yields
 401: \[
 402:  \gamma_s:=\lim_{j\to\infty}\frac1j\log u_j(s).
 403: \]
 404: If \(s<\sigma_0\), the formal identity
 405: \(U_s=(1-B_s)^{-1}\), positivity, and the preceding root classification show
 406: that the radius of \(U_s\) is \(r_s\).  At \(s=\sigma_0\), it is one.  If
 407: \(s>\sigma_0\), then \(U_s(1)=(1-B_s(1))^{-1}<\infty\), while
 408: \(u_j(s)\ge b_j(s)\) prevents the radius of \(U_s\) from exceeding
 409: \(R_B(s)=1\).  Hence
 410: \[
 411:  R_U(s)=\begin{cases}r_s,&s<\sigma_0,\\1,&s\ge\sigma_0,
 412:  \end{cases}
 413:  \qquad \gamma_s=-\log R_U(s)\ge0.
 414: \]
 415: For \(H_m(s)=\sum_{j=0}^m u_j(s)\), the exact renewal identity gives
 416: \[
 417:  H_m(s)\le S_{-s}(m)\le4H_{m+1}(s).
 418: \]
 419: Since \(m^{-1}\log H_m(s)\to\gamma_s\), this proves
 420: \eqref{eq:all-real-pressure} and the root equation.
 421: 
 422: For \(t>-\sigma_0\), put
 423: \[
 424:  \mu_t(p/q):=q^t e^{-P(t)c(p/q)}.
 425: \]
 426: The root equation makes this a probability measure.  The root lies strictly
 427: inside the relevant convergence circle, and
 428: \(\log q\ll d(p/q)\), so the defining series and all its parameter
 429: derivatives converge locally uniformly.  The analytic implicit-function
 430: theorem applies.  With \(X=\log q\) and \(C=c(p/q)\), differentiation gives
 431: \begin{equation}
 432:  P'(t)=\frac{\mathbb E_{\mu_t}X}{\mathbb E_{\mu_t}C},
 433:  \qquad
 434:  P''(t)=
 435:  \frac{\mathbb E_{\mu_t}[(X-P'(t)C)^2]}
 436:       {\mathbb E_{\mu_t}C}.
 437:  \label{eq:pressure-derivatives}
 438: \end{equation}
 439: The fractions \(1/2\) and \(1/3\) have \((C,q)=(3,2)\) and \((5,3)\),
 440: and \(\log2/3\ne\log3/5\).  Thus the variance in
 441: \eqref{eq:pressure-derivatives} is strictly positive.
 442: 
 443: It remains to justify passage to the critical endpoint.  For the canonical
 444: regular continued fraction \(p/q=[0;a_1,\ldots,a_r]\), with \(a_r>1\),
 445: the conversion between regular and negative continued fractions gives
 446: \[
 447:  d(p/q)=a_1+\cdots+a_r-1,
 448:  \qquad c(p/q)=2(a_1+\cdots+a_r)-1.
 449: \]
 450: The fixed-denominator mean theorem of Panov and Liehl
 451: \cite{Panov1982,Liehl1983,AistleitnerBordaHauke2023} states that
 452: \[
 453:  \frac1{\phi_{\rm E}(q)}
 454:  \sum_{\substack{1\le p<q\\(p,q)=1}}(a_1+\cdots+a_r)
 455:  \sim\frac6{\pi^2}(\log q)^2.
 456: \]
 457: Consequently, both the numerator and denominator in
 458: \eqref{eq:critical-pressure-slopes} converge absolutely, since they are
 459: bounded by constant multiples of
 460: \(\sum q^{1-\sigma_0}\log q\) and
 461: \(\sum q^{1-\sigma_0}(\log q)^2\), respectively.  Dominated convergence in
 462: the first identity of \eqref{eq:pressure-derivatives} gives the stated finite
 463: positive right derivative.  The pressure is identically zero to the left of
 464: \(t_c\), so its left derivative is zero.
 465: \end{proof}
 466: \fi
