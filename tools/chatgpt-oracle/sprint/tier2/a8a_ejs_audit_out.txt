496 6. Discussion and relation to prior work

497 Two-sided deficiency convergence strengthens the classical calendar-time information
498 calculation for stationary renewal sampling [6, 17]. It shows that the Palm and
499 stationary-window experiments have asymptotically the same bounded-loss decision
500 problems, not merely matching Fisher information. The effective sample-size conver-
501 sion then yields Palm information divided by mean cycle length and multiplies an
502 i.i.d. canonical-gradient covariance by that mean.
503 At the collision boundary, the ambient DQM chart determines the information
504 matrix while the half-space Rn-1 × [0, ) determines the decision problem. This
505 distinction explains both the one-sided Gaussian power envelope and the need to
506 interpret efficiency and minimax bounds inside the fixed constrained experiment [4,
507 15].
508 Locally conic and loss-of-identifiability theory predicts a quotient coordinate and
509 a boundary limit [5, 14], but positive collision information remains model-specific.
510 Here the exact fourth-order collision pole cannot be synthesized from the order-three
511 centre pole or the separated order-two poles. Sampling preserves the corresponding
512 exponential-polynomial separation, so the efficient-information Schur complement
513 stays positive on the compact stratum.

23 1. Introduction

24 A stationary renewal record observed through a deterministic calendar window does
25 not consist of a deterministic number of complete cycles. The first and last cycles
26 are censored, the number of intervening cycles is random, and a window may contain
27 no renewal. These features are harmless for many first-order calculations, but they
28 matter when an i.i.d. Palm argument is used as a substitute for the actual experiment.
29 Conditioning a prescribed number of cycles to fit in the window is not legitimate: it
30 changes their joint law.
31 Our first result removes that boundary-cycle problem at the level of statistical
32 experiments. Given a stationary renewal window of length N , one kernel extracts
33 the first mN = N/µ0-N  complete interarrivals, where 1/2 <  < 1. In the reverse
34 direction, a kernel uses the supplied Palm sample and appends base-law cycles after
35 it is exhausted. The two couplings fail only if the record contains too few complete
36 cycles, or if generation in the reverse direction needs more than the supplied cycles
37 plus a short base-law continuation. Hellinger locality controls that continuation.
38 Both deficiency directions therefore vanish uniformly, without conditioning Palm
39 gaps on fitting inside the window.

# Verification Before Completion

## Overview

Claiming work is complete without verification is dishonesty, not efficiency.

**Core principle:** Evidence before claims, always.

**Violating the letter of this rule is violating the spirit of this rule.**

## The Iron Law

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

If you haven't run the verification command in this message, you cannot claim it passes.

## The Gate Function

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

| Claim | Requires | Not Sufficient |
|-------|----------|----------------|
| Tests pass | Test command output: 0 failures | Previous run, "should pass" |
| Linter clean | Linter output: 0 errors | Partial check, extrapolation |
| Build succeeds | Build command: exit 0 | Linter passing, logs look good |
| Bug fixed | Test original symptom: passes | Code changed, assumed fixed |
| Regression test works | Red-green cycle verified | Test passes once |
| Agent completed | VCS diff shows changes | Agent reports "success" |
| Requirements met | Line-by-line checklist | Tests passing |
