23 1. Introduction

24 A stationary renewal record observed through a deterministic calendar window does
25 not consist of a deterministic number of complete cycles. The ﬁrst and last cycles
26 are censored, the number of intervening cycles is random, and a window may contain
27 no renewal. These features are harmless for many ﬁrst-order calculations, but they
28 matter when an i.i.d. Palm argument is used as a substitute for the actual experiment.
29 Conditioning a prescribed number of cycles to ﬁt in the window is not legitimate: it
30 changes their joint law.
31 Our ﬁrst result removes that boundary-cycle problem at the level of statistical
32 experiments. Given a stationary renewal window of length N , one kernel extracts
33 the ﬁrst mN = ⌊N/µ0−N γ⌋ complete interarrivals, where 1/2 < γ < 1. In the reverse
34 direction, a kernel uses the supplied Palm sample and appends base-law cycles after
35 it is exhausted. The two couplings fail only if the record contains too few complete
36 cycles, or if generation in the reverse direction needs more than the supplied cycles
37 plus a short base-law continuation. Hellinger locality controls that continuation.
38 Both deﬁciency directions therefore vanish uniformly, without conditioning Palm
39 gaps on ﬁtting inside the window.

```
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

## Common Failures

| Claim | Requires | Not Sufficient |
|-------|----------|----------------|
| Tests pass | Test command output: 0 failures | Previous run, "should pass" |
| Linter clean | Linter output: 0 errors | Partial check, extrapolation |
| Build succeeds | Build command: exit 0 | Linter passing, logs look good |
| Bug fixed | Test original symptom: passes | Code changed, assumed fixed |
| Regression test works | Red-green cycle verified | Test passes once |
| Agent completed | VCS diff shows changes | Agent reports "success" |
| Requirements met | Line-by-line checklist | Tests passing |

## Red Flags - STOP

- Using "should", "probably", "seems to"
- Expressing satisfaction before verification ("Great!", "Perfect!", "Done!", etc.)
- About to commit/push/PR without verification
- Trusting agent success reports
- Relying on partial verification
- Thinking "just this once"
- Tired and wanting work over
- **ANY wording implying success without having run verification**

## Rationalization Prevention

| Excuse | Reality |
|--------|---------|
| "Should work now" | RUN the verification |
| "I'm confident" | Confidence â‰  evidence |
| "Just this once" | No exceptions |
| "Linter passed" | Linter â‰  compiler |
| "Agent said success" | Verify independently |
| "I'm tired" | Exhaustion â‰  excuse |
| "Partial check is enough" | Partial proves nothing |
| "Different words so rule doesn't apply" | Spirit over letter |

> **Theorem 5 (Stationary isolated-double-pole limit experiment).** Fix \(n,\varepsilon,M,c_0\), known \(\Delta\tau>0\), and the serial positive killed-reset realization (1.2)–(1.3), and suppose \(\mathcal C_n(\varepsilon,M,c_0)\ne\varnothing\). Let \(P_{\eta,\delta}^{(N)}\) be the stationary length-\(N\) binary renewal record in this fixed serial order, at one isolated real double pole with all other rates simple and separated as in (3.1).
>
> **(A) Uniform LAN and the limit experiment.** For bounded \(u\in\mathbb R^{n-1}\) and \(v\in[0,\infty)\), uniformly over the collision stratum,
>
> \[
> \log\frac{dP_{\eta_0+u/\sqrt N,v/\sqrt N}^{(N)}}{dP_{\eta_0,0}^{(N)}}
> =
> \binom{u}{v}^{\!\top}\Delta_{N,\eta_0}
> -\frac12\binom{u}{v}^{\!\top}I_n(\eta_0)\binom{u}{v}
> +o_{P_{\eta_0,0}}(1),
> \tag{3.15}
> \]
>
> where \(\Delta_{N,\eta_0}\Rightarrow\mathcal N_n\{0,I_n(\eta_0)\}\) uniformly in bounded-Lipschitz distance. The local experiments converge to the Gaussian shift on \(\mathbb R^{n-1}\times[0,\infty)\), and the information is uniformly nondegenerate by (3.5).
>
> **(B) Efficient collision test.** Partition \(I_n\) according to \((\eta,\delta)\) and set
>
> \[
> J_n(\eta)=I_{\delta\delta}-I_{\delta\eta}I_{\eta\eta}^{-1}I_{\eta\delta}>0.
> \tag{3.16}
> \]
>
> The residualized-score test \(\phi_N\) in (3.14) has uniform asymptotic level \(\alpha\). At \((\eta_N,\delta_N)=(\eta_0+u/\sqrt N,v/\sqrt N)\), its limiting power is
>
> \[
> 1-\Phi_{\mathsf N}\{z_{1-\alpha}-v\sqrt{J_n(\eta_0)}\}.
> \tag{3.17}
> \]
>
> This is the Gaussian half-space power envelope among tests with uniform local asymptotic level \(\alpha\).
>
> **(C) Attainable and lower recovery rates.** The measurable procedure in Estimator 4 gives root-\(N\) estimates of \(\eta\) and \(\delta\) and an induced rate multiset \(\widehat{\mathcal R}_{n,N}\) satisfying
>
> \[
> d_m\!\left(\widehat{\mathcal R}_{n,N},
> \{\{\widehat c_N+\sqrt{\widehat\delta_N},
> \widehat c_N-\sqrt{\widehat\delta_N},
> \widehat\theta_{3,N},\ldots,\widehat\theta_{n,N}\}\}\right)
> =O_P(N^{-1/4})
> \tag{3.18}
> \]
>
> uniformly over the compact stratum and bounded \((u,v)\). The centre and canonically ordered separated rates remain root-\(N\). At every fixed base, Lemma 7 gives a strictly positive lower limit for threshold risk on two alternatives separated by \(\sqrt{v_0}N^{-1/4}\). Hence \(N^{-1/4}\) is uniformly attainable on the stated bounded local families and pointwise locally minimax-optimal in rate.
